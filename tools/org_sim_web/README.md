# 组织模拟台（org_sim_web）

组织域的**可玩设计草稿**——组织系统的机制与数值以本台为活体草案迭代，定稿后回铸 Godot 正片（`modules/organization`）。它不是发布物、不是正式 UI，只服务设计对齐：设计断言本身归设计文档（01/03/04/17 号），本页只记工具自己的事。

## 运行

| 方式 | 命令 / 入口 | 用途 |
|------|------------|------|
| 开发迭代 | `npm run dev`（Vite HMR，改即见效） | 日常迭代设计 |
| 出包 | `npm run build`（产出单文件 `dist/index.html`）→ 覆盖本目录 `sim.html` | 落稳定入口 |
| 直接玩 | 双击 `sim.html`（单文件离线可开） | 创始人验收/把玩 |

依赖：Node.js ≥ 18。`node_modules/`、`dist/` 不入仓，`sim.html` 入仓（构建产物即交付物）。

dev 模式暴露 `window.__sim`（S/advance/reset/玩家操作），供浏览器自动化与控制台直驱模拟；生产构建不含。

## 布局

- **标题栏**（第一行）：品牌 + 基础资源（粮/药材/木材/铁矿）+ 仓库总览 + 时钟/倍速/参数/重开
- **横排**（第二行，页签**平分整排**，独立成排备将来扩展）：组织 / 仓库
- **组织页**：地形条（场地缓冲堆）+ 在编/待业 + 动员（耕战一体）+ 建组织（**平时折叠**，展开按系统分类）；主体＝组织分列卡片（槽位板）+ **建造侧栏**（右侧，建筑行点开分座操作，无数量标记）。**点槽行就地展开操作**，再点收起
- **仓库页**：分类标签（全部/基础资源/材料/制品/场地堆存/厂内半成品）+ 瓦片网格；容量条在标签行右侧。图标只用在物品瓦片与成本芯片

## 机制清单与占位数值（设计数值以此为准，定稿回铸）

- **市政厅六槽**：领导/军事/行政/生产/运输/科研；**生产槽的默认形态是一级子节点「生产部」**（内含采集/建造/制造三槽）。开局即最低限度运转：生产部采集/制造各一人（采集=泛采集兜底 0.4/人时），建造槽放**建造组织**（测量/施工×4/质检/材料管理，开局仅 2 名施工）——组织树即构筑树（01 §2.6）
- 专门组织入驻路径：采集/建造/制造类组织 → 生产部对应槽（自动入驻时顶岗者让位回待业）；运输/军事/科研 → 市政厅对应槽
- **建筑按座计**：同型可多座、每座独立软装；**组织进驻一座对应建筑实例**（组建自动进驻空置同类、无则空挂受限、落成自动接纳、解散退驻；03 §一）——解锁/工序按所驻那座算
- 岗位机制钩子：**测量**（建造组织）在岗施工效率×1.15；**调度**（运输队）在岗未通报场地搬运折扣 ×0.5→×0.7；额外椅子（伐木小屋软装）通报阈值 0.3→0.15
- 科研院（后期空壳）槽位：课题管理/实验×3/文献记录——新技能长在研究员本人身上（04 §三）
- 地形三类：树林→木材、矿洞→铁矿、农田→粮/药材；场地缓冲堆上限 40
- **粮≠食物资源**（05 §一铁律）：进食可选增益、无饥饿，后续绑人口繁衍
- 速率：采集 0.8/人时（所驻小屋+工具架 ×1.25）、搬运 1.2/人时、工序 0.6/人时；顶栏/瓦片的速率为每时净流量
- 仓库容量 250；运输队搬运同质化坑位 ×5（随建筑规模的设计待扩展）
- 锻造坊工序链：熔炼(熔炉)→锻打(铁砧)→淬火(水槽)→开刃(磨石)；铁水/毛坯/淬火件为厂内物品；锻打可吃铁水或外购铁锭
- 借调：信息槽缺人自动从本队作业岗借调（原槽圈停、目标槽半透明人名+慢速圈）；工厂工时在可开工工序间均摊——一人厂独轮回全工序
- 动员=产率减半（动员官须在市政厅军事槽）；人名/组织名不带编号，同名聚合（村民×3）
- 后期组织（冶炼坊/常备军/训练营/科研院）标注「后期」；前提/资源不满足时按钮禁用并悬停示因

## 结构

```
src/
├── sim.js            # 全部游戏逻辑：地形/建筑/组织目录、响应式状态、推进循环、玩家操作。
│                     # 机制与数值的单一真相源——改设计=改这里的目录与常量

├── App.vue           # 骨架 + 100ms 节拍推进 + 页签切换
└── components/       # 纯渲染：TopBar（标题栏+平分页签横排）、OrgPage（工具栏+建组织折叠面板）、
                      # OrgCols（分列卡片+槽行+内联槽位操作+借调动效）、
                      # BuildSide（建造侧栏：建筑行内展开）、Warehouse（分类标签+瓦片网格）
```
