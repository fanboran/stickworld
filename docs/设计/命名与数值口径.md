# 命名与数值口径

> **性质**：全局基础口径（不是某个系统的设计）——游戏内名词的命名风格 + 资产类数值的刻度。新增内容（据点/建筑/单位/资源/科技/文案）与改动数值前先读本篇。
> **出处**：创始人 2026-09-22 纠正（原话口径见 §一/§二 首段引文）。
> **适用面**：`config/` 全部配置 + 一切玩家可见文案。

---

## 一、命名口径：一律通用描述性称谓

> 创始人原话：「全都是描述性称谓，比如箭塔就叫箭塔，别整的像武侠小说似得，串味了。」

**规则**：

- 名字**直接说出它是什么**——用它的样子、材料、功能来称呼：箭塔就叫「箭塔」、石造仓库就叫「石造仓库」、低矮土墙就叫「低矮土墙」。
- 风格**现代直白**：用今天口语/新闻/政论里在用的词，不搞古风武侠腔，也不用书面雅化词堆气氛。
- 组合名可以长，但要**每个词都在描述**（材料 + 形态 + 用途）；一旦出现"只负责好听"的词，就串味了。

**判据（关键，别判过头）**：这条口径清的是**时代感**，不是"有没有形容词"。**现代通用词照样能用**——「铁腕要塞」「黑石营地」「红色山林」都合规（"铁腕""黑石"是今天在用的说法，且说了这地方的性质/样子）；真正要换的是**古风武侠词**（寨、堡主、山庄、镖局、某某寨主）与**雅化书面词**（苍翠、碧波、赤砂、幽影、穿云、寒霜）。

**反面示例（不要这样起名）**：

| 反面 | 毛病 | 描述性写法 |
|---|---|---|
| 赤岭寨 | "寨"是武侠/古代寨堡词，"赤岭"是雅化的文学地名（说不清是什么样） | 红色山林 |
| 苍翠猎团、碧波联邦、赤砂汗国（假设的反面名） | "苍翠/碧波/赤砂"是雅化书面词，只负责好听 | 修饰词换成描述其样子/环境的词（如 森林猎团、海洋联邦、沙漠汗国） |
| 穿云箭楼（假设） | 文学化修饰（"穿云"不说它是什么） | 箭塔 |

**三段自检（起名后逐条过）**：

1. **说人话**：这个名字能直接回答"这是什么东西"吗？（要塞/营地/仓库 ✓）
2. **查时代感**：修饰词是**今天在用的词**吗？——铁腕、黑石、红色、石墙、低矮、大型 ✓；苍翠、碧波、赤砂、幽影、穿云、寒霜 ✗（书面雅化），寨、堡主、山庄 ✗（古风武侠）。
3. **查定位词**：有没有武侠/玄幻常见的身份或机构词（寨主/镖局/掌门/宗门/仙盟）？有就换。

**适用范围**：据点名、建筑名、解锁项名、单位名、资源名、系统名、界面文案——一切玩家可见名词。技术标识（`ter_bandit_camp_02`、`unlock_stone_warehouse` 等 id）不受此约束，它们只求语义清晰。

## 二、资产数值口径：不膨胀（参照口袋妖怪火红那代的手感）

> 创始人原话：「资产数值别几十几十的，就别有数值膨胀的感觉，全都整10和直接数字最后一位不写。」「你按照常识和游戏策划的理解去做数值，和口袋妖怪火红那一代的数值一样不膨胀就行。」「怎么还是整10的？」（第三次追问的要点见下条）

**规则**：

- **资产类数值**（资源数量、建造成本、占领奖励、价格、招兵等一切"账目上的数"）**不膨胀**——标尺是 GBA 世代口袋妖怪（火红/绿宝石那一代）的手感：**位数少、一眼读得出、单次数值不叠成天文数字**（那边的量级是"一瓶药 300 元、路上捡到 500 元、一次伤害两位数"）。
- **取自然数，不要清一色整十**：数值按手感直接写（民居 28 木、兵营 45/32/14），不为凑整而取整十；**满仓都是 10 的倍数会显得假、也就有了"膨胀感"**——这是创始人 2026-09-22 明确纠正过的一点（"怎么还是整10的？"）。整十可以用，但别扎堆；无意义的零头（63.5、37.4 这类小数）同样不要。
- 具体取值按**策划常识**判断——成本与收益、成长节奏、难度曲线要对得上；这是一条"不膨胀 + 可读 + 有质感"的口径，不是一张死板的取整表。同一系统内的数值保持同档，不要"几十几十"地往上叠。
- **现役执行（2026-09-22 全仓重定标后的刻度）**：
  - **据点奖励**：黑石营地 木12、石9；红色山林 木12、石11、铁9；铁腕要塞 石22、铁13。
  - **建筑成本**：一档 8~28（草棚 木9；民居 木28/石12；农场 木18/石9；土墙 木8/石12），二档 17~45（兵营 木45/石32/铁14；集市 木22/石11/铁7；标准城墙 木14/石38/铁11），三档 26~55（学院 木52/石38/铁16；大型城墙 木34/石77/铁21；议事厅 木43/石67/铁23），顶档 木78/石58/铁42（铁匠铺 Lv4）。**全仓资产数值上限 78，无三位数。**
  - **招兵**：木12 + 石9（= 一次占领奖励的量级，占一营即够招一名民兵）。
  - **开局资源**：木85 / 石75 / 铁32（≈ 民居成本的 3 倍）。
  - **采集与产出**：玩家手采与村民伐木/采矿同为 9/拍；铁匠 5 矿 → 3 锭/拍。资源点储量：树 35~75、石 28~48、铁 18~36、钻 9~18、金 18~36。
  - **科技研究消耗**：一档 9~14、二档 26~38、三档 52~78。
  - **物流**：道路建造 木9~18 / 石9~75、维护 1~9；载具工程量 9~45；承运每公里 1~50。
  - 资源基准价维持原小位数（木3 / 石4 / 矿8 / 液态法力15 / 铁锭20 / 丝绸50）；法系单位的「法力消耗」是 SWL 战斗校准锚点（与 base_hp/base_attack 同批；现 `asphalt_cost` 字段随实施更名），不属本刻度。

**边界（本条不管什么）**：

- 物理/战斗/手感参数不属于"资产数值"：箭速 637.5、走速 120、撤仗阈值 0.7/4.0/75.0 这类按各自手感与仿真需要取值，不受"自然数/小位数"约束（改这些是手感调参，不是资产重定标）。
- 计数类（守军 3/5/8 人、编队人数、建筑宽度格数）是**个数**不是刻度，直接写实数。

**范围**：全仓资产数值（建筑成本、资源产价、招兵、初始资源、采集与产出量等）按本条口径统一重定标；重定标时**成本与收益要一起看**（只压奖励不压成本，奖励会显得没意义）。执行与验收见 [`../项目/交接/资产数值重定标-进度与交接.md`](../项目/交接/资产数值重定标-进度与交接.md)。
