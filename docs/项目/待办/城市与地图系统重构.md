## 补全项（创始人确认）

- [ ] **城镇朝向决定道路方向**：大世界地图上城镇的随机朝向决定从场景图左/右边界走出分别到达哪些道路（依赖战略图完成）
- [ ] **道路遭遇战**：行军途中遭遇敌方触发战斗（低自由度全面战争式行军，依赖战略图 + 行军系统）（2026-09-09 对账：场景图遭遇战链已做——game_root 遭遇战战场注册 + 敌军 spawn；剩战略图行军遇敌）
- [ ] **城镇地面贴图差异化**：不同类型城镇使用不同硬化地面贴图（矿业/农业/军事等）

## 重构项（原始八诉求）

- [ ] **城镇动态扩张**：地图大小随城镇规模增长，`map_left`/`map_right` 可变
- [ ] **城墙改为 Building 类型**：可建造/破坏/穿越，不在地图边界，可能有多层（旧城墙保留+新城墙新建）
- [ ] **城外环境**：城墙外约 100 格的自然环境（森林/草原/绿洲），城外地面贴图与城内不同
- [ ] **战场类型扩展**：遭遇战/攻城战/守城战三种，攻城守城利用城墙阵地（2026-09-09 对账：遭遇战+守城战已上线（game_root 注册循环）；攻城战骨架在 `battle_director.start_siege_battle`（按 siege_side 找墙布阵，反向布阵待扩展）；工程战未动）
- [ ] **战场 spawn 动态**：我方位置根据行军方向决定（从南往北走 → 右侧/南面），不固定左边
- [ ] **战场持续性**：玩家走回撤退点返回城镇后战场战斗不停止，由 AI 自动指挥（2026-09-09 对账：mark_player_absent/present 标记 + 战斗继续 tick 已做（battle_director.gd:146，P0 简化）；缺完整 AI 自动指挥，P1+）
- [ ] **工程战/攻城战**：我方阵地变为城墙（如果有城墙），需攻破城门入城
- [ ] 基于以上诉求重新设计地图系统架构（方案待定）
