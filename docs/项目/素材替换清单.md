## 三、登记规则

- 每引入一个外部参考资产，**当场登记**本清单（来源/用途/替换方向三列必填）
- 提取脚本 `tools/ai/extract_terraria_sfx.py`、`stick-world/tools/ai/extract_swl_sfx.py` 产出的每个 WAV 都属于第一类，逐条登记
- 公开 checklist：grep 本清单第一类 → 逐项替换 → 全量测试 → 版本号打"可发布"标记
