# 核心玩法循环

> Stick World 的三层循环。核心 = 设计层级架构 → 观察自动化运转 → 发现问题 → 优化架构 → 帝国扩大 → 需要更复杂的架构。

---

## 一、时刻级循环（0-30 秒）

根据当前所处层级不同：

| 层级 | 典型动作 | 即时反馈 | 微奖励 |
|------|----------|----------|--------|
| L1 个体 | 移动/攻击/采集 | 打击感、粒子、音效 | 击杀/采集成功 |
| L2 小队 | 下达移动/攻击指令 | 小队阵型变化、火力输出 | 击退敌军/完成施工段 |
| L3 编制 | 布置战术/调度 | 战线推进/建筑进度条 | 占领关键位置/工地完工 |
| L4 区域 | 签署法令/调整税率 | 报表数值变化 | 财政转盈/科技突破 |
| L5 帝国 | 观察报表/调整制度参数 | 帝国效率指数变化 | 发现优化空间 |

**核心原则**：30 秒内必有可感知的反馈。

---

## 二、会话级循环（1-3 小时）

```
审视帝国现状 → 发现问题/机会 → 
    ├─ 调整军事编制/战术
    ├─ 调整科研架构/方向
    ├─ 调整经济参数
    └─ 颁布新法律 → 
观察自动化运转（5-15 分钟）→ 
    ├─ 放大看某个战场/工地/城市
    ├─ 看报表
    └─ 发现新问题/瓶颈 →
干预/优化 → 回到循环起点
```

| 你在哪个规模 | 干预频率 | 观察 vs 干预比例 |
|-------------|----------|-----------------|
| L1-L2（小规模） | 几乎持续 | 10% / 90% |
| L3（中等） | 每 5-10 分钟 | 50% / 50% |
| L4-L5（帝国） | 每 15-30 分钟 | 80% / 20% |

后期更多是在"看海"——后期满足感来自**看自己设计的机器在跑**，而非操作。

---

## 三、长期循环（整局：12-20h）

```
流浪（L1个体） → 部落（L1-L2） → 城市（L2-L3） → 王国（L3-L4） → 帝国（L4-L5）
```

不是五个独立的"阶段"——是你的管理范围自然扩大，能使用的层级逐步解锁。

**长期驱动力**：

| 驱动力 | 前期 | 中期 | 后期 |
|--------|------|------|------|
| 生存压力 | 强 | 弱 | 无 |
| 扩张欲望 | 弱 | 强 | 弱 |
| 优化满足（看机器跑） | 无 | 中 | 强 |
| 收藏驱动 | 弱 | 中 | 强 |
| 叙事沉浸 | 强 | 强 | 强 |

## 四、自动化类比（对标《戴森球计划》）

> **设计产线 → 观察运转 → 发现瓶颈 → 优化 → 扩建 → 更复杂的产线**

只不过这里的"产线"是组织架构，"产出"是军事胜利/科技进步/经济繁荣。

| 《戴森球计划》 | 本游戏 |
|---------------|--------|
| 手搓采矿机 → 自动采矿 | 手操小队 → 指挥官自动指挥 |
| 设计产线 → 自动化生产 | 设计指挥链 → 自动作战 |
| 星际物流 | 全国物流网络 |
| 戴森球 | 统合世界 |
| 每个齿轮是你亲手放的 | 每个组织是你亲手搭建的 |

## 五、防滚雪球

1. **管理复杂度超线性增长**：领土翻倍 ≠ 管理难度翻倍
2. **多线冲突**：长国境 → 多条战线 → 考验指挥链设计
3. **内部矛盾**：不同民族/文化的火柴人
4. **科技扩散**：敌人也会学你

## 六、重玩价值

| 维度 | 差异化 |
|------|--------|
| 文明选择 | 农耕/游牧/商业/海洋 → 不同最优组织架构 |
| 起始位置 | 不同资源分布 |
| 组织架构 UGC | 社区分享指挥链/科学院架构 |
| 自我挑战 | 不开附身通关 / 纯游牧 / 经济胜利 |

## 七、P0 循环断点诊断（2026-09，代码层审计结论）

> P0 出征与领地循环（采集→建造→编队→征伐→结算）已测试锁死、全链路可玩，但**玩起来循环转不起来**。本节是代码层审计后的断点清单与闭合方向，供「游戏循环深化」实施线（见 [`项目/交接/游戏循环深化-进度与交接.md`](../项目/交接/游戏循环深化-进度与交接.md)）作为设计输入。

### 7.1 断点清单（玩家视角）

| # | 断点 | 现状证据 | 后果 |
|---|------|---------|------|
| 1 | **兵源断** | 无任何招募/征兵/人口代码；全村恒 2 个村民（`NPC_COUNT=2`）；编队=零消耗组织已有单位 | 战损永久减员，打一两仗就无兵可带——"招兵循环没迭代起来"的直接原因 |
| 2 | **兵营空壳** | buildings.tres 的 barracks 写着"训练战斗单位"，无任何消费逻辑 | 建兵营零玩法回报 |
| 3 | **经济单腿** | 产出只有玩家手动采集 + 一次性征服奖励；farm 等建筑无产出 tick | 后期资源流入枯竭 |
| 4 | **无 sink** | 资源唯一出口是建造；无军饷/维护费/食物 | 通关后资源无处消费，经济不闭合 |
| 5 | **规模断** | 守军 3/5/8、攻城波封顶 9；引擎性能按 196 人混战优化 | 玩法结构永远凑不出"有规模的战斗" |
| 6 | **职业断** | NPC 只会建造/搬运（FORAGE 工种空挂）；采集是玩家附身专属 | 劳工队无人可派，小镇生活感缺失（见 [`系统/12-小镇生活与美术.md`](系统/12-小镇生活与美术.md)） |
| 7 | **威胁断** | 零敌方反扑/袭击；守城战只能玩家手动开 Demo | 建城墙/塔没有防御需求支撑 |
| 8 | **终局断** | 3 据点占完即空图，战略图是纯展示层 | 通关即内容终点，无长线钩子 |

**总评**：现状是一条**单向流水线**——每个环节的产出都不回流（打仗赢资源→无兵可招→资源无处花），所以体感"循环没有制造起来"。

### 7.2 闭合方向（AI 提案，待创始人定向后逐条细化）

1. **兵源闭环**（最优先，直接回应断点 1/2）：村民 →（兵营 + 资源/装备消耗 + 训练时间）→ 士兵；战损由人口再生产补员。人口增长挂住宅/食物（见方向 3/4）。
2. **战斗规模抬升**（断点 5）：据点守军编成放大到 10~20 + 敌将；玩家军团目标 30~50（编队扩容 + 随行上限）；攻城战 50v50 级压测（196 基准内）。
3. **经济自动产出端**：NPC 职业劳作产出（伐木/挖矿/打铁——与小镇生活线 C 共用实现）。
4. **持续性 sink**：军饷（编队按人头发饷）+ 占领地驻军维护费；资源 → 兵力 → 战斗力 → 新资源 的回路由此闭合。
5. **威胁反扑**（断点 7）：被占据点的原势力定期反攻（raid 计时器 → 守城战接线；架构 §九 retaliation 字段位已预留），防御建筑获得存在意义。
6. **终局长线**（断点 8）：L1 家园区之后的多区域扩张目标/新据点动态生成（依赖城镇生成管线 B 线）。

优先级建议：1 → 4 → 2 → 3（C 线并行）→ 5 → 6。其中 1/4/2 是"循环转起来"的最小闭合集。
