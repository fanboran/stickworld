## 阶段 0：原型验证（0.1-0.8 完成 · 新 0.9 实施中 · 验收待人工）

**目标**：验证"管理学概念→好玩的游戏"核心假设。

**实际达成**：
- 0.1~0.8 实施完成（GameRoot 骨架 → 村落地图 → 行为 AI → 定居点建设 → 小队战斗 → 编队指挥 → 玩家附身 → 多场景衔接）
- 带队出征 + 队伍类型编制系统实现（原型循环"编队/战斗"环节阻塞解除）
- P0 收口执行计划（数据清理/EnterTrigger/资源接入/数据驱动）+ 测试链稳定化（S1-4）+ 战斗链路收口（S2-1）完成
- 分层测试套件全绿（`-- --fresh-start` 约定），依赖解耦图谱已更新（见 [`P0重审与稳定化方案.md`](P0重审与稳定化方案.md)）

**P0 范围**：0.1~0.8 + 新 0.9 基础战略图（L1 单层）——8 城邦 + 随机地块边界 + 道路 + 卫星图底图 + 边界线着色（P 社索引图机制），点击聚落进出场景图。聚落模型见 [08-程序化世界生成.md §0.19](../设计/系统/08-程序化世界生成.md)，技术方案见 [战略图架构.md §10 SM-1'](../技术/架构/战略图架构.md)。室内系统归阶段 1/2（见下方第 8 项）。
- 实施条目见 [`待办事项.md`](待办事项.md) 高优先级"P0 新 0.9"

**内容（原始计划）**：
- 阶段 2（部落首领）的核心循环
- 简易定居点建设
- 小队级战斗（10-30 人）
- 基础资源管理

**验收标准**：创始人觉得"这个循环好玩"。**未达成**——待创始人亲手跑原型循环（建造→编队→任命→下令→战斗→附身→跨图→战略图）后确认，确认后启动阶段 1。

## 阶段 1：核心系统（Alpha）

**目标**：八层核心结构全部可玩。

**内容（按依赖解耦后的推荐顺序，P0 隔离项逐个解封）**：
1. **科技系统（征服制）**：需先建 TechnologyManager（当前 api.gd 转发到不存在的 manager）+ 按 04-科技系统.md 从"研究制"改为"征服获得"
2. **数值数据驱动**：`config/units/stickmen.tres` 接入实体（兵种差异），BalanceConfig 读取器已就绪——科技/装备/战斗深化的共同前置
3. **物流运输**：config/logistics 数据已有，需新建 logistics 模块
4. **经济系统深化**：资源供需价格模拟（resource_manager 的 `_update_price`/`_tick_supply_demand` TODO）+ 建筑升级/修理（construction_manager stub，依赖科技条件）
5. 组织系统深化：`load_preset`/`export_as_preset` stub 补全、树状层级 UI、逐层指挥 AI
6. 军团级战斗 / 大地图扩张（expansion 模块从零建）
7. **战略图深化**（P0 已做 L1 单层）：L2/L3 粒度 + Shader 化 + 动态聚落建筑群 + 拼接预览（战略图架构 SM-2~SM-5）
8. **室内系统**：透明化/INDOOR/MegaInterior 完整化（依赖建筑模块化 B 系列）

**验收标准**：从阶段 1 到阶段 3 的完整流程可玩。
