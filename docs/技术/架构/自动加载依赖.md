## 三、依赖图

> 模块依赖图（高层 ASCII 版）见 [modules/README.md §2](../../../stick-world/modules/README.md#2-模块依赖图)。本节仅保留**循环依赖检查**细节。

### 循环依赖检查

**结论：无编译期循环依赖；WorldState ⇄ SaveManager 为一对运行期互相引用（WorldState._ready 注册 → SaveManager 模块注册表，SaveManager 经注册表调用 WorldState 存档接口），经注册回调解耦。**

- EventBus → 零依赖 ✓
- ConfigManager → 零依赖 ✓
- WorldState → EventBus + SaveManager（_ready 中调用 `SaveManager.register_module` 注册存档接口）
- TimeManager → 仅依赖 EventBus ✓
- AudioManager → 依赖 ConfigManager ✓（ConfigManager 不依赖 AudioManager）
- SaveManager → WorldState（经模块注册表）+ ConfigManager（_process 读自动存档间隔 `game/auto_save_interval_sec`）
- BalanceConfig → 仅依赖 EventBus ✓

## 四、初始化顺序

> 完整 ASCII 流程图见 [README §10 Autoload 依赖](../../../stick-world/modules/README.md#10-autoload-依赖)。
>
> 原则：
> 1. 零依赖的先初始化（EventBus）
> 2. 数据层先于服务层（WorldState 先于 SaveManager）
> 3. 服务层最后（AudioManager）
>
> 注：WorldState._ready 会调用 SaveManager.register_module 注册存档接口。Godot 4.7 的 autoload 语义是先实例化全部 autoload、再按树序触发 `_ready`，因此 WorldState 声明在 SaveManager 之前仍能注册成功；调整声明顺序时须保持该语义成立。
