# 09-输入与操作复刻

> 目标：把原版 Stick War: Legacy 的操作方式复刻到键鼠，并在其上做键位可配置、
> 键盘可视化配置、手柄适配。本文档是立项依据 + 缺口清单 + 方案调研结论。
> 状态：**附身层已落地**（含弓手动拉弓，键位走 InputMap）；P1（附身段之外的
> 键位数据化）~ P4 待排期。
>
> 职责边界：本文档管**输入方案设计**（操作映射、键位配置、调研结论）；
> **操作层复刻缺口**（动画/骨骼/事件/皮肤等对账结论）以
> [`../../项目/审计/总账/翻译缺口总账.md`](../../项目/审计/总账/翻译缺口总账.md) 为唯一出口，
> 新发现缺口一律先补总账，不在本文档另立清单。

## 一、原版操作方式（复刻基准）

原版分两层操作。机制真值来自 IL2CPP 逆向实锤
（[`../../项目/审计/SWL拉弓操控逆向_2026-09-19.md`](../../项目/审计/SWL拉弓操控逆向_2026-09-19.md)，
旧版 2022.1.9 代码级）：

### 战略层（主玩法，鼠标为主）
- 底部兵种卡出兵（点卡 → 花金币在雕像处生成单位）
- 左键点选 / 拖框选单位；右键/左键点地移动、点敌攻击
- 阵型命令按钮（防御/集结/推进等，全局生效）
- 全局技能按钮（兵种解锁后：箭雨、治疗、矛兵狂暴、召唤等法术——原版如此；召唤类法术已裁决保留 2026-09-29，复刻照常）
- 矿工自动挖矿循环，无需指挥

### 附身层（User Control，点单位接管）
- 方向键 / WASD 移动（含 y 轴纵深）
- 攻击键出招，**无目标可空挥**（纯动作，无伤害）
- **弓箭手专属拖拽拉弓**（`ArcherControls`，原版唯一特殊 Controls）：
  按住拖拽定方向与力度 → 轨迹预览点 → 松手放箭，瞄准时全局慢放
  （力度公式 `Clamp(|拖拽向量|×5/屏宽, 0, 1)`，详见审计文档）
- **自动瞄准是 AI 专属行为**（非附身出兵的弓手自动锁最近敌；
  附身时切换为手动瞄准）
- 部分兵种有附身技能（矛兵投矛 `ThrowSpear`、掷后拔剑等）

## 二、PC 键鼠方案（附身层，行业最佳实践翻译）

原版触屏交互按 PC 键鼠惯例翻译——瞄准自由度（方向）交给鼠标指向，
蓄力自由度（力度）交给按住时长：

| 操作 | 原版（触屏） | PC 翻译 | 行业参照 |
|---|---|---|---|
| 移动 | 虚拟摇杆 | WASD / 方向键 | 通用 |
| 弓·瞄准 | 向后拖拽定方向 | **鼠标位置=瞄准方向**（实体朝向/仰角连续跟随鼠标） | Minecraft / M&B / Terraria |
| 弓·蓄力 | 拖距×5/屏宽→力度 | **按住左键时长→力度**（0→1，真实时间计时不受慢放影响） | MC / M&B / 原神 |
| 弓·放箭 | 松手 | 松开左键；初速=lerp(v_min, v_max, power)，伤害走 `0.6+0.4×draw_power`；**轻点=最小力度快速平射**（原版 ArrowSpeedMinPower 语义） | 原版 |
| 弓·瞄准慢放 | 拖拽时自动 timeScale | 拉弓期间自动 Engine.time_scale=0.5（可配置） | 原神瞄准 |
| 弓·轨迹预览 | AimingDots 预测点 | 拉弓期间抛物线采样点列，透明度随距离衰减 | 原版 ArcherPredictedArrowPath |
| 矛·投掷 | ThrowSpear 独立技能 | 按住左键蓄力投矛；轻点=近战戳刺 | 2D 投掷通用 |
| 杖·施法 | 攻击键（自动锁敌） | **指向施法**：按住后落点=鼠标世界坐标，AOE 圈预览，松开施法 | ARPG 指向施法 |
| 剑·攻击 | 攻击键 | 点击=攻击（自动锁最近敌） | 已对齐 |
| 格挡 | 格挡按钮 | 右键按住举盾（矛士等带盾兵种） | 通用 |
| 空挥 | — | G 键 | 原版语义（无目标出招） |
| 走/跑切换 | — | Alt 切换 | 通用 |
| 搬运/建造/翻包/建筑交互 | — | F（点击取放 / 按住连续采集 / 翻包 / 建筑菜单统一入口） | 通用 |
| **换武器** | — | **滚轮=循环切换 Hotbar 武器格并换装**（换装即切换操作方式）；数字键 1-9/0 直达 | MC / Terraria |
| 缩放（附身态） | — | **Shift+滚轮**（滚轮默认让位武器切换；创始人定稿） | 通用 |
| 缩放（非附身） | — | 滚轮（战略层现状） | 现状 |
| 背包·角色 | — | E（模态合一窗口：装备+背包+属性） | RPG 肌肉记忆 |
| ~~脱离卡死~~ | — | ~~H~~（UI 撤除，方法保留给测试/设置面板） | — |
| 切战斗/探索模式 | — | Q | 本项目惯例 |
| 退附身 | 退出按钮 | ESC | 通用 |

设计要点：
- **不做反向拖拽**（愤怒的小鸟原手势在 PC 鼠标上属冷门交互，与窗口边缘
  冲突；鼠标指向+按住时长覆盖同样的两自由度且手感更好）。
- AI 侧不受影响：AI 弓手仍走自动瞄准路径（原版同构——附身才手动）。
- 排除项（后续待办）：AI 弓箭 Draw→Hold→Reload 三段动画节奏（需动画
  资源拆段）、矛掷后拔剑（需双武器切换支持）。

## 三、附身层键位（InputMap action）

附身层输入走 project.godot `[input]` 段的 action（可重绑对象），不硬编码
keycode：

| action | 默认绑定 |
|---|---|
| possess_move_left / right / up / down | A/←、D/→、W/↑、S/↓ |
| possess_attack | 鼠标左键 |
| possess_block | 鼠标右键 |
| possess_swing | G |
| possess_mode | Q |
| possess_interact | F |
| possess_walk_toggle | Alt |
| possess_unstuck | H |
| possess_escape | ESC |

附身层以外的键位（探索层、game_root_shortcuts 全局键）仍是硬编码，
P1 完整迁移见 §5.2。

## 五、缺口清单（按优先级）

### 5.1 已落地
- [x] 空挥（`weapon_mount.perform_swing()`）——出对应武器攻击动作、
  进冷却、无目标无结算（弓 = 拉弓不放箭，与原版一致）。单测
  `test_strike_frame._test_swing_no_target` 钉死行为。
- [x] **弓手动拉弓**（PC 方案：鼠标指向+按住蓄力+轨迹预览+松手放箭+
  瞄准慢放）——逆向实锤后按 §二 方案实施。
- [x] 矛蓄力投掷、杖指向施法（同拉弓状态机）。
- [x] AI 附身技能三档（Personality.UserControlSkill 对齐）+附身增益
  （回血/溅射）。
- [x] 附身层键位 InputMap 化（§三 action 表）。

### 5.2 P1 —— 键位数据化（后续一切的地基）
附身层已迁 InputMap；剩余：探索层 4 项、全局 8+ 项（game_root_shortcuts
硬编码）、武器面板/调试键。迁到 Godot **InputMap action**
（project.godot input 区声明 action，代码改用
`Input.is_action_pressed` / `event.is_action_pressed`），才有重绑定的操作对象。

### 5.3 P2 —— 设置面板键位重绑（含鼠标左右键）
- 设置面板新增"按键"页：action 列表 + 当前绑定 + 点击监听新输入（键/鼠标键）
- 冲突检测（同键多 action 警告/交换）、恢复默认
- 持久化：ConfigFile 存 override，启动时覆盖 InputMap
- 开源参考：
  - [KoBeWi/Godot-Input-Remap](https://github.com/KoBeWi/Godot-Input-Remap)（资源式，键+手柄）
  - [dastmo Runtime Controls Remap](https://store.godotengine.org/asset/dastmo-runtime-controls-remap/)（Asset Library，带现成 UI）
  - [Godot 官方 demo：重构键位的 Input Mapping UI 思路](https://www.reddit.com/r/godot/comments/170834y/how_do_you_let_the_players_change_the_controls_of/)

### 5.4 P3 —— 键盘可视化配置（用户点名的方案）
设置页里画一把键盘（QWERTY 键帽网格 + 鼠标示意图），每个键帽上标注绑定的
action 名；点击键帽 → 按下新键即替换；鼠标左右/中键单独一块。实现要点：
- Control 自绘（GridContainer 键帽按钮，104/87 键布局常量表）
- 键帽文案 = `InputEventKey.as_text()`（自动处理修饰键）
- 无需第三方库，纯自绘约 300~500 行；P2 的重绑逻辑复用

### 5.5 P4 —— 手柄适配
- Godot 4 内建 SDL 手柄映射（Xbox/PS/Switch Pro 免配置），InputMap 里给每个
  action 加 JoypadButton/JoypadMotion 绑定即可
- 左摇杆移动（带死区）、按键 glyph 提示（社区资产
  [Kenney Controller Prompts](https://kenney.nl/assets/controller-prompts) 等免费包）
- 鼠标语义操作（框选/点地）在手柄下需要光标虚拟化方案——参考
  Godot 资产库 "virtual mouse" 类插件，或战略层专为手柄设计轮盘菜单
- 开源参考：KoBeWi 库原生支持 joypad；Godot 官方文档
  [InputEventJoypadButton/Motion](https://docs.godotengine.org/)

### 5.6 P5 —— 原版操作细节补全（依赖对应系统立项）
- ~~弓的键鼠微调~~（逆向实锤关闭：原版附身即手动拉弓，已按 §二 方案落地）
- 兵种出兵卡 / 阵型命令按钮 UI 化（现在靠键盘，原版是底部按钮）——依赖战斗生产 UI 立项
- 全局技能按钮 —— 依赖法术系统立项（未移植清单 §7-B）
- 附身技能键（矛兵举盾等姿态）—— 依赖姿态格挡扩面（已有 seek_cover 一处）
- 教程提示（原版 InGameTips 类）—— 依赖新手引导立项
