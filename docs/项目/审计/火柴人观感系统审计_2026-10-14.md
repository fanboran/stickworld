# 火柴人观感系统审计_2026-10-14

> 定向审计：继续观感修复前对火柴人表现链的系统性排查。范围＝HD-2D 关节烘焙渲染管线（char_rig_3d/buckets/双图集/shaders）、feed 层（hd2d_map_base._sync_character_render）、动画姿态链（stickman_rig/skeleton/weapon_mount/visual_controller/procedural_overlay）、实体视觉状态（死亡/淡出/受击/LOD）、特效锚点（伤害飘字）。方法＝两路静态精读＋关键项提交级追溯复核＋实机 48 档 60s 连拍逐帧肉眼验（含局部裁图）。
> 结论速览：**4 个高杀伤实锤**（尸体表现/攻击定帧/飘字锚/描边缩放回归）＋ 8 个表现缺口 ＋ 一批成本与死代码。修复顺序提案见 §五。

## 一、A 类·高杀伤实锤（直接可见）

### A1 死亡变体被等值门禁拦截——过半尸体"站着死"，地上几乎无躺尸
- `visual_controller.gd:173-175` 死亡终态门禁只放行精确名 `"dead"`/`"dead_headshot"`；而 `stickman_entity.gd:1184` 经 `pick_dead_anim()` 取池随机：普通死池 `["dead","dead_v2"]`（**50% 拦截**）、爆头池 8 变体（**87.5% 拦截**）。`health_component.gd:42-45` 确认 `died.emit()` 时 `is_dead()` 已真——变体名必被拦，`_current_anim` 停留在生前 walk/idle/attack，尸体以生前姿势原地淡出。rig 侧同门禁（`stickman_rig.gd:614`）用 `begins_with("dead")`，两处口径不一致＝门禁漏改。
- **连带 A1b 尸体双驱动淡出**（`stickman_entity.gd:1199-1208` tween 与 `528-542` 物理帧计时两套并行写 `modulate.a`+`queue_free`）：有遗物尸体（战斗多数——掉武器即有 loot）在 t≈12.9s 被物理帧路径以 **alpha≈0.36 瞬删**（tween 12s 间隔起步太晚），消失瞬间可见跳变；无遗物尸体的 tween 整段是死代码。两套时长真相源（5/1.4s vs 4/1.2s）。
- **实机实证**：48 档 60s 连拍第 45/60 秒帧，68~74 阵亡，地面躺尸仅 1~2 具＋遗物金球；按尸体可见时长（4.9~12.9s）推算应有 10~20 具在场。
  - `F:\VSCode\game-2\.temp\战场重构\temp\观察场快照\20261014_165517_p1\auditaudit_p1_第45秒.png`
  - `F:\VSCode\game-2\.temp\战场重构\temp\观察场快照\20261014_165517_p1\auditaudit_p1_第60秒.png`
- 修法方向：门禁改 `begins_with("dead")`（与 rig 侧同口径）＋删 tween 块以物理帧计时为唯一真相源。

### A2 受击插播吞掉攻击回切计时——攻击定帧滑步＋镜像幻影第二刀＋锁足定身放大
- `visual_controller.gd:113-122` 单槽 oneshot 计时：出手设 override=attack＋计时＝攻击时长；挥砍中途被打 → `play_hit`（:433）**覆盖同一槽**且 base 传空 → 受击计时走完后 `:104-107` base 为空跳过回切，`_current_anim` 永远停在 `"attack"`。
- 后果三连：① 实体侧 `is_attack_anim_active()`（`stickman_entity.gd:1340-1341`，只读 `_current_anim`）恒真 → P1 攻击锁足的移动闸把它放大成**定身在攻击末帧直到下次出手**；② feed 轮询拿到 `(attack, seq+1)` 与镜像当前 `(hit_front, seq+1)` 不同 → `char_rig_3d.gd:330-334` 重播整段攻击＝**无伤害幻影第二刀**，播完仍冻结；③ `entity_motion` 的 attacking 门禁永不允许切 walk/idle。
- 混战中"出手窗内挨打"是高频事件。修法方向：oneshot 计时槽受击插播不覆盖攻击计时（改双槽或受击结束后补回切）；`is_attack_anim_active` 与镜像回切同源。

### A3 伤害飘字锚不吃 depth 缩放——遗留悬案「Δy 13~17px 超容差」归因闭环
- 链路：`damage_pipeline.gd` 锚=实体原点（视觉脚线）→ `fx_library.remap_body_pos`（:220-244，地面压缩＋**恒定** `body_lift()`=50.23）→ `:294-296` 头顶偏移**恒定** −62。而镜像角色渲染端髋高/头顶全部乘 `depth`（`char_rig_3d.gd` `_f_s = S×_depth`，feed 传 `depth_scale_at(y)`∈[0.92,1.10]，血条锚 `char_rig_3d.gd:741-754` 就乘了 depth）。误差=112.23×(1−depth)：行走带最远端字偏高 ~9px、最近端偏低 ~11px，**峰谷 sweep≈17.6px**——与探针两轮实测 worst 13~17px 量级精确吻合。修法方向：`fx_anchor_lift` 协议升级为带 y 查询（内部乘 depth），头顶偏移同理；动手前先对齐 fx 审计探针口径。

### A4 描边缩放补偿断链（裁决#35 P0 批回归）——zoom 变化后描边档/脚底接地垫全部冻结
- `_watch_stroke_eff()`（`char_rig_3d.gd:642-649`）定义后**全仓零调用**：裁决#24 落地时在 `_process` 每帧调用，P0 批（`2273b651`）拆 `_process_inner` 埋 StickProf 计时点时该行被误删。后果：相机缩放跨 0.5 rig px 量化档后无人重报图集规格——描边格位停在 build 时档（过粗/过细失配），**脚底接地垫 `_foot_pad_rig` 同步失效**（裁决#26「脚底穿模」修复的几何前提）。`update_outline_eff` 只更新浮点无人消费。
- 修法方向：`_process_inner` 补回一行调用（每帧一次 roundf＋比较，成本可忽略）。

## 三、C 类·成本/健壮性/死代码

1. **每帧 `OS.get_environment`**：`char_rig_3d.gd:683`（每实体每帧）——P0 治理同族残留，应入 `_ready` 缓存布尔；`char_direct_buckets.gd:127`（每桶每帧，量小）。
2. **`get_bar_state` 每帧每实体新建 13 键字典**（`health_bar_indicator.gd:166-189`，feed `hd2d_map_base.gd:341-342` 每渲染帧调）＋ `apply_bar_state` 无条件 `queue_redraw`（:216-229）——血条回读已降 15Hz，喂入侧未同步。
3. **图集烘焙失败无重试触发点**（`char_joint_atlas.gd:118-137`）：回读 4 连败后 `_fp=""` 但 `ensure()` 只在 build/缩放档变化时被调——首帧视口异常时全角色隐身且不自愈（低概率高杀伤，建议 publish 侧补一拍失败重试）。
4. **武器/血条贴图无 mipmap**：武器贴图 `mipmaps/generate=false`＋`char3d_weapon_atlas` 无 mip 过滤；血条图集 4320×864 以 `filter_linear` 采到屏上几十 px（约 10:1 缩小）无 mip——远景缩小的闪烁/闪动候选源（血条残余「闪烁」复验时应一并 A/B）。body 图集自烘 mip（`generate_mipmaps`）无此问题。
5. **死代码清单**（清理项）：`char3d_body_fade.gdshader`（零引用）；`weapon_mount.get_blocking`/`is_swinging`/`weapon_anim_event` 信号/`BOW_AIM_VISUAL_TIMEOUT` 分支；`stickman_rig.ANIM_HIT`＋`set_outline_canvas_scale`/`outline_zoom_external`＋`get_bone_by_id`/`get_bone_ids`；`visual_controller._pick_idle_variant` billboard 分支白掷骰（:199-202）；`StickmanWeapon.attach`（休眠且握点数学是修复前旧版，防复活）。
6. **进程级环境变量副作用**（`char_rig_3d.gd:164` `STICK_BATCH_RIG=0`）：首张 HD-2D 卡 build 后全进程生效，同进程混开 2D 战场会把小兵退回旧矢量路径。改 per-instance 参数为宜（疑点，取决于混图流程是否存在）。
7. **LOD T2 对 HD-2D 角色断链**（`stickman_entity.gd:1562-1571`）：rig==null 时远景隐藏/动画降频整段跳过——性能杠杆在主战场无效（性能另案，登记在案）。
8. **crowd 路线（非 HD-2D 图战斗）三问题**：代理丢池变体＋命中帧错拍（`crowd_renderer.gd:340-345`）、受击后移动单位定格滑行（`stickman_rig.gd:902-904`＋`visual_controller.gd:423-436`）、A1 死亡门禁同款。当前观感主线（HD-2D）不受影响，`battle_instance.gd:161-164` billboard 图跳过 crowd。
