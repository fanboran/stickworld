## 〇、Running with Rifles 士兵 AI（"大致反编译"：exe strings + Mod XML 数据层）

RWR 是原生 C++（rwr_game.exe，无法反编译出源码），但其 Mod 友好设计把**士兵射击 AI 的核心参数
放在数据层**（media/packages/*/weapons/*.weapon + exe 字符串表），可直读：

**weapon XML（ak47.weapon 实例）**：
- `sustained_fire_grow_step="0.40"` / `sustained_fire_diminish_rate="1.2"` —— **持续射击散布增长/停火恢复**：
  连射越久打得越散（每发 +grow），停火按 rate 恢复。RWR 士兵"会点射不无脑扫射"手感的数据基础。
- `kill_probability="5.2"` + `kill_decay_start_time="0.33"` / `kill_decay_end_time="0.68"` ——
  **击杀概率随子弹飞行时间衰减**：命中≠击杀，贴脸必杀、远距命中常轻伤——命中距离感的核心。
- `retrigger_time`（扳机间隔）、`accuracy_factor`、`projectile_speed`。

**exe 字符串表（AI 参数名，rwr_game.exe strings）**：
`ai_burst_time` / `ai_burst_time_variance` / `ai_burst_wait_time(_variance)`（点射节奏：打 x 秒停 y 秒，带方差）、
`ai_max_distance_to_shoot`（超距不开火）、`ai_sight_range_modifier`、`ai_use_throwables`、
`ai_stop_to_fight`、`ai_attack_spread_block_multiplier`（散开进攻系数）、`ai_pick_prevention_time`。

**落地记录（2026-09-05 Round 12，三项全部实装）**：
1. sustained_fire 连射散布 ✅ `weapon_mount.gd`：每箭热度 +0.40（上限 1.2，实际 σ×(1+热度)），恢复率 1.2/s→0.10/s 按我方弓射速（~0.5发/s vs RWR 步枪 ~10发/s）等比换算——连放 3 箭 σ≈1.6x、6 箭到顶 2.2x，脱战 ~12s 回满；
2. 点射 burst 方差节奏 ✅ `behavior_attack.gd`：散布热度 ≥0.8 时下一箭持瞄时长 ×1.8~3.2 随机倍（ai_burst_wait_time[_variance] 语义），停火等散布恢复；
3. 击杀概率飞行时间衰减 ✅ `arrow_projectile.gd`：命中伤害乘飞行时间衰减带 0.35s 内满伤 → 0.75s 后 0.5 倍下限（RWR 0.33/0.68 按 HP 制与箭速 850px/s 换算，≈300px 内贴脸满伤 / 640px 外半伤）。

## 一、Terraria 日月运行（Main.cs `DrawSunAndMoon`，:63847 起）

太阳**不是圆弧**——是"线性横穿 + 抛物线高度 + 地平线放大"：

```
dayT   = time / 54000                    // 白天进度 0..1（全天 54000 tick）
sunX   = dayT × (屏宽 + 日宽×2) - 日宽    // 线性横穿整屏（含两侧余量）
p      = pow(abs(dayT×2 - 1), 2)          // 抛物线：0=正午 1=晨昏
sunY   = bgTopY + p×250 + 180             // 正午高挂 180，晨昏贴地 +250
sunScl = 1.2 - p×0.4                      // 地平线处太阳放大 1.2x，正午 0.8x
rot    = dayT×2 - 7.3                     // 随行进微旋转
```

月亮同公式，夜间 32400 tick：`scale = 1.2 - 0.4p`（地平线放大），`rotation = time/32400×2 - 7.3`。
月盘贴图 **9 种**（按世界选择盘面），月相 = **8 帧竖条图集**按 moonPhase 取帧裁切。
颜色规则：**普通夜强制纯白绘制**（`SetBackColor` 尾部把月亮色强制白），只有血月才走色 ramp——
月亮是夜空中不随 bgColor 染色的例外（本项目同构：月面纯白 + 月相阴影圆直接取当前天空底色，
新月时阴影圆与天空无缝）。
另有 sunModY/moonModY 微扰（每帧 ×0.999 衰减——事件的余波摆动）。

## 二、晨昏色彩（Main.cs `SetBackColor`，:64451 起）

时段分段线性 ramp（不是连续函数，按 tick 区间硬切换，段内 lerp）：

| 时段 | sun/moon tint 终点 | 背景 bgColor 终点 |
|---|---|---|
| 黎明 t<13500 | (55,75,5)→白（**绿调日出**） | (25,35,35)→白 |
| 午后 37800-45900 | 白→(175,125,155) | 白→**粉 (235,120,170)** |
| 日落 >45900 | →(55,25,55) | →暖紫红→(35,35,35) |
| 夜前半 | (205,155,155)→… | (35,5,5)→(5,5,5) |

雨/墓场等再乘衰减系数。**要点：黄昏的天空是粉的、黎明的太阳是绿的**——和直觉相反，是 Terraria 天空"耐看"的配方核心。

> 夜间 bgColor 的精确分段与月相 floor 取值见 §七（复刻实现的查表依据）。

## 三、云系统（Cloud.cs 全文 456 行）

- **池**：200 槽静态数组；世界生成时 `numClouds = rand.Next(200)` ——云的数量本身就是随机的。
- **scale 0.7-1.3 = 深度**：`GetParallax()` 三档（scale<1 → 0.07 系；≤1.15 → 0.19 系；更大 → 0.23 系，内部再平方调制）——**小云远、慢；大云近、快**。
- **运动**：`position.X += windSpeedCurrent × 9 × GetParallax() × dayRate`——全局**风**驱动，非每云自漂。相机横移时按各自 parallax 回拉（:321）。
- **生灭**：出屏（±600px 余量）即 inactive；Alpha 以 0.001/帧渐入渐出——云永远软进出，无跳变。
- **摇摆**：rSpeed 随机游走 ±0.0002/帧封顶，rotation 夹 ±0.02 rad——极慢的钟摆感。
- **云色 = bgColor × (scale×Alpha)**（cloudColor 方法）——云的亮度/颜色**完全继承天空色**：黄昏粉云、夜晚暗云零特判。
- **排序**：UpdateClouds 冒泡，小 scale 排前（近处画后面？——绘制序使远云不被近云穿插）。
- **稀有云**：RollRareCloud 1/10 概率掷事件门槛云（Boss 击败后解锁特殊云）——云有人格。
- 出生 Y：`-0.25..0.15 × 屏高`，小云再上移（远云更高）。

## 五、背景层跨全图平铺（Main.cs :53724 等 8 处同构）

```
bgStartX = -IEEERemainder(bgWidth + camX × bgParallax, bgWidth) - bgWidth/2
```

每层按贴图宽度 **modulo 回绕平铺** + 相机 × bgParallax 偏移——任意宽度无限延展，层间 bgParallax 分档。天体/云/背景三者用不同的视差体系（云按 scale 分档、背景层按层分档）。

## 六、Kingdom Two Crowns 水体（网络调研；IL2CPP 无法本地反编译）

- 官方：创作者 Noio（Thomas van den Berg）2017 年在 Raw Fury 分享过初代 Kingdom 水面做法（社区称 "Sexy Water" 帖）。
- 玩家可关反射换帧数 → 反射是**实时渲染**（非烘焙）。
- 技法拆解（社区复刻共识）：
  1. **镜像反射**：水线以下翻转绘制岸上精灵（或屏幕纹理镜像）；
  2. **正弦扰动**：反射横向正弦偏移，随深度加深；
  3. **岸边白沫**：滚动的白色泡沫条带（多为**预制的循环贴图条**而非程序泡沫）；
  4. 像素画游戏需 UV 量化保锐利。
- 布局：水在**岛屿两端**（灵感：阿姆斯特丹运河），玩家走到地图尽头就是海。

## 七、夜空 bgColor 分段线性表（Main.cs `SetBackColor` 精确取值）

`SetBackColor` 按游戏 tick 做**分段线性插值**（段内 lerp、段间硬切换）。白天轴 0..54000、
夜晚轴 0..32400 两套时间轴，首尾闭环：日落终点 = 夜起点、夜终点 = 黎明起点。

| 时段 | 时间轴 | bgColor 走向 |
|---|---|---|
| 黎明 | 白天 0→13500 | (25,35,35) → 白 |
| 午后 | 白天 37800→45900 | 白 → **粉 (235,120,170)**（黄昏粉峰） |
| 日落 | 白天 45900→54000 | 粉 → (35,35,35)（入夜灰黑） |
| 夜前半 | 夜晚 0→16200 | (35,35,35) → (5,5,5)（深夜最黑） |
| 夜后半 | 夜晚 16200→32400 | (5,5,5) → (25,35,35)（黎明前回暖） |

**月相亮度 floor**：夜间 bgColor 三通道设下限——新月 Empty = 11、满月 Full = 19，按月相线性内插
（满月夜整体比新月夜亮一档）。雨/墓场等再乘衰减系数（见 §二）。

要点：夜空不是纯黑——(5,5,5)~(35,35,35) 之间的极暗"灰黑底"，剪影感来自前景与天空仅数个
灰阶的差值。本项目复刻把该表直译为 `RenderingServer.set_default_clear_color` 关键帧
（`modules/environment/api.gd` SKY_BG_KEYFRAMES，时间轴映射到本项目太阳 5..21 时），
与 CanvasModulate 环境光照（LIGHT_KEYFRAMES，午夜≈(14,14,19)）**双轨分离**——
天底色不经过 CanvasModulate，发光体另走除法补偿（见 §四引注）。

## 九、极光（AuroraSky.cs）

- **触发**：雪原 biome + 夜晚 + 无暴风雨；同时 1~3 条（数量按月相）。
- **HSL 配色**：hue = GlobalTimeWrappedHourly/60 + cos(带内 t×2π×2.5)×0.1——色相随游戏时间
  缓慢轮转（绿→青→蓝→紫），带内再叠 cos 微调制；sat = 1.0，lum = lerp(0.5, 1.0, t)
  （底部暗、顶部亮）。
- **几何**：VertexStrip 140 段竖条帷幕；高度 lerp(0.4, 0.1, t)×1080、横摆 cos(t×π×3)×0.4、
  厚度 lerp(0.2, 0.05, t)×1080（t 为带上归一化位置：根部厚、梢部细）。
- **淡入淡出**：强度淡入 0.3/s、淡出 0.5/s（软进出无跳变，与 §三 云的 alpha 渐变同思路）。
- **混色**：与世界 tile 色 lerp 0.08（轻微环境融合）。

本项目复刻同落 `modules/world/scripts/map/sky_stars.gd`：AURORA_HUE_SPEED = 0.022/s
（一夜约 25s 转 0.55 圈），ADD 混合子节点 + unmodulate 补偿。
