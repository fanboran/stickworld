## 一、动画层：未译 80 个，分三档

### A 档——战斗完整性直接缺口（建议优先）
- **连击段**：Swordwrath-Attack2、Spearton-Attack2/3（原版近战多段攻击；我们只有 Attack1，
  配合已翻译的 AnimationCancelFraction 才能构成完整连击节奏）
- **矛兵举盾姿态组（9 个整组）**：Spearton-Block/Block2/Block3、Block-Attack1/2/3、
  Block-Crouch、Block-Walk、（Hit-Spearton-Block-1/2 受击）——原版姿态格挡是完整状态机
  （举盾站立/举盾行走/举盾中攻击/举盾中受击），我们只有 Swordwrath-Block 单动画 + bool 姿态。
  姿态格挡扩面（09 文档 §3.6 / 分析文档 §7-E）立项时整组翻译
- **挖矿**：Miner-Mine（真挖矿动作；现 build 用 Miner-Attack1 凑，语义错位）
- **受击分部位/分强度（8 个）**：Hit-Head-Front/Back-Small、Hit-Head/Mid-*-Big-1、
  Hit-Head-Butt(2)——原版受击分头/躯干 × 大/小（爆头受击、重击），我们只有 Mid-Front/Back-Small
- **死亡变体（10 个）**：Death2、Death-Headshot-Forward、Death-Headshot-Spear、
  Death-Headshot-Spearton(±Spear)、Death-Headshot2(±Spear)、Archidon-Death1/2
  ——爆头死亡我们只有 1 个通用版，原版按兵种/前扑方向分 7 个
- **弓节奏**：Archidon-Hold（拉满保持）、Archidon-Reload（上箭）——原版弓的
  Draw→Hold→Reload 三段节奏，我们只有 Draw；弓攻速节奏（GetDrawAnimationSpeed 的原文）依赖它
- **兵种行走/奔跑差异化**：Archidon-Walk/Walk2/Run、Magikill-Walk、Spearton-Run
  （现在全兵种共用剑士 walk/run）
