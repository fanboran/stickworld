## 三、双层线问题——完整因果链（已消灭，防复发）

1. **LANCZOS 振铃**：1024 缩放在轮廓外产生 1-2px 半透明光晕（alpha 20~174，非单调有振铃谷）。
2. 低阈值墨线基面把光晕算轮廓 → **墨在光晕/实体边各画一次** = 双线。
3. 光晕像素 RGB 振铃偏暗 → cel 分档涂深色带 = 即使不描墨也有假圈。
4. **最终方案**（2026-09-08 起仅豁免 6 枚沿用）：①全分辨率 alpha 二值化（≥128 保留，光晕抛弃）→ 缩小 LANCZOS 自生 1px 干净 AA；②描边在**最终显示尺寸**上画（1024 画完缩小=线缩没）；③线=1px 核心+内侧渐变+高斯 0.6 AA。**非豁免图标已被「超分抗锯齿」取代**（保留渲染软 alpha+BOX 缩放，见 §五），二值化+LANCZOS 的硬边/振铃问题随之消灭。
5. 黑脸（心形正面全黑）根因独立：`cam.matrix_world` 在 depsgraph 更新前读取是**陈旧单位阵**，主光被放到物体正后方。修复=读矩阵前 `view_layer.update()`；照明问题标准定位手段=**头灯实验**。

## 五、关键决策与教训（防重踩，详版在提案文档）

- **多灯毁方向性**：补光/环境/轮缘叠加使明度场失去方向性，cel 分档边界退化成贴轮廓同心圈（"双描边感"来源之一）。只留一盏主光。
- **平面形体无内部差**（旧结论，方案已被否决）：平面朝相机的物体真实光照打不出色差——v9 曾用合成期**径向假光衰减**解决；**2026-09-08 创始人否决**（假光把平面劈成斜向色阶，违反「一面一色」），正解=渲染端面烘色（见「分档架构定版」条）。假光仅存于豁免图标（锤/骨头/钥匙串/路牌/短剑/账本），勿在新图标上复用。
- **黑脸根因**：读 `cam.matrix_world` 前必须 `view_layer.update()`，否则是陈旧单位阵，主光会跑到物体正后方。定位手段=**头灯实验**。
- **AgX 偏色**：ID 纯色 pass 必须 `view_transform='Standard'`。
- **材质钳零**：`materials.clear()` 会把 `material_index` 钳 0——多槽物体恢复槽位后必须按法线重指派。
- **锥体禁用**（极点棱纹，底尖用拉伸球）；圆柱禁整体细分（桶形，只边缘 BEVEL）；球体要细分。
- **5.2 API 漂移**：节点/枚举输入一律索引访问+try/except 探测（Base Color→inputs[0]、POLY→CURVE、FULL→BOTH、edge_face→bmesh）。
- **测量纪律**：验收直读小尺寸原图；颜色判定在 RGBA 本体上做（合成图底色污染）；输出必须乘 255；居中用四边距数字验收不用肉眼。
- **脚本尾部唯一**：sed 追加会残留重复块，后块覆盖先块输出（v9 曾因此丢能量参数）。
- **搬目录断路径**：脚本从 `temp/` 抢救到 `tools/icon_pipeline/` 后，`dirname(__file__)` 与 CWD 相对 `temp/` 两套旧假设全失效——gen 写进脚本目录、compose 读 CWD 相对 `temp/`，从仓库根跑会用陈旧输入**假通过**。修复=三脚本统一锚定 `<仓库根>/temp/`（回归：21 张成品与验收样张逐字节一致）。新脚本入管线一律用 `__file__` 锚定仓库根，禁止 CWD 相对路径。
- **扩 ID 色板会污染旧图标回归**：ID 候选 5 色→10 色后，锤头红/黄材质的 AA 混合中间色恰好=新橙 (1,.5,0)，接缝像素改判家族，hammer 三尺寸回归即挂。修复=旧 tag 锁 5 色候选子集（compose `NIDS`），新母题才用 10 色。**扩色板必须回归旧全套。**
- **5.2 API 漂移续**：`primitive_capsule_add` 属性存在但未注册（hasattr 探测不够，调用才报错）→ try/except + 圆柱双球退化（端球沿旋转后局部 Z 偏移）；曲线 `fill_caps` 已改名 `use_fill_caps`。
- **椭球无尖角**：拉伸球做晶体在 64px 是圆钝"耳朵"读不出晶尖——尖角形体用 4 棱平锥（帐篷/晶体，刻意棱面许可），曲面形体才用拉伸球。
- **瓶内液体不可见**：不透明瓶壁挡住内部液体 pass，64px 读不到——药瓶=整瓶药水色+瓶口软木塞+白色气泡，一体才可读。
- **部件前后关系按相机定**：相机在 +x/−y 方向，−y 更靠相机；页面/封面谁在前按 −y 近摆，摆反了白页被红封面吞掉。罗盘指针重踩此坑（首版放 +y 被盘面挡到 ID 图红像素为 0）——浮在盘面上的小部件（指针/刻点/贴纸）一律放 −y 侧。
- **分档架构定版（面烘色+直方图分档，创始人反馈三轮返工的结论）**：手绘 cel 的铁律是**平面一面一色**，曲面才用渐变——任何「往平面上打渐变」的方案（径向假光等）都会把平面劈成斜向色阶，被创始人否决。定版三层：①**渲染端面烘色**（`gen_motifs.py bake_flat_faces`）：平面着色网格按「面法线·主光方向」量化三档灰烘进 FACE 域顶点色（单材质+Attribute 节点，不破单槽纪律），每面恰好一色、朝向不同色不同；曲面网格（球/胶囊/环/曲线管）保持白模受光走真实球形光；倒角修改器生成的新面从相邻基面插值属性=柔和棱过渡。②**compose 分档**：采样域（腐蚀掉轮廓 AA 环，防环像素压低 p5）→ 明度场 p5/p98 拉伸 → 一维 k-means 三簇（档位切在直方图结构上）；**展宽 <0.15 的单面物体跳过拉伸/聚类走固定阈值**（k-means 对独苗直方图会在量化噪声上劈簇出噪点，罗盘盘面教训）。③模糊半径收紧 0.012×尺寸（大半径亮面沿棱渗入暗面自成一档=「棱变独立色」）。**已验收图标全链路豁免**：`NO_STRETCH`（compose 不拉伸/旧固定阈值）+注册表 `classic=True`（渲染端跳过烘色全白模）——两处必须同时生效，豁免表扩减须重新逐字节验收。现表 = 锻造锤/狗骨头/钥匙串/账本/路牌/短剑 6 枚；**爱心 2026-09-08 被创始人解除豁免重做**（3/4 视角立体枕形+撤假光，走新管线）。
- **超分抗锯齿（软 alpha+BOX）**：渲染本是 2x SSAA+64x MSAA，边缘 alpha 平滑，旧管线却二值化（≥128）再 LANCZOS 重采样——AA 只剩一圈硬边还带振铃风险。定版：非豁免图标保留渲染原生软 alpha + **BOX 面积平均缩放**（纯平均无负瓣零振铃）；软 alpha 边缘环像素用最近实心像素的部件色填充（防 BOX 把黑底 RGB 混进边缘出黑边）。描边仍在最终尺寸上画不受影响。豁免 6 枚走旧硬边+LANCZOS 路径逐字节锁定。**描边宽度档**：环境变量 `ICON_STROKE`（默认 1.0=现行 1px 规格；1.5/2.0 向内加半/满权重第二圈，仅外轮廓圈），对照页 `temp/stroke_compare.png`，创始人选档后把默认值定死。
- **死代码勘误：「锤头三面锁档」从未生效**：其条件 `len(th)==3` 对二元组档位表 `(0.36,0.68)` 永远为假（len=2）——历届验收样张（锤/基本体 ≥128px）本来就是纯光场分档的样子，分支已删除。教训：**抄写/交接的条件要核对取值域**，`len(元组)` 不等于"档位数-1 之外的想象"。
- **透明容器=轮廓曲线勾壁**（`flask`/`erlenmeyer`/`testrack`/沙漏玻璃）：瓶壁用一条沿器皿纵剖面的开口曲线 tube 勾出，内部药水实体+空气留空（棋盘格透出）——透明感在 64px 直接成立。**旧结论「瓶内液体不可见=整瓶药水色」作废**（那是实心瓶壁挡液体的权宜之计）。
- **三棱柱/多棱柱对镜头定向**：verts=3/4 的圆柱要「盘面朝镜头」时，rot 先 X90 再绕**全局 Y** 转角度调顶点方位（如斧刃 `(90°,-120°,0)`）；绕全局 Z 转会把已立起的盘面再度侧倾成薄片（斧头首版教训）。顶点初始方位：X90 后顶点落在 XZ 平面 0°/120°/240°，Ry(ψ) 使角度变为 α-ψ。
- **斜置部件用显式轴向，不堆欧拉**：罗盘指针 `rotation=(0, 35°, 0)` 即 +z 轴向 `(sin35,0,cos35)` 指东北；再叠 Z 旋转角容易算错落点（罗盘首版指针方向错）。斜向小部件（指针/贴纸）一律放 **-y 相机侧**（v9 部件前后关系教训的延伸）。
- **64px 部件「少而大」**：手这类多部件形体（掌+四指+拇指）在 64px 必散架——收敛到两个大部件（圆拳+食指）才可读；同理旗帜三片必须挂在杆同一侧（对称分布读成两面旗），钱袋圆球+细颈+飞币读成手雷（改梨形双球+宽口金币外露）。
