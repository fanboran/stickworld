# 08 · 拓展性

> UI 体系如何长大：换肤、字体、数据驱动、大界面注册、多分辨率。
> 核心思想：**变体在 token 层解决，结构永远一套。**

---

## 一、三层主题架构（换肤的原理）

```
StickTokens ──换文件──▶ 另一套 Tokens（如 parchment_tokens.gd）
    │
StickStyle（纯函数：token → StyleBox）
    │
StickTheme（打包成 Theme）──▶ 挂根节点，整树生效
```

- 所有样式都是 **token 的纯函数**，主题之间没有结构差异
- **换肤 = 换一套 token 值**，控件零改动
- 多套视觉并存时，token 从常量文件升级为 Resource（`ui_skin.tres`），
  StickStyle/StickTheme 改读 Resource 字段（接口不变）

## 二、主题变体规划（层级皮肤）

上游规范的风格演变（L1-L2 石头 → L3 羊皮纸 → L4-L5 全息 → 终局金饰）以
**皮肤包**落地，每包 = 一套 token 值 + 可选底纹/描边材质：

| 皮肤 | token 差异示例 | 材质 |
|------|---------------|------|
| 黑玻璃（默认，P0-P1） | 现行值 | 无 |
| 石头（L1-L2） | RADIUS 0、BORDER 暖灰、底更厚 | 噪点底纹 |
| 羊皮纸（L3） | WINDOW_BG 换米黄半透明、TEXT 换深褐 | 纸纹 |
| 全息（L4-L5） | BORDER 换青蓝、ACCENT 换冷白 | 扫描线 |
| 金饰（终局） | ACCENT 换金、BORDER_STRONG 换金 | 描边角饰 |

切换时机：随管理层级渐隐渐显一起插值（04 §四的 modulate 通道顺带换皮肤包）。

## 三、字体切换

| 点 | 设计 |
|----|------|
| 现状 | Godot 默认字体 + 系统自动 CJK 回退（中文可显） |
| 注入点 | `Theme.default_font`（StickTheme.create 预留单行赋值位） |
| 规范 | 正文字体须覆盖 CJK；等宽字体仅用于数值/坐标（P1 选资产） |
| 字号 | 一切字号出自 token；字号缩放 = token 系数（07 §四无障碍） |

## 四、界面缩放与多分辨率

- **布局铁律**（沿用仓库规则）：场景是布局唯一真相源；全屏根走
  `UIKit.full_rect()`；角落 HUD 自设 anchor 挂具名槽
- **界面缩放**：`ui_scale` token → 根节点 `scale` 或 theme 字号/尺寸系数
  （模板已把尺寸集中成 BTN_H/ROW_H 常量，缩放有单一阀门）
- 目标分辨率：1920×1080 基准，`canvas_items` + `expand`（现有 project 设置不变）
- 极端比例（21:9 / 4:3）：顶栏三段自适应（中区弹簧），快捷栏超宽时换行

## 五、数据驱动内容

约定：界面内容**默认是一张数据表**（Dictionary/Array const 或 .tres/.json），
工厂按表装配。已有的表：菜单/设置/工作区/快捷栏/资源槽/通知文案。

加内容的标准动作 = 改表，而不是写 UI 代码。表放哪：

| 内容 | 位置 |
|------|------|
| 演示/模板数据 | 模板脚本 const（现状） |
| 正式游戏数据 | `config/excel/` 管线（沿用 Excel 数据管线）或 `.tres` |
| 文案（翻译预备） | 集中文本表，key 引用（P2 本地化前置） |

## 六、大界面注册挂点

现状：业务面板由 SystemSetup 手工挂到 UIRoot 槽位。
规划（P1）：**界面注册表**——界面 id → 场景/工厂 + 默认槽位 + 快捷键：

```gdscript
# 示意（落地时放 ui_global/api.gd 旁）
UIRegistry.register("org_panel", preload("res://.../org_panel.tscn"),
    {"slot": "ModalOverlay", "hotkey": KEY_O, "singleton": true})
UIRegistry.toggle("org_panel")   # 开/关/提到栈顶
```

收益：新大界面不改 UIRoot 代码；快捷键表自动生成；模态栈有统一管家。
注册表与 02 篇模态栈规则（同类单例/压栈/ESC 退栈）一体实现。

## 七、主题热切换

```gdscript
StickTheme.refresh(root)   # token/skin 变更后重建 Theme，整树即时生效
```

- 设置页"界面缩放/皮肤"改动走此通道，免重启
- 运行时换 skin：`StickStyle` 改读 skin Resource → 调用 refresh 即完成
- 回归自检：打开 `component_gallery.tscn` 目检全族控件
