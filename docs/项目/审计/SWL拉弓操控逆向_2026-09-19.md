## 附身操控架构(旧版 2022.1.9 实锤)

命名空间 `StickWar.UserInterface`:

- **`Controls : MonoBehaviour`(附身操控基类)**:字段 `Joystick joystick`(虚拟摇杆移动)、`attackButton`/`blockButton`(攻击/格挡按钮)、`primaryCooldown`/`secondaryCooldown`(冷却圈)、`maxMinions`(召唤上限);方法 `UnitHasBlockButton()`、`IsFireBall()`(巫师火球判定)。
- **`ArcherControls : Controls`(弓箭手专属子类,旧版唯一特殊 Controls)**:字段 `SCREEN_DIVIDE_RATIO = 0.35`、`LineRenderer pullBackLine`(拉弓弦线)、`startDrawPosition`/`currentPosition`(拖拽起止点)、`isABowDraw`(拉弓中标志,偏移 0x89)、`_power`(拉弓力度,0x8C)、`arrowCam`(箭矢镜头按钮)、`arrow`/`ArrowToFollow()`(镜头跟随箭矢)。
- 拖拽事件:`OnPointerDown`/`OnBeginDrag`/`OnDrag`/`OnDragEnd`/`OnPointerUp`/`UpdatePullBack(startPosition, position)`。

**结论:拖拽拉弓是弓箭手专属交互;其他兵种(剑士/矛士/法师/巨人)走摇杆+攻击键的通用 Controls,无拖拽瞄准。**

## 拉弓力度公式(反汇编 OnDrag @ RVA 0x8B2614 实测)

```
delta = 指针当前位置 - startDrawPosition
若 |delta| > 10:方向符号 = Mathf.Sign(-delta.y)(记录上拖/下拖,决定箭仰角方向)
power = Mathf.Clamp(|delta| × 5 / Screen.width, 0, 1)   // 拖 1/5 屏宽 = 满弓
Archer.DrawBow(power)                                    // 每帧拖拽实时调
OnDragEnd:isABowDraw = false(松手放箭走 Archer.ReleaseAttack)
```

`ArcherControls.Update()` 内有 `Time.timeScale` 操作——瞄准慢放(新版 metadata 的 `SlowMotion` 符号与之对应)。

## Archer 主类(StickWar.Game.Entities.Archer : Unit)

关键字段:`_currentAim`/`_targetAim`(瞄准角插值)、`_startDrawPosition`、`_drawPower`、`_directionToShootArrow`、`isCastleArcher`(城堡弓箭手)、`NumArrowsLaunchedWithoutDamagingATarget`(空箭计数)。

关键方法:`Aim(angle)` / `IsAimed()` / `UpdateAim()`(角度渐进追踪)、`DrawBowGradually(power)`(**AI 渐进拉弓**)、`DrawBow(power)`(玩家拖拽直调)、`CurrentDrawPower()`、`ArrowLaunchVector()` / `ArrowLaunchDirection()` / `ArrowSpawnPosition()` / `SpawnArrow()`、`GetDrawAnimationSpeed(name)`(拉弓动画速度随力度)、`IsReloading()`。

## 轨迹预览点(愤怒的小鸟同款)

`ArcherPredictedArrowPath : MonoBehaviour`:字段 `numberOfPredictionsIntoFuture`(预览点数)、`timeBetweenPredictions`(点间隔)、`dotScale`、`dots: List<SpriteRenderer>`;方法 `UpdateAimPoints(Archer archidonBeingControlled)`(**直接吃被控弓箭手**)、`ProjectilePositionOverTime(startingPosition, startingVelocity, t)`(抛物线采样,按初速+时间推每个点的位置)、`AlphaRatio(r)`(点透明度随距离衰减)、`GetAimingArchidon()`。

## AI 侧附身技能(非玩家单位也会"玩")

## 本项目差距对照(详见与创始人对话,摘要)

1. 弓:本项目附身左键=自动瞄准最近敌人+恒定满弓;原版附身=拖拽定方向+`Clamp(|delta|×5/屏宽,0,1)` 定力度+轨迹点预览+慢放+松手放箭。**弹道层(抛物线/爆头/插箭)已追平,缺的全是输入与预览 UI 层。**
2. 其他兵种:原版就是摇杆+攻击键(+格挡键),本项目 WASD+左键/右键语义等价,**差距不大**;矛士投矛(`ThrowSpear`)本项目未做独立操作。
3. AI 附身技能(Personality.UserControlSkill 三档)、城堡弓箭手(isCastleArcher)为本项目未规划的原版细节。
