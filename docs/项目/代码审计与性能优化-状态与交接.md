## 二、卡顿嫌疑点（初步代码走读，待实测确认）

1. **极光全图逐列绘制**（`stick-world/modules/world/scripts/map/sky_stars.gd:199` `_on_aurora_draw`）：横跨全图 9800px、步进 24px → 每条带约 408 列 × 3 条带 × 2 个 `draw_rect` ≈ **每次重绘 ~2450 条绘图命令**，12Hz 重绘。可见窗仅 ~1300px，绝大多数画在屏外。
2. **星野全量绘制**（同文件 `_draw_starfield`）：380 颗星全画（含屏外），大星再加 2 条 `draw_line`；星星分布在 9800px 宽度上，可见约 5%。
3. **全屏后处理 shader**（`modules/environment/scripts/post_process.gdshader` + `post_process_layer.gd`）：六层采样（分级/天光/炫光 glow+streak+ghost/渐晕/色差），核显上是固定 GPU 开销。
4. **战斗渲染**（已记录于 `docs/项目/待办事项.md` §战斗性能后续）：96v96 每单位 ~30 条 Line2D，核显 2~16 FPS；已有基准 `tests/dev/battle_perf.gd`。此为已知独立瓶颈，不与本轮环境嫌疑混判。
5. 每帧 `RenderingServer.set_default_clear_color`（`environment_system.gd:141`）与多处 `_process` 内 `get_luminance()`/查找节点——量级小，顺带归入帧逻辑分支处理。

### 性能热点清单（按类型分流到性能分支，审计分支不动）

**分支 `agent/perf-env-rendering`（环境渲染，第一优先——当前卡顿主嫌疑）：**
- P0 极光全图逐列 `draw_rect`：9800px/24px 步进 × 3 带 × 2 rect ≈ 每次 ~2450 命令、12Hz（sky_stars.gd `_on_aurora_draw`）→ 只画可见窗 ± 余量（预期 ~20-40× 命令削减）
- P0 星野 380 颗全量画（含屏外）→ 可见窗过滤（`_draw_starfield`；`_process` twinkle 循环可同场加窗过滤）
- P1 ambient_motes 每帧无条件 `queue_redraw`（56 circle/帧昼夜不停）→ 对齐 fireflies 的 30Hz+夜间门控
- P1 AmbientSparkleSpawner 只挂不卸（~300 资源点 × 6 CPUParticles2D 离屏照常 CPU 模拟）→ 出视距离 detach（挂载已廉价）
- P2 TreeYarnBall/RockPainting `_draw` 每笔 new RandomNumberGenerator（树 ~520 笔/团每秒重绘）→ 变体 RNG 预建缓存

**分支 `agent/perf-frame-logic`（恒开每帧浪费，改动小收益稳）：**
- global_hud 每帧 String 拼接 + text 赋值 + add_theme_color_override，零脏检查 → 脏检查（参考 clock_widget 正确做法）
- debug_info_panel 隐藏后仍每帧全实体扫描+重建文本 → `set_process(visible)` + 节流
- hover_indicator 无 hover 也每帧 queue_redraw + 全实体扫描 → 条件重绘/节流
- possess_panel `_process` 面板隐藏也每帧重建信息字符串 → 可见性早退
- build_menu `_on_resource_changed` 隐藏时全量重建列表 → 不可见早退
- main_menu 行走彩蛋每帧 `load()` 纹理 + 路径字符串 → preload 两帧、帧切换才赋值
- zoom_bar 标签每帧无条件写 text → 阈值守卫（对齐自有滑条做法）
- possession_indicator / middle_scroll_overlay 每帧无条件 queue_redraw → 条件化

**分支 `agent/perf-battle-sim`（战斗模拟热循环，有 battle_perf.gd 基准）：**
- behavior_attack `_apply_flank` 每 tick O(n) 质心 × SWORD/SPEAR 默认开 = 96v96 约 27 万次/秒 → 改 `get_alive_allies_of` 缓存列表
- 溃逃/掩体每 tick 全列表 `get_nearest_enemy`（无网格无节流）→ 节流或网格查询
- stickman_entity 每单位每帧 2 次 `get_node_or_null("StatusEffects")` → `_ready` 缓存；分离帧两次邻域查询合并
- arrow_projectile 每帧对目标 `get_node_or_null("Collider")`（箭雨数百次/帧）→ setup 缓存
- procedural_overlay `_rig.get("_current_anim")` 反射读取 → 公共方法；stickman_rig 动画事件键逐帧字符串重建 → 预解析
- battle_instance alive 缓存每帧 filter 产 2 个新数组 → 原地重填；formation_system 每渲染帧全量小队扫描/光环 → 并入 0.5s 节拍
- weapon_mount 宿主死亡后 `_physics_process` 不停机 → 死亡早退
- resource_gen 生成期 O(n²) 株距检查（开局加载帧百万次距离计算）→ cell 桶哈希（一次性成本，最后做）
