# 编辑器工具索引

> 本文档索引所有 `addons/` 和 `tools/` 下的编辑器扩展、命令行工具、@tool 辅助脚本。

> **使用方式**：当用户提到"放置建筑"、"网格标尺"、"烘焙动画"、"代码扫描"等关键词时，先查本表的「关键词反查表」定位脚本，再读脚本头注释获取细节。

| 字段 | 值 |
|---|---|

| 类型 | EditorPlugin（`@tool`） |

### worldgen/ — 世界生成管线（仓库根 `tools/worldgen/`，非 stick-world 内）

> 目录按生成阶段拆分：`l3/`（L3 大陆/地区）· `l2_export/`（L2 网格提取/烘焙 + 全部视图导出）· `l1/`（L1 地块合并/生成）· `legacy/`（早期分形链）· `archive/`（人工调整工具留档）· `experiments/`（河流实验）。output 历史候选图已移出 git（备份在 `tools/worldgen/_backup/`）。

**L3 大陆/地区（`l3/`）**

| 工具 | 用途 | 输入 → 输出 |
|------|------|-------------|
| `l3/fractal_continent.py` | 分形大陆生成（Delaunay 高度合成 + 河流追踪，8192 级） | 大陆蒙版 → 高度场/河流/预览 |
| `l3/region_split.py` | L3 地区划分（watershed 沿地形切分；`--size` 分辨率自适应） | 8192 高度场 + 大陆蒙版 → `regions/region_labels.npy` |

## 维护规则

- **新增工具**：在 `addons/` 或 `tools/` 下新增任何脚本时，**必须同步更新本文档**（添加条目 + 关键词反查表）。
- **常量变更**：`BUILDINGS_DIR`、`CELL_SIZE`、扫描目录等关键常量变更后，同步更新本文档「操作资源」字段。
- **删除工具**：删除脚本时同步删除本文档对应条目。
- **路由入口**：本文档由 [rule.md](../../.trae/rules/rule.md) 的「项目文档导航」表格引用，AI 在用户提到编辑器工具/插件关键词时应优先读本文档。
