# 03 · 主菜单与流程

> 启动到进入游戏的全部屏级界面：主菜单、新游戏、载入屏、读档、制作名单。
> 模板：`main_menu_template.tscn`。

---

## 一、启动流程

```
启动 → BOOT（autoload 初始化/存档索引）→ 主菜单
主菜单 ├ 继续游戏 → 载入屏 → 游戏（读最近槽位；无档则灰置）
       ├ 新游戏   → 确认框（P1 向导）→ 载入屏 → 游戏
       ├ 读取存档 → 读档界面 → 载入屏 → 游戏
       ├ 设置     → 设置界面（与游戏内同一份）
       ├ 制作人员 → 名单页
       ├ 原声带   → 曲目播放器页（§八；与制作人员挤一行的方钮）
       ├ 测试场景 → 测试场景选择面板（开发构建限定）
       └ 退出游戏 → 确认框 → 退出
```

`project.godot` 主场景即 `main_menu.tscn`（启动第一屏），主菜单负责切换到
游戏根（`game_root.tscn`）。

### 2.2 要素表

| 要素 | 说明 | 数据 |
|------|------|------|
| 标题 | 手绘大字（暖白字+深墨描边贴纸感），进场淡入 + 呼吸脉动 | 固定文案 |
| 菜单列 | 纸面按钮数据驱动；新游戏 = PRIMARY 实底琥珀 | `MENU_ITEMS`（加项=加一行） |

| 原声带方钮 | 与「制作人员」挤一行的正方形方钮（图形 = 自绘音符），进曲目播放器页 | `MENU_ITEMS[*].companion` + §八 |
| 测试场景 | 全量场景选择面板（左分类右列表），debug_only | `SCENE_GROUPS` 分组扫描 |
| 右侧临时演示入口 | 精选橱窗便签组，开发构建限定（§2.4） | `DEV_SHORTCUTS` |
| 版本角标 | 右下，暖墨半透明小字 | 版本常量 |
| 背景 | 黄金时刻天空渐变 + 暮色远/近山 + 手绘漂移云 + 飞鸟，鼠标视差 | `MenuBackdrop` |

### 2.3 为什么菜单是居中浮窗不全屏海报

"窗户不是海报"：主菜单本身就是一块浮在世界上的玻璃。P1 计划让背景直接渲染
慢速漂移的战略图（玩家的帝国实景），标题与菜单浮在其上——从打开游戏第一秒
就在强化"这是个活着的世界"。

### 2.4 右侧临时演示入口（开发构建限定）

菜单列右侧贴邻一组「临时演示入口」便签：精选最能展示工作量的场景——
组件全族陈列 / 12v12 大乱斗战场 / 单位动作画廊 / 开发者试玩场。
设计上刻意自述临时：组头小字「随时撤」、纸面半透明降档样式，发布构建整组不建
（与「测试场景」面板同一 debug 门槛）。与「测试场景」面板的分工：面板是全量
索引，这组是精选橱窗。

配套约定：**开发场景统一「ESC → 确认弹窗 → 回主菜单」**——`DevSceneEscape`
autoload（`modules/debug_gui/scripts/dev_scene_escape.gd`，仅 debug 构建生效）
对 `res://tests/dev/` 与界面模板陈列目录生效；ESC 在 `_input` 层拦截（内嵌真实
GameRoot 的场景里 ShortcutGate 会抢 ESC 开暂停菜单，晚层拦截兜不住），
本地 ESC 语义优先让位：有可见 StickWindow 时先关窗、模态栈开着时先退栈；
确认框开着时 ESC 等效取消。

## 四、载入屏

✅ 已实现（`modules/ui_global/scenes/menus/loading_screen.tscn`），主菜单「新游戏/继续/读档」均经它过渡：

| 要素 | 设计 |
|------|------|
| 底 | 纯黑不透明（载入期没有世界可透） |
| 进度 | 中央细进度条（琥珀 fill），`LOAD_SECONDS`(2s) 内 0→100%（视觉过渡） |
| 提示 | 中央轮换提示（`LOADING_TIPS` 数据驱动，加一条=加一行） |

当前为**过渡型载入屏**：同步场景切换下进度是视觉过渡。真正的异步/分阶段进度加载
（含"正在生成地块…"阶段文字、世界生成期 ESC 中止）留待世界生成并行化（阶段 1）。

现有 `SavePanel`（5 槽位列表）已可用，演进到**卡片化**：

```
┌─ 存档槽 1 ────────────────────────┐
│ [缩略图] 帝国历 3 年 · 北境村落      │

| 要素 | 来源 |
|------|------|
| 缩略图 | 存档时截屏（P1，SaveManager 预留写入点） |

## 八、原声带页（曲目播放器）

📐 独立场景 `modules/ui_global/scenes/menus/soundtrack_player.tscn`（`.tscn` 只放居中列，
内容代码装配）。入口 = 主菜单「制作人员」同行的方钮；页内「返回」与 ESC 回主菜单。
背景复用主菜单的 `MenuBackdrop`（同一片天空，见 §2.1）。

版式按曲目播放器的行业惯例：左曲目表、右正在播放（曲名 / 进度 / 走带 / 音量 / 电平表）。

```

│ [返回（ESC）]                       原声带                       │
│                          火柴人帝国模拟 · 全部配乐（原创…）        │
│  ┌── 曲目 ──────────┐ ┌── 正在播放 ────────────────────────────┐│
│  │ 01 原野·序  1:56 │ │ 原野·夜                                ││
│  │ 02 原野·昼  1:47 │ │ B 小调 · 63 BPM · 2:02 · 3 层           ││
│  │ 03 原野·夜  2:02 │ │ 编制　钢琴 · 弦乐 · 钟琴                 ││
│  │ …（清单每首一行）  │ │ 游戏内强度分层　钢琴 → +弦乐 → +钟琴       ││
│  │                  │ │ 0:02 ─────●─────────────────── 2:02    ││
│  │                  │ │   ⏮   ⏯   ⏭   ⟳     音乐音量 ────●──   ││
│  │                  │ │   ▁▂▅▇█▇▅▃▂▁（BGM 总线电平表）           ││
│  └──────────────────┘ └────────────────────────────────────────┘│
│           空格 播放/暂停 · ↑↓ 选曲 · ←→ 上/下一曲 · ESC 返回      │
└───────────────────────────────────────────────────────────────┘
```

### 8.1 要素表

| 要素 | 说明 | 数据 |
|------|------|------|
| 曲目表 | 编号 + 曲名 + 时长；当前曲 ACCENT 琥珀高亮；点击即播 | `MusicDirector.get_track_list()`（= `music_manifest.json`） |
| 正在播放 | 曲名 / 调性·速度·时长·层数 / 编制 / 强度分层（后两项从层明细推出） | 同上 |
| 进度条 | 可拖动 seek；拖动期间不被播放位置回写 | `preview_position()` / `preview_duration()` / `preview_seek()` |
| 走带键 | 上一曲 / 播放暂停 / 下一曲 / 循环开关（默认开） | `start_preview()` / `set_preview_paused()` / `preview_finished` |
| 音乐音量 | 写 `AudioManager.set_volume("bgm")`——与设置面板同一份值、同一写者 | `ConfigManager` `audio/bgm_volume` |
| 电平表 | BGM 总线实时峰值的电平显示（非频谱，§8.2） | `AudioServer.get_bus_peak_volume_left_db` |
| 键盘 | 空格 播放/暂停 · ↑↓ 选曲（在播则同时切曲）· ←→ 上/下一曲 · ESC 返回 | `_unhandled_input` |

### 8.2 为什么这么设计

- **曲目表不另立一份**：清单（`music_manifest.json`）是作曲家与引擎的唯一契约，
  页面直接投影它——加一首曲子界面自动多一行，界面不可能与"实际会放出来的东西"脱钩。
- **页面不自己播音频**：音乐归 `MusicDirector`（预览模式：绕过情境解析、固定满层、
  离场还原，见 [音乐系统 §八](../../技术/架构/音乐系统.md)）；本页只管"点哪首、显示什么"。
  音量走 `AudioManager`，守住"总线音量只有一个写者"。
- **图形自绘而非图标资产**：StickHand 字体不含 ▶ ⏸ ⏮ ⏭ ♪（实测 `has_char` 全 false），
  图标管线也没有对应母题——播放器走带键与音符角标由 `SketchDraw` 矢量自绘
  （`SketchGlyphButton`），不为六个控件级扁平图形去开三渲二管线。
- **电平表不是频谱**：引擎侧没有现成的 FFT 读数，真频谱要往总线上挂
  `AudioEffectSpectrumAnalyzer`——那是 AudioManager 的地盘（总线唯一写者），
  一个菜单页面不该去改音频图，所以只做"总线电平 × 窗函数"的经典电平显示。
- **离场还原**：预览是"过路状态"，`_exit_tree` 调 `MusicDirector.stop_preview()`
  还原入场前在放的曲目（主菜单当前无背景音乐则淡出静音），不留残留状态给玩法场景。
- **默认不自动起播**：进页先高亮第一首、显播放键——与主菜单当前静默的现状一致，
  不让"点进一个页面"突然出声。
