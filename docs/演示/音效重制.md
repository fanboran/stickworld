# 音效重制

> SFX 事件表全量重制：触发侧（事件接线）与资产侧（WAV 库）两侧完成并过客观验收。

- **触发侧**：按音效触发规范把事件全量接入 `audio_manager.gd` 的 `SFX_EVENTS`/`SFX_POLICY`（事件 → 音源 → 播放策略）
- **资产侧**：程序合成 WAV 库重制替换，来源与许可登记在册
- 剩余人耳验收随实机进行

无渲染产物（听感验收）。
