# 经济系统

> **口径来源**：本档按 [`../完整版蓝图.md`](../完整版蓝图.md) §3.3（生产链 × 渐进自动化）与创始人 2026-09-29 口述裁决（**初期高度非市场、市场是建设成果、物流即经济、情报与物流耦合**）全面重写。凡标〔提案/待定〕处为 AI 按行业实践推导的实现方案，未经创始人定稿，不得当作已确认设定引用。实施排期对齐 `DEC-15`：经济整体重做在地图系统重构完成之后（[待办事项-建筑系统.md](../../项目/待办事项-建筑系统.md) 总账 §十）。

## 目的

经济不是一个独立面板，也不是开局就存在的市场。世界起点**高度非市场**——绝大多数聚落自给自足，只有少数商路上存在点对点贸易；**全图统一的大市场是玩家（与 AI 政权）在统一进程中疏通管道（道路、航运、治安、组织）建设出来的成果**。建设完成之后，市场对玩家退为账面数字——玩家经营的是管道，不是价格。

## 玩家体验弧（三阶段）

| 阶段 | 经济形态 | 玩家做什么 |
|---|---|---|
| 一：自给与手操分配 | 无市场——经济的实体是"生产→运输→消耗"的分配问题 | 亲自采集、亲自搬运、逐次下令分配（RTS 式手操，开局手忙脚乱是预期体验） |
| 二：商路贸易 | 点状市场——仅商路连接的据点间存在贸易与价差 | 组织化生产与物流网络成为经济主体；民间商队在商路上逐利 |
| 三：统一大市场 | 网络市场——全图价格联通，宏观可调 | 疏通与维护管道；通过宏观参数间接影响，市场本身退为账面数字 |

即便阶段一，世界也不是死的：商路上有民间贸易在跑，玩家个体期可在 AI 城打工/交易（蓝图 §3.9 公共层）——只是它还不成"市场"，只是点对点的钱货交换。

## 一、模拟因果铁律（经济侧）

- **禁抽象资源 tick 惩罚**：无军饷、无维护费（蓝图 §七已裁决砍除）；养兵维持 = 士兵个体的穿衣与装备损耗
- **进食是可选增益**：食物是吃了改善个体状态与情绪的消耗品（泰拉瑞亚式），不吃无惩罚、不设「食物」资源（2026-09-27 裁决）
- **断供无系统惩罚**：补给断供的后果 = 物/人不在场的物理事实（没箭射不了箭、缺员岗位空置），不存在叠在事实之上的 debuff
- **价格是涌现结果**："不从火星来"——价格由供需与运输成本决定，锚定价由配方树递归推导（见 §五），不是策划拍脑的数

## 二、物流即经济（阶段一/二的主体）

价格机制缺位时，**物流本身就是经济**：

- 生产链三要素（建筑 × 人 × 工具）的产出不会瞬移——每一段移动都是真实的运输劳动（物资靠运，蓝图 §1.4）
- **物流三大消费端**：军队驻扎维持（穿衣/装备损耗/弹药/液态法力）、据点（聚落）维系（建材/工具）、研发系统存在（教育资源与材料）——这三项就是生产链的消耗侧结构
- **分配 = 编制问题**：怎么编排运输计划、怎么分配供给，是组织系统的本职（物流是人事任命：手操个体 → 专人委托 → 运输队 → 部门，见 [06-物流系统.md](06-物流系统.md) §四）
- 物资在产地与消费地之间的**真实在场与不在场**，就是阶段一经济的全部状态——没有价格表可看，有货没货、在哪、多久到，就是全部经济信息

## 三、情报与物流高度耦合

信息也是一种要靠腿运输的货物（[01-组织系统.md](01-组织系统.md) §8.1：情报是需要传递的资源）：

- **情报网骑在物流路网上**——道路、信使、快马既是商路也是情报路；修路 = 物流与情报双收益
- 情报的新鲜度取决于传递速度：后方看到的报表永远是延迟快照
- 经济、物流、情报三系统在架构上是**同一个"物资-信息物理传递层"的三张面孔**，不是三个独立面板——实施时共享路网、载具、传递延迟的底层（架构细化随实施批次落架构文档）

**生产细粒度到工序与个人**：没有黑盒生产——兵器制作由多道工序组成，每道工序之间的物料都要真实的人占用编制去搬运。怎么编排编制、怎么设计建筑，让更少的人用更短的时间造出需要的兵器，是贯穿全程的核心难题；后期玩家可以封装出专司批量组建编制的组织（元层级，见 [01-组织系统.md](01-组织系统.md) §2.3），搭组织才变成"随手一挥"。

## 五、价格机制（阶段二/三的运行规则）〔提案/待定〕

行业实践映射（维多利亚3 / Anno / Kenshi / Distant Worlds 的取舍，详见对话分析与实施时逆向）：

- **市场单元 = 城/据点**：每城一个价格池；政权内**不**设统一市场——地区差价留给运输去抹平，地理差异（偏远物产运不出来 = 穷）由此自然成立
- **价格 = 成本递归锚 + 逐步调价 + 钳制带**：锚定价由配方树递归推导（叶子资源 = 采集工时 + 工具折旧，加工品 = 配方消耗 × 工时），每经济 tick 价格向供需缓动一步（`价格 += k × (需求 − 供给)`），钳制在锚的固定倍数带内防通胀/通缩螺旋
- **民间商队 = 分布式均衡器**：商队逐差价而动（低频决策"哪条线差价最大"），把两地价差抹平到"差价 ≈ 运输成本"为止——修路/开河的经济回报由此自然成立，商队可被劫掠（战略打击点）；商队即组织系统打"商业"标签的 NPC 组织，复用物流与组织系统，不另造机制
- **市场网络生长 = 统一进程的一部分**：商路逐条接通、城逐个入网，全图统一大市场是建设成果的累计；AI 政权同样可以扩张自己的市场网（世界对称）
- **必需品与增益品弹性不同**：装备耗材是硬需求（短缺 = 部队维持不住），战粮类是可选（没人买只是跌价）
- **玩家自身的采购会反噬**：大军采购装备推高价格（战争拉动经济：战争→武器需求↑→铁价↑→挖矿更赚钱→矿工增多）——这是涌现玩法，不做玩家豁免

## 六、模拟分档与时间分频

- **空间分档**（蓝图 §3.4 已裁决）：焦点城实体模拟（村民/建筑/物真实运转）/ 离屏城账面 tick（人口/经济/建军三项）/ 玩家视角切过去升档为实体
- **时间分频**〔提案〕：行为层逐拍（伐木 9/拍）→ 经济 tick 挂游戏日（价格重估/账面结算）→ 战略结算更低频；经济 tick 挂游戏时间不挂渲染帧，暂停即冻结
- **升档不跳变**〔提案，建议补入蓝图 §五质量底线〕：账面城升档为实体后，产出入库量级一致——否则玩家盯着的城一升档数值跳变，等于自曝模拟是假的
- **确定性**：同 seed 同经济轨迹（固定步长 + 固定遍历顺序），读档后世界经济不漂移

## 七、货币与 sink

- 货币存在（雇佣/打工/交易用钱，蓝图 §3.9 追随者三机制之"雇佣"）。账目双轨现状延续：资源 float 台账（仓库级）× 物品实例（个人/容器级），两套账的桥接点是"领取/存回"的就地转移（[10-武器装备与个人库存.md](10-武器装备与个人库存.md) §五）
- **sink 全部落在模拟因果上**：装备耐久损耗与修理（E-4 闭环）、建材、液态法力（施法/附魔/魔法建筑/维持异形单位）、战粮类可选增益品、图章/谱系等收藏向奢侈品——无抽象军饷/维护费
- 税收（阶段三宏观参数）：高税 → 民间投资↓ → 经济活力↓

## 八、AI 政权经济（离屏账面）

- AI 内政 = 账面级三项 tick（人口/经济/建军，蓝图 §3.4 已裁决），不做建筑清单级离屏细算（离屏细算玩家看不见，性价比低）
- W7 开战判定链（打得过 + 够得着 + 内政余量）消费账面经济——开战需要内政余量，这是账面经济的天然消费端
- 〔提案〕"价涨 → 从业者增多"的职业响应：个体换职业的选择器复用 L1 效用轮盘（WB1 架构同款），收入差是一个 weight，饿/安稳/习惯是其它 weight——经济 AI 与战斗 AI 共用同一套效用骨架

## 九、经济循环

```
阶段一：自然资源 →（人+工具 采集）→ 原材料 →（真实运输）→ 消耗端（军队驻扎/据点维系/研发）→ 装备损耗与再造
阶段二：+ 商路点对点贸易（价差 = 套利空间，民间商队逐利）
阶段三：+ 全图价格联通 → 宏观参数（税/管制）→ 民间响应 → 市场退为账面数字
```

## 十、数值与验收口径

- 全部资产数值遵守 GBA 不膨胀口径（[命名与数值口径.md](../命名与数值口径.md) §二）；运行时价格浮点平滑移动、显示取整、配置表维持自然数
- 验收锚点对齐蓝图 §五质量底线"生产链"行：**人真的在建筑里干活、工具真的提升产出、产出真的被消耗——数值 tick 模拟产出 = 占位**
