## 关键决策速查（详表随设计定稿建档）

| 决策 | 结论 |
|---|---|
| 任务范围 | 锁路线图三件套；诉求三项（涌现/情报/头衔）边界外另立任务（AI 推荐默认，可推翻） |
| 逐层指挥深度 | 抽象命令链（command_chain 延迟已就位 + 分解 AI），信使实体另立任务 |
| 预设编制内容 | v1 只建骨架树；GDD [待补充] 的编制数值不硬造 |
| 预设挂接语义 | load_preset 独立根为主；带 parent 时须预设顶层 tier = parent.tier−1（不做层级平移——平移会让「师」落到连级，语义错乱） |
| 双形态预设源 | load_preset 接受 String（查 presets.tres）或 Dictionary（export_as_preset 产物直灌）——为构筑谱系（GDD §6.1 玩家蓝图派生）预留，不新增 API 面 |
| 树 UI 落点 | 独立 OrgPanel 窗口（GDD §5.1 同一面板管所有组织）；FormationPanel 保持战斗侧快捷位不并 |
| 批次1回看推翻项 | 蓝图 id 改语义键 / 补模板字段导出 / Variant 拆双方法（零消费方窗口破坏性升级，不留兼容层）；详架构文档 §1.4、§八 |
| **惩罚/延迟/指挥官三铁律** | ①惩罚来自真实模拟因果（禁 ×1.5 类折扣）；②延迟=传输媒介物理传播（距离÷速度，层级数不直接生延迟）；③指挥官不变量：中间层=某人实际指挥下级指挥官的事实（任命在先节点随之；两排长合成不了元帅）；L1 可 FORMING 招兵；伤亡=唯一空缺（过渡态）→按补位原则自动补位（军衔最高顶上，P0 以指挥属性代理；补上即真指挥官）无人可用才挂起；玩家层级动态（开局≈班长级，"L5=玩家"已撤）；"系统自动填补"系 AI 误设已撤——均创始人 2026-09-11 裁决；详架构文档 §4.2/§4.3/§八 |
