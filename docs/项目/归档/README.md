2. **命名规范**：`原名-YYYY-MM.md`（保留可读原名 + 入档年月）。**禁止**"废弃/过期/old"类后缀——文档的存续状态由本 README 声明，不进文件名。
3. **入档动作**：从原目录移入 + 原引用处改为指向本目录；条目若在待办清单中，同步压缩为摘要行。
