## 设计要点（AI 提案，实施前可微调）

- **随机的是结构与布局，不是美术风格**（死亡细胞判据）：L1 同一文化圈内，seed 决定街区骨架/地标落位/通道走向；材质库与色彩语言全区统一。
- **风格配置层**（CityProfile）：`seed / 尺寸档 / 材质配比（茅草:木:石权重）/ 层高分布（1~3 层概率）/ 建筑密度 / 地标集（铁匠铺区/市场/兵营广场/仓库/码头）/ 城墙 tier`。每城一个 profile → "各有特色"来自配比与地标，不来自换皮。
- **布局骨架生成**：主街走向 → 街区分块 → 功能区锚定（地标先占位，民居填充）→ 出口对接（左/右 ChunkTrigger 与注册表一致）。确定性：同 seed 同城。
- **规模目标**（AI 提案待实测）：家园主城 ≥8192px；L1 其余城按等级 4096~8192。
