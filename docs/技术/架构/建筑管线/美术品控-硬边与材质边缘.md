# 美术品控：硬边、倒角与材质边缘

> **结论先行**：廉价感的三大来源是 ①无倒角的 90° 硬棱（光线切过是一条死线，无高光过渡）②贴图在几何边缘硬切（纹像素质止在棱上，像贴纸）③材质交接处的硬缝（石↔木、墙↔地、屋面↔山墙直接相接一条死线）。业界解法高度一致：**真实几何倒角 + 边缘磨损（curvature 驱动）+ trim/过渡件**。本文把这些落成本管线的硬规则。

## 一、业界方案（2026-09 调研）

| 方案 | 内容 | 出处 |
|---|---|---|
| **真倒角 > 画倒角** | 直接对网格棱做 chamfer（哪怕 1~2 段），让边缘自然接光；比法线贴图里"画"出来的边高级得多。无倒角+手绘边磨是"廉价资产"的典型特征 | Polycount《Using a normal map for beveled edges along with tiling textures》 |
| **Trim sheet 工作流** | 专门制作横向/纵向平铺的"边条贴图"处理开口、边缘、材质交接；大资产靠真倒角 + trim 提细节，避免依赖 4K 烘焙法线 | Beyond Extent《Trimsheets Deep Dive》；Ryan Lopez / Environment Art 101 教程系列 |
| **边缘磨损 = 曲率掩码** | Substance：烘 Curvature map → Edge Wear smart mask 生成棱线磨白/掉漆；Blender：**Bevel 节点（小半径）输出法线与真实法线做 Dot Product 得边掩码**（Pointiness 在低模不可靠，弃用）。注意 **Bevel 节点仅 Cycles 可用**，EEVEE 需 workaround | Blender Manual（Bevel 节点）；Blender Artists 论坛原理帖；3D Secrets《Substance Painter-like Edge Wear in Blender》；Adobe Substance 3D Designer Edge Wear 节点文档 |
| **CS2 / Source 2 观感** | Source 2 为 CS 系引入全套 PBR 材质体系（反照率/金属度/粗糙度 + 材质编辑器）；其硬表面观感"贵"的直接来源是 PBR 标准化 + 高密度材质 + 硬表面普遍的平滑法线/倒角处理（引擎内部流程未公开，此处为公开资料可证部分） | Valve Developer Community（Source 2 材质/工具贴图）；Source 2 Material Editor 教程 |

## 二、本管线落地规则

### 2.1 几何层（治 90° 硬棱）——根子在 Builder 原语

1. **所有可见外棱默认倒角**：半径按物体尺度取档——建筑大件（梁/柱/檐口/窗台）2~3 单位、家具板边 1~1.5、小件道具 0.5~1。Blender 落地：Builder 的 box/柱原语加 bevel 参数，或装配完成后挂 `Bevel` modifier（segments=1~2，按边角阈值 >30° 只倒可见棱）。
2. **20° 俯视的棱优先**：顶面↔立面的转折（檐口、窗台板、台阶、垛口、女儿墙）是高光带主要来源，必须倒角；完全背光的棱可省（面数纪律）。
3. **墙面↔地面交角**不用几何倒角，用接地 AO 暗带（已有 contact_shadow 体系），交角再叠一条 2~4 单位的脏污收边。

### 2.2 材质层（治贴图边缘硬切）——EEVEE 可用的边缘磨损

4. **倒角面打标记、材质读标记**：建模时给 bevel 面写入几何属性（如 `edge=1`），材质树里用 Attribute 节点读取，在倒角带混入"磨白层"：木质→浅木色、抹灰→露砖/石、铁→金属亮边、漆面→掉漆见底。这是 EEVEE 下替代 Cycles Bevel 节点的可靠做法。
5. **贴图不跨棱硬切**：长条材质（木梁、屋面板、檐板）UV 沿长度流动，端头必须有封端——木梁端面年轮、砖砌端头收边、屋面板端头瓦当；石墙到转角用收边石/隅石（quoin 已有，扩到所有石墙转角）。
6. **材质交接必须有过渡件**：石↔木（披水板/压条）、屋面↔山墙（泛水，已有 chimney 同款做法推广）、墙↔地（砂浆珠/护墙板/溅泥带）。**禁止两种材质直接相交一条死线。**

### 2.3 贴图层（治平铺重复与接缝）

7. 与地面贴图同规则推广到墙面/屋面材质：**多变体 + 做旧 decal + 低频大尺度斑驳**，破坏周期感（地面批次已在做，见 `ground_tiles.py` 任务）。

### 2.4 验收门禁（新增）

- **棱线高光检查图**：强侧光特写下，所有可见棱必须呈现"亮→暗"的高光渐变带，出现死线即打回；
- **1x 可见性**：倒角带与磨白层在游戏 1px/单位尺度下 ≥1px 可辨，不可见的白做（省面数）；
- **交接缝扫描**：逐栋检查材质交接处是否有过渡件或 AO 缝，裸切即打回。

## 三、实施排期（对接建筑管线 v3）

1. Builder 原语加 bevel（几何层一次性收益，全部装配器继承）；
2. 倒角面属性标记 + materials.py 加"磨白层"mix（EEVEE 可用）；
3. 端头封端与过渡件补齐（buildings.py 各装配器 + props.py）；
4. 产出棱线高光检查图过门禁。
