## 一、视觉哲学

### 1.0 手绘涂鸦是全局唯一皮肤

主菜单、载入屏与游戏内全部 UI（HUD/弹窗/面板/按钮/进度条/分隔线）统一走
**手绘涂鸦皮肤**（主菜单已实装：`StickTheme.create()` 默认 SKETCH）：
贴图烘焙控件（`modules/ui_global/scripts/sketch/` 控件族挂 `assets/ui/sketch/`
沸腾帧贴图）+ StickHand 程序化手写字体。Theme 层留 Flat 玻璃 StyleBox
（GlassStyle）兜底未自绘的原生控件（TabContainer/HSlider 等）。

**亮背景的形态规则**：白描边贴图（`BORDER` 系）只保证在深底上可见；浮在
亮背景（如主菜单暖金天空）上的控件换**墨线形态**——
- 次级按钮：`SketchButton.ink_skin`（奶油纸底 + 深墨描边贴图，"纸签"感）；
- 主行动点：`ButtonKind.PRIMARY`（实底琥珀 + 深墨描边，黑字）——14% 琥珀底
  只在黑玻璃上可读，亮底上强调色必须实体化（§1.5 同纪律）。
墨色与血条 `COLOR_OUTLINE` 同源："血条亮世界黑墨线"的同一思路。

文字统一 **StickHand**（`tools/fonts/gen_hand_font.py` 产）：以站酷快乐体
（开源可商用，马克笔等粗手绘风）为骨架，字形轮廓点做确定性小幅高斯扰动 +
微倾斜——每个字"定型地微微不一样"，笔画等粗可读性高，矢量无损、布局零漂移；
改扰动风格 = 改管线脚本重跑，不手改产物。

### 1.1 窗户不是海报

界面是一块**纯黑半透明的玻璃窗**：游戏画面从面板底下透出来，玩家永远不"离开"世界。
参考《僵尸毁灭工程》——面板没有海报式的美术底图，只有黑底、细描边、文字。
模态（弹窗/确认框）打开时，遮罩（GenerativeBackdrop）**一体绘制**：全屏压暗打底，
叠加均匀排布的旋转**圆角立方体**网格（低透明白、带 3D 挤出感的顶面）+ 鼠标靠近排斥
（立方体被推开），为玻璃窗添一点"活的"质感。

**为什么**：
- 本作是"无缝缩放"游戏，玩家在 Micro↔Strategic 间连续滑动，界面若是不透明海报，
  每次开合都是一次"出戏"；玻璃窗让观察与操作同时成立。
- 世界观：火柴人本身是黑色的，黑是世界观底色，黑底 UI 是天然延续而非风格选择。

### 1.2 一个强调色

全套 UI 只有**一个强调色：琥珀**（火光色）。用于且仅用于：

| 用途 | 例子 |
|------|------|
| 主行动点 | 新游戏 / 确定 / 应用 |
| 选中态/激活态 | 当前标签页、当前速度档、选中列表项 |
| 关键数值 | 资源图标、摘要统计数字 |

危险（红）、警告（黄）、信息（蓝）、成功（绿）是**语义色**，只出现在反馈场景
（通知、删除按钮、不足提示），不参与装饰。强调色滥发会导致玩家无法一眼找到"该点哪"。

### 1.3 信息密度服从层级

- 微观层级（L1/L2）：UI 稀疏、字大、只显示个体相关信息
- 宏观层级（L4/L5）：UI 密集、字小、允许报表式排布
- 快捷栏等"操作区"鼓励**密集堆叠**（《博德之门3》技能栏式满足感）

### 1.4 手绘涂鸦层（游戏内主视觉）

游戏内一切面板/按钮的底与描边由**自绘控件**承担，与血条
`HealthBarIndicator` 完全同源：同一 `_wobble` 伪噪声公式、同一 0.12s 沸腾
重掷节拍、同款"实心扰动多边形 + 粗马克笔描边"画法。

**控件族**（`modules/ui_global/scripts/sketch/`）：

| 控件 | 替代 | 说明 |
|------|------|------|
| `SketchPanel` | PanelContainer + stylebox | DARK（大弹窗）/ LIGHT（HUD 横条）两档；烘焙沸腾贴图，面板描边用 `BORDER_PANEL` 30% 档、底含 2~3% 纸感噪点（黑场是"材料"不是"没画"） |
| `SketchButton` | Button | 烘焙四态沸腾贴图（NORMAL/ACCENT/PRIMARY/DANGER + ink_skin 纸面形态）；hover 微缩放 1.03 |
| `SketchProgress` | ProgressBar | 手绘轨道 + 填充（相位错开的独立沸腾） |
| `SketchLineEdit` | LineEdit | 凹槽底 + 聚焦琥珀描边 |
| `SketchSeparator` | H/VSeparator | 手绘波浪线 |

**绘制纪律**（烘焙管线，`temp/gen_sketch_ui_a10.py`，技术详见
[手绘贴图烘焙管线](../../技术/教程/手绘贴图烘焙管线.md)）：
- 边框永远在标准圆角矩形位置上，扰动是纯小幅双向摆动（血条质感来源），
  **不做任何系统性内缩**
- wobble 振幅分两档：小件（按钮/凹槽/页签）1.1，**面板 1.8**——0.95~1.1 在
  静态下读作"线画虚了"，面板级要 1.5~2.2 手绘感才不依赖沸腾动画成立
- 角弧半径扰动钳下限防自交（三角化失败的教训）；过小矩形回退普通矩形画法
- 平铺自检三关（形状守卫/接缝跳变/肉眼验收）任何槽位失败即停产

**为什么自绘而不是贴图**：贴图（含 AnimatedTexture）是循环近似，且所有控件共享
同一纹理缺乏"逐个手画"的差异；自绘每控件独立 seed 逐帧随机重掷，是真沸腾——
与血条在同一个世界里的同一种"活"。

### 1.5 比例与紧凑纪律

- **字号跟控件走**：按钮文字 ≥ 控件高的 1/2（32px 按钮 ≥16px 字、44px ≥18px），
  不做"大按钮小字"的空洞感；调控件尺寸时同步审字号比例。
- **对比优先于装饰**：可读性问题优先用加粗（`SketchFonts.bold()` 伪粗）、
  底色对比、字号档位解决；描边/阴影是最后手段（描边让字糊、观感脏）。
- **强调色只上底不上字**：ACCENT 按钮字色 = 白 + 伪粗，区分靠琥珀底
  （14%/hover 26%）；琥珀字在暖背景上不可读，禁止再用。
- **弹窗随内容自适应**：小对话框（确认框等）宽度由文本撑开、紧凑内边距
  （`SketchPanel.compact`），一行内容就一行高度；固定大 min 宽/高是大面板
  （设置/暂停）的特权。

## 二、色彩 Token

### 2.1 基底

| Token | 值 | 用途 |
|-------|-----|------|
| `WINDOW_BG` | 黑 88% 不透明 | 大面板/弹窗底（主窗体） |
| `WINDOW_BG_LIGHT` | 黑 72% 不透明 | HUD 横条/内嵌区块（更透的玻璃） |
| `MODAL_DIM` | 黑 60% 不透明 | 全屏模态遮罩压暗（生成艺术叠加其上，见 §1.1） |
| `GROOVE_BG` | 黑 45% 不透明 | 输入框/滑条凹槽底 |

### 2.2 描边（三级 token）

| Token | 值 | 用途 |
|-------|-----|------|
| `BORDER` | 白 16% 透明 | 分隔线/凹槽等**内部**分隔（最弱档） |
| `BORDER_PANEL` | 白 30% 透明 | 面板/窗体描边——"窗框"必须看得见（16% 在黑底静态近乎隐身） |
| `BORDER_STRONG` | 白 38% 透明 | 悬停/聚焦态（最强档） |

烘焙脚本（`temp/gen_sketch_ui_a10.py`）的配色是本表离线镜像，改 token 同步改脚本。

### 2.3 文字

| Token | 透明度 | 用途 |
|-------|--------|------|
| `TEXT` | 100% | 正文/按钮 |
| `TEXT_DIM` | 55% | 辅助说明 |
| `TEXT_FAINT` | 32% | 占位符/角标 |
| `TEXT_DISABLED` | 25% | 禁用态 |

### 2.4 语义色

| Token | 色 | 纪律 |
|-------|-----|------|
| `ACCENT` | 琥珀 | 唯一强调色，见 §1.2 |
| `DANGER` | 红 | 删除/战败/错误通知 |
| `WARN` | 黄 | 资源不足/警告通知/数量徽标 |
| `INFO` | 蓝 | 信息通知/链接 |
| `SUCCESS` | 绿 | 完工/增益 |

### 2.5 按钮态底色

按钮底色 = 白色叠加：`BTN_BG` 7% / `HOVER` 15% / `PRESSED` 4% / `DISABLED` 3%。
在黑玻璃上叠加白色薄层产生"浮起"感，不引入新色相。

### 2.6 内容色板（纹章/组织标签/图标/点缀）

**内容色 ≠ 操作色**：内容色是"画在画面里的颜色"（纹章填色、组织标签色、图标、地图/报表点缀）；操作引导仍只有琥珀一个强调色，内容色不出现在按钮/选中态。

**作用域**：全局**内容色**登记表——纹章/图标/组织标签/背景生成管线取色的唯一来源，也是 3D→滤镜图标管线的 LUT 量化目标；**不是**全屏后处理（世界贴图保持既有色，色板从中派生故天然协调），也不限 UI 局部。

**派生方法（不许先定数量再凑色）**：色板从游戏贴图盘点派生——盘点工具对 assets 资源图标/天空背景/武器装备/地面建筑逐组提取主色，色板只做"黑玻璃上可读"的明度/饱和微调：

| 色族 | 数量 | 来源 |
|------|------|------|
| 草绿 | 4 | 地面草地 `#84b43c`/`#6c9c3c`/`#54843c` |
| 青碧 | 3 | 背景树线/近山 `#3c8484`/`#549cb4`/`#246c54` |
| 天蓝 | 2 | 远山/云 `#6c9ccc` |
| 琥珀棕 | 4 | UI 琥珀同源 + 木建筑/木盾 `#845424`/`#6c3c0c` |
| 土石 | 4 | 资源图标 `#6c543c`/`#9c9c9c`/`#848484` |
| 红 | 2 | 补缺（阵营/战旗）：语义红 DANGER 降饱和压暗 |
| 紫 | 1 | 补缺（色相缺口） |

代码真相源：`StickTokens.CONTENT_PALETTE`（20 色）。按名取色 `StickTokens.content_color(&"moss")` 风格 → `content_color(&"grass")`；按 hash 环取 `content_color_at(i)`。验收图：`temp/palette_review_v2.png`（纹章墙应用示意：受光渐变/三层描边/铆钉/飘带，生成脚本 `temp/gen_palette_review_v2.py`）。扩展时按同方法（先盘点后派生、标注来源），数量由色族自然决定。

## 四、形状与间距

| Token | 值 | 说明 |
|-------|-----|------|
| `RADIUS` | 3 | 通用圆角（接近直角的"冷"感） |

## 五、动效

| Token | 值 | 用途 |
|-------|-----|------|
| `T_FADE` | 0.12s | 悬停/渐隐渐显 |
| `T_PANEL` | 0.18s | 面板开合 |
| `T_TOAST` | 3.0s | 通知停留 |

纪律：动效只做**透明度和位移**；例外是按钮 hover 的 **1.03 微缩放**
（"浮起"手感成立，pivot 居中实现干净，幅度上限 1.05——不做弹跳/回弹）。
缩放渐隐渐显（连续缩放时 UI 按层级淡入淡出）是核心动效，见
[04-游戏内HUD](04-游戏内HUD.md) §四。

## 六、图标

图标由**三渲二管线**生产（`tools/icon_pipeline/`，管线与母题库详见
[`../../项目/交接/图标管线与美术升级-进度与交接.md`](../../项目/交接/图标管线与美术升级-进度与交接.md)）：
3D 建模渲染 → LUT 量化到 CONTENT_PALETTE（§2.6）→ 面烘色 cel 分档 + 描边 + 超分，
母题库 73 枚。

| 项 | 规范 |
|----|------|
| 风格 | 彩色（CONTENT_PALETTE 量化），微立体手作感，与黑玻璃/手绘语言同屏 |
| 尺寸 | 64px 基准（管线同出 128/256 档） |
| 取用 | `StickIcons.tex(&"母题名")` 运行时直查 `assets/icons/<名>_64.png`（中文成品名即母题 id）；固定语义走 `StickIcons.semantic(&"res_gold")` 映射 |
| 已接线 | HUD 快捷栏/资源条（模板与正式 ResourceBar）/工作区快速操作按钮；缺图自动回退单字占位/色块，不硬凑 |
| 存放 | `assets/icons/`，命名 `<母题中文名>_64.png`（如 `短剑_64.png`） |
