# 图标清单与缺口

> **是什么**：图标管线成品的全量清单（含定稿状态）+ 游戏 UI 的图标接线点 + 库中尚缺、需要立项制作的母题缺口。任何 UI 处要挂图标，先查本文档；做完接线，回来更新接线表。

## 一、图标库现状

- **来源**：`tools/icon_pipeline/` 三渲二管线（Blender 渲染 → compose 合成），产物 64/128/256 三档 PNG。
- **库存位置**：`stick-world/assets/icons/<中文母题名>_<尺寸>.png`。
- **运行时取图**：`StickIcons.tex(&"母题名")`（`modules/ui_global/scripts/theme/stick_icons.gd`）——跨模块固定语义走其 `SEMANTIC` 表，场景级映射写在各使用处的数据表里。
- **总量**：73 枚 = 67 枚母题注册表（`motifs.py`）+ 锻造锤 + 5 枚基本体（立方体/正球/圆柱/圆锥/圆环）。

## 三、UI 接线点（现况）

| 位置 | 条目 | 母题 |
|---|---|---|
| 全局 HUD 设置按钮 | 设置 | 齿轮 |
| 主菜单 | 继续游戏 / 新游戏 / 读取存档 / 设置 / 测试场景 | 卷轴 / 旗帜 / 两本书 / 齿轮 / 立方体 |
| 设置面板（左分类列） | 游戏 / 画面 / 音频 / 控制 / 调试 | 罗盘 / 望远镜 / 哨子 / 按按钮小手 / 放大镜 |
| 暂停菜单 | 继续游戏 / 设置 / 存档管理 | 卷轴 / 齿轮 / 两本书 |
| 暂停菜单·功能 | 总览报表 / 物流网络 / 成就 | 账本 / 手推车 / 奖章 |
| 任务卡（QuestPanel 标题） | 阶段目标 | 卷轴 |
| 资源条（StickIcons.SEMANTIC） | 黄金 / 石料 / 铁矿 / 木材 | 金币 / 矿石 / 铁砧 / 板条箱 |
| 资源条（SEMANTIC 提案/待定） | 钻石 | 立方体（暂顶替，待补钻石母题） |
| 模板陈列（workspace/hud_template） | 工作区操作 / 快捷栏 | 各处数据表映射 |

接线规范：按钮 `btn.icon = StickIcons.tex(&"母题名")` + `icon_max_width` 压尺寸（按钮 18~22px）；TextureRect 用 18px KEEP_ASPECT_CENTERED。母题名即文件名，不加尺寸后缀。

## 四、缺口清单（需要制作的新母题）

| 缺口 | 影响位置 | 建议母题方向 |
|---|---|---|
| 退出/关闭类 | 主菜单「退出游戏」 | 门 / 电源开关 / 帐篷收起 |
| 科技树 | 暂停菜单「科技树」 | 树苗 / 分支结构 |
| 钻石 | 资源条 res_diamond（现以立方体顶替） | 刻面宝石 |

新母题制作流程：`motifs.py` 注册 build 函数 → `gen_motifs.py` 渲染 → `compose_icon_small_ui.py` 合成 → 网页验收 → 定稿入库。注册表与 compose 的 TAGS 同源，`accept_sheet.py`/`review_server.py` 自动带上新枚。
