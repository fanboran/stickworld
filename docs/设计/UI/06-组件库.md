# 06 · 组件库

> 标准组件清单与用法。组件的样式全部来自主题层（StickTheme），
> 装配全部走工厂（StickKit）。陈列与回归自检页：`component_gallery.tscn`
> （改任何 token 后打开它目检一遍即完成回归）。

---

## 一、分层结构

```
StickTokens（常量）→ StickStyle（StyleBox 工厂）→ StickTheme（Theme 打包）
                                                        │
StickKit（控件工厂）── 组装带语义的控件 ─────────────────┘（控件从 Theme 继承样式）
```

- **Token 层**：只放常量，不知道控件存在
- **Style 层**：StyleBoxFlat 工厂（窗体/按钮族/标签页/进度条/分隔线）
- **Theme 层**：把样式+字号+颜色打包成 Theme，挂任意根节点整树生效
- **Kit 层**：带语义的控件工厂（label 档位/button 变体/section/toast/confirm）

## 二、组件清单

### 2.1 基础控件（主题直接覆盖）

| 控件 | 主题钩子 | 说明 |
|------|---------|------|
| Button | normal/hover/pressed/disabled + 字色 | 标准按钮族 |
| Label | font_color/font_size | 默认 BODY 档 |
| Panel/PanelContainer | panel → 黑玻璃窗体 | 一切面板的底 |
| LineEdit | groove 底 + 琥珀聚焦描边 + 琥珀光标 | 文本输入 |
| OptionButton | 复用按钮族 | 下拉选择 |
| CheckBox/CheckButton | 字色 | 开关（图形暂引擎默认） |
| HSlider | groove 槽 + 琥珀滑块 | 数值滑条 |
| ProgressBar | groove 底 + 琥珀 fill | 进度条 |
| TabContainer | 选中=琥珀底光+2px 底条 | 标签页 |
| ItemList | 黑玻璃底 + 琥珀选中 | 列表 |
| HSeparator/VSeparator | 白 16% 细线 | 分隔线 |
| TooltipPanel/Label | 黑玻璃 + HINT | 提示框 |

### 2.2 Kit 语义组件

| 工厂方法 | 说明 |
|---------|------|
| `StickKit.label(parent, text, kind)` | 五档标签：TITLE/SECTION/BODY/HINT/TINY |
| `StickKit.button(parent, text, cb, kind, h)` | 三变体：NORMAL/ACCENT/DANGER × 三高度 26/32/44 |
| `StickKit.section(parent, title)` | 带琥珀小标题的 VBox 区块 |
| `StickKit.row(parent, sep)` | 横向行容器 |
| `StickKit.field_row(parent, name, hint)` | 设置页键值行（左名右控件位） |
| `StickKit.separator(parent)` | 水平分隔线 |
| `StickKit.toast(layer, text, kind)` | 自动淡出的即时反馈条 |
| `StickKit.confirm(layer, ...)` | 模态确认框（见 05 §三） |

## 三、数据驱动装配模式

组件库支撑的**核心模式**：界面内容 = 数据表，工厂按表装配。

```gdscript
# 加一项设置 = 加一行（settings_template SETTINGS_SCHEMA）
{"key": "ui_scale", "label": "界面缩放", "type": "slider",
    "min": 75, "max": 150, "step": 5, "default": 100},
```

已落地的 schema：菜单项（MENU_ITEMS）、设置（SETTINGS_SCHEMA）、
工作区（WORKSPACES）、快捷栏（QUICK_SLOTS）、资源槽（RESOURCES）、
模板清单（TEMPLATES）。新界面默认先问一句：**内容能不能是一张表？**

## 四、添加新组件的流程

1. 判断层级：纯样式差异 → 加 token/StyleBox；新交互控件 → 加 Kit 工厂
2. 工厂方法只依赖 token，不写死字面量
3. 在 `component_gallery.tscn` 对应分组陈列（加一组 = SECTIONS 加一行 id + 一个构建函数）
4. 在本篇 §二表格登记
