## 二、两条必须知道的实测结论

探针留在 `stick-world/tests/dev/`，可重跑（**用带窗口模式**，headless 下音频不推进）：

1. **`tests/dev/audio_pause_probe.tscn`：引擎不会随 `SceneTree.paused` 停音频。**
   暂停 0.6s 期间播放位置推进 **+0.607s**；`process_mode` 为 INHERIT 或 ALWAYS 无差别；
   `AudioStreamPlayer2D` 同样。⇒ "暂停时雨声还在响"是**真问题**，必须显式 `stream_paused`。
2. **`tests/dev/audio_2d_probe.tscn`：只要场景里有 `Camera2D` 就有距离衰减，不需要 `Listener2D`。**
   但**监听点是"屏幕中心"，不是相机节点**（把相机挪到原点 + `FIXED_TOP_LEFT` 后，发声仍以
   屏幕中心为原点）。距离扫描（`max_distance=1000`、`attenuation=1.0`）：
   `0px −16.4dB / 200px −17.9 / 500px −21.3 / 800px −28.7 / 990px −54.4 / ≥1001px 完全静音`。
   ⇒ 半径必须跟着可视范围走：本机 `ZOOM_MIN 0.5` 时半对角线 2203px、`ZOOM_MAX 2.0` 时 550px，
   写死一个值必然在某一端出错。已实现为相机推送"半对角线 × 1.05"（夹在 400~4000px）。

## 四、下一步（按优先级）

1. **资产落盘后必须跑一次编辑器导入**（`bash stick-world/tools/check_godot_errors.sh` 会做
   `--editor --quit`）。原因：`play_event` 用 `ResourceLoader.exists()` 判断变体是否存在，
   **新落盘的 wav 在没有 `.import` 之前一律被判为"缺失"→ 静默丢音**（覆盖旧文件不受影响，
   新文件 `unit_hurt_a/b/c`、`ui_denied`、`victory_fanfare` 必须导入）。
   导入后用 `test_sfx_policy` 的"资产对账"输出核对：应当**没有**"全部变体缺失"的事件。
2. 素材替换销账：`docs/项目/素材替换清单.md` 的 Terraria/SWL 条目全部改为"已替换"，
   并核对"无孤儿资产"（每条 wav 都在某张表里可达）。
3. 观感验收（**只有人能做**）：
   - 战斗里"一片痛叫"是否变回"有兵器声"（附身单位与非代理档应当有声）；
   - 采集/受击的密度是否从"机关枪顿挫"变成"很多人"；
   - 空间化：把镜头拉到战场一端，另一端的声音是否明显更轻/听不见；缩放拉远后
     **看得见的**单位是否仍听得清（这是半径自适应要保的那条）；
   - 暂停时是否彻底安静（只留音乐）、恢复后雨声是否无缝接回；
   - `SPATIAL_ATTENUATION = 1.5` 的衰减陡峭度是否合适（【提案/待定】）。
4. 未做的三件（详见规范 §12.2）：`attack_bow`/`attack_pickaxe` 的 `Sound` 数据（须与 Spine
   重导流程一起做，手改会被重导覆盖）；BGM 侧链压缩机（约 5 行，需听感定参）；
   小兵代理档的发声链 / 战斗氛围层（碰 crowd/sim 热路径，单独立项）。
5. 收线：全量测试 + 报错自检干净 → 合并 `agent/music-overhaul` 进 `main`（音乐与音效同一分支）。
