- [ ] **箭矢 AMMO 品类+弓耗弹**：ItemDef.ammo_id 字段预留（设计文档 10 §4 弹药接线，Demo 期默认免弹）——箭进背包（堆叠 50）、射击扣弹、翻包掉箭束；为投矛/法术消耗铺路的"弹药进 items 域"首个样板
- [ ] **掉落个体化**：翻包式掉落已改向落地（尸体遗物容器+ContainerScreen 翻检，2026-09-20）；余项 = 死亡掉落的**个体化**（按个体 loadout/背包生成遗物，现按 weapon_type 反查生成）——依赖个体背包（E-4）
- [ ] **个体背包/给 NPC 发装备 + loadout 消费**：items 域与 loadout 结构就位但**无人写入**（仅读档回填）——三步兑现"每个火柴人都有独立记录"：spawn 按兵种生成 loadout / 战前给特定队伍配发更好装备 / 死亡掉落按 loadout 生成；NPC 侧库存是物流量级的事，随 E-4 经济闭环批次（E-0~E-4 分期蓝本：[武器装备与个人库存.md](../../技术/架构/武器装备与个人库存.md) §十）
