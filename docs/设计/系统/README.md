# 系统设计文档

> `docs/设计/系统/` 目录导读：逐系统的机制设计（是什么/做什么/为什么）——GDD §六逐系统简述的展开篇。
> 实现方案（怎么做）在 `docs/技术/`；逐系统实施状态对账在 [`技术/架构/数据与契约/模块依赖关系.md`](../../技术/架构/数据与契约/模块依赖关系.md)。

## 序列说明

- `01~13`：正编序列（与 GDD §六的系统清单对应），编号即建册顺序。
- `14~16`：后补定档——`14-背包与装备系统` 为已定稿系统；`15-建筑功能规格`、`16-聚落等级与建筑分级` 为**提案/待定**（分别挂 DEC-14 决策闸门与创始人圈选），编号≠定稿。
