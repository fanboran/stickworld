# 烘焙资产总账（Blender 烘焙域全状态）

Blender 离线烘焙资产的**总账**：烘出的、失联的、备妥未烘的、明确不烘的，四态全登记。与同目录另两册分工——《[建筑资产清单.md](建筑资产清单.md)》登记管线**能力**（代码能产什么），《[建筑管线v3-烘焙导出与游戏接入.md](建筑管线v3-烘焙导出与游戏接入.md)》登记**契约**（四件套/锚点/入库规范），本册登记**资产实态**（哪个 def 哪个档到了哪一步）。优化建筑系统时按态查册、按态处置。

**生成基准**：main `0f43a7dc` 代码 + 2026-09-16 磁盘点验；"备妥未烘"一节由装配器 `*_TIERS` 表与卡片集程序化比对得出（非手抄）。产物多在 gitignored `temp/`，随时可被收线清掉——重跑命令随节附上。

## 一、状态口径

| 态 | 定义 | 处置动作 |
|---|---|---|
| 在役已烘 | 产物在盘且被运行时消费 | 直接入库/消费 |
| 已烘失联 | 烘过、磁盘已清；契约与烘焙器仍在 | 重跑再生成 |
| 备妥未烘 | 装配器/预制件/定尺齐备，未烘或未导出 | 按需补烘 |
| 明确不烘 | 设计上不走烘焙路径 | 登记在案，免反复当缺口排查 |

## 六、优化切入点索引（提案/待定）

- **烘焙资产正式入库**：卡片集本体在 gitignored `temp/`、兜底在 `tests/dev/`（测试夹具语义），`assets/` 无入库位；两条路径（proto25d 卡 / bake 四件套）都需按契约文档 §四 落正式入库与 `verify.OK` 门禁。
