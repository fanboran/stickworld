## 0. 红线（本会话用惨痛教训换来的，违反任何一条都会立即失去用户信任）

1. **用户指令范围外的一个参数、一行实现都不许改。** 本会话四次翻车全部源于
   "顺手改动"：改粗细时动了笔长和密度、重写时把枝简化成超粗双线、加颜色随机
   冲淡了明暗层次、改布局时动了相机没验证。用户原话："你不要再瞎几把改了"。
2. **"恢复"必须精确回到用户指定的版本，不许"近似重实现"。** 用户说恢复时，
   指的是那个版本的视觉产物；任何重新实现都是新东西，都会有偏差。
3. **每个可回退状态立即 git commit。** 本会话前半程零提交，导致用户要求回退时
   只能靠记忆重写参数（且写错）。用户原话："你这么久一直没有提交你的文件导致
   你回退不回去吗？"
4. **多 AI 并行同一工作区：** 严禁 `git add -A` / `git stash -u`（本会话 stash
   事故差点卷走并行 AI 的工作）。只 add 自己明确负责的文件；报错先甄别归属再认领。
5. **拿不准用户意图就停止并逐字确认**，不要赌。本会话"延长树干"被理解错两次
   （先动了枝叶分布、再放大了树冠），每次都引发用户暴怒。
6. 用户要**实时反馈**（滑条即见效果）、要**过程可视化**（管线各中间态并排展示
   且带文字标记）。Python 拟合单棵 8-10 秒，用户不接受。

## 5. 技术坑速查

- Godot 4：Color 的 HSV 用属性 c.h/.s/.v（无 get_hsv）；lambda 调用 xf.call()；
  min()→minf；Dictionary 值参与 `:=` 推断报 Variant 警告（当错误），
  一律 `: float = float(d["k"])`；屏幕坐标 y 向下（pivot 变换写反曾致整树倒挂）。
- headless 无渲染：SubViewport 烘焙/截图只能真机；check_godot_errors.sh 有
  瞬时误报（缓存竞态，重跑即净）。
- Python：hash() 进程随机化不能当种子；PIL 笔是平头（mona-3 stamp_canvas
  已加圆头）；NumPy 2.0 移除 ndarray.ptp；大批量 replace 必须验证生效
  （旧串不匹配会静默失败）。
- stroke_paint.py：paint(src,dst,total,mask,size,bg,layers,spirals)；
  mask=笔中心硬判定（<0.5 整笔丢），alpha=笔并集；预乘消底仅色距回退路径。
- 外部仓 F:\VSCode\DSH\mona-3\generator.py（用户逆向库，加了圆头+mask 过滤，
  该仓不在本 git）。
