# 乐曲清单（Cue Sheet）

> 本文是音乐资产的**主键表**：一个 cue（乐曲）对应一个游戏状态，一个 `cue_id`
> 对应磁盘上的一个目录。设计意图见 [音乐设计文档.md](音乐设计文档.md)。
>
> 曲名与 cue_id 的对应关系、分层与循环点**由代码生成**（`tools/music/compose/cues.py`
> 与交付的 `music_manifest.json`），本文是它们的可读版本。**改谱面请改代码，
> 不要只手改本文**——两者不一致时以代码与清单为准。

## 二、分层表（tier = 强度档位）

运行时按游戏强度逐层淡入：tier 0 常驻，tier 越大越"热闹"。
同一 cue 的全部层**等长、同循环点、同和声进行**，所以任意组合都能叠加。

| cue_id | tier 0（地基） | tier 1（常规） | tier 2（点亮） |
| --- | --- | --- | --- |
| `menu_title` | piano | strings | — |
| `field_day` | piano | strings | harp, bells |
| `field_day_b` | piano | **harp**, strings | bells |
| `field_night` | piano | strings | bells |
| `village` | piano | guitar | marimba, winds |
| `village_b` | piano | **marimba**, guitar | winds |
| `village_night` | piano | guitar | marimba |
| `interior` | piano | — | — |
| `interior_hall` | piano | strings | bells |
| `strategic` | pad | vibraphone, piano | bells |
| `battle` | piano | strings, perc | winds |
| `battle_b` | piano | strings, perc | winds |
| `battlefield` | piano | strings | winds |
| `sting_*`（四首标点） | 各层均 tier 0（整叠同播，不分档） | — | — |

> 变奏 B 组里**主奏层降一档**（`field_day_b` 的 harp、`village_b` 的 marimba）：在这一版里它是主奏而不是点缀，若仍按基础曲的 tier=2 处理，低强度下整首会没有旋律。
> 标点短句（sting）不分层强度——它们是"事件"，一次播完，四首都是多层整叠（各层音量已在交付件里配平）。

## 四、自适应设计

### 4.1 纵向混音（vertical remixing）

引擎加载同一 cue 的全部层，同时开始播放，用**层音量**表达强度。
层的进入顺序固定为 **钢琴 → +弦乐 → +钟琴**，退出顺序相反。
底层设计保证：**任何一层被静音，其余层仍是完整的音乐**——
这是"层"能自由开关的前提，也是"骨相好"的检验标准。

### 4.2 状态切换（horizontal re-sequencing）

状态切换以**量化到小节**的交叉淡化为默认（详见引擎侧设计）。
循环体之间可直接硬接（和声在 32 小节处闭合，接得回开头），
跨调性/跨速度的切换用交叉淡化。

### 4.3 昼夜

昼夜不换曲，而是切换到**同主题不同调式**的另一首（`field_day` ↔ `field_night`、
`village` ↔ `village_night`）。两者共享同一串音阶级数，玩家听到的是同一段旋律换了心情。

### 4.4 变奏族轮换（长时抗疲劳）

玩家会在同一张图上停留很久、反复进出同一场景，同一首曲子会循环几十遍。
对策是给**听得最多的三个场景**各准备"同源第二版"，运行时按轮换播放：

| 族 | 基础版（主奏） | 变奏版（主奏） | 变的是什么 |
| --- | --- | --- | --- |
| 野外 · 昼 | `field_day`（钢琴） | `field_day_b`（竖琴） | 主奏从钢琴换到竖琴；钢琴退成纯伴奏；钟琴只在收束句 |
| 村落 | `village`（钢琴 + 长笛点缀） | `village_b`（马林巴） | 主奏换到木质打击；吉他更活跃；长笛只收尾 |
| 战斗 | `battle`（钢琴推进） | `battle_b`（弦乐推进） | 推进音型从钢琴换到弦乐；钢琴改为骨架；定音鼓更疏 |

**约束**（运行时轮换无缝的前提，由 `test_music_director` 的"族成员同调同速同长同层名"守住）：
同调性、同 BPM、同循环拍数、**层名一一对应**。
轮换按**进入场景的轮次**（第一次进基础版、第二次进变奏版、第三次又回基础版），
不在循环点上硬切——循环尾巴是折回处理过的，切断会露出接缝。

## 五、交付规范

| 项 | 规格 |
| --- | --- |
| 采样率 | 48000 Hz |
| 声道 | 立体声 |
| 格式（游戏内） | OGG Vorbis，`libvorbis -q:a 6`（约 190kbps） |
| 格式（存档） | 母带 WAV 24bit/48kHz，放 `tools/music/out/master/`（不进版本库） |
| 响度 | 音乐 **-15 ±0.5 LUFS**；sting **-14**（文件按流媒体量级交付，游戏内位置由音量滑条决定） |
| 真峰值 | ≤ -1.0 dBTP |
| 循环信息 | 写在 `music_manifest.json`，加载时赋值给 `AudioStreamOggVorbis` |
| 路径 | `stick-world/assets/audio/bgm/<cue_id>/<layer>.ogg` |
| 清单 | `stick-world/assets/audio/bgm/music_manifest.json` |

`music_manifest.json` 的每条 cue 含：
`title / bpm / bar_beats / bars / beat_count / loop / loop_offset / key /
duration_s / loudness_lufs / layers[]`，其中每个 layer 含
`name / file / tier / db`。
