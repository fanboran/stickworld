## 一、总结论

**设计语言本体不过时，方向是对的且有辨识度；「过时」的是三处文档滞后、四处执行欠账，以及整个主菜单。** 手绘沸腾 + 黑玻璃 + 琥珀唯一强调色的组合在 2026 年仍属前沿 niche（手作感 anti-UI 是当下独立游戏被尊重的差异化路线），纪律本身自洽；但截图里它读作「未完成的原型」而非「克制的风格」——差距全部在执行层，逐条如下。

## 三、文档 vs 代码冲突（文档过时点，须回写）

1. **§1.0「手绘是全局唯一皮肤」是愿景不是现实**：`stick_theme.gd:8-13` 注释与实际行为仍是「SKETCH=游戏内 / GLASS=主菜单载入屏」——主菜单从未迁移。文档宣告了没发生的事，这正是主菜单跑偏的根因。
2. **§三字号表滞后**：代码 2026-09-06 已整体 +1~2（BODY 15/TITLE 24/DISPLAY 36）并新增 `FONT_BANNER 44`、`FONT_HUD 17` 两档，文档表还是旧值且缺这两行。
3. **§六图标章被推翻未更新**：文档写「assets/ui 为空、单色白线性素描 16×16」——图标管线任务已落地 3D 渲染→LUT 量化到 CONTENT_PALETTE 的彩色图标 73 枚（验收工具齐备），单字占位仍是模板现状但规格已完全不同；§六描述的是被否决的旧方案。
4. **§五动效纪律被代码违反**：文档「只做透明度和位移，不做缩放弹跳」vs `stick_kit.gd:96-103` 按钮 hover 缩放 1.03。二选一：删缩放，或修文档（推荐后者——1.03 微缩放手感成立，且 pivot 居中实现干净）。

## 四、执行层观感问题（语言没错，火候不到）

1. **对比度越过了「隐身线」**：`BORDER` 白 16% 在黑 88% 底上，静态看面板边界消失，「窗户」看不见窗框。建议边框分三级 token：分隔线保持 16%、**面板描边提到 28~32%**、悬停 38%（现值）——「细」的纪律保留，「看得见」是底线。
2. **黑场没有材质**：纯黑平底读作「没画」而不是「风格」。建议面板底叠 2~3% 亮度的细噪点（手绘纸感）或四角晕影；空屏背景（设置/陈列这类悬浮大面板场景）启用 §1.1 的 GenerativeBackdrop 或暖黑晕影，让黑是「材料」。
3. **wobble 幅度低于风格可读阈值**：0.95px 的扰动在静态下读作「线画虚了」而非「手绘」。面板级建议 1.5~2.2px（按钮小件可保持 0.95），让手绘感不依赖沸腾动画也成立。
4. **图标层缺位是最大观感缺口**：单字占位（剑/盾/旗…）让所有面板显裸。图标管线 73 枚已验收——**接线进 HUD 快捷栏/资源条/工作区按钮**是把「原型感」变「成品感」单笔收益最大的一步。
5. **面板密度纪律**：设置/工作区内容自适应缩面板，或分区填充；面包屑/辅助文字提一档对比（TEXT_DIM→新中间档）。
