# 遗留参照与功能差距

> **定位**：HD-2D 场景图与旧 2D 地图链路的对照底账。表一列 **HD-2D 尚未覆盖/未接回的功能点**及其旧系统规格出处——对应功能接回 HD-2D 时照规格实现；表二列 **已被替代但保留在库的旧链路**——性质与保留价值，防误删误改。
> HD-2D 运行时系统见 [`HD-2D街景系统.md`](HD-2D街景系统.md)；场景图整体架构见 [`场景与战斗架构.md`](../场景与战斗架构.md)。

## 一、HD-2D 尚未覆盖/未接回的功能点

| 功能点 | 现状 | 规格出处（旧链路代码） |
|---|---|---|
| 村间道路图 | `road_a_b.tscn` 为 2D RoadMap（主街↔村B 旅行链在用） | `modules/world/scripts/map/road_map.gd`（地图结构/两端出口触发器） |
| 守城战 | `siege_battlefield.tscn` 为 2D 守城图（左出回主街）；HD-2D 战场图是开阔野地，不含守城布景/波次敌军 | `modules/world/scripts/map/siege_field.gd`（FIELD 巨墙/巡墙弓手/城门泥路）+ `siege_wall.gd`（TOWN/FIELD 墙形态）+ `siege_director.gd`（波次组织）；出城选项框规格见表二 `siege_gate_prompt.gd` |
| 森林附属图 | `forest_zone.tscn` 为 2D 村图（战场右出可达） | `modules/world/scenes/maps/forest_zone.tscn`（挂 `modules/world/scripts/map/village_map.gd`） |
| 室内系统 | `mega_interior.tscn` 为 2D 图；HD-2D 无室内形态（剖视/可进入两类均未接） | `modules/world/scenes/maps/mega_interior.tscn` + `modules/world/scripts/travel/mega_interior_exit_trigger.gd`；内景前后分层/前墙 alpha 规格在 `modules/building_gen/buildings/building_exterior.gd`、`interior_props.gd` |
| L1 八城邦聚落 | `l1_settlement_00~07.tscn` 全部为 2D 村图（战略图 P5/D1 进城入口） | 场景挂 `modules/world/scripts/map/village_map.gd`；布局产出 `tools/worldgen/l1/settlement_mapgen.py` |
| 建造/建筑设施玩法 | HD-2D 图 `supports_village_facilities()=false`（GameRoot 门控整体跳过）——PlacementGrid 放置/施工/仓库/兵营实体/WorkSlots 均不在 HD-2D 图落地；村民工位靠露天工位（铁砧）兜底 | `modules/construction/scripts/construction_manager.gd`（项目/施工/搬运）+ `modules/world/scripts/placement/placement_grid.gd`（占地网格）+ `modules/building_gen/scripts/building.gd`（WorkSlots/PassageBarrier/建筑存档）+ `modules/town_life/scripts/profession_registry.gd`（"building" 组工位寻位与回退链规格） |
| 招兵 | `recruit_manager` 扫 2D `building_host` 的兵营实体——HD-2D 图无 2D 建筑宿主，链路不可达 | `modules/organization/scripts/recruit_manager.gd`（`find_nearest_barracks`/`BARRACKS_DEF_ID`） |
| 2D 天空/环境演出 | 星野日月极光流星/萤火虫/降雨/远空飞鸟/浮尘/正下方水带只挂 2D 村图；HD-2D 自有程序化天空+漂移云牌+昼夜光照档，星野/天气类无对应物 | `modules/world/scripts/map/` 下 `sky_decor.gd`（视差壳）+ `sky_stars.gd`/`sky_aurora.gd`（星月/极光/流星）+ `sky_birds.gd` + `fireflies.gd` + `weather.gd` + `ambient_motes.gd` + `pond.gd`；挂载点 `village_map.gd` `_mount_sky_decor()` |
| 2D 地形绘制 | 草地纹理/城内遮罩/土路视觉是 2D 图专用（HD-2D 地面走 3D 世界坐标锚定贴图，见 HD-2D街景系统 §三点五） | `modules/world/scripts/map/terrain_renderer.gd` + `modules/world/shaders/ground_band.gdshader` |

> 上表"旧链路"均为**在役系统**（道路/守城/森林/室内/L1 仍可从旅行链或战略图进入）——本表语义是"HD-2D 尚未覆盖的功能点及其规格出处"，不是废弃清单。2D 村图链路（`village_map.gd`/`terrain_renderer.gd`/`initial_buildings_list.gd`/`placement_grid.gd` 等）服务上述在役图，处置随各图 HD-2D 化排期走，不单独立案。

## 二、已被替代但保留的旧链路

| 文件/链路 | 性质 | 规格价值 |
|---|---|---|
| `modules/world/scenes/maps/battlefield.tscn`（注册名 `battlefield_2d`） | 旧 2D 战场图：不进任何旅行链，仅作 dev 空旷演练场 | 战斗/AI 集成测试开机图（`tests/helpers/combat_test_setup.gd`、`tests/integration/test_ai_behaviors.gd` 等经 `GameRoot.boot_map_id_override` 挂入）——2D 空旷图秒级开机的测试基座，战斗测试迁移 HD-2D 前不可动 |
| `modules/world/scripts/map/town_siege.gd` | 无场景挂载（extends VillageMap；原宿主村A 2D 图已删，现无任何场景/活代码引用） | 家园守城布景规格（TOWN 墙门段/地图边界收窄/引路泥带）；处置待裁决 |
| `modules/world/scripts/map/siege_gate_prompt.gd` | 无场景挂载（仅 `town_siege.gd` preload） | 出城选项框规格（征伐/开守城战/出城逛战场/去隔壁地区，经 `expansion.launch_campaign` 出征入口）；处置随守城链归属一并裁决 |
| `tests/dev/proto_25d/`、`tests/dev/proto_hd2d/probe_rig*` | 2.5D/HD-2D 原型与探针（正式实现在 `modules/hd2d/`；proto_hd2d 下的 `bake_props.py`/`bake_nature.py` 是在役烘卡脚本，不属于此列） | `tests/dev/proto_25d/card.gdshader` 为正式卡 shader 的同源底稿（正式版独立改造）；`probe_rig*` 与 `verify_hd2d_*.gd` 是渲染姿态/旅行链的验收入口 |

> **共用件正名（清理旧档时勿波及）**：`resource_gen.gd`（资源分布算法）、`resource_node.gd`（纯逻辑采集点）、`chunk_trigger.gd`（出口触发器）、`environment_system.gd`（game_time 时钟 = HD-2D 昼夜数据源）由 HD-2D 宿主直接消费；`village_map.gd` 系在役服务表一各图——均不是遗留链路。`assets/resources/*_paint_*.png` 现由 `modules/ui_global/scripts/hud/resource_bar.gd` 作资源图标引用，同样在役。
