# HD-2D 角色渲染：描边/血条与抗锯齿

> 关节烘焙路线（`modules/hd2d/scripts/char_rig_3d.gd` → `char_direct_buckets.gd` → `char_joint_atlas.gd`/`char_bar_atlas.gd`）的观感口径文档：四个渲染桶的深度/排序语义、血条 HUD 层裁定、以及全链抗锯齿（AA）分析。观感裁决记录见 `docs/项目/交接/战场观感重构-进度与交接.md`。

## 一、渲染桶与深度语义

角色视觉由四个 3D MultiMesh 桶组成（每 hd2d_world 一份）：

| 桶 | 材质关键语义 | 深度写 | 深度测 | 排序优先级 |
|----|--------------|--------|--------|------------|
| 描边桶 | edge_cutoff 0.5 硬切、白实例色、沿法线垫后 ZB_STROKE | 总是 | 有 | 0 |
| 身体填充桶 | edge_cutoff 0.5 硬切、真色 | 总是 | 有 | 0 |
| 武器/盾桶 | 按纹理分桶、ZB_WEAPON 置前 | 从不 | 有 | 0 |
| 血条图集面片 | **免深度测试（HUD 层）**、priority 10 | 从不 | **无** | 10 |

- 同角色"填充盖描边、只在剪影外轮廓出线"由深度天然实现：填充恒比描边近 ZB_STROKE（`char3d_body_opaque.gdshader` 头注）。跨角色/建筑走真深度（画布 y-sort 的 3D 等价物）。
- **血条＝单位 HUD 层**（创始人裁定）：免深度测试 + 透明排序优先级 10，恒浮于一切单位件之上；条与条之间同优先级仍按 3D 深度排序（前排条盖后排条）。劳作进度条/接管框同批改 HUD 语义（`no_depth_test`）。语义代价：城内单位躲在建筑后血条仍可见——RTS 惯例，可接受。
- 为什么血条不能走真深度：血条面片沿法线只向相机前移 ZB_BAR（0.03 世界单位），而战场接战的行间距是几十世界单位（2D 行距 90px × 0.75 = 67 单位）——前排身体对后排血条是压倒性的深度优势，接战一团就成片吞条。血条是读件不是景片，遮挡语义归 HUD。
- 血条锚点/尺寸现状口径（沿自整卡烘焙时代常数）：锚高 `BAR_H = 136×PX ≈ 5.67` 世界单位 ≈ 2.65 倍角色身高（角色 144 rig px ≈ 2.14），槽宽 120 原生 px ≈ 1.9 倍角色身高——条群整体悬浮在队伍上空、单条比角色宽。**收回头顶贴挂（136×S）＋按 rig 比例缩条**为待裁决项，动前须过目。

## 二、尺度链（AA 分析的底数）

- 相机为正交、26° 俯角；zoom=1 时 1 世界单位 = 1 屏幕像素，1 格 = 24 单位。
- 1 rig px 屏上 = `RIG_SCREEN(0.35625) × zoom` 屏幕像素；角色卡 144 rig px ≈ 51×zoom 屏 px。战场观察档 zoom=0.75 → 角色 ~38px 高。
- 图集对屏幕的 minification：关节图集 2× 超采样后，texel:屏 ≈ 7.5:1（LOD≈2.9，恒吃 2~3 级 mip）；血条槽位同理 ~3× 缩小。
- **核心矛盾：战场档下角色是"深度缩小的小目标"，一切屏上特征都按 ~4× minification 折算**——1 rig px 的特征到屏上只剩 0.27px，落在亚像素预算之外。

## 三、抗锯齿手段矩阵

可见边缘分三类，各自的有效 AA 手段不同：

| 边缘类型 | 例 | 有效手段 |
|----------|----|----------|
| 几何边 | 地面/建筑/天幕 quad 轮廓 | MSAA 3D 4×（工程级 `msaa_3d=2`） |
| alpha 裁边 | 角色/描边/武器/血条的可见轮廓（全是贴图 alpha） | **MSAA 无效**（fragment 结果按像素复制，discard 边缘锯齿照旧）→ 唯一正解 = mip 链 + alpha 坡道 |
| 2D 画布矢量边 | 飘字底框、调试框 | hd2d_world 进树期间视口 msaa_2d 被 post 层关掉（整屏拷贝的历史教训）；文字有字体级 AA 不受影响 |

### alpha 裁边链的既定口径

1. **关节图集**（身体/描边）：引擎画布光栅化器 2× 超采样烘焙 → RGB 白化（防 mip 混入透明黑垫致外缘发暗）→ `generate_mipmaps()` → `filter_linear_mipmap` 采样 → `edge_cutoff=0.5` 等覆盖率硬切。0.5 切在等覆盖率线上：内边界 crisp，mip 摊开后存活的残余坡宽 ~1 屏 px，即恰到好处的 AA；更软的阈值会让 mip 裙边全留着（实测 4~14px 白糊）。
2. **武器贴图**：导入管线自带 mip + shader 默认 `filter_linear_mipmap`。
3. **血条图集**：回读纹理同样带 mip 链（回读时 `generate_mipmaps()`）+ `filter_linear_mipmap`；UV 内缩垫 8px（LOD2 足迹 4px，防低级 mip 吃邻槽）。无 mip 的细横条在 ~3× 缩小下闪断/爬行。

### 亚像素特征预算（描边宽的定档依据）

描边环带屏上宽 = `2 × eff × RIG_SCREEN × zoom`。环带经 mip 均值后 alpha 被摊薄，低于 edge_cutoff 即碎裂消失——**环带必须 ≥2 屏 px 才吃得住战场档缩小**：

- `OUTLINE_SCREEN_PX = 1.0`：屏宽下限口径（zoom 0.75 实测环 ~1.9px）。
- `OUTLINE_WIDTH_RIG = 1.5`：特写世界宽锚（zoom 拉近后以 rig 世界宽为准，不随屏宽下限膨胀）。
- 描边宽档随相机缩放 0.5 rig px 量化换档，换档异步重烘图集（旧贴图原子换新，`_watch_stroke_eff` 监视）。

## 四、post 链对边缘的染色（实测金/青镶边的来源）

3D 链本身是干净的——`STICK_HD2D_STAGE=b`（跳过 post/辉光/DOF 的诊断档）实测头部边缘过渡：草地 → 白坡（233,236,186）→ 灰（145,151,161）→ 墨（45,42,45），教科书级 AA。全效档（stage c）同一位置变成金（222,170,37）→ 黄白 → 青 → 蓝（88,160,232）的彩虹缘。A/B 二分实证：**彩虹镶边 = 后处理链的产物**，机制是辉光（softlight 混合、bloom 0.10）与分离调色（冷阴影/暖高光）逐通道作用在 ~1px 的 AA 坡上——softlight 压通道时值越低压得越多，草地上白坡的 B 通道被压最狠 → 偏金；墨侧暗部吃冷阴影 → 偏蓝紫。白描边环芯在全效档实测也是 (255,255,120) 级的暖白，非纯白。

这是"HD-2D 电影感"（辉光/分级是既定验收口径）与"边缘纯净度"的耦合代价：观感裁决若要边缘纯净，旋钮在 `_apply_light` 的 `glow_bloom`/`glow_intensity` 与 post 的 `saturation`/`split`——调低即退彩，动的是全局画面风格，归观感裁决管。

## 五、已知残余与时域混叠（接受项）

- **血条内容 15Hz**：`get_image()` 是 GPU→CPU 同步停顿（48 档实测 8~10ms/次），回读节拍 15Hz——面片位置 60fps 跟手，但条的**内容**（血量变化/受击抖动）以 15Hz 步进，相机横摇时有轻微滞后感。既定成本取舍。
- **2D 画布 MSAA 缺席**：post 层在树期间 msaa_2d 关闭，2D 矢量特效边无 AA。影响限于装饰性特效，恢复 msaa_2d 会让 post 通道出彩散（历史实测），维持关闭。
- **战场关远焦模糊**：DOF blur 在非战场景掩盖远处锯齿，战场为构图契约关闭（半屏地面无远焦语义）——远排单位的 alpha 锯齿靠 mip 链独立兜底。
- **26° 纵深压缩**（sin≈0.44）：地面纵深压到屏上不足半高，行与行屏上叠得狠——这是"挤"的观感来源，归分离半径管（战场超级大椭圆 56/220），不是 AA 问题。

## 六、渲染链诊断口（工位）

| 开关 | 作用 |
|------|------|
| `STICK_HD2D_STAGE=a/b` | 静默启动时跳过后处理/辉光/DOF（b = 有角色无 post），渲染链 A/B 二分 |
| `STICK_DUMP_ATLAS=1` | 关节图集烘焙后整图落盘 `user://atlas_dump_*.png`（RGB 纯白性验证用） |
| `STICK_TRACE_PARTS=1` | 部件搬运 trace（图集版本/格位/游标/描边实例色/tint） |
| `STICK_TRACE_ATLAS=1` / `STICK_TRACE_WRITE=1` | 图集重烘 trace / 桶跳写塌陷 trace |
| `STICK_SUN_SHADOW=0` | 关实时太阳阴影（shadow pass 成本对照） |
