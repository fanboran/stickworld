## 三、按键绑定页（P1）

- 表格式：动作名 | 主绑定 | 副绑定 | [重置]
- 点绑定格进入"按任意键"捕获态（ESC 取消捕获）
- 数据源：`InputMap`；冲突时两格同时标红
- 内置动作清单沿用现有 InputMap action，新增动作须先注册再进表

---

## 四、无障碍页（P1 预留）

| 项 | 说明 |
|----|------|
| 字号缩放 | 独立于界面缩放的纯文字放大（theme font_size 全局系数） |
| 高对比描边 | BORDER 16%→40%，照顾低视力 |
| 色弱模式 | 语义色改形状+色双编码（warn 加▲、error 加✚） |
| 减少动效 | T_FADE/T_PANEL → 0 |

## 五、交互规范

| 行为 | 规则 |
|------|------|
| 即时生效项 | 改动直接写 ConfigManager（音量/开关类） |
| 应用生效项 | 进"待应用"暂存，点【应用】统一落盘（窗口模式/界面缩放） |
| 恢复默认 | 重置当前分类（弹普通确认框） |
| ESC | 有待应用改动 → 弹"放弃修改？"确认框；无 → 直接关闭 |
| 打开时机 | 主菜单与游戏内同一份界面（游戏内经 ESC/齿轮，打开即暂停） |
