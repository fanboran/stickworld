## 二、文档清单（按性质）

**核心架构（长期维护）**：场景与战斗架构.md（含 场景与战斗/ 子目录六篇）、模块依赖关系.md、模块API契约.md、系统交互与EventBus.md、核心实体与状态机.md、自动加载依赖.md、数据流全景.md、存储架构设计.md、平衡框架.md。

**专项架构（垂直域，随对应任务演进）**：战略图架构.md、世界地图数据流.md、建筑模块化设计.md、出征与领地架构.md、火柴人战斗系统设计.md。

**调研报告（决策前置，拍板后归档或并入正式文档）**：寻路避障调研.md。

## 三、维护约定

1. **新架构文档进本目录须在本 README 登记**（清单加一行 + 场景表按需加行）。
2. 每份文档头部标注**状态**（如：设计基线 / 部分实装 / 调研报告）与**关联文档**——既有惯例，新文档延续。
3. 摘要迁移模式：modules/README.md 承载模块视角速查（依赖图/数据流/autoload 摘要），架构目录承载深度细节；两边定位重叠时以"摘要指向正文"处理，不双写。
4. 调研报告类拍板后：结论并入对应正式文档，原报告删除（同"审计快照用完即删"约定）。
