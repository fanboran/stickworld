## 二、血泪裁决清单（已毙设计，一个都不许复活）

1. **建筑是实例、按座计**：不出现"某类型建筑"的整体状态（未建✓/数量×N 标记）；软装逐座配
2. **设备解锁看本组织所驻那座**（组织↔建筑实例绑定），不蹭全城
3. **机构由构筑产生**：没有"塞已有组织/搬塞"操作；构筑＝选中空槽出候选（构筑树＝选择题，可递归）
4. **效果只走物理因果**：工具（工具架）、载具（手推车）、鼓风（风箱→炉温→熔炼）、状态（兵役制）可以；**抽象乘数 buff 一律禁止**（修路+10% 这类）；无依据的"加速/衰减"数值不许编
5. **命名**：城市级用 局/中心/队/坊/所/营；不用"xx部"（国家级）、游戏内不出现"xx组织"称呼；无行政槽（市政厅本身即行政）；领导槽＝市长
6. **不设「食物」资源**：进食是可选增益、无饥饿惩罚（05 §一）；耕地产物＝农作物单条目（「粮/药材」不设独立资源，见 16）
7. 人名/组织名不带编号；同名在编聚合显示（村民×3）
8. **槽位提示写实、逐槽各异**：不套模板句式；"负责XX"只限名字即活计的纯体力岗；不用"解锁XX/开启XX系统"句式（放人＝干活）；颜色（必须/半必须/增益）已表意，说明不重复 staffing 信息
9. 岗位三分类：**必须**（至少一人该组织才能开工）/ **半必须**（需人运行、可移调顶岗——不叫"借调"）/ **增益**（无人只是缺该功能）
10. **任意职能槽都可下辖组织**（矿石信息内可设矿务所）；**机构入驻即算在岗**（下辖组织有在编＝履职）
11. 机构芯片不加"机构·"前缀
12. UI：列无标题；**不做槽→卡连线**（已删，别再试）；emoji 只限物品瓦片与成本芯片；页签平分横排；顶栏只放基础资源；建造在建筑页（城市一排，两端扩建位展开菜单）；底部不放事件流；建造菜单不放数量标记；侧栏 VSCode 式拖拽调尺寸（panel.js，双击复位、localStorage 记忆——模板里用解构出的顶层 ref，嵌套对象里的 ref 不自动解包）
13. **无劫匪/海盗设定**；市场是阶段二成果（商队等待商路域）；战斗侧一律不做
14. 建造/采集/制造合一为生产槽→生产局（采集中心/工程队/制造中心递归）；工程队不设材料岗（建材运输归运输系统）
15. 教官不会的教不了是废话不写；自明废话不进任何文案
16. 一站式总览不亲自产信息：各组织面板数据来自其自身信息位；情报组织规模只影响总览**更新效率**（文书要真有人运回市政厅），绝不 gate 信息量；面板置顶/挂主菜单是玩家设置
16. **基础原料三种**（05 §四定稿口径）：原木（树林）/矿物→铁矿（矿洞，金属暂只做铁）/农作物（耕地，**粮与药材同源合并、单产物**）；木材/木板/铁锭都是工序产物（加工品）——旧资源名「粮/药材」不许复活，各地形产物单一、无产物切换面板
17. **衍生品进目录须有真实消费端**（成本表/工序投入/机制实物前提，如手推车→运输队载具门槛、铁剑→成军军械储备）；只做得出抽象 buff 的工具类衍生不进目录（铁斧一类已毙）
18. 无采购渠道（市场是阶段二成果）：文案不写"外购"，库存来源写"初始库存/自产"
19. 必须建筑的组织（各制造坊/训练营/常备军/人事局/科研院）构筑需对应建筑有空座实例——候选禁用并示因；关键岗位可再挂设备门槛（如教官需训练场·木人桩）
20. 建造/组织自动化三阶段是究极模拟目标（01 §4.6）：前期手动指派→中期 RTS 定点→后期城市/地区级自适应；sim 已种：工程队·自动扩建、人事局·自动补员（规模越大自动化越高）
21. 开局＝聚落最小形态：根组织「聚落」（人口达 30 升格更名市政厅）+市政厅/仓库各一座，一切从零搭（完全体只是参数面板可载入的样板）；城市是一整排、市政厅居中、向两侧扩建（03 §八），建造归建筑页（第四页签，两端扩建位展开菜单）
22. 住房容量由床位决定（建筑总账 6.6 创始人口径，sim 落为基准4+床铺翻倍）；数值取整十不膨胀（命名与数值口径）；15-建筑功能规格是 AI 提案不得当权威
23. 产地三态：树林=不可到达（产出仍进场堆待运，堆不设上限）/耕地=主城内（产出进场堆待运）/矿洞=卫星城（唯一堆容 40+80×卫星仓、唯一可建卫星仓处）；**三线都要搬运工搬回——仓库满停的是搬运不是采集**；运输吃运距物理折算；建筑宽度按 8 格原子块口径（民居4/设施类8/市政厅16），民居可双层（木质上限2）；槽名「教育」（科研院入驻），官署→办公楼（禁古风词：衙署/案牍/演武）
24. 三线产出都进场地堆、都要搬运工搬回（纠正旧『直入仓』口径）；仓库满停搬运不停采集（树林/耕地无限堆、矿洞堆容满停采）；通报/移调/搬运折扣对三线全部生效
25. 同型组织集团化扩编＝中间层（总坊/总队：总管+下辖×3，下辖各需自驻建筑）；中间层不再嵌套
26. 施工撤单＝未开工环节全额返料（已开工环节料已砌进结构不返）；软装拆卸仍全额返料——库满软锁的玩家出口；不引入抽象丢弃
27. **末道手艺门槛**：细活要会艺者把关，粗工序不锁开局——五厂末道工序（刨光→木工、开刃→锻造、熬制→制药、装配→木工、冶炼→冶炼）须在编有人会该艺才能开工；无人会＝该道停摆（⏸ 报「缺手艺」：练人或等对口新生儿）
28. **耐久 sink**：手推车每 240 搬运人时折损一辆、常备兵役常备军每 150 时换装领铁剑×1（领用须军需岗在编，无人/无剑＝呈报流警告、不叠加惩罚）——**物理折损不是抽象维护费**
33. **耕地产出不作口粮**：农作物只做 入药/纤维（搓绳）原料——移民、人口、一切维持都不耗农作物（无「战粮类增益品」品类，见裁决35）
34. **拉动制物流**：产出默认堆产地空地（树林/耕地无上限），**仓库收货政策开着才回运**（三种基础原料独立开关，默认全关）；仓库逐座可限定收货类型（分类仓），某类容量＝收该类座数×单座容量（各类独立，满一类不堵别的）；运输计划（偏重）仍为调度岗偏好——多城分布式仓/前线补给沿此模型扩展，不做「一口气全搬回仓」
31. **移民制**：人口增长＝移民吸引（空床+安家口粮 农作物10），外来成年匠人档案（属性3~9、匠艺概率高）——新生儿机制不做
32. **建筑 BOM 分部位多材料**：墙体/屋顶/地面/五金/索具逐部位料单（格宽×材质系数口径、总量取整十）；材料全部自三种原料工序派生（木梁/木瓦/铁钉/铁板/绳索），石材仍非功能原材料；前期建筑无铁制品、冶炼坊壳五金用生矿（防自锁）；设备装了就分走均摊工时——按需装/拆（拆卸返料）
30. **工序槽 n:1 是设备语义非工位上限**：同槽多人＝一设备多班（卡头显示 N 人）——别把它当产能天花板
29. **禁用「师承」一词**：统一「教学人」——该词不精确且犯古风忌；全库已改，不许复活

## 四、常见坑

- 手滑写出 `S.buildings[b].shell` 一类单例残留——建筑是数组
- 误把 rates 当每拍增量：已归一为**每时净流量**
- 锻造坊锻打可吃外购铁锭（altCity），做对照实验前先把无关资源清零
- 空岗工序经移调语义照常开工（一人厂均摊工时）——这是特性不是 bug
- 后台标签页深度节流：Playwright input 派发会挂起、`setTimeout` 被钳到分钟级（僵尸脚本延后执行还会与新脚本竞态互踩）——页面内脚本一律用 `el.click()` 派发 + 微任务链（`await Promise.resolve()` ×N）等 Vue 渲染，别用 sleep
- 验证存档迁移/加载：注入旧档后 reload 会被页内回写覆盖（saveTimer 30s + beforeunload 都在写 `orgsim.save`）——先 patch `Storage.prototype.setItem` 屏蔽该键再刷新，新页面上下文自然恢复

35. **无「战粮/奢侈品」品类**（创始人裁决 2026-11-09）：经济目录不设战粮类增益品与奢侈品——内容扩充对象＝建材构件（+武器）；「进食可选增益」只是弱化进食规则本身，不指任何已定品类
36. **无「前期/后期」阶段概念**（创始人裁决 2026-11-09）：建筑/组织不标阶段徽标、文案不带阶段词——何时出现是玩家搭出来的涌现；搭台期的占位语义（"这块以后填"）不得进游戏文本
37. **施工＝结构工作量制**（创始人裁决 2026-11-09）：建筑按施工环节拆分，每环节挂**工作量**（结构量，非工时）与材料——**时长＝工作量÷作队出力，是涌现值**，禁止工时/BOM 整包手编常数；环节开工即扣料（料不齐该环节等料⚠、别环节照跑）
39. **命名禁现实文化圈专属词**（创始人裁决 2026-11-09）：本作西幻背景——中式营造词（柱础/八大作/瓦瓦一类）与任何现实专有行话不得进游戏文本；工艺词用中性现代汉语（场地/地基/立架/铺椽/铺顶/筑墙/门窗/粉刷/夯地；工种＝木匠/小工）
40. **工种＝专门作队组织**（创始人裁决 2026-11-09）：不同工艺由专门组织完成——木匠队（吃 cft）/小工队（吃 str）挂工程队·木匠/小工槽（直派人员或整队入驻，库务所同款）；跨工种真并行、各出各力不抢人手；对应作队无人＝该环节停摆⛔
41. **建筑形制定工序链**（创始人裁决 2026-11-09）：不同类型建筑不同工作流——**棚**（开敞：无墙无门窗）/**屋**（圆木围合：垒木墙板皮顶，自举段）/**架**（梁柱：锯材梁椽+板墙+木瓦顶+厂制门窗铁件）
38. **层数＝加层施工单**（创始人裁决 2026-11-09；上限值 11-09 二次修订按调研推导）：不是开工选项——对既有建筑加建「拆旧顶→接柱立架→架楼板→上层墙→楼梯→盖新顶」六环节（拆顶期房屋无顶）；**层数上限＝材质定层：茅草棚1 / 木板房3 / 石头房4 / 砖瓦房5**（中世纪木构2-3层+轻木规范3层/砌体高厚比/近代砖混保守值；旧值「木上限2层」作废）；上层≤下层承重收进与 jetty 悬挑为后续
42. **营造序＝先骨后皮、先顶后墙**（创始人裁决 2026-11-09，建筑学调研实证）：屋面先于填墙（有顶无墙优先遮雨）；**茅草＝收割副产**（0.5 比率与农作物同堆同运——不设独立资源线）；**茅匠队**＝第三工种作队（茅草顶铺苫，thatcher 只在屋面阶段进场）；粉刷环节产出实体抹灰语义（正片 plaster 材质）
43. **页签解锁门槛＋设计岗**（创始人裁决 2026-11-09）：顶栏后三页要对应槽位在编才解锁——建筑←生产槽、仓库←运输槽、总览←情报槽（槽有人或有在编成员的机构入驻都算）；**设计岗**＝工程队新岗，在编才能看建筑页各座的内部结构预览（剖视图）——信息有主人，不是 UI 免费送的
44. **一横排＝一层；二层＝块上加号**（创始人裁决 2026-11-09）：城市一排只表示地面层；加层入口是各一层块上的「＋」（把该座一层当地基在其上加建），不在开工选项里
45. **无封闭检查**（创始人裁决 2026-11-09）：建筑默认封闭（整栋原子块）——不做缺氧式封闭域判定；房间等价物＝建筑/内构段本身，类型由内含物定（ONI 房间判定只取「内含物定类型」这半）
46. **基础行为不算技能**（创始人裁决 2026-11-09）：采集三线/搬运/施工是任何单位都能干的基础行为——技能表只留手艺与识字（木工/锻造/制药/冶炼/识字），个体差异走属性（17 号）
47. **先放人后构筑，人转任主管**（创始人裁决 2026-11-09）：槽位必须先放人才可构筑组织；构筑时槽内首位在编者自动转任新组织「主管」（各组织自带主管槽），余者回待业——常备军动员官流转等特例全部由此通用规则收编
48. **点空槽＝自动放人＋筹建读条**（创始人裁决 2026-11-09）：点空槽自动从待业选最合适的入岗（会本组织手艺优先、对应属性次之）；构筑改为父组织面板下达**筹建任务**——槽内经办人读条 3 时建出组织（撤走经办人＝任务作废）；开局村民基本技能全有（技能稀缺由移民带来）；同质化槽一人有技能即可运转（membersHave 组织级即此口径）
49. **放人＝放机构，同一效果**（创始人裁决 2026-11-09）：效果由在编的人提供，机构只是人的容器——只带主管的机构＝只放一个人；空机构不算在岗；岗位描述写职能单轨，不写"放人xx/放机构xx"双轨
