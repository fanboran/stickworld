# 活跃任务登记

> 全项目「跨会话长任务」的唯一活跃登记（自 AGENTS.md「会话交接」段独立成档）。
> **只有交接类任务需要读本文件**：新会话恢复任务（用户说「继续 <任务名>」）、任务收线/登记更新时；其余会话不预载。
> 维护纪律：worktree 增删、分支收线、产物迁移后**当场**同步对应行；待创始人人工验收的产物必须写完整 Windows 绝对路径（带盘符），写之前先 `ls` 确认存在。
> **登记行模板（四要素，防行内长文）**：任务一句话定位 / 状态与下一步各一句 / 交接档路径 / 验收产物绝对路径——实现细节、门禁数字、诊断过程一律写交接档，不进登记行。
> 流转规则：本表只登记**正在推进**的任务与无交接档的在跑分支。收线/合并 → 条目移[待创始人验收](待创始人验收.md)；验收通过且无尾巴 → 交接档移 `归档/`、验收档删行，有尾巴 → 移[缓期与悬置任务](缓期与悬置任务.md)；缓期任务复活 → 移回本表。
