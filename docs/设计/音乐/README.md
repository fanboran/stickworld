## 一句话总览

一部**主题与变奏**式的作品集：一条 8 小节主主题（「原野」），在九个场景里以
不同调式、织体、编制复现——白天 D 大调的明朗、夜里 B 小调的幽暗、小镇 G 大调的
摇曳、室内 F 大调的独白、战场 D 小调的急促。每首 32 小节无缝循环，
按 3 档强度分层（钢琴 / +弦乐 / +钟琴），运行时按游戏状态纵向混音。

作曲与混音全部由 `tools/music/` 的管线离线生成；音源为公有领域钢琴采样库
（CC-BY）与宽松许可的 GM SoundFont；全部旋律为原创，只借鉴公有领域作品的技法。

## 维护约定

1. 改**作曲**（旋律/和声/织体/编制）→ 改 `tools/music/compose/`，并同步
   [乐曲清单.md](乐曲清单.md)（清单由代码生成，本文是可读版本）。
2. 改**混音配方**（EQ/压缩/混响/摆位）→ 改 `tools/music/musiclib/mix.py`，
   并同步 [作曲技法参考.md](作曲技法参考.md) §七 与
   [音乐质检规范.md](../技术/音频/音乐质检规范.md) 的实测基线。
3. 引入任何**外部素材**（采样库/环境音录音）→ 当场登记
   [音乐资产登记与来源.md](../技术/音频/音乐资产登记与来源.md)。
