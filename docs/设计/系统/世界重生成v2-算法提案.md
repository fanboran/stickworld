## A1 资源禀赋与宜居度场（新增层）

**目标**：为聚落密度、城市规模、国家扩张、荒地判定提供统一的自然地理输入；承载「扰动参数拟真化」的主体。

**算法**：
1. **基础场派生**（从底图逐像素）：河流密度（核带宽卷积）、湖泊距离场、坡度/绝对高程、群系类别、海岸距离。
2. **资源簇散布**：矿脉/沃土带/渔场/盐井按群系先验 + FBM（分形布朗运动）扰动生成空间簇——**空间自相关，禁白噪声**（现实资源成带成片）。每类资源一个「丰度场」。
3. **宜居度合成**：`suitability = Σ w_b(biome) · f(水, 坡度, 距湖海) + g(资源丰度向量)`——分群系标定权重（沙漠/冰原/高原基线低，河流沿线拉高，绿洲/河谷成局部高点）。
4. **通行/进攻成本场**：`attack_cost = 基础通行性（坡度/植被/沙漠）· 河流穿越罚 · 跨海罚`，与宜居度场并行输出——供 A4 合并边权直接消费（「地理上更容易进攻」的显式载体）。

**关键参数**（拟真扰动参数化的主体）：FBM 频率与幅度（每资源类独立）、各群系宜居基线、资源→宜居增益曲线、通行性各因子系数。全部进 `state_params.json`，重生成时整体可调。

**验收**：宜居度热区与河流/群系分布目视吻合；贫瘠区（撒哈拉/青藏原型带）出现大片低值连续区域；资源簇成片不成噪点。

## A2 文化场 v2：文化相似度连续化

**目标**：把「文化圈硬边界」改为「文化连续场 + 文化间相似度」——相似文化的地块更容易合并成同一国家（创始人定向）。

**算法**：
1. **文化基底点**：在宜居度较高的区域撒 K 个文化源点（K≈15-25，泊松盘间距），每个源点带属性向量（语系、生计模式：农耕/游牧/渔猎/商贸、地形偏好）。
2. **文化扩散场**：多源测地场（复用现有 flood-fill 的 cost 骨架，k_slope/k_river 沿用），每 tile 得到「主导文化 + 混合度」；文化过渡带（两源场强接近处）形成模糊边界而非硬线。
3. **文化相似度矩阵**：源点两两相似度 = 语系相同加分 + 生计模式相近加分 + 地形偏好重叠加分，归一到 [0,1]。
4. **tile 级相似度**：两 tile 文化相似度 = 各自主导文化相似度 × (1 - 各自混合度衰减)——过渡带上的城与两侧都「半亲」。

**与现状差异**：现 9 文化圈硬锚定 region、跨圈罚 k_culture 单一常数；v2 相似度连续、可学习「游牧圈吞并相邻农耕边缘」这类自然形态。

**验收**：文化分布图呈有机斑块+过渡带；相似度矩阵无孤立全零行（每种文化都有近亲）。

## A3 聚落生成：差异化密度与规模谱

**目标**：城市规模分布与空地频率按地理环境差异化——贫瘠地区整片 L1 仅一两个超小村庄，富庶平原大城密集；荒地（无聚落 tile）由宜居度自然产生（不后处理撒荒地）。

**算法**：
1. **密度采样**：泊松盘采样聚落位置，**盘半径由局部宜居度映射**（宜居→小半径密集，贫瘠→大半径稀疏，超过阈值无聚落）——密度差异连续，非按地区硬编码。
2. **规模赋值**：每聚落 `population_score = clamp( h(局部宜居度, 资源丰度) · LogNormal(μ_b, σ_b) )`——地区内对数正态散布（多数小村、少数大城），地区间基线 μ_b 由宜居度分位数决定（贫瘠带整体左移）。
3. **档位映射**：level 仍由 population_score 阈值映射（沿用场景口径 0.187/0.342，4/5 档留给人口成长），但 v2 数据端单一口径（顺手消掉 l1/l3 双阈值不一致——完善点登记档在案项）。
4. **荒地语义**：无聚落 tile 不分配 owner（无主荒地）；荒地总量与分布由宜居度阈值自然控制——撒哈拉/青藏原型带自动成为大片荒地，边疆缓冲带零星荒地。

**验收**：全球聚落密度图与宜居度图目视强相关；贫瘠 L1 地区聚落 ≤2 且全 1 档；荒地成片出现在预期带；全球城数落在目标区间（约 800-1200 可调）。

## A4 国家生成：随机规模谱 + 自然合并（核心）

**目标**：全域统一碎度——规模谱随机多样：一城小邦、几城小国、十几城区域强权并存，比例随 seed 扰动；哪些城合成一国由文化相似度×进攻成本×距离自然决定。

**算法**：
1. **都城抽取**：从聚落按「都城适宜性」排序（资源禀赋 × 文化中心性 = 主导文化的场强质心 × 间距）抽 N_c 个都城候选，四叉树最小间距筛选（沿用）——都城天然落在富庶与文化中心。
2. **规模目标采样**：每国目标城数 `target_i ~ 截断对数正态`（或移位 Zipf）：中位数 3-5 城、上尾到 12-18 城、下尾 1 城（城邦）；全局按 `Σtarget = 总城数` 归一。**规模谱参数可调**（碎度旋钮：median/σ/上限），一次生成内各国目标互相独立——「各种规模都有可能」。
3. **加权合并分配**：城图多源 Dijkstra/竞价分配（骨架沿用），**边权 v2**：
   ```
   w(edge) = geo_cost(edge) · (1 + k_culture · (1 - 文化相似度(tile_u, tile_v)))
                        · (1 + k_capital · 与都城测地距离衰减)
                        / expansionism_i
   ```
   - `geo_cost` = A1 进攻成本场沿线积分（地理上易进攻 → 边权低 → 更易同国）+ 山脊/大河停驻（沿用）
   - `文化相似度` = A2 连续值（相似文化 → 合并罚低）
   - `expansionism_i` 每国随机系数（沿用 0.75~1.45）制造有机不均
4. **规模收敛**：Balzer 式面积反馈迭代（骨架沿用），但目标从固定 Zipf 序改为第 2 步的采样值 `target_i`——大国自然多吃、小国到量即止。
5. **后处理**：normalize 消飞地（沿用，阈值随混合度放宽——文化过渡带允许少量跨相似文化飞地，更自然）；一城国保留（不强行吞并）。
6. **政体属性**：is_city_state = target==1 自动标记；首都 = 都城；色板 LUT 沿用 palette.py。

**验收**：规模谱直方图符合目标分布（含 ≥若干 12+ 城大国、≥若干 1 城邦）；国界与文化过渡带、山脊/河线目视重合度高；跨文化硬切国界占比低；重跑同 seed 逐位一致。

## A5 每局运行时扰动：版图固定，状态多样

**目标**：世界底图与国家版图发布时预生成固定（世界是玩家的记忆点）；每局差异化靠状态扰动，不重排版图。

**算法**（现 population_score ±15% 的多维延伸，全部 `hash(id)+run_seed` 确定性）：
- 人口/守军扰动（已有，M1 初始化器实现）
- 国家初始「战争烈度/记仇值」扰动（M3 W7 开战判定的初始条件每局不同）
- 资源点丰度/再生参数扰动（影响经济 tick 与战略价值）
- 边缘城归属微扰（可选，仅国界模糊带 ±1 城翻转，保持版图大体稳定——默认关，创始人可开）

**边界纪律**：不扰动地形/群系/文化/国界主干——「同一张世界、不同的局」。

### 调研引出的提案增补（待创始人圈选）

**A6 生成期加速历史（DF 路线轻量版）**（已圈选）：A4 分配完成后，跑 K 轮（K≈几十）轻量虚拟历史——每轮随机触发兼并战（大国按进攻成本场选软柿子吞并小国/城邦）、继承解体（大国概率碎一地，WorldBox chaos 同构）、边疆易手——让最终版图带"战争史痕迹"：自然边界 = 打出来的战线。天然满足「地理上更容易进攻的更容易合并」（易攻方向就是整合方向），且大国/碎国的最终规模谱由模拟涌现，比纯采样分配更有历史质感。代价：实现+调参成本高于纯分配，可做可选档（K=0 即退化为纯 A4）。

**政权/城市名生成（构造型语言）**（已圈选）：A2 文化场每文化生成语素库（音节表+构词法），政权名/城市名从文化语素合成——193 政权占位名问题的治本方案；生成名仍走「提案/待定」交创始人筛选后定稿。
