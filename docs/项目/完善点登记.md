# 完善点登记

> **用途**：登记待完善点——距离完整商业化游戏还缺的东西都收（一个面板、一段音效、一套成就这种大小都算，不做毛坯房）。发现什么记什么，按所属域归置，不设固定分类。
> **方式**：各任务会话实施中遇到就记，不专门立项盘点；subagent 的发现随汇报上报、主会话汇总。已在役的能力不记（如 BGM/主菜单/设置面板已有）。
> **纪律**：凡属 AI 建议而非创始人确认的标〔提案/待定〕；**登记不等于立项**，圈选后才进批次。条目写「缺什么、在哪、影响什么」，不写实施方案。

## 战斗与单位

- SFX 管线设计完备但接线范围不明：`audio_manager.gd` 的 SFX_EVENTS/SFX_POLICY 事件表已成体系，哪些玩法事件真的在播声、哪些设计了没接（战斗命中/UI 操作/建筑完工）——待实施中核实补记。
- 战斗超时兜底口径待复核：demo 征伐的 `duration_limit=240` 秒已随 M0 拆除，battle_director 现行超时收束口径需复核——大规模会战与小遭遇战共用一个硬顶是否成立。
- 战形差异无表达：营地野战/要塞攻坚/城镇巷战三种战形（蓝图 §3.1）各需专属机制与场景（城墙/掩体/街道），现据点图同质。

## 世界与政权

- `unlock_granted` 发射端悬空：M0 拆 ConquestManager 后建筑解锁只来自 `STARTING_UNLOCKS` 基线——世界模型接发射方之前，玩家做任何事都不解锁新门禁，进程感断线。
- `settlement_updated` 无生产发射方：人口再生/招兵不广播——聚落在战略图上的 blob 规模永远不长。
- 省份政治侧表是静态快照：`province_politics.gd` 不随运行时占领变动——M3 拉锯开后省面板/邻省渲染会展示过期归属。
- 政权 states 表四处冗余：political_data.json / l3_city / 13 份 l2 / 出生 l1 各一份——政权名/色任何改动须全量重跑生成器+刷 bin。
- 80 政权名占位：`names_status: "提案/待定"`（出生 8 城邦除外）；城市显示名同为占位（map_label_layer 用「城市 N」，数据端城市名未定稿）。
- `regions.tres`/`civ_differences.tres` 零消费死数据：BalanceConfig 扫描装载但全仓无读者（factions.tres 已退役）——退役候选，待裁决；对应 xlsx sheet 仍在导出范围。
- `出征与领地架构.md` 与 M0 后现状漂移：territories.tres 已删但文档 §2.1/§2.2 仍按其存在描述，需按政权归属新定位整体梳理。
- `平衡框架.md` 表述与实物疑似不符：写 `expansion_*.tres` 文件名模式，仓库内无此名文件。
- 城市档位阈值双口径并存：l1 场景口径（0.187/0.342）与 l3/l2 blob 口径（0.35/0.55）在生成端并存，约 75% 城两套档位不一致——统一契约取场景口径（锚定 SettlementRef.Level），战略图 blob 与账面档位的视觉不一致是 worldgen 数据层问题，待生成端裁决统一。
- `political_data.json` 无 bin 伴生、靠 export include 留存：exclude_filter 收紧会静默降级到空世界（json 兜底路径在导出包内被排除）——生成端补 bin 或导出白名单显式覆盖。
- **荒地地块缺失（设计-实现缺口）**：三出身「部落首领=荒野小聚落」「成政权节点=荒野自建聚落所在 tile 归属变更」（蓝图 §3.9）都以无主荒地为前提，但生成端把全部陆地分给了 80 政权——实测 1048/1048 tile 带聚落且有主、零无主 tile，l3 政治图保留码（0 海洋/253 自由城邦/254 湖泊/255 灰底）也无「无主」码。玩家自建聚落只能落在 AI 领土上，语义拧巴；M5 三出身被堵。解法方向待创始人定：生成端初始留无主荒地（边远/贫瘠带）/ 运行时战争毁灭产生无主地 / 两者兼有；契约侧无需改（owner 为空即可表达，L1TileDef.owner_state_id 已支持空）。

- ~~城块呈圆盘状~~ **已裁决废止**：地块网格固定不重切（属性层路线，见交接档「方向修正」），圆盘问题随 city_split 路线一并作废。
- blob 三档形状差异（low/mid/high）：参数已放大（gamma 0.7→1.5、level 带 g_max 抬升），但需 blob_v2 几何链重烤后才可见（`blob_v2_generate` 产 npz 未在工作区，见交接档 §五）。

- **细缝的最后一轮收敛慢**（城块划分）：缝隙从 13.3% 收敛到 2.3% 后，继续迭代（撒更多填缝点）时 `city_split_v3` 的「老 L1 分组多源生长」在大点数下计算量陡增（单轮 20 分钟+，内存 2.3GB）。根治方向：生长算法改用「多源 BFS + KDTree 邻域」（当前逐分量扫描），或填缝点不参与生长（只按「盘∩缝」直接落块）。位置：`tools/worldgen/l1/city_split_v3.py` grow_cities / `tools/worldgen/l3/fill_gap_seeds.py`。

## 经济与资源

- 资源域仍挂 `test_region`：玩家村资源走 region="test_region"——资源区域骨架未接世界真源，M2 多城账面经济没有归属可挂。
- 招兵成本硬编码：`RECRUIT_COST` 写死在 recruit_manager.gd，未走 balance_config。

- 文本呈现载体零实现：对话/信件/字幕/播报系统不存在——剧情人物、战报、传闻、任务文本等一切叙事内容没有容器。
- 战争情报面板缺失：出征选目标的情报（守军/战形/战利品，蓝图 §二主轴）只有 settlement_tooltip 骨架（归属行恒隐藏）。
- 政权详情面板缺失：战略图无法点开某国看详情/定位疆域——80 政权多了玩家建立不了「谁在哪」的心智地图。〔提案/待定〕
- i18n 层缺失：文案中文硬编码，无本地化框架（出海时是全量改造）。〔提案/待定〕
- 领土流转只有染色：M3 拉锯的战争标记/易手动效无实现——「活的战略图」看不出哪里在打。〔提案/待定：形态待 M3 定〕

## 存档与健壮性

- schema 迁移框架空壳：save_manager `_migrate_loaded_schema` 占位放行——未来 schema v3+ 旧档迁移无实装框架。
