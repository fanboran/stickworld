## 二、阶段打法（映射到图上里程碑）

行业通行的阶段门（Stage-Gate）打法，本项目已在图上自然成型，不需要另立阶段计划：

| 阶段 | 准入（已在图上） | 核心内容 | 准出（收口门） |
|---|---|---|---|
| 0 原型验证 | —（已完成） | 建造→编队→下令→战斗→附身→跨图→战略图 | p0_prototype ✅ + **p0_accept（创始人人工验收，就绪待办）** |
| 垂直切片 | p0_accept | 复刻收尾（P8/debt/fx/法术/物品栏）+ Demo 内容链（天气/河流/模式变体/观察场扩展） | demo_content → **demo_release** |
| Alpha 核心系统 | p0_accept | 经济循环链、地图重构链、GDD 系统补全链（科技/组织/法律/外交） | 六门齐 → content_freeze |
| Beta 深度 | content_freeze | 打磨群（平衡/UX/本地化/Steam）+ 好玩性验证 | fun_done + launch_prep → release_gate |
| 发布与运营 | release_gate | 上线、营销、DLC/工坊 | launch → live_ops |

**制作人核心判断**：
1. **"find the fun first"——p0_accept 是全局第一优先**。项目最大风险是"层级管理→好玩"假设
   未经验证（fun_done 挂在它后面，但它本身只需创始人跑一遍原型循环）。在它完成前，
   Demo 与 Alpha 内容都在为未验证假设积累成本。建议创始人验收窗口安排在任何新派活之前。
2. **Demo（垂直切片）先于 Alpha 铺开**：demo_release 链与正式版收口链并行不悖，
   Demo 既是宣发前置（mkt_promo_plan 挂它）也是第二次好玩性验证。Demo 链最长支线
   ext_art→asset_p1/p2/p4/p5/p7（外部美术采购）——**外部产能是 Demo 观感的真瓶颈，
   采购/制作应立即启动**（它是纯等待型节点，越早挂起越早解锁）。
3. **复刻主线应收口而非续摊**：复刻（SWL 对标）是手段不是目的。P8 巨人+三个缺陷修+
   皮肤/音效后即 main_done；11e/variant_units 冻结项等 dec_unit_roster 拍板——
   决策任务就绪且零代码成本，**创始人拍板一次即可解冻整簇**。

## 三、关键路径与产能瓶颈

- **关键链在组织→指挥系统**（construction→任务板→组织驱动→自主战术→附身→战术面板→UI 成熟）。
  这条链是本项目差异化卖点（管理学玩法）的脊柱，**每一跳都值得优先派发**——
  当前建议派活组合里 construction_split 常驻第一就是这个原因。
- **加并发只能压非关键路径**：当前 62 个就绪任务远超并行线数（域互斥下实际可派 ~6 线/轮），
  多开 AI 并行线的边际收益主要在 UI 线/战略图线/工程债线互不冲突的窗口。
- **压缩关键路径的手段**（按优先级）：
  1. 拆任务：ui_possess_full（多层级附身/AI 协奏/权限 UI）可拆为机制层（先做）与表现层（并入 tactical_panel_ext）；
  2. 提前决策：autonomy_tactics 上游只有 org_driven_behavior——把 org_driven_behavior 的
     "工程组织→建造"与"军事组织→战斗"两个映射拆成可并行的两个交付物；
  3. 外购：ext_art 通道前置启动（纯等待）。
