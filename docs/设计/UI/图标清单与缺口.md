# 图标清单与缺口

> **是什么**：图标管线成品的全量清单（含定稿状态）+ 游戏 UI 的图标接线点 + 库中尚缺、需要立项制作的母题缺口。任何 UI 处要挂图标，先查本文档；做完接线，回来更新接线表。

## 一、图标库现状

- **来源**：`tools/icon_pipeline/` 三渲二管线（Blender 渲染 → compose 合成），产物 64/128/256 三档 PNG。
- **库存位置**：`stick-world/assets/icons/<中文母题名>_<尺寸>.png`。
- **运行时取图**：`StickIcons.tex(&"母题名")`（`modules/ui_global/scripts/theme/stick_icons.gd`）——跨模块固定语义走其 `SEMANTIC` 表，场景级映射写在各使用处的数据表里。
- **总量**：92 枚 = 86 枚母题注册表（`motifs.py`）+ 锻造锤 + 5 枚基本体（立方体/正球/圆柱/圆锥/圆环）。
- **描边定值**：反向壳描边 **1.5px@64**（128/256 档同比例 1.8/2.0，创始人 2026-09-11 拍板）。历史快照曾横跨 v1 图像域与早期壳厚多代而参差 1~2px，2026-09-11 全量重渲后全库一致——**任何管线参数变更后必须全量重渲覆盖入库**，避免再出现新旧代差。

接线规范：按钮 `btn.icon = StickIcons.tex(&"母题名")` + `icon_max_width` 压尺寸（按钮 18~22px）；TextureRect 用 18px KEEP_ASPECT_CENTERED。母题名即文件名，不加尺寸后缀。⚠ 勿对带文字的按钮开 `expand_icon`——与文字并存时图标被布局压到不可见（见 `tests/dev/_diag_btn_icon.gd` 对照实验）；纯图标按钮才可用。

### 审计后决定不挂图的位置（2026-09-10 全量审计）

- **存档面板**：保存/读取/删除/关闭为小号动词按钮，文字已达意，铺图标反而挤。
- **通知条**：info/warn/error 已有级别色标区分，无自然对应的库内母题。
- **组织面板 / 编成面板**：表单型 UI（创建/加入/下拉）+ 未实装占位按钮，图标无增量信息。
- **角色属性面板**：各属性行需要成套属性字形（力/敏/体/智/志），现库无对应母题，留待专项立项。
