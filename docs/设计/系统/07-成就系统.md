# 成就与图章系统

## 目的

满足收藏欲，提供有限边界内的"收集掌控感"——不是无限的成就通货膨胀，而是精心设计的、每一枚都有美术价值的图章集合。

## 玩家体验目标

- **收集满足**：每获得一枚图章都是一个小高潮——图章本身是值得欣赏的电子工艺品
- **持续展示**：图章不被藏在菜单深处，在主界面/帝国概览中显著可见
- **边界感**：单机游戏有限的总数让收集有"能集齐"的踏实感
- **叙事载体**：某些图章承载着游戏中的史诗时刻

---

## 一、图章设计原则

### 1.1 美术标准

- 每枚图章是独立的原创美术作品——不是换个颜色/数字的模板
- 火柴人风格的精致小图标，类似迷你勋章
- 参考《明日方舟》徽章的美术品质，但更突出火柴人特色
- 图章有物理质感——金属、宝石、皮革等材质表现

### 1.2 形态规则

- **手工有限清单**：每枚成就都由手工设计，对应做成某件具体的事（打赢某场硬仗、造出某件东西、走到某个地方）——一锤子纪念，不挂任何游戏内奖励（不给数值、不给物品）。
- **平权**：无稀有度分层、无隐藏档——所有图章同等可见，谁也不比谁金贵。
- **图标即主体**：每枚图章一枚原创图标，展示参照《泰拉瑞亚》——图标墙 + 边框 + 悬停详情的一页式陈列，按类别分组。
- **未获得＝灰暗剪影**：能看到轮廓，知道自己还缺什么；获得后全彩点亮。

## 三、展示系统

图章**不藏起来**：

| 位置 | 展示内容 |
|------|----------|
| 主菜单/总览报表 | 最近获得的图章轮播展示 |
| 总览报表面板 | 图章墙（可滚动查看全部）；日常展示形态为图标 + 计数 |
| 存档选择界面 | 该存档获得的图章数量展示 |
| Steam 成就 | 与 Steam 成就系统同步 |

### 图章墙规则

- 类似勋章陈列柜的视觉布局，按类别分区排列
- 已获得的图章＝明亮、有金属光泽；未获得＝灰暗剪影（能看到轮廓）
- 悬停显示图章名称与获得条件

---

## 四、图章的收藏感

不同于把精美徽章藏进档案页——单机游戏的图章应该是玩家主动展示的收藏品：

- **显著可见**：主界面就能看到
- **物理质感**：火柴人风格的勋章设计，金属/宝石材质
- **故事载体**：部分图章附带一小段游戏中的历史记录（获得的日期、当时的帝国状态）
- **仪式感**：获得重要图章时弹出全屏展示动画

与 Steam 成就的区别：Steam 成就只是一个弹窗，然后被遗忘——本作的图章是持续展示的收藏品。

---

## 边缘情况

- **覆盖存档**：新存档的图章重新开始收集（图章是存档绑定的）
- **创意工坊/模组**：模组可以添加新图章，但标记为"非官方"，不计入收藏完成度
- **速通/特殊规则**：自定义规则下获得的图章正常解锁
