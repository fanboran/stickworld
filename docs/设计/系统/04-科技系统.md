# 科技系统

> **Demo 阶段**：科技主要通过征服获得（打下敌国解锁其科技）。后期帝国规模才需要自主研发。
> **Demo 版**：以军事武器科技为主，小部分生产科技为辅。

## 目的

不是抽象的"点按钮研究"——知识长在具体的人身上，科技随人口与人才的获得而来（征服、俘获、招揽、事件），后期帝国规模才涉及自主研发。科技分三大类：制造、法术、管理。

## 玩家体验目标

- **征服驱动**：打下敌国→获得对方的科技，不是点了等倒计时
- **知识长在人身上**：科技的载体是具体的人——获得人口、俘获人才就是获得科技；人才流失即科技流失
- **分类清晰**：制造（武器/装备/建筑）、法术（元素/附魔/召唤）、管理（组织效率/行政能力）
- **后期研究**：大规模帝国才需要亲自组织研究——研究具体到个人，消耗教育资源

## 一、科技分类

### 1.1 制造科技

武器装备、建筑工艺、载具制造。对应 Excel 表：`制造.xlsx`（原 `科技树.xlsx` 改）。

军事武器的微操——后期解锁的战术能力——算管理科技，不算制造。

### 1.2 法术科技

元素法术、附魔术、召唤术、治疗术等。对应 Excel 表：`法术科技.xlsx`。

法师 = 科学家 + 工程师。法术 = 对世界底层规则的操纵。

### 1.3 管理科技

组织架构效率、行政能力、战术指挥。对应 Excel 表：`管理科技.xlsx`。

"经济科技"本质上是对资源的利用能力，属于管理科技的一个子集。

## 二、科技获取方式

### 2.1 知识随人走（机制总纲）

科技不是抽象进度条，是**长在具体的人身上的知识**（工匠/学者/法师）。一切获取方式的本质都是"获得掌握知识的人或其成果"：

| 方式 | 说明 |
|------|------|
| **征服/占领** | 打下城市 → 城中人口掌握的技术为你所用；获得人口即获得其知识 |
| **人才获取** | 俘获/招揽敌方首席科学家、名师匠人 → 其知识为你所用 |
| **事件获取** | 遗迹探索、特殊事件触发 |

**反面**：人才流失即科技流失——学者被敌国挖走或杀死，对应科研能力随之受损。

已获科技的图谱化展示（科技源流、流入路径、知识携带者标注）见 [`11-构筑谱系系统.md`](11-构筑谱系系统.md) 技术谱系图。

**重要**：敌人也会获得你的科技。科技不是独享的，扩散是时间问题。

### 2.2 自主研究（具体到个人）

后期帝国规模才启用：用通用组织系统组建科学院，课题落在**具体研究员**身上——资质决定效率，研究**消耗教育资源**。花多少编制和物力在科研与教育上，是帝国的核心权衡：教育投入不足则无才可用，过度则挤占生产。

### 2.3 大科学工程

后期高阶科技必须自主爬树——组织"曼哈顿计划"级的魔法科研工程：海量资源与编制持续投入，全国物资可能被挤兑短缺；指挥水平不够则任务长期停滞。玩家体验的是亲自主持一项超大型科研计划的难处。

## 三、Demo 阶段策略

- 科技以征服获得为主
- 制造科技（武器/装备）优先
- 小部分法术科技（基础法术）
- 管理科技暂不启用（demo 规模太小）
- 后期才解锁自主研发机制

---

## 四、法律系统

法律树独立于科技树。对应 Excel 表：`法律系统.xlsx`。

部分法律选择有道德张力。每条法律有：
- 可量化效果（如 +20% 生产力）
- 不可量化的叙事后果（民众舆论、国际声誉）

法律可以废除，但废除有代价（适应期混乱、利益集团反弹）。
