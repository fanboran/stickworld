# 遗留参照与功能差距

> **定位**：HD-2D 场景图与旧 2D 地图链路的对照底账（2026-09-16 旧 2D 图全量清退后更新）。
> 表一列 **HD-2D 尚未覆盖/未接回的功能点**及规格出处——对应功能接回 HD-2D 时照规格实现；
> 表二列 **在库的原型/探针资产**——性质与保留价值，防误删误改。
> HD-2D 运行时系统见 [`HD-2D街景系统.md`](HD-2D街景系统.md)；场景图整体架构见 [`场景与战斗架构.md`](../场景与战斗架构.md)。

## 一、HD-2D 尚未覆盖/未接回的功能点

| 功能点 | 现状 | 规格出处 |
|---|---|---|
| 村间道路图 | 旧 2D 道路链已清退，步行跨图暂以直达替代；HD-2D 行军道路未做（创始人裁决走 HD-2D） | 旧规格（`road_map.gd`/`road_map_generator.gd`，分段生成+两端出口触发器）走 Git 历史 |
| 守城战 | 旧 2D 守城链已清退；HD-2D 守城（城墙阵地+波次敌军）未做（创始人裁决走 HD-2D，战斗走出征系统） | 旧规格（`siege_field/siege_wall/siege_director/town_siege.gd`，FIELD 巨墙/巡墙弓手/波次组织）走 Git 历史；出城选项框现役形态见 `modules/world/scripts/map/hd2d_gate_prompt.gd` |
| 室内系统 | 旧 `mega_interior` 传送链已清退；室内由建筑管线 v3 内景承担（29 套内景/前墙 alpha 分层已入库），进室内玩法接线未做 | 内景分层/前墙 alpha 规格在 `modules/building_gen/buildings/building_exterior.gd`、`interior_props.gd`（在役） |

## 二、在库的原型/探针资产

| 文件/链路 | 性质 | 规格价值 |
|---|---|---|
| `tests/dev/proto_25d/`、`tests/dev/proto_hd2d/probe_rig*` | 2.5D/HD-2D 原型与探针（正式实现在 `modules/hd2d/`；proto_hd2d 下的 `bake_props.py`/`bake_nature.py` 是在役烘卡脚本，不属于此列） | `tests/dev/proto_25d/card.gdshader` 为正式卡 shader 的同源底稿（正式版独立改造）；`probe_rig*` 与 `verify_hd2d_*.gd` 是渲染姿态/旅行链的验收入口 |

> **共用件正名（清理旧档时勿波及）**：`resource_gen.gd`（资源分布算法）、`resource_node.gd`（纯逻辑采集点）、`chunk_trigger.gd`（出口触发器）、`city_gen.gd`（算法村/聚落生成）、`conquest_anchor.gd`（据点布阵锚点）、`environment_system.gd`（game_time 时钟 = HD-2D 昼夜数据源）由 HD-2D 宿主直接消费，均不是遗留链路。`assets/resources/*_paint_*.png` 现由 `modules/ui_global/scripts/hud/resource_bar.gd` 作资源图标引用，同样在役。
