## 一、先把"静谧治愈"拆成 8 个可调变量

日系静谧配乐不是"某种和弦"，而是**8 个变量同时被压到某个区间**。任何一条跑出
区间，听感立刻塌成"流行歌"或"游戏罐头 BGM"。

| 变量 | 目标区间 | 失控表现 |
| --- | --- | --- |
| 音区中心 | 中高音区（钢琴旋律 C5~C6，伴奏 C3~C4） | 偏低=发闷；偏高=发尖 |
| 织体密度 | 同一时刻 ≤3 个有音高的声部；最小单位 8 分音符 | 16 分密集=罐头感 |
| 和声张力形态 | 张力来自 **add9 / sus4 / maj7 的色彩**，不是属七的功能 | V7 密集=流行/爵士味 |
| 明朗与幽暗的比例 | 大调段与自然小调段交替 | 全程小调=丧；全程大调=甜腻 |
| 旋律留白率 | 休止占 25%~40% 时值 | 无留白=没有呼吸 |
| 亮度重心 | 明亮成分集中在 2~5kHz；10kHz 以上克制 | 亮片感=电子味 |
| 空间尺寸 | 单一主混响 RT60 约 2~3 秒 | 干声=廉价；多重混响=糊 |
| 动态度 | 段内 4~8 LU，靠**叠层**而非推音量 | 全曲一个响度=平淡 |

## 二、和声语汇

### 2.1 三个日音圈标配进行【有据】

日本音乐圈把**小室进行 / 卡农进行 / 王道进行**并称三大进行：

| 名称 | 级数 | 听感 |
| --- | --- | --- |
| 王道进行 | `IV–V–iii–vi`（4536，常扩展为 4536251） | 明亮、推进 |
| 卡农进行 | `I–V–vi–iii–IV–I–IV–V` | 循环、怀旧 |
| 小室进行 | `vi–IV–V–I` | 哀愁 |

**关键**：这三条几乎从不原样出现，而是被**降速 + 分解 + 加九音**处理。
同一串 `IV-V-iii-vi`，用 72BPM、8 分音符分解、每和弦加九音，听感就是"治愈"；
用 128BPM、柱式和弦、光三和弦，听感就是"偶像歌"。

> 本项目采用：卡农进行作为**全部大调曲目的和声地基**（`compose/common.py`
> 的 `CANON`），自然小调骨架 `i-v-VI-III-iv-i-iv-v` 用于夜与叹息，
> 田园骨架 `I-iii-IV-V-I-vi-IV-V` 用于小镇，`i-VI-III-VII` 用于出征。

### 2.2 久石让的和声手法【有据】

对《天空之城》的乐理分析给出了三条可直接编码的规则：

1. **顺阶低音线（stepwise bass）**：低音按音阶级进，用转位凑低音
   （Bm/D、G/B、Em/G），不追求根音跳进。
2. **关系大小调成对出现**：小调 A 段 ↔ 关系大调 B 段，用一个 4-5 进行
   （如 Am–B7）作为"回小调"的门轴。
3. **十度平移（tenths）**：旋律关键音与低音保持十度关系（= 三度 + 八度），
   这是"温暖、开阔"的物理来源。

同一批分析里还有一条很关键的现象：**重属和弦被当作色彩而非功能，可以悬着不解决**。
这正是"柔和但不流行"的核心手段之一——属七的功能感太强，一堆 V7 会把音乐推向
流行/爵士，而悬置的重属只提供色彩。

> 来源：《天空之城》乐理分析（搜狐 / 徐又《乐理综合实战手册》）、
> 久石让和声研究相关文库摘要（详见调研记录）。
> 本项目采用：顺阶低音与转位（`nearest_voicing` 的平滑声部连接）、
> 关系大小调成对（D 大调 ↔ B 小调）、色彩优先于功能的和声取向。

### 2.3 和弦色彩清单

| 类型 | 写法 | 功效 | 用法要点 |
| --- | --- | --- | --- |
| add9 | Cadd9 / Fadd9 / Gadd9 | 明亮但不甜 | 大调 I/IV/V 上加九音，**不加七音**（加了就爵士） |
| 6/9 | C6/9（C-E-A-D） | 最典型的"日系日常"音 | 段首/段尾落脚 |
| sus4 | Gsus4 → G | 悬留→解决 | 解决落在下一拍或下一小节强拍 |
| maj7 | Fmaj7 | 雾气感 | 小调段借大调色彩时用 |
| 借用 | 大调里借 `iv / bVI / bVII` | 突然的怀旧/苦涩 | 每段最多一小节，立即回本调 |
| 重属 | `F#7→B7`、`A7→D` | 色彩推进 | **可以不解决**（见上） |
| 平行调 | 同主音大小调互换 | 光照变化 | 桥段或最后一遍变奏 |

## 三、旋律特征

| 维度 | 建议值 | 说明 |
| --- | --- | --- |
| 动机长度 | 2 小节（4/4）为基本单位，4 小节一句 | |
| 音域 | 10 度以内，极值不超过 12 度 | |
| 音程 | 级进为主；每 2 小节允许 1 次 ≤ 四度的跳进作点缀 | |
| 留白 | 休止占 25%~40%；每 2 小节至少一个 ≥ 八分休止 | |
| 句尾 | 弱起进入，落音在长音（二分及以上） | |
| 装饰 | 长音的约 30% 加倚音；句尾加半拍回音 | |
| 与和声的错位 | 旋律先现或延留 1 拍（低音换和弦后旋律仍停在上一个和弦音） | |
| 重复 | 同一动机出现 4 次：原形 → 加装饰 → 换配器 → 升高八度 | |
| 五声规避 | 大调旋律在重拍回避第 4、7 音 | 东方/民谣底色 |

**怀旧型旋律轮廓**（源自德沃夏克《念故乡》，公有领域）：级进上行 → 停在音阶的
3 音或 5 音并拉长 → 下行级进。这条轮廓是"温暖怀旧"的骨架，本项目主主题的
句尾落点（停在 3 音或 5 音、不落主音）即由此而来。

## 四、配器与分层

| 层 | 乐器 | 音区 | 织体 | 要点 |
| --- | --- | --- | --- | --- |
| 主角 | 钢琴 | C3~C6 | 分解和弦 / 旋律 | 踏板每和弦换一次；旋律比伴奏响 |
| 底色 | 弦乐群（弱奏长音） | C4~A5 | 全音符/二分音符 | 动态 pp~mp；每 2~4 小节换和弦 |
| 光点 | 钟琴 / 钢片琴 / 马林巴 | 高八度 | 每小节 1~2 个点状音 | 与旋律同音或高八度，绝不抢拍 |
| 木质 | 木吉他 / 竖琴 | C3~C5 | 琶音 | 钢琴主旋律时由它走分解 |
| 独奏木管 | 双簧管 / 长笛 / 英国管（**每曲只选一件**） | C5 附近 | 单旋律 | 双簧管=温暖、长笛=气声、英国管=怀旧 |
| 合成 | 温暖 Pad | 全频 | 长音 | 低音量基底 |
| 环境 | 风 / 虫鸣 / 水 / 鸟 | — | 循环铺底 | −30 ~ −24dB |
| 特殊 | 八音盒 | 高 | 单旋律 | 段首/段尾，混响发送最大 |

**分层铁律**：同一时刻最多 3 层"有音高内容"同时活动。第 4 层进入必须有一层退出。
这条比任何 EQ 都更能保证"不糊"。

**层的进入顺序固定为 钢琴 → +弦乐 → +钟琴**（Key 社"泪目三段式"的顺序），
退出顺序相反。

## 五、节奏与速度

| 项 | 值 |
| --- | --- |
| BPM | 62~84（治愈核心 68~78）；极简向可 50~60 |
| 拍号 | 4/4 为主；6/8 用于流动感；3/4 用于追忆段 |
| 摇摆 | 无 swing；切分以附点八分为主，**禁用密集 16 分** |
| rubato | 每音符落点 ±10~25ms 的随机偏移；不做全局变速 |
| 音区 | 中声区为主——动森的官方设计理念即"音区居中、速度偏慢、乐器数量少" |

**琶音织体模板**（以 C 和弦为例，全部以 8 分音符为最小单位）：

1. 上行窄琶音 `C3-E3-G3-E3` —— 最"日常"
2. 跨八度上行 `C3-G3-C4-E4`（根-五-八-十）—— 开阔
3. 十度平移型：左手 `C2`，右手 `C4-E4` 平行移动 —— 久石让手法
4. 全分解 16 分 `C3 E3 G3 C4 E5...` —— **只在情绪高点 1~2 小节使用**
5. 钟摆型 `C3-G4-E3-G4` —— "水面反光"感
6. 弦乐长音对位：弦乐走全音符根音，与钢琴 8 分分解形成**密度反差**

## 六、动态与"柔和但不平淡"

柔和却不平淡，**不是靠音量，而是靠"层数的时间轴"**：

1. **层进层出**：每个事件点增减 **1 层**（不是改音量）。
2. 段内动态 4~8 LU，全曲 6~10 LU；乐器 CC 动态锁在 mp~mf，**禁止 ff**。
3. **渐强用 8~16 小节尺度**实现，让听者察觉不到"在推"。
4. **单点峰值**：全曲只允许 1 个真正的高点（通常在第 3 遍主题），时长 ≤4 小节，
   之后立刻回落。
5. 结尾淡出或"主和弦长音 + 混响自然衰减"，**不做 ritardando**
   （变速会破坏循环对齐）。

## 七、混音与母带偏好

### 7.1 低频：为什么不糊

1. 除低音提琴与 Pad 外全部高通：钢琴 52Hz、弦乐垫 145Hz、竖琴 150Hz、
   钟琴 310Hz、木管 175Hz。
2. 低频只保留一条"承重梁"：80~200Hz 只允许一个源。
3. 弦乐垫"宽而不厚"：不叠同八度的多个弦乐音色，靠 M/S 展宽而非加厚。
4. 低频段整体**单声道化**（M/S 的侧信号高通），耳机上宽、音箱与单声道上依然稳。

### 7.2 高频：为什么不刺耳

- 高频**不做整体提亮**，而是在 2.5~2.8kHz 给旋律一点"存在感"（+1~2dB），
  让旋律浮出来。
- 6~9kHz 的乐器共鸣峰（钟琴、八度音）**窄带压掉**（-1.8 ~ -2.6dB）。
- 用软饱和替代高频激励器增加"空气感"，避免"咝"声。
- ⚠ **但要注意音源的固有音色**：本项目用的钢琴音源本身偏暗（实测频谱斜率
  约 −11dB/oct，4kHz 以上几乎无能量），对它做"高频收敛"会把成品压成闷罐。
  高频该提还是该收，**必须按实测频谱决定，不能按乐器成见**。

### 7.3 空间

| 用途 | 类型 | RT60 | 预延迟 | 发送量 |
| --- | --- | --- | --- | --- |
| 主空间（钢琴与整体） | Hall | 1.8~2.6s | 20~40ms | 18~25% |
| 弦乐垫 | Hall（更长） | 2.4~3.0s | 30~50ms | 30~40% |
| 色彩打击 | Plate | 3.0~3.6s | 40~60ms | 40~50% |
| 室内场景 | Room | 1.1~1.5s | 15~25ms | 15~20% |

### 7.4 响度

目标 **−17 LUFS / 真峰值 ≤ −1.2 dBTP / LRA 2~9 LU**。比流媒体（约 −14 LUFS）
低，理由见 [音乐质检规范.md](../../技术/音频/音乐质检规范.md) §一。

## 八、结构形式

1. **基本段落**：`A(8) – B(8) – A'(8) – C(8)`；本项目主主题即 32 小节
   = 4 个 8 小节乐句。
2. **主题变奏法**：同一主题做多个配器版本（钢琴独奏 / +弦乐 / +打击），
   **和声不动、只改配器与力度**。这是 Key 社与动森的共同做法。
3. **循环长度**：32 或 64 小节，必须是整数小节。
4. **无缝循环的三个条件**：和声在边界处闭合、边界无变速、混响尾跨边界处理。
5. **长时抗疲劳**：动森式做法是"带旋律版本"与"只有伴奏版本"交替播放。
   本项目标为**提案/待定**（见设计文档 §八）。

## 十、给程序化作曲的可执行清单

浓缩成可以直接写进代码的规则。**本项目实际采用的条目打 ✓**。

**和声**
1. ✓ 默认调式：大调与自然小调成对；**禁用和声小调的增二度**（一出现就是西洋古典味）
2. ✓ 内置进行模板：卡农 / 王道 / 小室 / 田园 / 出征（`theory.PROGRESSIONS`）
3. ✓ 和弦默认单位是七和弦以上；九和弦、六九和弦、挂留为常用语汇
4. ✓ 段首/段尾用 6/9 或 add9 落脚
5. ✓ 每 4 小节至少 1 次 sus4 悬留（`sus_float` 模板）
6. ✓ 小调段用自然小调；多利亚色彩用于明亮的小调段
7. ✓ 关系大小调成对：D 大调 ↔ B 小调（同一主题、不同调式）
8. ✓ 允许重属七出现且可以不解决（色彩优先于功能）
9. ✓ 借用和弦库：`iv / bVI / bVII`，每段最多一小节
10. ✗ 转调 +1 半音（本作是变奏集，不需要）

**旋律**
11. ✓ 动机 2 小节、一句 4 小节、八小节一乐句
12. ✓ 音域 ≤10 度，中心音区按乐器定（钢琴 C5~C6，木管 C5~A5）
13. ✓ 级进优先，每 2 小节最多 1 次 ≤ 四度跳进
14. ✓ 休止 25%~40%；句尾长音留白
15. ✓ 句尾停在 3 音或 5 音（不落主音），循环处开放
16. ✓ 全曲唯一最高点只出现一次，出现后立刻留白
17. ✗ 倚音/回音装饰（当前未实现，列为可增强项）
18. ✓ 大调旋律重拍回避第 4、7 音

**织体**
19. ✓ 钢琴左手低音 + 右手 8 分音符分解（`add_piano_accompaniment`）
20. ✓ 弦乐垫走全音符/二分音符长音，每 2 小节换和弦（`add_pad`）
21. ✓ 色彩打击每小节 1~2 个点状音，落在弱拍（`add_bell_accents`）
22. ✓ 竖琴跨八度分解（`add_harp_figures`）
23. ✓ 16 分密集只在情绪高点短暂出现（当前克制使用）

**配器分层**
24. ✓ 同屏音高层 ≤3；第 4 层进入前有一层退出
25. ✓ 配器顺序 钢琴 → +弦乐 → +钟琴（tier 0/1/2）
26. ✓ 每曲只用 1 件独奏木管（小镇=长笛、战斗=双簧管）
27. ✓ 环境音层与音乐分轨可调（`assets/audio/ambience/`）

**节奏、速度、动态**
28. ✓ BPM 58~104，治愈段 58~84
29. ✓ 每音符落点 ±10~25ms 随机偏移模拟 rubato（`humanize_timing`）
30. ✓ 禁 swing；切分以附点八分为主
31. ✓ 力度锁在 mp~mf；全曲一个高点
32. ✓ 渐强由层数增加实现，不靠推音量（`apply_velocity_arch` 只做微调）
33. ✓ 不做 ritardando（循环必须对齐小节）

**混音、母带、结构**
34. ✓ 主 Hall RT60 2.2s / 预延迟 26ms；色彩打击 Plate 3.3s；室内 Room 1.3s
35. ✓ 高通与高频处理按乐器分档，且**以实测频谱为准**
36. ✓ 输出 −17 LUFS / TP ≤ −1.2 dBTP / LRA 2~9 LU
37. ✓ 结构 `A-A-B-C`（32 小节），和声每 8 小节闭合
