## 侦察结论（2026-09-09 已完成，勿重复摸底）

### 实现现状
- 火柴人**纯矢量绘制零贴图**：`modules/units/scripts/rig/stickman_skeleton.gd` `_build_limb`（:231-260）每段肢体 = 容器 Node2D + 两层圆头 Line2D——`stroke` 描边层（宽=肢体厚 23×scale + OUTLINE_WIDTH×2，z_index=-1）+ `fill` 填充层（宽=23×scale，z=0）；头部两层 40 边 Polygon2D。`OUTLINE_WIDTH=2.0`（:25）。
- **全局两遍渲染**（:227-230 注释自述）：所有肢体 stroke 全部 z=-1 压底、所有 fill 全部 z=0 置顶 → 全身填充无缝融合、描边只在整体剪影外缘露一圈。
- `_make_line`（:263-273）**显式不开 Line2D.antialiased**，注释声称"项目已开 msaa_2d"——该前提已失效（见下）。
- 相机：`modules/world/scripts/camera/camera_rig.gd` 用 Camera2D.zoom，`user_zoom ∈ [0.5, 2.0]`；**线宽是世界像素常量，无屏幕像素补偿**（units 模块 grep zoom 零命中；对照：world_map 有 b443c26a「描边改固定屏幕像素」先例）。

### 根因排序（已抓到实锤）
1. **project.godot 的 [rendering] 段被摧毁**：`stick-world/project.godot:63` 现为一行乱码键——4.7.2 解析器把段头前的中文注释吞行+乱码合并（同类事故两次：85a2f3c0、2c2865f7），`[rendering]` 段头连同 `msaa_2d=2(4x)` 一起落进了 [physics] 段 → **运行时 MSAA 2D 实际关闭，全项目零抗锯齿**。缩到 0.5 zoom 时描边 27 世界像素只剩 ~13.5 屏幕像素，锯齿必然刺眼。修复成本最低收益最大。
2. **全局两遍渲染结构性抹掉臂-躯干内描边**：任何 fill 都盖住一切 stroke，臂/躯干交界处的分隔线被躯干填充盖掉 → 读作融合体。这不是 bug 而是 14b6c67c 回退链式分层的**设计后果**（当年 e8eb6b3e 链式分层实现过分隔线，因接缝问题被整体放弃）。
3. 缩小时描边随 zoom 线性变细无下限 + 白描边对 0.82 灰身体对比度低 → 糊/融观感放大器。
4. 头部 40 段 Polygon2D 在 0.5 zoom 下每段 4.5°，无 AA 时有棱角（小项）。

### 历史修复线（勿重走弯路）
`97e2b8e0` 矢量化 → `936b28c5` 两遍渲染 → `e8eb6b3e` 链式分层（五条链 z 递增+肩髋胶囊补丁，**曾实现分隔线**）→ `835e1296`/`22310e87` 接缝补丁 → `c27d6900` SWL 槽位序 → `14b6c67c` 回退全局两遍（现状）。AA 线：`d6a24531`→`03e4aae0`→`208a1a5f`→`85a2f3c0`→`2c2865f7`（配置事故）。
