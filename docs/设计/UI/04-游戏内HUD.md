# 04 · 游戏内 HUD

> IN_GAME 状态的常驻界面：HUD 布局分区、随层级渐隐渐显、工作区预设、时间控制。
> 模板：`hud_template.tscn`（HUD 骨架）、`workspace_template.tscn`（组织面板）。

## 一、布局分区

```
┌──────────────────────────────────────────────────────────┐
│ [‖ 1x 2x 4x] 第3天 14:20   木150 石90 铁34 沥12   [编制][地图][设置]│ ← 顶栏（三段式）
│                      ┌────────────┐                      │
│                      │   小地图    │ ← 顶部中央 240×80     │
│                      └────────────┘                      │
│                                                          │
│                    （游戏画面）                     [＋]   │ ← 缩放部件
│                                                     [－]   │   右下竖排
│ ┌──────────┐                                              │
│ │ 通知流    │ ← 左下堆叠 feed                              │
│ │ (≤5条)   │                                              │
│ └──────────┘                                              │
│        [剑1][盾2][旗3][镐4][包5][研6][仓7][医8][马9][书0]    │ ← 快捷栏
└──────────────────────────────────────────────────────────┘
   底部中央，密集堆叠
```

| 区 | 位置 | 内容 | 现状 |
|----|------|------|------|
| 顶栏 | 顶部通栏（黑玻璃条） | 左：时间控制；中：资源槽；右：系统入口 | ✅ GlobalHUD（模板重排） |
| 小地图 | 顶部中央 | 缩略图 + 视野框 + 实体点 | ✅ Minimap |
| 缩放部件 | 右下竖排 | ＋/－ + 缩放指示 | ✅ ZoomBar |
| 通知流 | 左下 | 堆叠 feed（≤5 条，3s 淡出） | 模板（现 GlobalHUD 单条） |
| 快捷栏 | 底部中央 | 10 格密集操作格：图标 + 热键角标 + 数量徽标 | 🧪 模板 |
| 模式面板 | 底部（快捷栏之上） | Village/Battle/Possess 整体替换 | ✅ ModePanel |
| 上下文面板 | 右侧 | 选中什么显示什么 | ✅ ContextPanel |

顶栏三段式分工：左管**时间**（玩家对世界的手）、中管**资源**（世界的状态）、
右管**系统**（对界面本身的手）——三类心智各就各位，不混排。

## 二、快捷栏：密集堆叠的满足感

参考《博德之门3》技能栏：格子小（52×48）、数量多、信息三层叠加
（主图标 + 左上热键角标 + 右上数量徽标）。

- 格子内容由**数据表**生成（模板 `QUICK_SLOTS`），空槽显示灰格可拖入
- 左键触发 / 右键详情（P1）；拖拽重排（P2）
- 随模式切换内容：村落模式摆建造/管理，战斗模式摆指令，附身模式摆技能

## 三、时间控制

| 速度 | 键 | UI 表达 |
|------|-----|---------|
| 暂停 | 空格 | 顶栏"‖"激活态（琥珀描边）+ 可选全屏淡色"已暂停"字 |
| 1x / 2x / 4x | 1 / 2 / 3 | 对应按钮激活态 |

- 打开 L4 模态自动暂停（设置中可改为慢速）；附身微操自动减速（设置项）
- 自动暂停条件（战斗开始/资源耗尽/聚落被袭）：P1，设置界面"游戏"页预留

| 小地图 | ◐ | ● | ● | ◐ | ○ |
| 资源条 | ○ | ◐ | ● | ● | ● |
| 通知流 | ● | ● | ● | ● | ● |

## 五、工作区预设（组织管理面板）

同一个组织管理面板，顶部标签 = 工作区（Blender 式 Modeling/Layout）：

| 标签 | 默认摆出的快速操作 | 右下摘要 |
|------|-------------------|---------|
| 军事 | 进攻/防御/行军/呼叫支援/部署/操练 | 编制数/总兵力/士气 |
| 科研 | 分配课题/审核论文/调拨经费/实验 | 在研课题/研究员/产出 |
| 工程 | 开工/验收/材料调度/质量检查 | 在建项目/工匠/完工率 |
| 行政 | 征税/户籍/司法/治安 | 聚落/人口/治安 |
| 商业 | 采购/销售/定价/物流 | 商队/流水/周转 |

**所有标签底层能力相同**：「完整功能」折叠区永远能展开全部操作
（模板 `FULL_OPS` 取并集演示，预设内已摆出的置灰防重）。

面板三段结构：左组织树（节点=组织，连线=隶属）/ 右上快速操作（3 列网格）/
右下摘要统计。树节点交互：悬停状态预览、右键菜单、拖拽调隶属（P1）。

## 六、通知流

- 左下堆叠 feed，最多 5 条，每条停留 `T_TOAST`（3s）后淡出
- 三级着色：info 蓝 / warn 黄 / error 红（对应 EventBus `ui_notification` 的 level）
- 重要通知（error）同步在顶栏铃铛位滞留角标（P1，点击回看历史）
- 落地接线：`UIRoot._on_notification` → 转发 feed 组件（替代现 GlobalHUD 单条 Label）
