## 一、玩家心智模型

玩家主要**选择建筑预设**：每种预设打包了设施内容、对应大小与预设材质——大小由设施内容决定，同一建筑可能有多种材质版本的预设。想要高度自定义时走**自由建造**路径，逐项选材质、尺寸、设施。

整栋建筑是一个**不可拆分整体**；建成后可进编辑模式调整设施与室内陈设（见 §4.3）。

**核心体验在室内**：室内像缺氧一样是一台精密运转的机器——在机构里上班的火柴人忙来忙去，设施各司其职。

**建筑与功能的关系 = 组织入驻为主、亲自使用为辅**：功能的主要运转方式是组织（机构）入驻——组织要运转，需要它所在的建筑具备它需要的设施；组织可以换址（从一栋合规建筑搬进另一栋），建筑不与特定功能永久绑定。没有组织入驻时，玩家也可以亲自使用建筑内的各设施（让游戏符合直觉）。

**运行逻辑原则**：功能经由游戏内机构与实体运转，不做 UI 抽象。蓝图即一例：蓝图是国家级建筑机构里的游戏内实体文档（不是 UI 抽象模板库），"把某栋建筑定为标准模板"＝对该机构下行政令——后续系统以此类推融会贯通，不急于实装，做到对应机构时按此原则处理。

## 二、四种基础材质

材质决定外观、层数上限、屋顶形状、建造所需资源。

| 材质 | 层数上限 | 屋顶形状 | 墙体结构 | 说明 |
|------|---------|---------|---------|------|
| **稻草棚** (thatch) | 1 | 人字草顶 | 无墙，仅前后支柱 | 早期/贫穷，最便宜 |
| **木板房** (wood) | 2 | 人字木板顶 | 前后木板 + 纵梁（隐藏） | 中期常见 |
| **石头房** (stone) | 3 | 平顶城垛 / 人字石顶 | 前后石墙 + 角石 | 中后期，坚固 |
| **砖瓦房** (brick) | 4 | 人字砖顶 / 平顶 | 前后砖墙 + 砖垛 | 高级，城市风格 |

**材质是软约束，不硬禁设施**：锻造设施可以装在稻草棚里，也能装在砖房里——材质不硬性禁用任何职能，但影响风险与效率（锻造、窑炉装进草棚/木房有火灾风险，石房/砖房才安心）；个别设施可能显式依赖特定材质（到具体设施设计时定）。层数上限与外观仍由材质决定。

**材质门槛**：材质本身不设技能门槛，但建材可能需要（有人会相关制造技能，04 技能本位）。
- 稻草、木板：随手可得
- 石头：需要采石场（可能需要有人会开采）
- 也可通过贸易从外地购买本地不产的建材

## 三、建筑尺寸

- 1 格 = 24 像素（与运行时 `PlacementGrid` 一致）
- **预设建筑的大小由预设绑定**（设施内容决定大小，随预设打包）
- **自由建造路径**：8 格原子块 + 1 格步进（不设上限；如需硬上限取 64）；设施占 8 格（或整数倍）宽，零头格浪费
- 每层高度由具体材质资源配置决定（架构不管，玩家只看视觉效果）
  - 例：稻草棚单层高 6 格（约 144px），棚顶 6 格高
- 层数上限由材质决定

## 四、设施（建筑内部功能单元）

设施是"装进建筑某一层的功能包"。

### 4.1 基础设施清单（待补齐）

| 设施 ID | 名称 | 功能 |
|--------|------|------|
| `forge_workshop` | 锻造作坊 | 打铁、武器生产 |
| `residence` | 住所 | 床、桌椅、村民居住位 |
| `warehouse` | 仓库 | 货架、货物存储 |
| `market_stall` | 市集摊位 | 商业交易 |
| `stable` | 马厩 | 马匹饲养 |

具体设施的场所需求（结构/材质/构型方面的要求，如马厩要门与通风）**到具体设施设计时逐个定**，不预设分类框架。

### 4.2 室内构造

室内是核心体验所在：缺氧式的精密运转机器——设施布局、工作位、机构成员的上班动线。具体构造随设施设计逐个补齐（资产与分层规格见 [建筑室内结构.md](../../技术/架构/建筑管线/建筑室内结构.md)）。

### 4.3 设施摆放

- **自动布局**：玩家不指定位置，系统从左到右贪心摆放
- **手动摆放**：玩家指定设施在第几层第几格，系统校验约束（不能悬空、不能叠加、该材质是否允许）
- **后期插入**：建筑建成之后，玩家可进入"编辑模式"往里加设施（校验约束后实例化）
- **室内陈设的格子级微调**：设施之下的**室内陈设**（家具、墙景、地面）以**格**为摆放单位，建成后进编辑模式可像沙盒游戏一样增删/移位。室内格与建造用的 `PlacementGrid` 同源（[建筑与聚落.md](../../技术/架构/场景与战斗/建筑与聚落.md) §4.2，24px 高精度），校验（不悬空、不重叠、位置语义合法）沿用设施摆放的同一套约束。**这条不松动"建筑是不可拆分整体"**（§一）：外壳/结构/材质仍是整栋原子块，可微调的是室内陈设这一层；陈设的资产粒度（结构带可平铺 + 家具/墙景独立卡）见 [建筑室内结构.md](../../技术/架构/建筑管线/建筑室内结构.md) §2.7。

## 五、屋顶

- 由材质决定形状（见 §二 表）
- 用**可伸缩无缝贴图**沿建筑宽度平铺 + 两端放端点贴图（山墙装饰）
- 屋顶分前后两层（屋脊前/后），与建筑的 `BackLayer / FrontLayer` 的 z 顺序一致
- 具体高度、坡度、端点形状由各材质的 `RoofShape` 资源指定

## 六、多层建筑的层间关系

- 每层都有地板，始终可见
- 只有最顶层有完整屋顶，其他层只有地板（作为下一层的天花板）
- 后期可支持"每层不同材质"（混合建筑），暂不做

## 七、建造流程（玩家视角）

1. 玩家打开建造菜单
2. 选择空白地块（PlacementGrid 上可建区域）
3. **选建筑预设**（自由建造为另一路径，入口呈现形式未定）
4. 资源预检
5. 预览建筑外观
6. 确认 → 扣资源 → 启动建造 → 工人施工 → 完工

**建造界面的"空建筑"**：各种建筑有默认的外形（默认构型参数随建筑类型自带，进建造/编辑所见即默认）。建造界面 = 功能建筑与空建筑（空木屋、空石楼）混排并列——空建筑不叫特殊选项，是普通选项之一，与各种功能建筑混杂在一起。**功能后置是可选路径，不是强制流程**：先造空壳，建好后放设施、陈设、挂机构；也可以带功能一步建到位（设施后期插入见 §4.3）。

**建造过程**：
- **P0：实现施工进度条 + 工人派工 + 建造动画**——基地建设核心体验，提前到 P0
- 不再"瞬间生成 OPERATIONAL"；施工进度与派工是建造循环的核心

## 八、建筑与聚落的关系

- 一个聚落（村落）由若干建筑组成
- 聚落的初始建筑清单在聚落生成时一并确定、首次加载自动落成（数据载体与加载机制属实现，见 [建筑模块化设计.md](../../技术/架构/场景与战斗/建筑模块化设计.md)）
- 建筑是聚落的"居民点 + 生产力单元"，不是装饰物

### 8.1 原生城市建筑的自动结构生成【停用——待建筑系统稳定后重新设计，本节旧稿仅存档参考，不立任务】

> **场景**：世界生成原生聚落时自动生成建筑群，非玩家手建。
> **关键**：建筑**不能用"横纵两个尺寸"约束**——它是**结构参数**，由一套结构规则/部件 + 合法约束 + 直觉频率组合生成。算法可以复杂，但换取的自由度与多样性值得。

- **结构部件（以原子块组合，替代"宽×深"）**：标准块层、退缩层、分裂、天桥、顶棚、混合材质层
- **二层 = 以一层为地面**：承重即"上层单元必须落在下层单元的支撑内"
- **随机量**：每个建筑随机选**结构形态** + **材质**（按文明限定池）+ **设施**（按功能池）
- **合法约束**：承重（上层 footprint 被下层支撑）、连通（楼梯/天桥可达）、功能（设施必须在合法结构内）
- **频率分布**：加权随机——简单矩形高频，退缩/分裂中频，天桥/顶棚/混合材质低频
- **与玩家建筑分工**：玩家手建 = 精修/进阶；原生自动建 = 带随机结构的基座

## 十、自然地形、软硬装与组织入驻

- **自然地形**：城市辖区自带地形（树林、矿洞、农田……），采集类组织的对应职能需要本城有对应地形——伐木要树林、挖矿要矿洞；农田既产食物也是炼药原料的来处。
- **开局自带**：城市初始已有市政厅与仓库各一座；市政厅不需要建筑具备任何特性就能让组织运行。
- **组织与建筑独立**：组织没有对应建筑也能基础运转（伐木队没有伐木小屋照样伐木），但进阶职能被禁（木材资源探测、记录一类槽位需要小屋里至少有一套办公桌椅与空间）；建筑内额外物件（工具架、额外椅子等）可提升运转效率。
- **同型可多座**：同一类型建筑可建多座（可并行施工），每座是独立的整栋、软装逐座配置；不存在"某类型建筑"的整体开关状态。
- **建造分硬装与软装**：硬装指建筑体本身——工厂体、屋顶、窗户位置；软装指室内的一切可置物——各工序设备、桌椅板凳，以及玩家纯为好看随手摆放的装修。工厂每道工序都必须有一台对应设备（软装）才能开工。
- 制造类建筑内部的动线设计（工序布局、物流路径）与建筑的关系见建筑管线文档；组织侧视角的工序/设备/半成品口径见 [`01-组织系统.md`](01-组织系统.md) §2.6。
