# 组织模拟台（org_sim_web）

组织域的**可玩设计草稿**——组织系统的机制与数值以本台为活体草案迭代，定稿后回铸 Godot 正片（`modules/organization`）。它不是发布物、不是正式 UI，只服务设计对齐：设计断言本身归设计文档（01/03/04/17 号），本页只记工具自己的事。

## 运行

| 方式 | 命令 / 入口 | 用途 |
|------|------------|------|
| 开发迭代 | `npm run dev`（Vite HMR，改即见效） | 日常迭代设计 |
| 出包 | `npm run build`（产出单文件 `dist/index.html`）→ 覆盖本目录 `sim.html` | 落稳定入口 |
| 直接玩 | 双击 `sim.html`（单文件离线可开） | 创始人验收/把玩 |

依赖：Node.js ≥ 18。`node_modules/`、`dist/` 不入仓，`sim.html` 入仓（构建产物即交付物）。

dev 模式暴露 `window.__sim`（S/advance/reset/玩家操作），供浏览器自动化与控制台直驱模拟；生产构建不含。

## 布局

- **标题栏**（第一行）：品牌 + 基础资源（只放地形产出：食物/药材/木材/铁矿）+ 仓库总览 + 时钟/倍速/参数/重开
- **横排**（第二行，页签**平分整排**，独立成排备将来扩展）：组织 / 仓库
- **组织页**：地形条（场地缓冲堆）+ 在编/待业 + 动员（耕战一体）+ 建组织（**平时折叠**，展开按系统分类：采集/搬运/施工/制造/军事/科研）；主体＝组织分列卡片（槽位板）+ **建造侧栏**（右侧，建筑行紧凑排布、点行内展开硬装/软装操作）。**点槽行就地展开操作**（派人/撤出/塞机构/选产物），再点收起
- **仓库页**：分类标签（全部/基础资源/材料/制品/场地堆存/厂内半成品）+ 瓦片网格；容量条在标签行右侧。图标只用在物品瓦片与成本芯片
- 拒止反馈落在按钮态上（禁用+悬停原因：明面前提未满足/资源不足），无事件流文本框；事件数据仍写入 `S.feed`（`__sim` 可查）

## 机制清单与占位数值（设计数值以此为准，定稿回铸）

- 地形三类：树林→木材、矿洞→铁矿、农田→粮/药材（炼药原料）；场地缓冲堆上限 40
- **粮≠食物资源**（05-经济系统 §一铁律）：进食是可选增益、无饥饿——粮是战粮类增益品原料，后续绑人口繁衍
- 市政厅槽＝系统名：领导/军事/行政/采集/运输/建造/制造/科研（01 §2.6）
- **建筑按座计**：同型可多座并行再建，每座独立软装（侧栏分座①②枚举）；**组织进驻一座对应建筑实例**（组建时自动进驻空置同类建筑，无则空挂受限；新建筑落成自动接纳空挂同类组织；03 §一「组织所在的建筑需具备它需要的设施」）——设备解锁/工序开工按本组织所驻那座算，不蹭别家的
- 额外椅子（伐木小屋软装）：木材信息联络更快——通报阈值 0.3→0.15 提前
- 速率：采集 0.8/人时（所驻小屋+工具架 ×1.25）、搬运 1.2/人时、工序 0.6/人时；未通报场地搬运 ×0.5；顶栏/瓦片的速率为每时净流量
- 仓库容量 250；运输队搬运同质化坑位 ×5（随建筑规模的设计待扩展）
- 锻造坊工序链：熔炼(熔炉)→锻打(铁砧)→淬火(水槽)→开刃(磨石)；铁水/毛坯/淬火件为厂内物品；锻打可吃铁水或外购铁锭
- 借调：信息槽缺人自动从本队作业岗借调（原槽圈停、目标槽半透明人名+慢速圈）；工厂工时在可开工工序间均摊——一人厂独轮回全工序
- 无饥饿系统（食物后续绑人口繁衍）；动员=产率减半（动员官须在市政厅军事槽）
- 人名/组织名不带编号；同名在编聚合显示（村民×3）
- 后期组织（冶炼坊/常备军/训练营/科研院）在分类面板内标注「后期」；前提/资源不满足时按钮禁用并悬停示因
