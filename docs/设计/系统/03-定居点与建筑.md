## 一、玩家心智模型

玩家不选"造一个铁匠铺"，而是**像搭积木一样组合出一栋建筑**：

1. 选**尺寸**：多大占地、几层高
2. 选**材质**：稻草 / 木板 / 石头 / 砖
3. 选**模块**：里面放什么功能（锻造作坊、住所、仓库、马厩、市集摊位……）
4. 系统按材质类型自动渲染外观，按模块位置在立面上自动开洞（模块外可见）
5. 整个建筑是一个**不可拆分整体**（类似监狱建造师，但县级自由度，不是泰拉瑞亚家具垒叠）

**运行逻辑原则**：功能经由游戏内机构与实体运转，不做 UI 抽象。蓝图即一例：蓝图是国家级建筑机构里的游戏内实体文档（不是 UI 抽象模板库），"把某栋建筑定为标准模板"＝对该机构下行政令——后续系统以此类推融会贯通，不急于实装，做到对应机构时按此原则处理。

## 二、四种基础材质

材质决定外观、层数上限、屋顶形状、建造所需资源。

| 材质 | 层数上限 | 屋顶形状 | 墙体结构 | 说明 |
|------|---------|---------|---------|------|
| **稻草棚** (thatch) | 1 | 人字草顶 | 无墙，仅前后支柱 | 早期/贫穷，最便宜 |
| **木板房** (wood) | 2 | 人字木板顶 | 前后木板 + 纵梁（隐藏） | 中期常见 |
| **石头房** (stone) | 3 | 平顶城垛 / 人字石顶 | 前后石墙 + 角石 | 中后期，坚固 |
| **砖瓦房** (brick) | 4 | 人字砖顶 / 平顶 | 前后砖墙 + 砖垛 | 高级，城市风格 |

**材质是软约束，不硬禁功能**：锻造作坊可以装在稻草棚里，也能装在砖房里——材质不硬性禁用任何职能，但影响风险与效率（锻造、窑炉装进草棚/木房有火灾风险，石房/砖房才安心）；某些职能还会显式依赖特定材质（见 §4.4 场所需求清单）。层数上限与外观仍由材质决定。

**材质解锁**：材质本身不需科技解锁，但建材可能需要。
- 稻草、木板：随手可得
- 石头：需要采石场（可能需要科技解锁开采）
- 砖：需要砖窑（可能需要科技解锁烧制）
- 也可通过贸易从外地购买本地不产的建材

## 三、建筑尺寸

- 1 格 = 32 像素
- **标准建筑 = 16 格 = 1 单元**（原子块）
- **玩家建造房屋类建筑默认 16 格整数倍**（16/32/48…）；可通过开关自由设宽。**功能模块占 16 格（或整数倍）宽**，零头格浪费
- 每层高度由具体材质资源配置决定（架构不管，玩家只看视觉效果）
  - 例：稻草棚单层高 6 格（约 192px），棚顶 6 格高
- 层数上限由材质决定

## 四、模块（建筑内部功能单元）

模块是"装进建筑某一层的功能包"。

### 4.1 基础模块清单（B3 阶段补齐）

| 模块 ID | 名称 | 功能 | 开口需求 |
|--------|------|------|---------|
| `forge_workshop` | 锻造作坊 | 打铁、武器生产 | 需要暴露（无前景墙） |
| `residence` | 住所 | 床、桌椅、村民居住位 | 需要窗 + 门 |
| `warehouse` | 仓库 | 货架、货物存储 | 需要大门 |
| `market_stall` | 市集摊位 | 商业交易 | 需要通透开口 |
| `stable` | 马厩 | 马匹饲养 | 需要门 + 通风口 |

### 4.2 模块对玩家可见性

模块放在建筑某层后，**外面的玩家能通过建筑立面的"开口"看到该模块**：
- 系统自动在模块对应的格子位置**不生成前景墙**（挖洞）
- 玩家走到建筑交互区，整面前景墙半透明，所有模块同时可见

### 4.3 模块摆放

- **自动布局**：玩家不指定位置，系统从左到右贪心摆放
- **手动摆放**：玩家指定模块在第几层第几格，系统校验约束（不能悬空、不能叠加、该材质是否允许）
- **后期插入**：建筑建成之后，玩家可进入"编辑模式"往里加模块（校验约束后实例化）
- **室内陈设的格子级微调**（2026-09-25 定）：模块之下的**室内陈设**（家具、墙景、地面）以**格**为摆放单位，建成后进编辑模式可像沙盒游戏一样增删/移位。室内格与建造用的 `PlacementGrid` 同源（[建筑与定居点.md](../../技术/架构/场景与战斗/建筑与定居点.md) §4.2，24px 高精度），校验（不悬空、不重叠、位置语义合法）沿用模块摆放的同一套约束。**这条不松动"建筑是不可拆分整体"**（§一）：外壳/结构/材质仍是整栋原子块，可微调的是室内陈设这一层；陈设的资产粒度（结构带可平铺 + 家具/墙景独立卡）见 [建筑室内结构.md](../../技术/架构/建筑管线/建筑室内结构.md) §2.7。

### 4.4 场所需求清单（结构 / 材质 / 构型）

彻底解耦不是唯一解——还有一种方法：**让某些职能依赖于一些特定的结构（比如前台开窗）、材质、构型（比如棚子，或者是修道院要有塔楼 + 居住空间）**。按约束强度分三类：

- **结构需求（硬校验）**：职能要求场所具备特定结构要素，不满足不可放置——如市集要通透前台、马厩要门 + 通风；§4.1 模块表的"开口需求"列是其现成子集
- **材质需求（软约束）**：不硬禁——锻造、窑炉装在草棚/木房是火灾风险，石房/砖房才安心；装得进去，风险与效率不同（§二 口径）
- **构型需求（复合配方）**：职能要求跨模块的组合构型——如修道院 = 塔楼 + 居住 + 礼拜的组合校验；"棚子"本身即一种构型

具体职能的场所需求清单随 [建筑功能规格.md](建筑功能规格.md) 逐模块补齐。

## 五、开口（Openings）

两类语义：

### 5.1 暴露豁口（MODULE_EXPOSE，自动）
- 模块占地格的前景墙自动不生成 → 玩家从外面能看见模块
- 无需玩家操作

### 5.2 装饰开口（DECORATION，手动，B1 阶段）
玩家可在立面上手动放置：
- **门**（DOOR）：贴图装饰 + 可进出
- **窗**（WINDOW）：贴图装饰 + 透光
- **通透口**（GAP）：大开口，如市集摊位的前台

## 六、屋顶

- 由材质决定形状（见 §二 表）
- 用**可伸缩无缝贴图**沿建筑宽度平铺 + 两端放端点贴图（山墙装饰）
- 屋顶分前后两层（屋脊前/后），与建筑的 `BackLayer / FrontLayer` 的 z 顺序一致
- 具体高度、坡度、端点形状由各材质的 `RoofShape` 资源指定

## 七、多层建筑的层间关系

- 每层都有地板，始终可见
- 多层建筑的非顶层也有屋顶段？不是：只有最顶层有完整屋顶，其他层只有地板（作为下一层的天花板）
- 后期可支持"每层不同材质"（混合建筑），但 B0 不做

## 八、建造流程（玩家视角）

1. 玩家打开建造菜单
2. 选择空白地块（PlacementGrid 上可建区域）
3. 选择尺寸（宽度、层数）
4. 选择材质（资源预检）
5. 选择模块列表 + 摆放（自动 or 手动）
6. 选择装饰开口（B1 后）
7. 预览建筑外观
8. 确认 → 扣资源 → 启动建造 → 工人施工 → 完工

**建造界面的"空建筑"**：各种建筑有默认的外形（默认构型参数随建筑类型自带，进建造/编辑所见即默认）。建造界面 = 功能建筑与空建筑（空木屋、空石楼）混排并列——空建筑不叫特殊选项，是普通选项之一，与各种功能建筑混杂在一起。**功能后置是可选路径，不是强制流程**：先造空壳，建好后放模块、陈设、挂机构；也可以带功能一步建到位（模块后期插入见 §4.3）。

**建筑与功能的关系 = 组织附身建筑**：功能不是建筑的固有属性，而是组织（机构）的落地方式——一个组织要运转，只需要它附身的建筑具备它需要的模块（并满足场所需求，见 §4.4）即可实现；组织可以换址（从一栋合规建筑搬进另一栋），建筑本身不与功能绑定。手搭的建筑会被合适的机构入住，外形乐趣与机构动态两全。

**建造过程**：
- **P0（2026-08 定）：实现施工进度条 + 工人派工 + 建造动画**——基地建设核心体验，提前到 P0
- 不再"瞬间生成 OPERATIONAL"；施工进度与派工是建造循环的核心

## 九、建筑与定居点的关系

- 一个定居点（村落）由若干建筑组成
- 村落的 `InitialBuildingsList` 存 `BuildingDef.tres` 列表，首次加载时自动生成
- 建筑是村落的"居民点 + 生产力单元"，不是装饰物

### 9.1 原生城市建筑的自动生成（叠叠乐式结构生成）

> **场景**：世界生成原生聚落时自动生成建筑群，非玩家手建。目标像《城镇叠叠乐》：高自由度、有机多样、千城千面。
> **关键**：建筑**不能用"横纵两个尺寸"约束**——它是**结构参数**，由一套结构规则/部件 + 合法约束 + 直觉频率组合生成。算法可以复杂，但换取的自由度与多样性值得。

- **结构部件（以 16 格 = 1 单元为原子块组合，替代"宽×深"）**：
  - 标准块层（1+ 个 16 格单元并排）
  - 退缩层（上层单元数减少/内缩，如 5 单元 → 3 单元，即 80 格 → 48 格）
  - 分裂（一层裂成左右两块，各若干单元，中间留 gap）
  - 天桥（左右两块间用桥连接，偶尔）
  - 顶棚（在已有层上加小单元 + 换材质，如石楼二层搭草棚）
  - 混合材质层（不同层不同材质）
- **二层 = 以一层为地面**：可自由在其上建造；承重即"上层的 16 格单元必须落在下层单元的支撑内"（见下方合法约束）
- **随机量**：每个建筑随机选**结构形态** + **材质**（按文明限定池）+ **模块**（按功能池）
- **合法约束（"在合法的情况下"）**：
  - 承重：上层 footprint 必须被下层支撑，不能完全悬空
  - 连通：所有块之间有可达路径（楼梯/天桥）
  - 功能：模块/房间必须在合法结构内（铁匠铺必带锻造、民居必带住所）
- **频率分布（"随机的足够合理"）**：**加权随机**——简单矩形**高频**，退缩/分裂**中频**，天桥/顶棚/混合材质**低频**（稀有建筑）。保证多样性的同时频率符合直觉
- **与玩家建筑分工**：玩家手动建 = 精修/进阶（美术需求）；原生自动建 = 叠叠乐式随机基座
