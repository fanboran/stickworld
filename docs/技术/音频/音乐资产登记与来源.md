> 本文登记本作**全部音乐与环境音资产的来源与许可**，是公开发布前版权复核的依据。
> 原则：能被追溯到具体来源、能被验证许可、能被替换。

## 一、三层版权结构

游戏音乐的版权不是一件事，而是三件事叠在一起。必须逐层确认：

| 层 | 内容 | 本项目的做法 |
| --- | --- | --- |
| **① 作曲（词曲著作权）** | 旋律、和声、编排 | **全部原创**。主题与九首曲子的旋律、和声进行、编排均为本项目新写，不改编任何在版权期内的作品 |
| **② 演奏/录音（邻接权）** | 某个具体录音 | **不采样任何商业录音**。全部音频由本项目在本地用采样音源离线渲染生成 |
| **③ 音源采样（采样库许可）** | 采样库里的单个音 | 只用许可清晰的采样库，逐条登记于下方 §三 |

**特别注意**：即使旋律已进入公有领域，"某个版本的录音"与"某个现代改编的编曲"
仍然受保护。因此本项目**不引用任何公有领域作品的旋律本体**，只借鉴其
**技法与结构特征**（例如德沃夏克《念故乡》"级进为主 + 色彩音长音 + 慢和声节奏"
的旋律轮廓，见 §四）。这样连"编曲相似"的风险都不存在。

**和声进行不受版权保护**。本作使用的卡农进行、王道进行、田园骨架、
出征骨架都是乐理层面的公共套路，可自由使用。

## 四、公有领域技法参考（非旋律引用）

以下经典作品**仅作为作曲技法与结构的参考**，不引用其旋律、不做改编。
清单用于说明"我们的写法从哪里来"，以及这些来源为何可以安全参考。

| 作品 | 作者 / 年代 | 公有领域依据 | 借鉴的具体手法 |
| --- | --- | --- | --- |
| 卡农与吉格（P.37） | 帕赫贝尔 / c.1680 | 逝于 1706，全球 PD | `I–V–vi–iii–IV–I–IV–V` 和声骨架（本作全部大调曲目的地基） |
| 3 Gymnopédies No.1 | 萨蒂 / 1888 | 逝于 1925，全球 PD | 慢速 3/4、大跨度低音 + 单音级进旋律、maj7/9 静态重复、无导音解决 |
| 贝加马斯克组曲 · 月光 | 德彪西 / 1890 | 逝于 1918，全球 PD | 三连音/琶音流动织体、大七与九和弦的平行移动 |
| 夜曲 Op.9 No.2 | 肖邦 / 1832 | 逝于 1849，全球 PD | 左手宽琶音 + 右手装饰性旋律、倚音与回音 |
| 平均律第一册 前奏曲 No.1 | 巴赫 / 1722 | 逝于 1750，全球 PD | 全曲单一分解和弦音型（8 分音符匀速铺满） |
| 第九交响曲「自新世界」第二乐章（念故乡主题） | 德沃夏克 / 1893 | 逝于 1904，全球 PD | **五声化旋律 + 级进轮廓 + 色彩音长音 + 慢和声节奏 + 单件独奏木管**——本作主主题旋律轮廓的直接来源 |
| 《童年情景》梦幻曲 | 舒曼 / 1838 | 逝于 1856，全球 PD | 短动机（2 小节）+ 级进 + 长音落在三音 |

版权期依据：中国大陆为作者死后 50 年；日本经 TPP 修法后为死后 70 年（2018 起施行），
但**修法前已过期的作品不会复活**；上述作品均为 19 世纪及更早，全球范围（含日、中、
欧、美）均属公有领域。

**明确排除**：任何现代改编与商业录音（含把古典旋律改编为流行演奏的版本、
影视/游戏原声带录音、以及各类"翻奏"视频音频）**一律不得采样、不得复刻其编曲**，
即使其旋律来源是公有领域。

## 五、环境音层

环境音（风 / 鸟 / 蝉 / 夜虫 / 海浪 / 溪流 / 雨 / 村落）共 8 条，交付于
`stick-world/assets/audio/ambience/`。**逐条来源、许可、作者与质检数值**登记在
`tools/music/docs/ambience_sources.md`——那是一个独立管线（无调性的噪声场，
不是 MIDI 作曲），维护规则与素材表都在该文件里。

摘要：

- 来源路线为**网络采集（Wikimedia Commons / OpenGameArt 的 PD / CC0 / CC-BY）
  + 程序化合成融合**；每条记录 URL、许可、作者、原始格式与时长。
- 许可要求：只取 **CC0 / Public Domain / CC-BY**；CC-BY-SA、非商业、来源不明
  一律不用。
- 用到 **CC-BY 素材**的是 `cicada_summer` 与 `village_ambience`（均经改编），
  **发布时必须署名**。可直接使用的署名串见
  `tools/music/docs/ambience_sources.md` §五。

## 六、音源选定结论

**GM SoundFont 选定的结果与依据**（在三个候选上实测对比后确定）：

**选定：`MuseScore_General.sf3`**（v0.2，39.9MB，**MIT**，作者 Frank Wen /
Michael Cowgill / S. Christian Collins）。理由：

1. **弦乐是真实立体声采样**——实测它与 FluidR3_GM.sf2 的弦乐长音波形相关性
   0.9997（同源），而 FluidR3Mono 只有 0.738、GeneralUser 是 -0.04。
   立体声宽度 dry 实测 L/R 相关 0.118，谱质心 1917Hz（暖）——正是"柔和长音垫"
   需要的音色。
2. **过得了本项目自己的质检门槛**——全部 15 个声部的折叠单声道损失都 < 3 LU
   （最大 2.53）。
3. **许可最干净**：MIT，附加采样为 CC0 / Public Domain；**署名义务**见下。
4. 体积最优（39.9MB，唯一小于 100MB 的强候选），且 SF3 的 Vorbis 压缩采样在
   FluidSynth 2.3.4 下渲染正常。

**备选：`FluidR3_GM.sf2`**（148.4MB，MIT，Debian 包解出，md5 与包内清单逐字符
一致）。弦乐与主力同源，且 GM51 更暖（谱质心 1808Hz vs 2537Hz）、有立体声竖琴。
若将来某个垫子听感需要更暖、且不在意体积，可换用它。

**被否：`GeneralUser GS`（v1.471 / v2.0.3）**。两个硬伤：① 本项目主弦乐垫用的
GM51 上，它折叠单声道损失 3.25 LU，**超过本项目 3 LU 的门槛**；② 其 LICENSE
自述"无法 100% 确定所有采样的来源"，对商业发布是风险。
