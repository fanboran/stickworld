# 命名与数值口径

> **性质**：全局基础口径（不是某个系统的设计）——游戏内名词的命名风格 + 资产类数值的刻度。新增内容（据点/建筑/单位/资源/科技/文案）与改动数值前先读本篇。
> **出处**：创始人 2026-09-22 纠正（原话口径见 §一/§二 首段引文）。
> **适用面**：`config/` 全部配置 + 一切玩家可见文案。

---

## 一、命名口径：一律通用描述性称谓

> 创始人原话：「全都是描述性称谓，比如箭塔就叫箭塔，别整的像武侠小说似得，串味了。」

**规则**：

- 名字**直接说出它是什么**——用它的样子、材料、功能来称呼：箭塔就叫「箭塔」、石造仓库就叫「石造仓库」、低矮土墙就叫「低矮土墙」。
- 风格**现代直白**：不用雅化词、隐喻词、武侠/玄幻腔，不为了好听而绕。
- 组合名可以长，但要**每个词都在描述**（材料 + 形态 + 用途）；一旦出现"只负责好看"的词，就串味了。

**反面示例（不要这样起名）**：

| 反面 | 毛病 | 描述性写法 |
|---|---|---|
| 赤岭寨 | "寨"是武侠腔，"赤岭"是雅化的文学地名 | 红色山林 |
| 铁腕要塞 | "铁腕"是隐喻（形容统治手腕），不是它的样子 | 石墙要塞 |
| 苍翠猎团、碧波联邦、赤砂汗国（factions.tres 现名） | 形容词性雅名，"苍翠/碧波/赤砂"只负责好听 | 待国家层接入时按本口径重命名（P5） |
| 穿云箭楼（假设） | 文学化修饰 | 箭塔 |

**三段自检（起名后逐条过）**：

1. **说人话**：这个名字能直接回答"这是什么东西"吗？
2. **去修饰仍是它**：把形容词去掉，剩下的还是它本身吗？（"红色山林"去掉"红色"仍是山林 ✓；"铁腕要塞"去掉"铁腕"就只剩"要塞"，说明"铁腕"是多余的抒情 ✗）
3. **查词表**：有没有 寨/堡主/铁腕/苍翠/碧波/赤砂/穿云/寒霜/幽影 这类武侠玄幻词？有就换。

**适用范围**：据点名、建筑名、解锁项名、单位名、资源名、系统名、界面文案——一切玩家可见名词。技术标识（`ter_bandit_camp_02`、`unlock_stone_warehouse` 等 id）不受此约束，它们只求语义清晰。

## 二、资产数值口径：整十、不膨胀

> 创始人原话：「资产数值别几十几十的，就别有数值膨胀的感觉，全都整10和直接数字最后一位不写。」

**规则**：

- **资产类数值**（资源数量、建造成本、占领奖励、价格等）一律取**整十**——不写个位零头（个位恒 0）。
- **量级克制**：同一系统内的数值保持在同一档，不要"几十几十"地往上叠，避免玩家一眼看到就把数字感知成"通胀了"。
- **现役执行**（据点奖励，AI 提案待实测定稿）：黑石营地 木10、石10；红色山林 木10、石10、铁10；石墙要塞 石20、铁10。

**边界（本条不管什么）**：

- 物理/战斗/手感参数不属于"资产数值"：箭速 637.5、走速 120、撤仗阈值 0.7/4.0/75.0 这类按各自手感与仿真需要取值，不受"整十"约束。
- 计数类（守军 3/5/8 人、编队人数）是**个数**不是刻度，直接写实数。

**待复核**：全仓既有资产数值（如建筑成本 民居 100/50、兵营 150/100/50、仓库等）是否按同一口径统一重定标——创始人 2026-09-22 未定档，定后回写本节并另批执行。
