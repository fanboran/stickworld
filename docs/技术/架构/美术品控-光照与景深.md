# 美术品控：光照与景深（创始人拍板口径 + 业界查证）

> **一句话**：本项目白天基调 = **高调照明（阳光明媚，禁止雾蒙蒙）**；景深 = **主场景零模糊 + 非线性逐层递增的远景虚化**。

## 一、为什么是高调照明

影视百年结论 + 游戏美术通用实践一致（调研 2026-09-13）：

| 要素 | 规范 |
|---|---|
| 整体 | 高调（high-key）：明亮、低反差（明暗比压缩）、强补光抬亮暗部——"轻快/乐观/安全"的经典范式 |
| 色温 | **暖主光 + 冷补光**（暖阳 + 天空冷蓝反弹）；暖色主导在游戏里暗示安全/正面 |
| 黑位 | 抬黑不致死黑，保留影子结构做体积 |
| 饱和度 | 明快=适当高饱和；降饱和留给紧张/压抑场景 |
| 白平衡 | 略偏暖，不极端橙 |
| 禁忌 | **雾/大气灰纱**（低对比+降饱和，全部抵消高调）——雾密度归零 |

## 二、本项目标定参数（HD-2D 原型实测，可作引擎侧起点）

- 光：环境 0.58 + 太阳 1.10 + 冷补光 0.12（不投影）；高调口径下贴图已含白天光照，场景光只做保底与氛围（光照别双计）。
- 后处理：曝光 1.14 / 对比 1.02 / 饱和 1.18 / lift 0.024；色调映射 LINEAR。
- 验收指标：白天图 mean ≈0.440、p1≈0.182（无死黑）、≥0.99 像素 <0.02%（无过曝白板）、高光峰值 ~0.90。
- 夜晚（对照）：夜 = albedo × tint(0.038, 0.049, 0.092) + glow×1.0（昼夜分层已标定，MAE 0.011）。

## 三、景深规范

- **主场景（临街一排建筑 + 角色）100% 锐利，零模糊。**
- 远景虚化 = **非线性逐层递增**：每层卡片材质自带 `blur_radius`（10-tap 螺旋、只糊颜色不糊 alpha），实测档位：第一层 1.6px / 第二层 4.0px / 城墙塔楼 9px / 远山树线 12px。Godot `Environment` DOF 只有近/远两档，做不出逐层——用卡片 shader 实现。
- 背景 = **多层稀疏**建筑共同盖住地平线（各层内部零散，不密集排），层后接远山/树线剪影，再上是天空（约占画面上部 2/3，地平线压低）。
- 依据：八方旅人初代的强移轴景深被社区广泛批评（"糊到看不清像素美术"），三角战略改为可关闭，后续 HD-2D 作品继续收敛——**不照抄强移轴**。
