> 索引行见 [`../待办事项.md`](../待办事项.md) 火柴人视觉修复节。事实与实测数据见

## 一、要解决的问题

创始人症状：「角色姿态经常很奇怪」（跑步没起伏、刺击没前冲、拉弓手不动、倒地只转不摔、
待机发僵）。SWL 的这批观感由 **translate 通道**（逐骨局部位移）承运，本项目 46 份动画
只导入了 rotate + root 起伏。

## 二、已确证的结构约束（别再试"补翻译"）

1. **肢体是静态胶囊**：`stickman_skeleton.build_limbs/_build_limb` 只在建骨时跑一次，
   胶囊挂**父骨**、位置取**子骨 rest 偏移**的中点与方向，运行时不重建。改子骨 `position`
   只把子树挪走、胶囊端点原地不动 → 肢节与关节脱开/叠压、剪影取并集融成团。
2. **rig rest 参数化 ≠ Spine setup**：两具骨架分别手写，不同源、不同量纲（Spine `bone3`
   (19.56, 0.16) vs rig `upper_torso` (2.85, −15.25)；Spine `minerarm2` (44.57, −0.89) vs
   rig `forearm_outer` (−34.7, 53.9)；Spine `bone`(spine_root) 在根上方 −109.76 vs rig (0, 0)；
   大腿 rig 66 vs SWL 82.7×0.5997≈49.6）。`rig_rest + Spine值` 是把两套不同原点/方向/量纲
   的数相加。rotate 能译是因为它走「相对直立参考姿态的差值」（θ = ref − spine角），
   天生不依赖两具骨架参数化一致；position 是绝对值，做不到。
3. **L1 角度全绿 ≠ 观感正确**：2026-10-11 实证——角度残差 ≤0.03° 的同时人物是团块。
   任何后续方案都必须带**绘制几何判据**（见 Phase 0 判据与路线 A3）。

## 三、确定性方案（Phase 0 的产出决定 Phase 1 走哪条路）

### Phase 0 —— 量化"姿态不保真"的构成（不动观感，可独立合入）

基准侧 `tools/dump_spine_pose.py` 已能算**含逐骨 translate 的 Spine 世界关节**（上一轮
实现过、回退时撤掉了 FK 中的 translate 参与，代码在 git 历史 `7e34aae8:tools/dump_spine_pose.py`）。
把这份能力做成**离线对照工具**（不进生产导入器），产出两样：

1. **误差二分**：对每个动画逐帧、逐骨对比「Spine 世界关节（含 translate）」与「rig 世界关节
   （仅 rotate + root）」的偏移，拆成
   - **常数分量**：与时间无关的部分 = 两骨架参数化/比例差；
   - **随帧分量**：随时间变化的部分 = 缺 translate 造成的运动差。
   输出每个动画两个分量的能量占比。
2. **同帧对照图**：`tools/render_swl_ref.py` 原版姿势 vs rig 出图（同动画/同帧/同机位）。

**分路闸（判据）**：随帧分量占主导 → 路线 A；常数分量占主导 → 路线 B。

### 路线 A（运动差主导）：位移传输 + 逐帧几何重建

- **A1 传输**：把 Spine 的逐骨 translate 由「Spine 父骨局部系」传到「rig 父骨局部系」。
  传输因子是**每骨常量**——两骨架的骨世界角恒差一个每骨常数（`C_b = Σ ref`），故两个局部系
  之间只差一个常量旋转（外加 y 镜像）；由 `_ref` 与两骨架 setup 方向现算，不留硬编码。
- **A2 逐帧几何重建**：填充几何不再建骨一次成型，而是每帧由「父骨原点 → 子骨当前局部偏移」
  现算。2D 矢量 rig 改 `Line2D.points`；HD-2D 图集路径改 quad 的尺寸/位姿推导（图集格位
  是按 rest 长度烘的，长度变化会拉伸圆头 → 需一并决策是否按轴缩放格位）。
- **A3 验收**：新增 L1「世界关节位置对账」（Phase 0 的判据转为门禁）+「剪影 y 跨度」与
  「两腿间距」守卫（上一轮翻车正是这里没有判据）+ 受控 A/B 出图。

### 路线 B（参数化差主导）：骨架参数化对齐

把 `SKELETON_DATA` 重建为 Spine setup 的等比映射（偏移 = setup × scale、y 取负），肢体改为
沿骨 +x 的胶囊（= Spine attachment 语义），`_ref` 补偿随之退役（θ = −spine角），translate
即可直接导入。
- 影响面（单一真相源变更）：46 份动画全部重烘、武器挂载（`weapon_hand`/`shield_hand`）、
  `HEAD_ORBIT`、`EXTRA_LIMBS`(20)、渲染序、HD-2D 图集规格与 quad 推导、进度条基类。
- **必须创始人视觉验收**：人物比例会变成 SWL 的（当前 rig 是自己一套比例）。
