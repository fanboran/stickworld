# 组织模拟台（org_sim_web）

组织域的**可玩设计草稿**——组织系统的机制与数值以本台为活体草案迭代，定稿后回铸 Godot 正片（`modules/organization`）。它不是发布物、不是正式 UI，只服务设计对齐：设计断言本身归设计文档（01/03/04/05/06/17 号），本页只记工具自己的事。

## 运行

| 方式 | 命令 / 入口 | 用途 |
|------|------------|------|
| 开发迭代 | `npm run dev`（Vite HMR，改即见效） | 日常迭代设计 |
| 出包 | `npm run build`（产出单文件 `dist/index.html`）→ 覆盖本目录 `sim.html` | 落稳定入口 |
| 直接玩 | 双击 `sim.html`（单文件离线可开） | 创始人验收/把玩 |

依赖：Node.js ≥ 18。`node_modules/`、`dist/` 不入仓，`sim.html` 入仓（构建产物即交付物）。

dev 模式暴露 `window.__sim`（S/advance/reset/玩家操作），供浏览器自动化与控制台直驱模拟；生产构建不含。

## 布局

- **标题栏**（第一行）：品牌 + 基础资源（粮/药材/木材/铁矿）+ 仓库总览 + 时钟/倍速/参数/重开
- **横排**（第二行，页签**平分整排**）：组织 / 仓库
- **组织页**：地形条 + 岗位图例 + 在编/待业 + 动员；主体＝组织分列卡片（**紧凑堆叠**、列间竖线分割、列内按父卡槽序排列，列无标题；不做连线）+ 右侧栏（**组织控制面板** + 建造）。**点空槽就地弹出选项：放一个人顶岗，或构筑对应的子组织**（候选按槽名给出＝构筑树的选择题，子机构可不断递归）
- **仓库页**：分类标签（全部/基础资源/材料/制品/场地堆存/厂内半成品）+ 瓦片网格；容量条在标签行右侧。图标只用在物品瓦片与成本芯片

## 机制清单与占位数值（设计数值以此为准，定稿回铸）

- **市政厅五槽**：市长/军事/生产/运输/科研（市政厅本身即行政，不设行政槽）；市长＝玩家
- **默认展示完全体**：城市级完整构筑样板（变体之一）——市政厅 → 生产局（采集队→伐木/采矿/农垦 · 工程队 · 工坊→锯木/锻造/药剂/冶炼空位）· 运输队 · 常备军（军事=动员官，训练=训练营）· 科研院；建筑与设备配齐、满员运转。设计上的**开局**仍为耕战一体最低运转（01 §2.6），本台为展示与把玩直接给完全体
- 复合组织（生产局/采集中心/制造中心）＝普通组织模板：槽里放子组织，**递归嵌套**；训练营多槽（训练管理/教官×4/器材管理）
- **建筑按座计**：每座独立软装；**组织进驻一座对应建筑实例**（组建自动进驻空置同类、落成自动接纳、解散退驻；03 §一）
- **岗位标签按用人类型三色**（工具栏图例）：**必须**（至少一人该组织才能开工，人数可弹性）· **半必须**（需人运行但不必时刻有人，可从本队别岗移调）· **增益**（无人也行，只是未解锁/缺失该功能——解锁类：军事放人解锁军队、训练解锁训练功能、采集/建造/制造开启对应线）；槽位提示极简：「负责XX」四字口径——颜色（必须/半必须/增益）已表用人语义，说明不重复
- **组织控制面板**（右侧栏，实际游戏为各组织专属复杂精美 UI，sim 模拟基础功能）：常备军·兵役制度（动员兵役=战时集结产率减半 / 常备兵役=职业兵动员不减产）；运输队·载具（人力/手推车 ×1.5）；锻造坊·锻打原料（铁水优先/铁锭优先）；农垦队·产物（粮/药材）
- 槽位候选＝**构筑树的选择题**：统筹层（采集队/工坊）或直挂单线（采集槽亦可直接放伐木队等——放弃统筹层）——不同机构是功能实现路径的偏好，如同计划 or 市场
- 岗位机制钩子：**测量**（工程队）在岗施工效率×1.15；**调度**（运输队）在岗未通报场地搬运折扣 ×0.5→×0.7；额外椅子（伐木小屋软装）通报阈值 0.3→0.15；工程队不设材料岗（建材运输归运输系统）
- 地形三类：树林→木材、矿洞→铁矿、农田→粮/药材；场地缓冲堆上限 40
- **粮≠食物资源**（05 §一铁律）：进食可选增益、无饥饿，后续绑人口繁衍
- 速率：采集 0.8/人时（所驻小屋+工具架 ×1.25）、搬运 1.2/人时、工序 0.6/人时；速率为每时净流量
- 仓库容量 250；运输队搬运同质化坑位 ×5（随建筑规模的设计待扩展）
- 锻造坊工序链：熔炼(熔炉)→锻打(铁砧)→淬火(水槽)→开刃(磨石)；铁水/毛坯/淬火件为厂内物品；锻打可吃铁水或外购铁锭
- 借调：信息槽缺人自动从本队作业岗借调（原槽圈停、目标槽半透明人名+慢速圈）；工厂工时在可开工工序间均摊——一人厂独轮回全工序
- 动员=产率减半（动员官在编）；人名/组织名不带编号，同名聚合（村民×3）
- 后期组织（冶炼坊/常备军/训练营/科研院）在空槽候选中标注「后期」；前提/资源不满足时禁用并悬停示因

## 结构

```
src/
├── sim.js            # 全部游戏逻辑：地形/建筑/组织目录、响应式状态、推进循环、玩家操作。
│                     # 机制与数值的单一真相源——改设计=改这里的目录与常量
├── style.css         # 全局样式（暗色）
├── App.vue           # 骨架 + 100ms 节拍推进 + 页签切换
└── components/       # 纯渲染：TopBar（标题栏+平分页签横排）、OrgPage（地形条+动员）、
                      # OrgCols（树形布局分列卡片+竖线分割+嵌套连线+四色岗位标签+槽内联操作/构筑候选）、
                      # OrgPanel（组织控制面板）、BuildSide（建造侧栏）、Warehouse（分类标签+瓦片网格）
```
