## 架构速记（细节见设计文档）

- 数据流：`spec.gd 声明 → layout/solver.gd（层几何/开间/屋顶参数）→ builders.gd 分发 → builders/{shell,smithy,civic,rural}.gd 装配 → comps.gd 构件 → draw/* 风格层 → gen_buildings.gd 出 PNG+JSON`。
- **22 种谱系**：街屋 8（cottage/house/townhouse/plaster_house/tavern/bakery/shop/guildhall）+ 铁匠铺四级 + 公共 5（church/chapel/tower/gatehouse/wall_seg）+ 田园 5（barn/stable/windmill/well/market_stall）。
- **开间（bay）参数化**：建筑 = 端件 + N 个开间，宽度变化 = 开间数变化，永不拉伸纹理。
- **确定性**：seed = `hash(["building_v2", def_id, width])`，构件级子流走 `painter.branch(tag)`；87 张 + 街景双跑 md5 一致已验证。
- **环境红线**：Polygon2D/draw_polygon 带 UV 采样坍缩为平涂——纹理一律 `draw_texture_rect`/仿射 `draw_set_transform_matrix`；纯色才 `draw_colored_polygon`。
- **纸纹后处理**：CanvasLayer+ColorRect 必须 `render_mode blend_mul`（普通 alpha 混合会整屏盖灰白）。
- 屋顶 rise 随宽度增高，img_h 由坡度推导（防宽建筑屋顶出画）。

## 关键决策记录

| 决策 | 理由 |
|---|---|
| 离线烘焙 PNG 而非运行时生成 | 风格上限、运行时零成本、旧管线 CPU 纹理拖慢 smoke 根除、确定性 |
| Godot 2D 渲染域而非 Blender | 正面立面是纯 2D 问题；照搬图标管线的流程纪律（注册表/确定性/拼页验收） |
| 开间体系替代旧"拉伸模型" | 拉伸会让中段纹理/窗距变形；开间增减是建筑学正确且自然的参数化 |
| 声明式 spec + 装配器（批次 2 重构） | 22 种建筑若每类手写会失控；参数化声明 + 特型 builder 才可持续扩展 |
| 元数据 JSON 随图入库 | 运行时只做"贴图+挂节点"，消费方（建造/攻城/工位/近墙透明化）契约不变 |
| 风格基线以参考图为准（批次 2 返工） | 首版偏"简笔抖动"，参考图是"干净墨线+高饱和暖色+实材质"，已对齐 |
