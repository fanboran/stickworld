# 音乐质检规范

> 本文定义音乐资产的**客观验收标准**：指标含义、目标区间、用什么算法算、
> 怎么判读。实现见 `tools/music/musiclib/loudness.py`，一键出报告见
> `python tools/music/qa_audio.py`。
>
> **先说清楚这份规范管什么、不管什么**：它管"有没有做坏"（响度不统一、
> 循环有断裂、高频刺耳、单声道塌陷、削波）。它**不管"好不好听"**——
> 那只能由人听。把客观指标当作品质的全部，会做出技术达标但不动人的音乐。

## 一、指标表

| 指标 | 含义 | 目标区间 | 算法 |
| --- | --- | --- | --- |
| **Integrated LUFS** | 整段感知响度 | 音乐 **-17 ±1 LUFS**；环境音 **-30 ~ -26**；一次性 sting 可到 -14 | ITU-R BS.1770：K 加权（两段双二阶）→ 400ms/75% 重叠分块 → -70 LUFS 绝对门限 + -10 LU 相对门限 |
| **True Peak (dBTP)** | 采样间峰值 | **≤ -1.2 dBTP** | BS.1770 附录：4× 过采样重建后取峰值 |
| **Loudness Range (LU)** | 动态范围 | **上限** 9 LU（下限放松，无缝循环本就该响度平稳） | EBU Tech 3342：短时 3s 窗口 → 门限 → 10/95 百分位之差 |
| **Crest Factor (dB)** | 峰均比 | 8 ~ 18；**< 6 说明压过头** | 20·log10(峰值/RMS) |
| **Clipped samples** | 触顶样点数 | **0** | `\|x\| ≥ 0.9995` 计数 |
| **DC offset** | 直流偏置 | `\|mean\| ≤ 0.001` | 直接求均值 |
| **Silence holes** | 意外静音空洞 | 0（>50ms 且 < -60dBFS 的段） | 10ms 短时 RMS 扫描 |
| **Seam jump (dB)** | 循环接缝跳变 | **≤ -30dB**（相对整段电平） | 取循环末 k 点与循环首 k 点之差的有效值，除以**全曲 RMS** |
| **Seam flux ratio** | 跨接缝谱通量比 | **≤ 3** | STFT 拼接段，接缝处谱通量 / 段内中位谱通量 |
| **Mono correlation** | 声道相关性 | **> 0**（负值意味着单声道会抵消）；展宽有过头保护 | L/R 皮尔逊相关 |
| **Mono loss** | 折叠单声道的响度损失 | < 3 LU | 立体声 LUFS − 单声道 LUFS |
| **Band 2–5k ratio (p95)** | 刺耳频段能量占比 | **≤ 0.30** | STFT 分帧，2–5kHz 功率 / 总功率，1s 平滑后取 95 分位 |
| **Spectroid centroid (p95)** | 谱质心 | ≤ 3500 Hz | STFT 一阶矩，95 分位 |
| **Spectral flatness (p95)** | 谱平坦度（噪声性） | ≤ 0.25 | 几何均值 / 算术均值，95 分位 |
| **Harshness score** | 刺耳度复合分（0~1，越小越柔和） | 见 §三标定 | `1.2·band25k + centroid/12000 + 0.8·flatness` |
| **IR tail energy** | 混响尾部是否被硬切 | 末 50ms 能量占比 **< 1%** | 直接算 IR 尾段能量占比 |
| **IR spectral slope** | 混响频谱是否偏白 | **-6 ~ -1 dB/oct**（粉噪 ≈ -3） | Welch 谱在 200Hz–8kHz 的对数拟合 |

### 为什么游戏音乐比流媒体低

流媒体目标约 -14 LUFS（Spotify/YouTube），而本作音乐总线定在 **-17 LUFS**。原因是：

1. **要给音效与语音留响度与峰值空间**。游戏里同时发声源远多于一首单曲。
2. **自适应音乐依赖动态对比**。安静→热闹靠层的增减，重压缩会把对比压平。
3. **玩家有独立音量与系统音量**，游戏不需要"比谁响"。
4. **长时间游玩**，高响度快速造成听觉疲劳——这与本作"久听不厌"的目标直接冲突。

## 二、判读口径上的两个陷阱

实现这些指标时踩过、且**只看单一声道测试信号完全看不出来**的坑：

### 2.1 积分响度是"声道求和"不是"求平均"

BS.1770 的 z 是各声道均方值按权重**求和**（L/R 权重 1.0）。写成求平均会让
立体声比单声道少 3 LU——而只测单声道信号时这个错误完全不可见。因此验收必须
同时包含：① "双声道同信号 = 单声道 +3 LU"；② 与独立实现（pyloudnorm）交叉验证。

### 2.2 循环接缝的归一化基准必须是全曲电平

循环结尾如果是自然衰减到静音（这是**好**写法），局部窗口的两段都接近零，
用局部窗口 RMS 做分母会让指标退化成"两个近零数相除"，判读结果毫无意义。
按全曲 RMS 归一后判读很直接：-30dB 以下基本听不见，-20dB 以上必然可闻。

## 三、刺耳度评分的标定

`harshness_score` 是**相对排序工具**，不是绝对物理量。它的用途是：在九首曲子
之间横向比较"谁更扎耳"，以及在同一首曲子的不同混音版本之间做 A/B。

标定方法与基线：

1. 用极端信号定标两端：白噪声一类应接近上限；自然收尾的纯音应接近下限。
2. 用本作全部成曲实测填中间（下表为 2026-09 首版实测）。
3. 告警阈值取"比我们自己一贯的水平明显更扎耳"——而不是套一个外部标准。

**首版实测基线**（九首，管线产出）：

| 指标 | 中位 | 范围 |
| --- | --- | --- |
| `harshness_score` | **0.077** | 0.060 ~ 0.149 |
| 2–5kHz 能量占比 (p95) | 0.021 | 0.008 ~ 0.070 |
| 谱质心 (p95) | 659 Hz | 545 ~ 768 |
| 谱平坦度 (p95) | ~0.000 | 0.000 ~ 0.001 |
| 峰均比 | 16.1 dB | 13.7 ~ 18.7 |
| 接缝跳变 | −19.0 dB | −36.2 ~ −13.3 |
| 单声道相关 | 0.205 | 0.049 ~ 0.310 |

据此：**`harshness_score` 告警线取 0.25**（中位 + 约 1.5 倍标准差），
**2–5kHz 占比告警线取 0.30**，**谱质心告警线 3500Hz**，
**谱平坦度告警线 0.25**。本作实测全部远低于告警线——这符合"柔和"的设计取向：
刺耳度低到 0.06~0.15，意味着高频没有被堆在 2–5kHz 这个最敏感的区间。

> 注意：平坦度、质心这类指标对**低电平、稀疏**的段落会退化（近静音的帧在数值上
> 接近噪声）。本实现已用"有源帧筛选"与高分位规避，但对一次性短句（stinger）仍
> 要小心：它的短时包络从起音一路降到静音，LRA 天然很大（实测 15~18 LU），
> 拿循环曲目的 LRA 上限去卡它是用错指标——故对非循环项豁免该项检查。

## 四、验收流程

```bash
python tools/music/selftest.py                        # ① 管线自检（算法对不对）
python tools/music/render_all.py                      # ② 渲染 + 混音 + 导出
python tools/music/qa_audio.py                        # ③ 出质检报告
python tools/music/qa_audio.py --check                # ④ 按阈值判定，非零退出即不通过
```

**分层验收**：

| 层 | 检查什么 | 谁来做 |
| --- | --- | --- |
| 算法正确性 | 自检全部通过（K 加权系数对表、与 pyloudnorm 一致、循环折回正确、限制器不越界） | 机器，进 CI |
| 资产客观指标 | §一 指标表全部达标 | 机器，进 CI |
| 主观听感 | 循环连续听 ≥ 10 分钟无接缝感、无听觉疲劳；静音环境下无刺耳 | **人** |
| 场景验收 | 在游戏里各状态切换无爆音、无相位跳变、音量跳变不突兀 | 人 + 引擎日志自检 |

**客观指标全绿不等于通过**。反过来说，客观指标不绿一定不通过——
这是这份规范的全部价值：把"明显做坏了"挡在人工听音之前。

## 五、阈值汇总（可直接用于 CI）

```
integrated_lufs        : -19.0 .. -15.5     (音乐总线；stinger 同区间)
true_peak_dbtp         : <= -1.2
loudness_range_lu      : <= 9.0             (下限放松：无缝循环本就该响度平稳；非循环项豁免)
crest_factor_db        : >= 7.0
clipped_samples        : == 0
dc_offset              : abs <= 0.001
silence_holes          : == 0
seam_jump_rms_db       : <= 12.0            (循环项)
seam_flux_ratio        : <= 3.0
mono_correlation       : > 0.0
mono_loss_lu           : < 3.0
spectral_band_2_5k_ratio_p95 : <= 0.30
spectral_centroid_hz_p95     : <= 3500
spectral_flatness_p95        : <= 0.25
```
