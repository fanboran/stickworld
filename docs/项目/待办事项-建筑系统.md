## 〇、维护规则（保持"单一总账"不退化）

1. **任务只登记在本档**。任何文档写"未完成事项"时，若属建筑系统，写编号引用（如 `INT-1`），不重抄条目文本。
2. **编号不复用、不重排**：任务完成时把 `[ ]` 改 `[x]` 并在末尾加完成标记（提交号），编号留着；删除条目才释放编号。
3. **状态只有四种**：`待办` / `阻塞(<编号或 DEC-x>)` / `在跑(<任务名>)` / `已否`。
4. **状态变更当场回填本档**——尤其 worktree 增删、分支收线、资产迁移之后。
5. 规格细节留在各自的规格档（内景结构 → 《建筑室内结构》§2/§4/§5.2；资产实态 → 《建筑资产清单》§四；玩法设计 → `03-定居点与建筑.md`）。本档管**做什么、谁等谁、什么状态**。
