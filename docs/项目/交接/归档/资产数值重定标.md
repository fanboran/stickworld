# 资产数值重定标 + 雅名清理

> **用途**：跨会话交接单一入口。本批为独立批次，主工作区 `main` 上直接执行（未开分支/worktree）；由调度会话核验提交（`72f434c0` 首轮 + 本轮按创始人纠正重定刻度）。
> **口径出处**：[`../../设计/命名与数值口径.md`](../../设计/命名与数值口径.md)（§一 命名 / §二 资产数值）——创始人 2026-09-22 纠正与复核裁决（含"怎么还是整10的？"那次纠正：**取自然数、不要清一色整十**）。
> **上游背景**：据点奖励已在 [`扩张循环-国家疆域与战斗结算.md`](扩张循环-国家疆域与战斗结算.md) §四⑤ 落地；本批把全仓其余资产数值对齐到同一刻度。

## 一、批次目标与口径

1. **资产数值统一重定标**：一切"账目上的数"（建造/研究/物流成本、资源基准价、招兵成本、开局资源、采集与产出量、资源点储量、占领奖励）改为**不膨胀的自然数**——位数少、一眼读得出、单次不叠成天文数字（标尺=GBA 世代口袋妖怪手感）；**取自然数、不追求整十**（满仓 10 的倍数会显假，创始人明确纠正过）；**成本与收益一起看**。
2. **不动的边界**（口径文档 §二 明写）：物理/战斗/手感参数（箭速、走速、撤仗阈值、`max_hp`、`build_time`、AI 半径/超时、单位战斗数值）与计数类（守军 3/5/8、编队人数、建筑宽度格数）不受约束。
3. **雅名清理**：玩家可见中文名一律**通用描述性称谓**——判据是"是否是今天在用的现代通用词"（创始人复核补充：铁腕/黑石/红色/平原/极北 等现代政论/新闻用词**合规保留**；清的是古风武侠词与雅化书面词：寨、堡主、苍翠、碧波、赤砂、幽影、穿云、寒霜）。

**定标总纲**：奖励不动（据点 12/9 档）、**成本侧压到"一座房子 = 一次占领奖励的 2~3 倍"**、采集产出与资源点储量同刻度收拢 → **全仓资产数值上限 78（铁匠铺 Lv4 木 / 骑兵战术研究），无三位数**（原地最高 700）。

## 三、成本-收益自洽性（为什么这个刻度能让奖励有意义）

| 关系 | 旧刻度（膨胀时代） | 定标后 |
|---|---|---|
| 占领奖励 vs 民居成本 | 木10 / 民居木100 → **1/10 座**（寒酸） | 木12 / 民居木28 → **≈ 4/10 座**（可见） |
| 占领奖励 vs 招兵成本 | 木10+石10 / 木30+石10 | **木12+石9 = 一次占领正好招一名民兵** |
| 开局资源 vs 兵营成本 | 木300 / 木150 → 2 座 | 木85 / 木45 → 1.9 座（手感不变） |
| 伐木拍数 vs 民居 | 民居木100 ÷ 20/拍 = 5 拍 | 民居木28 ÷ 9/拍 ≈ 3 拍；玩家手采 9/拍同速 |
| 一棵树的拍数 | 150~320 ÷ 20 = 7.5~16 拍 | 35~75 ÷ 9 ≈ **4~8 拍**（配合资源点数量，节奏同量级） |

要点：**奖励数值一分未压**（据点是设计锚），把膨胀的**成本侧整体压到"一座房子 ≈ 2~3 次占领奖励"**——于是奖励从"零头"变成"小半座房子 / 一名兵"，这正是口径文档 §二 要求的"成本与收益一起看"。经济节奏的净效果约快 2 倍（成本降幅大于产出降幅），实机手感待创始人验收（见 §五）。

## 六、关键决策

| 决策 | 结论 |
|---|---|
| 定标方式 | **奖励不动、成本侧压缩**：奖励是已定稿的设计锚，压缩成本才让奖励有意义（口径 §二"成本与收益一起看"） |
| 数值风格 | **自然数、不要清一色整十**（创始人三次纠正的最终口径）：满仓 10 的倍数会显假、反而有膨胀感；取值按策划常识（民居 28/12、兵营 45/32/14 这类） |
| 上限 | 全仓资产数值不超过 **78**（无三位数）；采集/生产类同步收拢以免经济节奏失衡 |
| 建筑比对基准 | 民居 = 一档基准（木28/石12），其余建筑按档位与材料配比排布（一档 8~29 / 二档 14~45 / 三档 23~77 / 顶档 78） |
| 命名判据 | 判"时代感"而非"有无形容词"——现代词（铁腕/黑石/红色/平原/极北）保留，古风武侠词与雅化书面词才换 |
| 据点名 | **不动**（铁腕要塞/黑石营地/红色山林为最终态） |
| Excel 与手写配置的边界 | 凡 `_meta.category == "excel_export"` 一律改 Excel 源再导出；手写（`territories.tres` / `professions.tres` / `techs.tres`）直接改文件 |
