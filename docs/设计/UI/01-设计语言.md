# 01 · 设计语言

> 视觉系统的设计原则与 token 总表。所有常量的**代码真相源**是
> `modules/ui_global/scripts/theme/stick_tokens.gd`（StickTokens），
> 本文是设计意图与使用纪律；数值以代码为准。

---

## 一、视觉哲学

### 1.1 双表面：深色玻璃窗 + 白色磨砂面板

界面是**玻璃窗**：游戏画面从面板底下透出来，玩家永远不"离开"世界。
参考《僵尸毁灭工程》+ 前端玻璃拟态（glassmorphism）——分两种表面：

- **深色面（全局默认）**：HUD / 主菜单 / 加载画面 / 游戏内常驻 UI —— 深色半透明玻璃 +
  浅色文字，亮世界背景下可读。世界观：火柴人由**黑色沥青**构成，黑是世界观底色。
- **浅色面（白色磨砂面板）**：弹窗 / 确认框 / 建造列表 / 资源条 —— 高透白 +
  柔和投影造深度，**不描边**。子树挂 `StickTheme.create_light_surface()`
  （文字反转为深色 `TEXT_ON_LIGHT` 系）。

**为什么双表面**：白色磨砂面板是弹窗级"卡片感"（信息聚焦、可读性高）；
常驻 HUD 若也是白色会在亮场景下被冲淡，深色玻璃保证任何背景下都稳。

### 1.2 按钮 = 深色磨砂玻璃

按钮一律深色半透明玻璃（`BTN_BG` 深蓝黑 50% 透明 + 白色低透明描边作边缘光），
**两种表面都成立**：深色面上是"黑玻浮起"，白面板上是"白卡深玻按钮"（前端经典配）。
悬停提亮、按压压暗。

### 1.3 模态遮罩 = 生成艺术背景

排他性面板打开时，画面变暗部分叠加**生成艺术**（`GenerativeBackdrop`）：
均匀排布的旋转圆润立方体（随机尺寸/相位/转速）+ 鼠标靠近排斥推开 +
光标周围柔和范围光晕。单节点 `_draw` 自绘，仅模态打开时运行。

### 1.4 一个强调色

全套 UI 只有**一个强调色：琥珀**（火光色）。用于且仅用于：

| 用途 | 例子 |
|------|------|
| 主行动点 | 新游戏 / 确定 / 应用 |
| 选中态/激活态 | 当前标签页、当前速度档、选中列表项 |
| 关键数值 | 资源图标、摘要统计数字 |

危险（红）、警告（黄）、信息（蓝）、成功（绿）是**语义色**，只出现在反馈场景
（通知、删除按钮、不足提示），不参与装饰。强调色滥发会导致玩家无法一眼找到"该点哪"。

### 1.5 信息密度服从层级

- 微观层级（L1/L2）：UI 稀疏、字大、只显示个体相关信息
- 宏观层级（L4/L5）：UI 密集、字小、允许报表式排布
- 快捷栏等"操作区"鼓励**密集堆叠**（《博德之门3》技能栏式满足感）

## 二、色彩 Token

### 2.1 基底

| Token | 值 | 用途 |
|-------|-----|------|
| `WINDOW_BG` | 白 90% 不透明 | 大面板/弹窗底（浅色面，带柔和投影） |
| `WINDOW_BG_LIGHT` | 黑 72% 不透明 | HUD 横条/内嵌区块/深色卡片（深色面） |
| `MODAL_DIM` | 黑 55% 不透明 | 模态遮罩压暗（生成艺术叠加其上） |
| `GROOVE_BG` | 黑 45% 不透明 | 输入框/滑条凹槽底（浅色面上仍是深槽） |

### 2.2 描边

| Token | 值 | 用途 |
|-------|-----|------|
| `BORDER` | 白 16% 透明 | 深色玻璃按钮边缘光（白面板不描边） |
| `BORDER_STRONG` | 白 38% 透明 | 悬停/聚焦态 |

### 2.3 文字

深色面默认（HUD/主菜单/游戏内）：

| Token | 透明度 | 用途 |
|-------|--------|------|
| `TEXT` | 100% | 正文/按钮 |
| `TEXT_DIM` | 55% | 辅助说明 |
| `TEXT_FAINT` | 32% | 占位符/角标 |
| `TEXT_DISABLED` | 25% | 禁用态 |

浅色面（白色磨砂面板子树，`create_light_surface()` 应用）：

| Token | 透明度 | 用途 |
|-------|--------|------|
| `TEXT_ON_LIGHT` | 100% | 正文 |
| `TEXT_ON_LIGHT_DIM` | 60% | 辅助说明 |
| `TEXT_ON_LIGHT_FAINT` | 38% | 占位符 |
| `TEXT_ON_LIGHT_DISABLED` | 26% | 禁用态 |

> 纪律：`StickKit.label` 的 HINT 档用 `modulate = TEXT_DIM`——modulate 是乘法，
> 深色底（浅色面主题）乘浅色 modulate 仍是深色，两表面自动正确，勿改。

### 2.4 语义色

| Token | 色 | 纪律 |
|-------|-----|------|
| `ACCENT` | 琥珀 | 唯一强调色，见 §1.4 |
| `DANGER` | 红 | 删除/战败/错误通知 |
| `WARN` | 黄 | 资源不足/警告通知/数量徽标 |
| `INFO` | 蓝 | 信息通知/链接 |
| `SUCCESS` | 绿 | 完工/增益 |

### 2.5 按钮态底色

按钮 = 深色磨砂玻璃：`BTN_BG` 深蓝黑 50% 透明 / `HOVER` 72% / `PRESSED` 65% 压暗 /
`DISABLED` 20% 灰。白色低透明描边（`BORDER`）作边缘光，两表面通用。

## 四、形状与间距

| Token | 值 | 说明 |
|-------|-----|------|
| `RADIUS` | 4 | 通用圆角（圆润感） |
| `RADIUS_PANEL` | 10 | 大面板圆角（磨砂质感） |
| `PANEL_SHADOW_*` | 18px | 白面板投影（替代描边造深度） |
| `BORDER_W` | 1 | 描边宽度（始终 1px，不用粗边框） |
| `PAD_X` / `PAD_Y` | 12 / 6 | 控件内边距 |
| `BTN_H` 系列 | 26 / 32 / 44 | 小/标准/大按钮高度 |
| `ROW_H` | 36 | 设置/菜单行高 |

间距系统：容器 separation 只取 4 / 6 / 8 / 12 / 16 五档。

---

## 五、动效

| Token | 值 | 用途 |
|-------|-----|------|
| `T_FADE` | 0.12s | 悬停/渐隐渐显 |
| `T_PANEL` | 0.18s | 面板开合 |
| `T_TOAST` | 3.0s | 通知停留 |

纪律：动效只做**透明度和位移**，不做缩放弹跳（与"玻璃窗"气质冲突）；
缩放渐隐渐显（连续缩放时 UI 按层级淡入淡出）是核心动效，见
[04-游戏内HUD](04-游戏内HUD.md) §四。

## 六、图标

现状：`assets/ui/` 为空，模板用**单字占位**（木/石/铁/沥/剑/盾…）。

图标资产规范（入库时执行）：

| 项 | 规范 |
|----|------|
| 风格 | 单色（白）线性素描，火柴人式极简线条 |
| 尺寸 | 16×16 基准，导出 16/24/32 三档 |
| 着色 | 运行时用 `modulate` 上语义色，资产本身纯白 |
| 存放 | `assets/ui/icons/`，命名 `ic_<域>_<名>.png`（如 `ic_res_wood`） |
