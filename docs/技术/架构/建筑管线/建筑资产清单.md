# 建筑资产清单

建筑管线 v3（`stick-world/tools/blender_buildings/`）全部可产出资产的台账：装配器、材质、道具、内景、自然物、地面、昼夜分层、城市布局与验收图索引。下游（HD-2D 运行时、世界地图、内容配置）按本清单查"有什么、叫什么、多大、怎么用"。

**生成基准**：本清单提取自 main `d666b24f` 的代码实态；一切数字以代码为准，再建/再删资产须同步改本清单。**分工**：分级规则与家族窗口看《聚落等级与建筑分级》；运行时消费（前墙 alpha、z 序、双路径）看《HD-2D街景系统》；内景前后层契约细节看《建筑室内结构》；硬边/材质边缘门禁看《美术品控-硬边与材质边缘》。本清单只登记"资产实态"。

## 六、地面体系（真无缝可平铺 + 分段链 + 过渡件）

- **可平铺贴图 12 种**（`SPECS`）：小鹅卵石 / 大鹅卵石 / 砖铺错缝 / 大石板 / 夯土 / 泥地车辙 / 砾石 / 灰渣土 / 草地 / 稀疏草土 / 沙地 / 木栈道。一张 = 4 格 = 128px = 1.68m；**双档交付 512（高清）/128（游戏）**，128 档按分辨率截断 fBm 层数重新取样（非降采样）；每种 **3 变体**（相位平移+种子偏移）；另出 alb/nrm/rgh 三通道。
- **分带结构**：路肩 96px（3 格）+ 路缘沟 8px + 道路带 160px（5 格）= 264px 纵向一条。**分段集（交付主形态）**：3 带 × 3 区带档（edge 夯土砾石/mid 旧砖碎石/center 石板大理石）× 5 变体段 = 45 段，16 格宽（512px）横向严格周期、任意顺序链式拼接；**规模=区带包含关系**：村=[edge]、镇=[mid,edge]、城=[center,mid,edge]。另有区域长条 4 种×3 变体（观感参考）、新旧过渡段 3、动态落地件 8（落地面环/端头/门前小径）、大尺度斑驳遮蔽图 mottle 256px。
- **decal 8 种**（引擎按种子+密度撒布）：污渍 / 水洼 / 苔藓 / 裂缝 / 碎屑干草 / 磨光带 / 修补块 / 门口通道（`SCATTER` 登记 density_per_10m 与尺寸区间）。
- **过渡带**：`ground_tiles` 登记鹅卵石↔土 / 石板↔土 / 砖铺↔草皮 3 条；`ground_transitions` 手工预制件库按"硬质收边"逻辑交付 **5 材质对 × 3 变体**（石板↔土镶边石 / 旧砖↔碎石立砌砖牙 / 夯土↔草皮草皮切边 / 砾石↔草皮矮路缘 / 木栈道↔泥地枕木横档），收边块逐块手写（line/units/els），264px 整幅放线后按带裁剪成件。
- **光照中性纪律**：全部产出 = albedo + 微 AO，不带方向性明暗；decal 同口径；变体化不破坏周期性与光照中性。

来源：`tools/blender_buildings/ground_tiles.py`（SPECS/BANDS/SEGS/DECALS/TRANS/PIECES、STRIP_* 常量、SCALE_ZONES）、`ground_transitions.py`（EDGES/PAIRS/MASTERS）。

## 七、昼夜分层（daynight）

- **合成公式**：`夜 = albedo × tint_night + glow × strength`。实测推荐 `tint_night = (0.11, 0.14, 0.26)`（≈白天 10~12% 冷蓝）、`glow_strength = 1.0`、bloom 阈值 0.75 起；albedo 只烘焙一次，tint 随昼夜插值，glow 仅夜间淡入。
- **发光判定（白名单语义）**：不靠材质名——扫描网格材质节点 `Emission Strength > 0.05`（EMIT_MIN）按连通性分簇，一簇 = 一盏灯/一处炉火/一扇彩窗；点光放簇前方 (-Y) 防灯具自遮挡，阴影保持开启。
- **发光族 FAMILY 9 族**（点光瓦数, 光晕系数）：lamp (20, 0.95) / fire (46, 1.15) / ember (12, 0.50) / crystal (24, 0.75) / rune_glow (10, 0.30)；彩窗/铅条窗/药瓶 (0, ·) 透光微光不投点光；window_lit (8, 0.70) 点亮的窗；未登记新材质走默认 (9, 0.55)。瓦数乘 `WATT_SCALE = 8e3` 换算场景尺度。
- **glow 层语义**：非发光材质槽 OBJECT 级换纯黑 + 世界压黑 + 灯全关 → 整图只剩自发光+光晕贴片，即引擎 additive 所需层；`HALO_NIGHT 0.55`（夜图起辉）/ `HALO_GLOW 1.00`（交付层足额）。

来源：`tools/blender_buildings/daynight.py`（FAMILY/NIGHT_TINT/GLOW_STRENGTH/WATT_SCALE 与头部"引擎侧合成建议"）。
