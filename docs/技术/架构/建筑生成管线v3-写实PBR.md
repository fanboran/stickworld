# 建筑生成管线 v3——写实 PBR（Blender 3D）

> v2（Godot 2D 手绘笔触）**废弃**：用 2D 程序化绘制（polyline + CPU 噪点纹理）模拟材质存在天花板，做不出砖石/茅草/木料的物理真实感。
> v3 改用项目既有的 **Blender 管线**（与 `tools/icon_pipeline` 同构的生产纪律），用 PBR 材质 + 真实光照渲染正面立面。
> v2 可复用部分：建筑谱系清单与宽度约束（3~16 格）、布局元数据契约（PNG + JSON）、验收工具形态（拼页/街景/确定性）。

---

## 一、方向与定位

### 1.1 风格定位：Stylized-Realistic（风格化写实）

**材质与光照走物理正确（PBR），造型与配色走风格化**——不是照片写实（会与矢量火柴人冲突），而是 Northgard / Townsmen / Graveyard Keeper 那类商业游戏的建筑做法：稻草看起来像稻草、砖看起来像砖、木头有木纹与体积，但构图干净、比例卡通、色彩统一。

判断标准（验收用）：**缩到游戏内实际显示尺寸（建筑高 200~400px）时，一眼能认出材质，且与火柴人同屏不违和。**

### 1.2 为什么 Blender（而非继续 Godot 2D）

| 维度 | Godot 2D 程序化（v2） | Blender 3D + PBR（v3） |
|---|---|---|
| 材质真实感 | 上限低（自绘线条 + 噪点） | Blender 节点材质（Brick/Noise/Wave/Voronoi + Bump/Displacement）＝ 工业级 |
| 光照 | 无（假阴影） | 真实太阳光 + 环境光 + 阴影 + 间接光 |
| 体积感 | 平面剪影 | 真实几何厚度、出檐、凹凸 |
| 复用 | — | 与 `tools/icon_pipeline` 同构（注册表 + 多 pass + 拼页验收 + 网页 review） |

### 1.3 与 v2 的资产关系

- **废弃**：`stick-world/tools/building_pipeline/`（Godot 2D 绘制域）不再演进；其产物 `temp/buildings/` 作废。
- **保留语义**：建筑 def 清单与宽度档（3~16 格）、meta JSON 字段（barrier/front_wall/workslots/interact_cells/can_stand_on/wall_tier）、城市分级（hamlet/village/town/city）与功能区配比思路。

## 二、技术管线（环节 / 输入 / 输出 / 门禁）

```
tools/blender_buildings/
├── materials.py     材质库：PBR 节点图（砖/石/木/茅草/瓦/抹灰/铁/麻布）  → 门禁：样片渲染通过
├── modules.py       模块库：墙段/坡屋顶/门窗/烟囱/塔/垛口/台阶/招牌/桶  → 门禁：单体样片通过
├── buildings.py     建筑装配：def 规格 → 模块组合（体量/开间/层数）      → 门禁：单体渲染通过
├── city.py          城市装配：规模分级 → 道路/分区/广场/城墙 + 建筑摆放   → 门禁：街景渲染通过
├── render.py        渲染：正交相机 + 光照 + 分辨率/采样/色彩管理           → 门禁：全量拼页通过
└── export.py        导出：PNG（@2x）+ meta JSON 对齐游戏内 1x 坐标
```

**流程（每个环节产出必须过门禁才进下游）**：
1. **材质**：单个材质样片（平面 + 球体）渲染 → 审"是否像该材质、是否与参考图同档"
2. **模块**：每个模块单体渲染（窗/门/屋顶/烟囱…）→ 审"造型与比例"
3. **单体建筑**：每 def × 宽度档 → 审"材质搭配/比例/细节/可读性"
4. **城市**：规模档街景 → 审"城市设计（分区/天际线/街道/构图）"
5. **入库**：全量拼页 + 游戏内实机对照

## 四、城市设计规范

### 4.1 规模分级

| 档 | 城墙高 | 建筑数 | 道路材质 | 特征 |
|---|---|---|---|---|
| hamlet 村落 | 140（矮墙，与单层房齐） | 10~12 | 土路 | 无广场，教堂/水井为中心 |
| village 村庄 | 220 | 14~16 | 土路 | 小广场 |
| town 镇 | 320 | 18~22 | 石板路 | 市集广场 + 城门 |
| city 城市 | 420 | 26~32 | 石板路 | 主街 + 广场 + 多塔楼 + 城墙马道 |

### 4.2 功能分区（由中心向两侧，权重固定）

核心 8%（市政厅/教堂/礼拜堂）→ 市场 22%（酒馆/面包房/商铺/摊/井）→ 工匠 22%（铁匠铺/马厩/草棚顶民居）→ 居住 34%（民居/街屋/抹灰街屋/农舍）→ 生产 14%（谷仓/风车/草棚）。

### 4.3 街道与广场

- **街道宽度** = 2~3 格（64~96px，可容火柴人群）
- **建筑退线**：建筑前进线与街道边线对齐，不得侵入道路
- **广场**：市场区中央留 6~10 格空场，中心放水井/雕塑/市集摊群
- **小巷**：每 4~6 栋留 1 格缝隙（打破"梳子齿"）

### 4.4 天际线与视觉重心

- 唯一最高点：**教堂钟楼**（或市政厅塔），位于城市中心偏后
- 次高点：城墙塔楼（等距 800~1200px，高低错落 ±15%）
- 城墙 = 城市轮廓基线，墙顶高于 80% 建筑
- **禁止等高建筑连排**：相邻建筑高差 ≥ 15%，或材质/颜色不同

### 4.5 街景构图

- 单排 = 街道立面（本项目）；可另出"俯视城市图"用于战略图参考
- 前景元素（桶/摊/树/井）打破平直，但必须落在街道内
- 左右两端以城墙转角收边，中央以广场/教堂形成视觉焦点

### 5.2 光照方案

- 主光：太阳（暖白 1.0/0.95/0.85），方位**左上前**（仰角 50°、方位 -35°），强度 3.0~3.5
- 环境：天空冷蓝（0.62/0.70/0.82）+ 地面反射暖棕，强度 0.8~1.0
- 补光：右后方弱冷光（0.15），压暗比 ≤ 2.5:1
- 阴影：柔和（sun angle 3°），接触阴影必须可见

### 5.3 相机与渲染

- 正交相机，正对建筑（正面立面）；屋顶带 8°~12° 俯角以显露屋面
- 分辨率：2x（1 格 = 64px）；输出透明底 PNG
- 彩虹管理：`Standard` 视图变换（保证与游戏内 2D 一致），不用 Filmic
- 采样：EEVEE Next 64 / Cycles 视需要
- 输出：`assets/buildings/gen/<def>_w<W>_v<V>.png` + 同名 .json

### 5.4 配色

- 木/茅草：暖棕黄系（主体积）
- 石/砖：冷灰 + 砖红（对比体积）
- 点缀：旗帜/招牌/窗帘用饱和暖色（红/金/蓝），**每栋 ≤ 2 处**，作为视觉焦点
- 禁止：高饱和纯色大面积、荧光色、纯黑（最深用 0.08 灰）

## 六、生产流程与品控

### 6.1 环节流水线（每环节独立验收，不合格打回上一环节）

| 环节 | 产出 | 验收标准（门禁） |
|---|---|---|
| M 材质 | 每个材质样片（平/球） | 像该材质 + 与参考图同档 + 缩到游戏尺寸仍可辨 |
| P 模块 | 窗/门/屋顶/烟囱/塔/垛口… | 造型正确、比例对、与其它模块能拼 |
| B 建筑 | def×宽度档单体 | 长宽比达标、门高 150、材质搭配合理、细节可读 |
| C 城市 | 规模档街景 | 分区/街道/广场/天际线符合第四章、无等距连排 |
| R 入库 | 全量拼页 + 实机对照 | 无渲染错误、meta 与 PNG 对齐、确定性复现 |

### 6.2 品质审查（每环节派审查员，以玩家 + 美术双视角）

- 审查必须**看图**并给出**逐条带证据的问题**（哪张图哪个部位），禁止泛泛而谈
- 严重问题（比例/材质不像/城市设计违规）必须打回重做，不得带病入库
- 每轮迭代记录在交接档

## 八、规范修订决议（对 §3~§5 冲突的拍板，与上文冲突时以本节为准）

前三章的规范在实施中被三个并行小组证伪了若干处，本节为**裁决结果**：

### 8.1 视角（重要变更）

**采用 3/4 偏航视角：相机水平偏航 12°（建筑朝右前方），俯角 10°。**
理由：参考图四张全是带偏航的三维视图；纯正视会把屋面压成平板（实测证据 `temp/pbr_yaw_compare.png`），失去"大面积屋面"这一参考图的核心特征。
- 街景中所有建筑使用**同一偏航方向与角度**（保持整齐）；镜像使用会破坏光照一致性，禁止。
- 游戏内 Sprite 用同一套图，方向感由玩家视角统一理解。

### 8.2 宽度与长宽比（修正 §3.1/§3.2）

- **带门建筑最小宽度 = 8 格**（裁决实施后的修订：6 格实测已是长宽比天花板 1.49、屋面占比仅 27%；
  「门 150 + 门框 8 + 有坡度的屋面」在 6 格（192px）内算术上必然超标，且加宽本身正是"别太窄"的正解）。
  4 格档仅用于小物件（水井/市集摊/城墙段/柱撑棚），6 格档保留给无门/矮体量（草棚、马厩开口、遮棚）。
- 长宽比统一口径：**网格宽 : 剪影总高 = 1 : 0.85 ~ 1 : 1.5**（单层）；**超出上界 = 竹竿，必须加宽或减层**。
- 双层建筑单列：**层高 175~195**（门 150 + 楣梁 25~45），总高 = 层高×层数 + 屋顶 rise；不得用单层长宽比约束双层。
- 民居/商铺/草棚等单层：6 格宽 → 高 190~230；8 格 → 高 230~300；12 格 → 高 300~420。
- 出檐：**每侧 18~23% 建筑宽度**（参考图实测比例），8 格建筑取 46~59px。

### 8.3 门与洞口的例外（修正 §3.1）

- 门净高 **150**、单扇宽 45~60。
- **复合门洞豁免**：谷仓大门（双扇合宽 ≤ 140）、马厩前檐开口、开放棚（无门）、城门拱洞——按各自 def 语义实现，不受 45~60 限制。

### 8.4 光照定标（修正 §5.2，以实测定标为准）

| 项 | 值 |
|---|---|
| 太阳 | 仰角 40°、方位 -38°，强度 3.0~3.5，暖白 (1.0, 0.95, 0.85)，sun angle 3°（柔影） |
| 环境光 | **强度 0.60**、天空冷蓝 (0.62,0.70,0.82) + 地面反射中性暖（0.8~1.0 会把暖色洗成橄榄绿，实测证伪） |
| 补光 | 右前弱冷光 0.15（背光对正对相机的立面无贡献） |
| 阴影 | 接触阴影必须可见；压暗比 ≤ 2.5:1 |

### 8.5 材质禁令（补充 §5.1）

- 抹灰墙**禁止锈褐色斑块**（只允许：颗粒、抹刀痕、泛潮斑、边缘剥落）；实测出现锈斑判不合格。
- 石砌偏蓝灰需校正（目标中性灰 0.60/0.58/0.54）。
- 缩到 25%（游戏内实际尺寸的量级）后必须仍能辨认材质类型——这是每个材质的**出厂门禁**。

### 8.6 城市规范豁免与修正（修正 §4.1/§4.4）

- **hamlet/village 豁免**"墙顶高于 80% 建筑"（矮墙档与单层房齐平即为合格）。
- 城墙塔楼：高度上限绑**教堂顶 - 30**，下限为"次高建筑 + 20"；同城塔高极差 **≥ 15%**（防等距发假）。
- 小档焦点：hamlet/village 使用**矮教堂档**（塔顶 400~480），风车/谷仓等高体量压到 ≤ 340，保证教堂为唯一最高点。
- 城市立面渲染时，**后城墙只画低矮背景轮廓**（按平面深度画完整后墙会夺走教堂钟楼的视觉重心 —— 布局组实测）。


## 九、首次品控结论与下一轮改造清单（美术总监评审）

### 9.1 水准判定（三批产出）

| 批次 | 判定 | 核心问题 |
|---|---|---|
| 材质库（12 种 PBR） | 玩家吐槽 | **游戏内实际尺寸（25%）下 12 种塌成 4 组灰/棕**；样片是平涂无光照响应；iron 不像铁；thatch 读成瓦楞板 |
| 建筑单体（6 def） | 玩家吐槽 | 正立面是纸板（无檐口厚度/檐下暗带）、窗与门等高且落地、二层复制粘贴且**镂空可见天空**、悬空斜条、烟囱悬空、锻炉方块堆、零道具零火光 |
| 城市布局器 | 不能看（作为美术方案） | 全饱和调试配色、等宽等距平行路网（梳子齿）、广场是空白、单排进深；**作为布局数据可用**，作为观感方案不可交付 |

**唯一净进步**：几何一致性、材质色板统一、可参数化程度显著优于 v2 手绘版；但属"从不能看变成样子货"，不是可卖水准。

### 9.2 下一轮改造清单（按品控优先级）

1. **立面修正（最高优先，占据玩家 90% 视线）**：屋面做可见厚度（檐口板 + 压条 + 屋脊瓦 + 山墙封檐板）、檐下 AO 暗带、烟囱落地带泛水；**窗型表化**（窗台 ≥ 0.9m、窗高:门高 ≤ 0.75、同立面同窗型 ≤ 2 次、上下层窗型差异化）；二层几何差异化（出挑/腰线/阳台）。
2. **材质标准重建**：定全局 texel density（128px/m，重点构件 256px/m）；重铺 12 种使"游戏内 1:1 裁切可辨"；重做 iron 与 thatch；污渍改独立 decal；tile 扩到 2×2 以上；补 wattle-and-daub / 木瓦 / 原木横叠 / 玻璃 / 自发光 5 种；样片改"球 + 立方体三角度"以证明 PBR 响应。
3. **消灭程序生成感**：路网层级化（1 主街 + 2~3 支路 + 巷，禁等距平行）、沿街连续街墙 + 退线 ±1~2 格随机、10~20% L 形/凹形院落、留后巷；广场实体化（铺装边界 + 中央纪念物/水井 + 棚架阵列）；院坝填附属物；出图分"真实材质版 / 调试色版"。
4. **道具层与灯光层**：20~30 件程序化道具库（木桶带铁箍/柴垛/招牌/灯笼/水槽/推车/长凳/篱笆/货箱），按建筑类型挂载；炉火/灯火自发光 + 暖色点光；正午/黄昏两套环境光；QC 图必须含接触阴影与檐下 AO 对照。
5. **校验工具**：修复剪影体检图（改真火柴人剪影 + 人高刻度）；城墙高度规则（墙顶 ≥ 80% 建筑）在小档的达标；新增自动校验——"道路格不得被占用""同建筑纹素密度差 ≤ 2 倍""同材质游戏尺寸可辨"。
