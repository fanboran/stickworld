## 一、三条修复（根因 → 改法）

### 1. 武器白色描边（billboard 路径）

**根因**：全融合描边作用在 `FusedOutlineGroup`（CanvasGroup）的**组缓冲**上——组内任何像素
（含武器）都会被外轮廓白线包一圈。武器原先挂在 `rig.get_parent()` = 缩进组内的
`OutlineGroup`，因此细武器（弓片/矛杆两三像素宽）被白线吞成"白武器"。

**改法**：`char_sprite_3d.set_weapon_type` 挂点取 `viewport` 本身（描边组之外，经
RemoteTransform2D 跟手骨，位姿不变）。2D 骨架武器本就是普通 Sprite 无 stroke 层、
crowd 批渲染不画武器——三条路径自此统一"武器不吃描边"。

### 2. 战斗粒子特效根除

删除两个战斗粒子源与其库定义（真删，不留开关）：

| 位置 | 原内容 | 处置 |
|---|---|---|
| `units/scripts/entity/health_component.gd` | 受击 `HIT_SPARK` 火花 | 删调用，留下"受击反馈走动画与血条"的注释 |
| `units/scripts/entity/weapon_ranged.gd` | 法术命中 `MAGIC_BLAST` 爆炸 | 删调用（AOE 伤害/击晕结算不动） |
| `fx/scripts/fx_library.gd` | `HIT_SPARK`/`MAGIC_BLAST` 常量 + `create_burst` 分支 + `_config_spark`/`_config_magic_blast` | 全删 |

保留：建造尘土 / 采集飘屑 / 环境星光（非战斗），以及非粒子的战斗反馈
（命中飘字、挥砍弧光、箭矢投射物、胜利彩带）。同步清理引用点：
`debug_gui/debug_tools_panel.gd`、`tools/fx_screenshot.gd`、`tests/unit/test_fx.gd`、
`modules/fx/api.gd`、`modules/fx/README.md`、`待办事项.md`（「12 特效扩容」撤销）、
`模块API契约.md`、`AI复刻执行计划.md`、`药剂工艺特效复刻参考.md`。

### 3. 随身特效与火柴人错位（视觉域协议铁律 2 的落地点）

**根因**：HD-2D 图里实体原点 = **视觉脚线**，而命中飘字/挥砍弧/箭矢按 2D 口径锚在
**髋**上；这些元素画在 2D 画布域，坐标不压缩就与压缩后的 billboard 部队错开
（飘字落在大腿/脚面高度、粒子云与箭矢飘在部队下方的空草地上——基线截图为证）。

**改法**：
- 新增地图协议 `MapBase.fx_anchor_lift()`（2D 恒等 0；`Hd2dMapBase` 覆写为
  `BILLBOARD_HIP_H_PX = 50.23` = char_sprite_3d 脚底锚 141 × RIG_SCALE 0.35625）。
- `FxLibrary.remap_body_pos(tree, pos)` = `remap_pos(地面锚) − 抬升`；命中飘字
  （`spawn_damage_text`）与挥砍弧（`spawn_slash_arc`）改走此口——飘字从脚面抬到
  头顶上方（原内部 −62 头顶偏移与抬升叠加），2D 图行为逐像素不变（零回归）。
- 箭矢自带 `VisualRoot` 容器逐帧补偏移（`_apply_visual_offset`）：**只压弹道地面线、
  弹道高度按原值保留**；地面线取「出弓点脚线 → 瞄准点脚线」按飞行进度插值
  （首帧位置 + 70 回推射手脚线；传入插地线 − 65 回推目标脚线）。Area2D 判定与
  碰撞形状留在根上（物理域不动）。

## 四、决策速查

| 决策 | 结论 |
|---|---|
| 战斗粒子 | **根除**（删代码，不留运行时开关）；战斗反馈由命中帧动画 + 血条 + 飘字 + 弧光承担 |
| 武器描边 | 任何场合武器都没有描边；billboard 武器挂 viewport 根（描边 CanvasGroup 之外） |
| 随身特效抬升量 | `BILLBOARD_HIP_H_PX = 50.23`（billboard 脚线→髋的视觉高度）；不随体型缩放（billboard 本就不随 body_scale） |
| 箭矢 | 物理/判定留在画布域；绘制走 VisualRoot 逐帧偏移，地面分量压缩、弹道高度不压缩 |
