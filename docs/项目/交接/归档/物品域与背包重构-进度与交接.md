## 关键决策(为什么这么做)

1. **items 域独立(L1)**:背包/尸体遗物/村仓/未来工坊仓库都是 ItemContainer
   消费者+ItemTransfer 原语——任何新库存场景零新概念(创始人方向,
   Valheim/RimWorld 同构)
2. **列表制背包**:无总数量限制,唯一上限=每类 max_stack(创始人裁决);
   "背包满"分支消失,装备/卸装恒可行
3. **滚轮语义**(创始人定稿):附身态滚轮=切武器,Shift+滚轮=缩放;
   非附身=缩放。ShortcutGate 拦截+CameraRig 门禁双保险
4. **stats 乘子不碰基准**:equip_attack/speed_mult 乘子字段+effective_damage
   统一出口,battle_sim 校准锚零影响(附身实体专属,脱离复位)
5. **翻包而非掉落**:尸体=容器,走近按 F 翻检;与村仓共用 ContainerScreen
6. **RegionStorage 归 items**:对 resources 是弱类型 api 注入(无硬依赖),
   归 items/core 避免 units→inventory 依赖环(实测环已断,audit PASS)
7. **hotbar 只收武器/工具/消耗品**:护甲/材料无高频切换语义(创始人指正)
