## 归档规则

1. **何时入档**：一次性计划执行完毕、快照类记录过期、结论已被正式文档吸收。
2. **命名规范**：`原名-YYYY-MM.md`；禁止"废弃/过期/old"类后缀。
3. **入档动作**：从原目录移入 + 原引用处改指本目录；待办条目同步压缩为摘要行。
