## 技术栈选型

| 项 | 方案 | 依据 |
|----|------|------|
| 引擎 | Godot 4.7 | 创始人指定，P0 阶段当前版本 |
| 脚本语言 | GDScript | Godot 原生，开发效率高 |
| 渲染管线 | Forward+ | Godot 4.x 默认渲染器，支持 2D + 3D 混合 |
| 2D 渲染 | Node2D + Sprite2D + AnimatedSprite2D | 平面 2D 画风 |
| 骨骼动画 | Skeleton2D + IK 修改器 | 火柴人战斗动画（见 [`../架构/场景与战斗/场景与战斗架构.md`](../架构/场景与战斗/场景与战斗架构.md) §7.1） |
| 物理 | CharacterBody2D + Area2D | 火柴人移动与碰撞检测 |
| 测试 | Godot headless 场景测试 | `tests/` 分层用例，`tests/run_all.sh` 驱动（详见 CONTRIBUTING） |
| AI 开发 | Vibe Coding 模式 | 创始人偏好，详见 [`AI工作流指南.md`](AI工作流指南.md) |

## 多人工作流（预留）

> 当前为单人开发阶段，以下为团队扩展后的协作设计。

| 角色 | 职责 |
|------|------|
| 主程/架构 | 核心系统、战斗逻辑 |
| 配合程序 | UI、工具、数据配置 |
| 美术 | 火柴人素材、场景、UI 皮肤 |

**协作工具**：
- 版本控制：Git + GitHub；Godot 标准 `.gitignore`
- 提交规范与分支策略见 [`../../CONTRIBUTING.md`](../../CONTRIBUTING.md)
- 多会话/多 worktree 并行规约见仓库根 `AGENTS.md`「会话交接」节

## 项目结构速查

> 完整目录设计见 [`../架构/场景与战斗/场景与战斗架构.md`](../架构/场景与战斗/场景与战斗架构.md) §十三「目录结构提案」。

```
stick-world/                     # Godot 项目根（res://）
├── project.godot
├── core/                        # 核心系统（修改需批准）
│   ├── autoload/                # 全局单例（event_bus / scene_manager / save_manager / config_manager）
│   ├── ui_framework/            # L0 UI 公共层（ui_kit 布局原语 + components 无依赖组件）
│   ├── services/                # 抽象服务
│   └── utils/                   # 通用工具类
├── modules/                     # 游戏功能模块（开发最频繁的区域）
│   ├── units/                   # 火柴人 + 行为 AI
│   ├── combat/                  # 战斗系统
│   ├── construction/            # 定居点建设
│   ├── organization/            # 组织架构
│   ├── world_map/               # 战略图模块（鸟瞰多边形领土）
│   ├── world/                   # 场景图模块（卷轴地图，含 GameRoot/Map/CameraRig）
│   ├── buildings/               # 建筑运行时
│   ├── environment/             # 环境/天气/光照
│   ├── player_control/          # 玩家输入分发/附身操控（框选/编队/战术指令在 combat/scripts/command/）
│   ├── ui/                      # UI 分层（GlobalHUD/ModePanel/Minimap 等）
│   ├── resources/               # 资源系统
│   └── debug/                   # 调试覆盖层（DebugOverlay）
├── scenes/                      # 顶层场景（game_root.tscn + chunk 模板）
├── config/                      # 数据驱动配置（maps / buildings / resources 等 .tres）
├── assets/                      # 全局共享资源（buildings/ 素材等）
├── addons/                      # 第三方插件
├── prototypes/                  # 原型实验区（不被正式逻辑依赖）
├── tools/                       # 自定义工具脚本
└── tests/                       # 自动化测试
```

> **术语提示**：「战略图」（`modules/world_map`，鸟瞰多边形领土，玩家不在其中）与「场景图」（`modules/world`，卷轴地图，玩家在其中）是两类不同的地图概念，详见 [`../架构/世界与战略图/世界地图数据流.md`](../架构/世界与战略图/世界地图数据流.md) §1。
