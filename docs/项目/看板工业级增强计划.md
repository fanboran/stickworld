## 核心概念（已拍板设计）

1. **认领机制（调度核心）**：txt 新字段 `认领=AI名`。认领≠状态——认领后卡片渲染特殊标识（琥珀边框脉冲/AI 名角标），
   状态语义 = "已认领待开工"。校验：认领任务必须前置全齐（可开工）。
2. **CLI 是 AI 的接口**（执行 AI 自发认领的机制）：
   - `python tools/deptask/gen.py claim <id> --by <AI名>`：原子认领（校验可开工→写 txt 认领字段→追加调度日志）
   - `python tools/deptask/gen.py release <id> [--by <AI名>]`：释放认领
   - `python tools/deptask/gen.py done <id> --by <AI名>`：标记完成+日志
   - `python tools/deptask/gen.py sim --agents N --rounds M`：多 AI 调度模拟器（生成模拟调度日志 jsonl，供运行图渲染/压力测试）
   - 调度日志：`docs/项目/调度日志.jsonl`（事件：claim/release/done/new，字段：ts/agent/action/task/lane）
3. **底部 IDE 面板**（LOGIC-8 trace-wrap/Blender 底栏式，占下方 ~40% 可折叠）：
   - Tab A **运行图**（火车运行图式 canvas：x=虚拟时间轮次，y=泳道，任务认领→完成画横条双线，运行中=琥珀蚂蚁线，完成=实线绿）
   - Tab B **调度日志**（事件流列表，mono，最新在顶，agent 色标）
   - 可整体折叠到只剩 tab 条。
4. **动效系统**（对标专业调度软件）：
   - 认领瞬间：卡片琥珀边框脉冲 ×3 + flyTo 镜头 + 底栏日志滚动
   - 进行中：卡片顶部呼吸微光
   - 完成：绿色确认闪 + kv 燃尽数字跳动
   - 关键路径/运行中链：琥珀蚂蚁线（已有，扩展到认领链）
5. **压力测试**：sim 生成 500+ 节点数据验证渲染帧率（draw 每帧全量，必要时增量绘制/离屏缓存）。
