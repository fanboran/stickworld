## 二、测试

### 2.1 悬置套件空跑失败（运行器缺陷）

7 个 integration 套件的 `.tscn` 已在 `9641bb87`（HD-2D 化第一批）改名 `.tscn.suspended` 悬置：
`test_construction_cycle / test_garrison_spawner / test_recruit_flow / test_save_roundtrip / test_town_life_harvest / test_town_life_worksite / test_village_map`。
但 `run_all.sh` 仍按 `test_*.gd` 枚举，加载失败即记 FAIL（各 1.5~2.2s 秒败，与断言无关）。悬置行为未写入 `tests/README.md`，运行器也不识别 `.suspended` 后缀——**悬置清单与运行器脱节，每次全量测试固定产出 7 个假失败**，淹没真信号。

### 2.2 test_cross_map_travel 稳定失败（2 处，两次复测均现）

- `[FAIL] 村落B: HD-2D 村实例`——断言 `map.has_method("get_layout_width") or map is ScriptVillageMap`，实际实例两者皆非：村 B 换 HD-2D 实例后测试与实现 API 漂移。
- `[FAIL] 反向旅行: 玩家在右侧入口`——`EntrySide.RIGHT` 回主街后玩家未落在右侧入口。今日 `1d3f0956`（城门洞通行/资源点迁出）后出现，真回归或断言过期二选一，需修复时裁决。

另注：首跑曾有另外 4 个失败（主街子节点/ChunkTrigger/玩家生成等），复测消失——为并发编辑瞬时态（`_ResourceGenScript` 常量先引用后声明、`FOREST_CLEAR_CELLS` 先用后定义）级联，非稳定问题。

### 2.3 运行时报错漏网（报错自检盲区）

headless 测试运行中实测出现（编辑器日志扫描覆盖不到）：
- `UnitLodDirector._is_trackable` 收到 previously freed 对象——LOD 轮询对已释放实体缺 `is_instance_valid` 防护。
- `Nonexistent function 'get_possessed_entity' in base 'Node2D'`——测试对地图脚本做鸭子类型调用，实例非预期类型时裸崩。
