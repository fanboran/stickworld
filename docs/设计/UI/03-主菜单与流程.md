# 03 · 主菜单与流程

> 启动到进入游戏的全部屏级界面：主菜单、新游戏、载入屏、读档、制作名单。
> 模板：`main_menu_template.tscn`。

---

## 一、启动流程

```
启动 → BOOT（autoload 初始化/存档索引）→ 主菜单
主菜单 ├ 继续游戏 → 载入屏 → 游戏（读最近槽位；无档则灰置）
       ├ 新游戏   → 确认框（P1 向导）→ 载入屏 → 游戏
       ├ 读取存档 → 读档界面 → 载入屏 → 游戏
       ├ 设置     → 设置界面（与游戏内同一份）
       ├ 制作名单 → 名单页
       └ 退出游戏 → 确认框 → 退出
```

现状：`project.godot` 主场景直进 `game_root.tscn`（启动即游戏）。
落地时在主场景前插主菜单场景，主菜单负责切换到游戏根。

## 二、主菜单

### 2.1 布局

```
┌────────────────────────────────────────────────┐
│                                          [总览] │ ← 模板导航（正式版无）
│                                                │
│         火柴人帝国模拟                          │ ← DISPLAY 34
│         从部落到大帝国 · 亲手设计，看它自转        │ ← HINT 弱化
│                                                │
│         ┌──────────────┐                      │
│         │  继续游戏     │ ← ACCENT，无存档时禁用 │ 280px 菜单列，
│         │  新游戏       │ ← ACCENT             │ 垂直居中偏左
│         │  读取存档     │                      │
│         │  设置        │                      │
│         │  制作名单     │                      │
│         │  退出游戏     │                      │
│         └──────────────┘                      │
│                                  v0.1.0-p0 原型 │ ← 版本角标 TINY
└────────────────────────────────────────────────┘
```

### 2.2 要素表

| 要素 | 说明 | 数据 |
|------|------|------|
| 标题/副标题 | DISPLAY + HINT 弱化 | 固定文案 |
| 菜单列 | 大按钮 44px，数据驱动 | `MENU_ITEMS`（加项=加一行） |
| 继续游戏 | 读最近存档槽；无存档 → 禁用态 | SaveManager 槽位索引 |
| 版本角标 | 右下，TINY + FAINT | 版本常量 |
| 背景 | 黑玻璃下透出的世界（P1：慢速漂移的战略图实景） | — |

### 2.3 为什么菜单列偏左不全屏海报

"窗户不是海报"：主菜单本身就是一块浮在世界上的玻璃。P1 计划让背景直接渲染
慢速漂移的战略图（玩家的帝国实景），标题与菜单浮在其上——从打开游戏第一秒
就在强化"这是个活着的世界"。

## 四、载入屏

✅ 已实现（`modules/ui_global/scenes/menus/loading_screen.tscn`），主菜单「新游戏/继续/读档」均经它过渡：

| 要素 | 设计 |
|------|------|
| 底 | 纯黑不透明（载入期没有世界可透） |
| 进度 | 中央细进度条（琥珀 fill），`LOAD_SECONDS`(2s) 内 0→100%（视觉过渡） |
| 提示 | 中央轮换提示（`LOADING_TIPS` 数据驱动，加一条=加一行） |

当前为**过渡型载入屏**：同步场景切换下进度是视觉过渡。真正的异步/分阶段进度加载
（含"正在生成地块…"阶段文字、世界生成期 ESC 中止）留待世界生成并行化（阶段 1）。

## 五、读档界面

现有 `SavePanel`（5 槽位列表）已可用，演进到**卡片化**：

```
┌─ 存档槽 1 ────────────────────────┐
│ [缩略图] 帝国历 3 年 · 北境村落      │
│          2026-08-17 14:30 · 2.4h  │
│          [读取]        [删除(红)]   │
└───────────────────────────────────┘
```

| 要素 | 来源 |
|------|------|
| 缩略图 | 存档时截屏（P1，SaveManager 预留写入点） |
| 元信息 | `save_meta`：游戏内时间/地图名/真实时间/游玩时长 |
| 操作 | 读取（ACCENT）/ 删除（DANGER + 确认框） |
| 自动存档 | 独立槽位区，不占用 5 个手动槽 |

删除必经**危险确认框**（05 §三）。

## 七、退出与中断

| 场景 | 行为 |
|------|------|
| 主菜单退出 | 危险确认框 → `get_tree().quit()` |
| 游戏内退出到主菜单 | 提示"未保存进度将丢失"→ 确认 → 自动存档（若开启）→ 回主菜单 |
| 游戏内直接关窗 | 同上到主菜单，但直达桌面 |
