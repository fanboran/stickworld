# 手绘贴图烘焙管线

> 程序化「马克笔手绘」UI 贴图的离线烘焙技术栈：Python/PIL 生成 → 九宫格平铺自检 →
> Godot StyleBoxTexture 实装 + 全局沸腾帧驱动。
> 设计意图与视觉纪律见 `docs/设计/UI/01-设计语言.md` §1.4；本文只讲技术。

---

## 1. 全景

```
temp/gen_sketch_ui_a10.py          烘焙脚本（参数/配方/几何/自检全在这一个文件）
        │  PIL 4x 超采样绘制 + LANCZOS 缩小
        ▼
temp/a11_round/{slot}_f{0..2}.png  96x96 沸腾三帧 × 17 槽位 + 分隔线 2 槽（57 张）
        │  拷入 assets/ui/sketch/
        ▼
SketchTextures（theme/sketch_textures.gd）  贴图加载 + 全局帧驱动
        ▼
SketchStyle（theme/sketch_style.gd）        九宫格 StyleBoxTexture 工厂
        ▼
SketchPanel / SketchButton / SketchProgress / SketchLineEdit   控件内部挂贴图
        + StickTheme（SKETCH 皮肤的 Button/Panel/Tab 等原生控件 stylebox）
```

**为什么离线烘焙而不是运行时自绘**：贴图路线覆盖面大（Theme 一次注入全控件吃皮肤，
含 TabContainer/滑条这类难换控件类的地方）；自绘路线（`SketchDraw`，血条同源沸腾）
质感更"活"但每类控件要写自绘类。两条路线共用同一套配色 token 与几何语言，当前
主视觉走贴图（控件类内部挂贴图实现），`SketchDraw` 保留给血条/齿轮钮等世界空间元素。

## 2. 核心算法（每一项的出处）

| 技术 | 做法 | 出处/先例 |
|------|------|----------|
| **沸腾线 line boil** | 边线路径逐帧重掷随机相位，边缘像手绘逐帧重画 | 手绘动画行业术语与现象（每帧重新描线导致的线条抖动）；游戏化先例：Cuphead 等手绘风作品的逐帧线条。本项目用确定性伪噪声离线烘焙 3 帧循环近似 |
| 确定性伪噪声 | `sin(i*127.1 + seed*0.3117)*43758.5453 → fract-0.5` | shader 圈经典 hash 变体（`fract(sin(dot(p,k)))` 系，IQ 等人 shader 作品常见），项目血条 `HealthBarIndicator._wobble` 同公式 |
| **无缝平铺** | 噪声用**整数频率余弦**，t=0/1 处值与导数双连续 | 程序化纹理无缝平铺的标准思路（周期函数）；本项目踩坑结论：sin 版接缝斜率突变会产生规律"竖刺"，cos 版消失 |
| **九宫格 9-slice** | 角固定、四边 TILE 平铺、中心纯色拉伸 | UI 业界标准（Java NinePatch / CSS border-image / Godot StyleBoxTexture） |
| 超采样抗锯齿 | 4x 画布绘制 → LANCZOS 缩小 | 离线渲染通用做法 |
| 马克笔线条 | PIL `line(joint="curve")` 粗线 + 圆头 | 自研组合参数（线宽 2.6px @96px 贴图） |

**几何约束（血泪教训，逐条有事故对应）**：
1. 直边必须**精确满覆盖**平铺带 `[MARGIN, TEX-MARGIN]`——圆角半径一旦伸进平铺带，
   接缝处就重复出现角弧尾巴（跳变断线）
2. 角弧端点必须与直边端点**同坐标衔接**——曾把弧圆心放角区角点，弧端点接不上直边，
   `draw_line` 自动补出竖直短线落进平铺带两端
3. 边线贴贴图边缘（INSET 0.6 只留线宽出血），不做系统性内缩——内缩一圈会让
   矮按钮内容区被吃掉（"按钮变一条横线"事故）
4. MARGIN ≤ 10——30px 矮按钮上下边带 2×10px 后中心还剩 10px

## 3. 烘焙参数（单一版本纪律：所有槽位共用）

| 参数 | 值 | 说明 |
|------|-----|------|
| `TEX` | 96 | 贴图边长 |
| `SS` | 4 | 超采样倍数（384 画布绘制） |
| `MARGIN` | 10 | 九宫格边距 = Godot 侧 `texture_margin` |
| `INSET` | 0.6 | 边线贴边出血 |
| `CORNER_R` | 6.0 | 角弧半径（弧完全落在角区 [0,10] 内） |
| `WOBBLE` | 1.1 | 边缘扰动振幅 px |
| `LINE_W` | 2.6 | 描边线宽 |
| `FRAMES` | 3 | 沸腾帧数 |

## 5. 烘焙与质检

```bash
# 生成 + 自检（形状守卫 + 平铺接缝跳变，任何槽位失败即退出码非零）
C:\Users\fanbo\AppData\Local\Programs\Python\Python312\python.exe temp/gen_sketch_ui_a10.py

# 人工验收图（4x LANCZOS 放大 / 360x90 平铺模拟，两张 PNG）
#   temp/a11_round/_验收_贴图放大.png / _验收_平铺效果.png

# 实装：拷入游戏资产并重导入
cp temp/a11_round/*_f[0-9].png stick-world/assets/ui/sketch/
godot --headless --path stick-world --import
```

自检三关（脚本内置，缺一不可——每一关都拦到过真事故）：
1. **形状守卫**：源图顶/底边线存在（拦"三角形/缺边"类几何错）
2. **接缝跳变**：平铺模拟（280x64）接缝坐标处边线 y 跳变 > 4px 即失败
   （只测接缝，不测全行——手绘波动本身不是缺陷）
3. **视觉验收**：放大图 + 平铺图肉眼过（像素探针测不出"好看"）

## 6. Godot 实装要点

- **不用 AnimatedTexture**：实测它在 StyleBoxTexture 渲染路径不推进帧（静图）。
  方案：`SketchTextures._FrameDriver`（挂 root 的 Node）每 1/7.5s 把全部注册的
  stylebox 的 `texture` 换到下一帧——stylebox 是共享资源，换引用即全局重绘。
  驱动挂载：`UIRoot._apply_theme()` 调 `SketchTextures.ensure_driver(get_tree())`
- **StyleBoxTexture 参数**：四边 `texture_margin=10`；`axis_stretch_* = TILE`
  （边平铺/分隔线），中心区纯色拉伸无损
- **控件路由**：`SketchPanel/SketchButton/...` 类内部挂贴图 override（接口
  tone/kind/ink 不变，调用点零改动）；Theme 层（`StickTheme.create()` SKETCH）
  的原生控件 stylebox 同走 `SketchStyle`——tscn 里的裸 Button/TabContainer 等
  也吃皮肤
- **亮背景墨色**：主菜单浮在天空上的按钮用 `SketchButton.ink`（深墨描边+黑字），
  贴图白描边在亮底不可见——见 01-设计语言 §1.0

## 7. 与自绘路线（B）的关系

同一设计语言的两条实现：贴图（本管线，覆盖广、烘焙质检可控）与自绘
（`SketchDraw`，血条同源真随机沸腾、每控件独立相位）。控件类内部当前挂贴图；
`SketchDraw.draw_gear`、血条、PlacementGhost 等世界空间/特殊形态仍自绘。
切换路线只动控件类内部实现，不动调用点。


## 8. 新增按钮样式操作手册（以加一个「成功」按钮为例）

一条链路动 6 个文件，按序执行（漏一步 = 样式不生效或贴图缺失告警）：

| 步 | 文件 | 做什么 |
|----|------|--------|
| 1 | `temp/gen_sketch_ui_a10.py` | `RECIPES` 加配方：`"success_normal": {"bg": C(0.45,0.8,0.48,0.14), "border": C(0.45,0.8,0.48,190)}` 等（色值**镜像 StickTokens**——token 先行，脚本同步） |
| 2 | 同上脚本 | 跑烘焙 + 过三关自检：`python temp/gen_sketch_ui_a10.py`（形状/接缝/退出码非零即停）；肉眼过 `_验收_*.png` 两张图 |
| 3 | 资产 | `cp temp/a11_round/success_*_f*.png stick-world/assets/ui/sketch/` 然后 `godot --headless --path stick-world --import` |
| 4 | `theme/sketch_textures.gd` | `_load_all()` 槽位清单加 `"success_normal", "success_hover"` |
| 5 | `theme/sketch_style.gd` | 加工厂方法 `success_normal()/success_hover()`（`_box(&"success_normal", PAD_X+2, 2)`） |
| 6 | `sketch/sketch_button.gd` + `theme/stick_kit.gd` | `SketchButton.Kind` 加 `SUCCESS` 并在 `_apply_flats` 的 base 映射；`StickKit.ButtonKind` 加同名枚举并在 `_setup_button` 加分支（字色/伪粗策略） |

验收：`tests/dev/sketch_compare.gd` 陈列区加一行跑起来看，再跑 `ui_shots` 回归。

**红线提醒**（01-设计语言 §1.5）：
- 强调色只有琥珀一个——新语义色按钮需先确认不破坏"一个强调色"原则
- 禁琥珀字（字永远白/黑/伪粗），hover 字色走 Theme 的反黑规则，别单独覆写
- 贴图单一版本纪律：新槽位必须与现有槽位共用 §3 全部几何参数
