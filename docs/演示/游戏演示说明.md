# 火柴人大战略 · 游戏演示说明

> 一款融合**大战略 × 横版实时战斗 × 工厂自动化**的单机游戏（Godot 4 / GDScript）。
> 本页是游戏演示的快速展示入口：怎么玩、做了什么、亮点在哪。

## 十分钟体验路线

启动游戏（Godot 编辑器 F5，或 `godot --path stick-world`）→ 主菜单点「新游戏」：

1. **采集**：WASD 移动，靠近树木/岩石按 `E` 采集——右上角阶段目标卡与顶部资源条实时反馈
2. **建造**：右下角「建造」→ 选建筑 → 左键放置 → 靠近按 `E` 施工
3. **编队**：顶栏「编制」创建编队（或 `Q` 切战斗模式框选士兵）
4. **战斗**：带兵向右行军穿过道路抵达战场，歼灭敌人——侧翼单位会自动包抄，士兵被击中会规避
5. 全部完成弹出**胜利结算**（用时/统计），之后自由沙盒开放

| 操作 | 按键 |
|---|---|
| 移动 / 采集·交互（可按住连采） / 战斗模式 | WASD / E / Q |
| 换武器（剑矛弓镐杖） | 1-5 |
| 战略图（地块/大陆） | Tab / M |
| 附身微操 | BattlePanel「附身选中单位」 |
| 暂停·继续 / 菜单 / 存档 | 空格 / ESC / F5·F9 |

## Demo 阶段实现亮点

### 演示引导与采集交互
- **四阶段目标链**（采集→建造→编队→战斗）+ 胜利结算：把第一个可玩原型（定居点建设 + 小队级编制 + 小规模战斗）串成 10 分钟可完成的引导演示；全事件驱动零轮询，监听资源/建造/编队/战斗四路信号；采集进度用基线快照法排除开局资源干扰
- **资源采集交互**：E 键多目标交互（工地/仓库/资源点统一检测分派）、采集即时反馈（弹跳+飘字+剩余量渐隐）、耗尽自毁

### 渲染与手感
- **全屏后处理管线**（单 pass shader 六层）：暖色分级、太阳炫光（核心光晕+水平光芒+ghost 光斑+呼吸）、渐晕、边缘色差、胶片颗粒——昼夜系统联动（夜晚转冷色、炫光淡出）
- **转场与打击感**：地图切换黑场渐变、尸体滞留淡出、受击硬直/击退/顿帧

### 程序化美术管线（零美术人力）
- **笔触拟合管线**：程序合成参考图（低多边形形状+光照）→ 逆向油画算法拟合（分层笔触+模拟画布叠压+误差驱动收笔）→ 形状 mask 抠图 → 游戏贴图

![笔触拟合贴图](演示/树木贴图_笔触拟合.png) ![石头](演示/石头贴图_笔触拟合.png)

- **天空装饰**：多层视差背景（星野 0.08 → 飞鸟 0.35 → 远山 0.55 → 树线/雾带 0.7-0.88，相机因子驱动扫动速率）+ 漂移云层
- **昼夜天空生命感**：夜晚 380 颗程序绘制星野淡入（大星十字 sparkle）+ 月亮（双层光晕/环形山/微升沉）+ 近地萤火虫短脉冲闪烁（星月在天、萤火在野），白昼成群剪影飞鸟横穿远空（会被山脊遮挡出纵深，入镜配一声远处啁啾）——与后处理共用同一亮度→昼夜因子，淡入节奏同步

### 音效与反馈
- **程序化音效层**：numpy 合成 11 个 WAV（采集敲击/获得叮、目标完成琶音、战斗胜负、UI），AudioManager 事件表落位零改动生效
- 资源条增减双色闪烁（扣红/得绿）、开局中央操作大提示（6 秒淡出）

### 士兵 AI（Running with Rifles 式参数基线）
- 兵种行为档案（基线+兵种覆盖的参数分层）：瞄准节奏、风筝保距、y 纵深个性漂移、攻击槽位排队、集火共享目标
- 灵动化三件套：**侧翼自动包抄**、站桩微移步、受击规避小跳

## 工程底座（Demo 之下）

14 个功能模块（api.gd 接口契约 + 32 信号全局事件总线解耦）、60+ 自动化测试（unit/integration/smoke 三层，增量执行 + pre-commit 钩子）、12 张 Excel 配置表管线（校验+幂等导出）、96 篇架构文档。详见 [AGENTS.md](../AGENTS.md) 与 [docs/技术/架构/](../技术/架构/README.md)。

## 已知边界（Demo 范围外）

科技树/物流/扩张系统为规划中（游戏内 K/O/J/L 打开的是路线图占位面板）；战略图聚落下钻、Chunk 流式加载在设计文档中未到实装阶段。
