## 1. BGM 侧链压缩机

- **改了什么**：`BGM` 总线挂 `AudioEffectCompressor`，检测源 = `SFX` 总线
  （threshold −24dB / ratio 3 / attack 20ms / release 250ms / 无补偿增益）。
  音效一密音乐自动让路，音效一停自动回来；压的量随音效实际能量**连续**变化。
  与既有状态档压限（战斗 −6dB / 暂停 −9dB / 结算 sting −4dB）叠加生效、互不替代。
  实现：`core/services/audio_manager.gd::_ensure_bgm_sidechain`。
- **预期听感**：战斗打得越凶，背景音乐整体越"退后"一分；刀剑声一停音乐自然回来。
  是柔和的整体呼吸，不是一记一喘，音乐也永远不该被压没。
- **怎么试听**：进一场十几人以上的战斗，站在打得最密的地方听背景音乐；
  把 SFX 音量滑条拉满对比更明显。
- **不对劲怎么调**（常量都在 `audio_manager.gd` 顶部，【提案/待定】标定的就是这组数）：
  - 每记挥击都在喘 → 加长 attack：`BGM_SIDECHAIN_ATTACK_US`（现 20000）；
  - 战斗里音乐被压没 → 抬 threshold：`BGM_SIDECHAIN_THRESHOLD_DB`（现 −24.0）；
  - 让路恢复得太慢/太快 → 调 `BGM_SIDECHAIN_RELEASE_MS`（现 250）。

## 2. 弓 / 镐 Sound 事件（武器动画音效桥）

- **改了什么**：world 装配层新增 `modules/world/scripts/weapon_anim_sfx_bridge.gd`：
  `attack_bow_release`/`attack_bow` 的 Hit 命中帧 → `weapon_bow_fire`（暂复用 swoosh 风声池），
  `attack_pickaxe` 的 Hit 命中帧 → `weapon_pick_hit`（暂复用 harvest_hit 敲击池）。
  动画数据自带 Sound 时桥自动让位（Spine 源补数后不双发声）。播放策略全走 `SFX_POLICY` 表。
- **预期听感**：弓手放箭"唰"一声与箭离弦同帧；镐敲石"哒"一声与触石同帧。
  AI 弓手时序准确；**已知相位差**：玩家手动放箭的声音比箭离弦晚约 0.5s
  （修齐需动 entity_possession 链，归附身重构批次，先听是否可忍受）。
- **怎么试听**：招一队弓手打一场（贴镜头听齐射）；或让小人拿镐采矿，站近听。
- **资产口径**：现在是风声/敲石池代打——专门的放弦音/触镐音等音效资产批次产出后，
  改 `SFX_EVENTS` 两键指向即可，键名是契约不动调用点。

## 3. 战斗氛围层（战场声场）

- **改了什么**：`BattleInstance` 每 0.5s 广播双方存活总数
  （新 EventBus 信号 `battle_engagement_changed`，start 发初值）；
  `MusicDirector` 挂一条战斗循环声场，三档音量随规模起伏
  （≥40 人 0.34 / ≥12 人 0.24 / 其余 0.15，4s 淡化），`battle_ended` 退场。
  用声场代替逐单位发声（小兵代理档不发动画事件，规范 §C4 推荐路线）。
- **预期听感**（资产就位后）：战斗中有一层人群/兵器底噪，人越多越响、
  打完 4s 内退去；与 BGM 侧链叠加后"场面越大音乐越靠后"。
- **怎么试听**：**当前不可听**——`assets/audio/ambience/battle_crowd.wav` 未产出

  机制面由 `tests/integration/test_battle_ambience.tscn` 覆盖（全绿）；
