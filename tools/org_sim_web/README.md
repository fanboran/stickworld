# 组织模拟台（org_sim_web）

组织域的**可玩设计草稿**——组织系统的机制与数值以本台为活体草案迭代，定稿后回铸 Godot 正片（`modules/organization`）。它不是发布物、不是正式 UI，只服务设计对齐：设计断言本身归设计文档（01/03/04/05/06/17 号），本页只记工具自己的事。**修改前先读 [修改必读.md](修改必读.md)**——历史裁决与操作规程固化在那里。

## 运行

| 方式 | 命令 / 入口 | 用途 |
|------|------------|------|
| 开发迭代 | `npm run dev`（Vite HMR，改即见效） | 日常迭代设计 |
| 出包 | `npm run build`（产出单文件 `dist/index.html`）→ 覆盖本目录 `sim.html` | 落稳定入口 |
| 直接玩 | 双击 `sim.html`（单文件离线可开） | 创始人验收/把玩 |

依赖：Node.js ≥ 18。`node_modules/`、`dist/` 不入仓，`sim.html` 入仓（构建产物即交付物）。

dev 模式暴露 `window.__sim`（S/advance/reset/玩家操作），供浏览器自动化与控制台直驱模拟；生产构建不含。

## 布局

- **标题栏**（第一行）：品牌 + 基础原料（原木/铁矿/农作物）+ 仓库总览 + 时钟/倍速/参数/重开
- **横排**（第二行，页签**平分整排**）：组织 / **建筑** / 仓库 / 总览——后三页要对应槽位在编才解锁（建筑←生产槽、仓库←运输槽、总览←情报槽；锁页签🔒悬停示因；裁决43），一站式总览＝把各处文书**运回市政厅的汇总快照**：信息量不随情报规模 gate（各组织面板自有数据源，全段常显）；情报链决定**更新效率**（汇总在编才有更新；采编每人周期 12→−3时 下限1时；无人=停更标陈旧）；段落置顶/挂主菜单由玩家点选（localStorage 持久）——01 §5.3
- **组织页**：地形条 + 岗位图例 + 在编/待业 + 动员；主体＝组织分列卡片（**紧凑堆叠**、列间竖线分割、列内按父卡槽序排列，列无标题；不做连线）+ 右侧栏（**组织控制面板**，VSCode 式拖拽调宽：左缘手柄、双击复位、宽度 localStorage 记忆）。**点空槽就地弹出选项：放一个人顶岗，或构筑对应的子组织**（候选按槽名给出＝构筑树的选择题，子机构可不断递归）；卡头悬停示所驻建筑与设备明细；未选组织时右栏＝**待业名册**（属性/会艺）
- **建筑页**：**城市一排**（03 §八——沿街一字排开、市政厅居中、向两翼扩建），整页横向条带渲染 cityCells()：每座建筑一块、块宽＝占格数（CITY_W，块内格子底纹示意占地），块面显示建筑名+座号与关键状态（仓库＝库存/容量、民居＝单双层与居住位、各厂＝设备 n/m+驻组织、市政厅＝现名与人口）；各一层块上的「＋」＝对该座加建二层（一横排只表示一层；材质定层上限：茅草棚1/木板房3，裁决38/44）；两端**扩建位**按钮就地展开建造菜单（各类型卡＝名/占宽/形制标（棚/屋/架）/工序链环节明细（工作量+逐环节料），资源不足禁用并示因），开工后排入对应翼末的**半透明施工块**（进度条，落成即入排；卫星仓在「矿井卫星区」段渲染）；点建筑块→页面下方**软装详情**（类型下实例列表+设备行+安装按钮，逐座配置；含**剖视图**＝逐层内构格+工位人点（**工程队·设计岗在编才可见**——裁决43）；面板高度 VSCode 式拖拽可调）；顶部**施工队列条**（当前单+在跑环节名/等料⚠+进度+排队数+施工人力）
- **仓库页**：分类标签（全部/基础原料/材料/制品/场地堆存/厂内半成品）+ 瓦片网格；容量条在标签行右侧。图标只用在物品瓦片与成本芯片

## 机制清单与占位数值（设计数值以此为准，定稿回铸）

- **市政厅七槽**：市长/军事/**行政**/生产/运输/**教育**/情报；市长＝玩家。行政槽管理人事与组织——**人事局**（人事/组织管理）：人事在编＝**自动补员**（待业者自动补进缺员的必须岗，在编越多补得越勤；场地堆总量不足两时活时不补搬运、采集线同判——卫星堆满停采不补、该线收货没开且场地堆已压单人两时产能不补（下游无消费入口）——饱和判断，不把过剩人口灌进空转岗；**无闲人时从多人非必须岗匀一人调剂**——must 岗被抽空不再无人可补，不拆其它 must 岗）；自适应扩建改编（01 §4.6 三阶段：手动指派→RTS 定点→城市/地区级规划）
- **开局＝聚落最小形态**（reset 默认）：根组织「聚落」+市政厅/仓库各一座，10 人（你+动员官+村民×8），初始库存 原木30/农作物30/**木材20**/木板10——自举本金（工作量制口径）：首屋（民居·屋 原7板2）+床（木4）+锯木坊（开敞棚 原10板2）+锯架（木8），板为一次性垫底、此后板/梁/椽/瓦/门窗全自产，低于此开局锁死（全城唯一木材产能是装了锯架的锯木坊）。**完全体样板**（loadDemo，参数面板载入）：市政厅 → 生产局（采集中心→伐木/采矿/农垦 · 工程队 · 制造中心→锯木/锻造/药剂/木器/冶炼）· 运输队（库管槽=库务所入驻）· 常备军（军事=动员官，训练=训练营）· 科研院；建筑与设备配齐、满员运转（样板三线收货全开——完全体得真搬运，开局默认全关是另一回事，裁决34；运输队开车＝一队一车按队占编、库备 2 辆周转；矿井卫星区一座卫星仓——矿堆容 +80、集中短驳；工程队自动扩建开着——近满自动排队新仓）
- **个体层**（17 号五属性＋04 号技能最小集）：每个村民出生即有五属性 str/int/agi/cft/cmd（sim 占位分布 2~8，同 seed 可复现）与技能清单（采伐/耕作/采矿 50%、木工/锻造 25%、制药/冶炼 20%、识字 15%）；开局「你」固定 识字+cmd7、动员官 cmd6；芯片悬停见个体档；**属性消费端**：采集/搬运吃 str、工序吃 cft（带宽 ±20% 占位系数）——力气大手巧活细的个体差异直接进产线
- **存档**：localStorage 自动存档（30 秒一次+关页前），刷新不丢城；顶栏「重开」清档新局；参数面板可按 seed 重开复现初始布局
- 复合组织（生产局/采集中心/制造中心）＝普通组织模板：槽里放子组织，**递归嵌套**；训练营多槽（训练管理/教官×4/器材管理）；完全体含冶炼坊（铁矿→铁锭线同场运转）
- **中间层扩编（集团化）**：母槽（制造中心·锻造、采集中心·伐木/采矿/农垦、生产局·建造）除直接放单厂/单队，还可构筑**总坊/总队**管理层（锯木/锻造/药剂/木器/冶炼总坊、伐木/采矿/农垦总队、工程总队）——各含总管（占位统筹岗）+ 3 个下辖槽，下辖槽各放一株同型组织（工厂类各需自驻一座建筑实例，硬前提不变）；中间层不再嵌套，同型多株组织的在编在总览按模板合计（类比：科学院下辖省科学院、军下辖营；完全体样板含锻造总坊→锻造坊示例）
- **建筑按座计**（宽度按 8 格原子块口径：民居4/设施类8/市政厅16；民居可**加层**至木质上限2层——加层＝对既有座的施工单「接层立架→上层墙顶」，不是开工选项）：每座独立软装；**组织进驻一座对应建筑实例**（组建自动进驻空置同类、落成自动接纳、解散退驻；03 §一）
- **建筑内构格**（03 §4.3）：软装带占格宽 w，每座建筑室内格容量＝CITY_W×2×层数（如锻造坊 16 格）；安装单也占格，超容拒绝（「室内格已满」）；布局＝逐层从左到右自动贪心（默认，手动摆位/编辑模式归正片）；建筑页软装详情渲染**剖视图**——逐层内构格，工序岗的人●点在他的设备格上、非工序岗◦散层内
- **岗位标签按用人类型三色**（工具栏图例）：**必须**（至少一人该组织才能开工，人数可弹性）· **半必须**（需人运行但不必时刻有人，可从本队别岗移调）· **增益**（无人也行，只是未解锁/缺失该功能——解锁类：军事放人解锁军队、训练解锁训练功能、采集/建造/制造开启对应线）；槽位提示极简：「负责XX」四字口径——颜色（必须/半必须/增益）已表用人语义，说明不重复
- **指令面板**（右侧栏，各组织专属运行操作所在地，01 §5.3；实际游戏为定制精美 UI，sim 模拟基础功能）：常备军·兵役制度（动员兵役=战时集结产率减半 / 常备兵役=职业兵动员不减产）；运输队·载具（人力 1.2/人时 / 手推车 1.8/人时——**一队一车按队占编、库中需有手推车才可切换**，实物在场门槛）与·装卸规则（均匀分运=按堆量比例 / 大宗优先=先清最大堆——场地少顶格停采、小堆排后，搬运次序的物理行为差异非乘数）；锻造坊·锻打原料（铁水优先/铁锭优先）；科研院·选题（实用优先/底层探究——占位，机制后续）；运输队·**运输计划**（均匀/偏重原木/偏重铁矿/偏重农作物——被偏重线运力×2，**调度在岗才生效**，排单是调度的活）
- 槽位候选＝**构筑树的选择题**：统筹层（采集队/工坊）或直挂单线（采集槽亦可直接放伐木队等——放弃统筹层）——不同机构是功能实现路径的偏好，如同计划 or 市场
- **效果只走物理因果，不做抽象乘数**：工具架=工具锋利（采集快）、手推车=载具运力、**风箱=鼓风提炉温（熔炼×1.2，实测精确）**；测量为纯职能岗（放线验收，机制后续）；**工序槽一设备多班**（裁决30）——工序槽 n:1 是设备语义非工位上限，同槽可多人（卡头显示 N 人）
- **任意槽可下辖组织**：木材信息/矿石信息/农情信息槽可放林务所/矿务所/农务所（巡看×2+记档），库管槽可放库务所（收发+盘点）；**机构入驻即算在岗**（下辖组织有在编=该职能履职，库务所在编即库管履职、搬运照转）
- **采集/军事岗位纵深**：农垦队——耕作×4 + 选种（留优种作来年种籽，占位）+ 农情信息；采矿队增**支护**（架坑木——矿场堆容 +20/人，实装）、**提升**（坑口吊运——采矿×1.25，同工具架物理口径，实装）、矿石信息、常备军增军需（军械换装领用——耐久 sink）；**场地堆通报三线通用**——场地堆过阈值且信息槽无人在岗＝自动从作业岗移调一人通报（伐木队·木材信息/采矿队·矿石信息/农垦队·农情信息），被通报场地搬运全速、未通报打 0.5 折扣，信息槽在岗即全速
- 额外椅子（伐木小屋软装）场地堆通报阈值 12→6；工程队不设材料岗（建材运输归运输系统）
- **产地三态**（05 §四＋裁决 23/24）：基础原料三种全部地形直出、**三线产出都进场地堆待运**——**树林**=不可到达（堆不设上限）；**耕地**=主城内；**矿洞**=卫星城（唯一堆容 40+80×卫星仓、唯一可建卫星仓处）。**三线都要搬运工搬回——仓库满停的是搬运不是采集**（树林/耕地继续无限堆、矿洞堆容满才停采；扩容或腾仓恢复）；装卸规则/信息通报同口径
- **施工＝结构工作量制**（裁决37/40/41/42）：环节 备料∥场地→地基→立架→铺椽→**铺顶→筑墙**（先顶后墙，营造实证：有顶无墙优先遮雨）∥夯地→门窗∥粉刷，每环节挂**工作量**与材料定额×体量（宽/8格）涌现料单——**时长＝工作量÷作队出力**（涌现值，无工时常数）；**工种＝专门作队**：木匠队（吃 cft）/茅匠队（吃 cft，茅草顶铺苫——thatcher 只在屋面阶段进场）/小工队（吃 str）挂工程队对应槽（直派或整队入驻），跨工种真并行各出各力、无人＝环节⛔；环节开工即扣料（等料⚠别环节照跑）；**形制定工作流**：棚（开敞：柱+茅草顶）/屋（圆木横叠墙 log_wall+茅草顶）/架（木骨梁 timber+板墙+木瓦顶 shingle+厂制门窗铁件）；冶炼坊门窗五金用生矿（防自锁，裁决32）；工厂产出受库容钳制
- **sim 建筑 ↔ 正片 def 映射**（对齐建筑管线材质库与内景矩阵）：锯木坊=smithy1 茅草棚工坊（开敞天然全透）/民居=house·cottage/仓库=warehouse·barn/锻造坊=smithy2/药剂坊=alchemy/书院=library/兵营=barracks/市政厅线=town_hall→governor_palace→imperial_palace；材质正片键：log_wall 原木横叠墙、plank_wall 板墙、timber 木骨梁、thatch 茅草、shingle 木瓦、plaster 抹灰（＝粉刷环节实体）
- **移民制**（裁决31/33）：人口增长＝移民吸引（非新生儿）——**有空床即来投**（外来成年匠人：属性 3~9、匠艺概率高于本地出生）；流失侧＝**村民闲置满 72 时（三天）离乡谋生**（在编者闲置钟清零，开局角色不离）——进城门是空床、离城门是没活干；耕地产出不作口粮（移民/维持零耗粮），只做入药/纤维原料
- **拉动制物流**（裁决34）：产出默认堆产地空地，**仓库收货政策开着才回运**（仓库页三线开关，默认全关）；仓库逐座限定收货类型（建筑页 select——分类仓），某类容量＝收该类座数×600（各类独立，满一类不堵别的）；单座容量 400→600——物流是「仓库拉动」不是「一口气全搬」
- **原料窄、工序深**（05 §四）：基础原料三种——树林→原木、矿洞→铁矿（矿物·暂只做铁）、耕地→农作物（单产物：入药与纤维原料；**收割副产茅草** 0.5 比率——与农作物同堆同运，铺顶料）；多样性靠工序不靠原料
- **农作物≠食物资源**（05 §一铁律）：入药与纤维原料；进食可选增益、无饥饿，后续绑人口繁衍
- 速率：采集 0.8/人时（所驻小屋+工具架 ×1.25）、搬运 1.2/人时（手推车 1.8/人时）、工序 0.6/人时；矿线运距物理折算——有卫星仓集中短驳 ×1，无仓矿口远背 ×0.6；速率为每时净流量
- **仓库按座实装+分类容量**：单座 600，某类容量＝收该类的座数×600（见「拉动制物流」条）；**搬运坑位＝5×仓库座数**（坑位上限随建筑规模，01 §2.6）；**工程队·自动扩建**＝仓库近满（≥90%）且无在办建造单时自动排一座新仓（木12+板10/20 工时），顶格停采时急救插队（建造单让位，按容差判满）
- **撤单与拆卸**：施工队列可撤单（未开工环节全额返料、已开工环节料已砌进结构不返、工时沉没——裁决26 按工序口径收窄）；建筑页软装可拆卸（全额返料，拆设备=对应工序停摆）——库满缺料软锁的玩家出口
- **工序链**：锯木坊 锯解(锯架) 原木→木材 → 制梁(制梁台) 原木→木梁 → 制瓦(制瓦刀) 木板→木瓦 → 刨光(刨台) 木材→木板 → 制门(制门台) 木板×2→门扇 → 制窗(制窗台) 木板→窗扇（后四道需木工）；锻造坊 熔炼(熔炉) 铁矿+木材→铁水 →锻打(铁砧)→淬火(水槽)→开刃(磨石) 出铁剑（熔炼燃料=木材，柴火物理）；药剂坊 炮制(切药刀) 农作物→净药材 → 熬制(药炉) 出药水；木器坊 备料(木工台) 木板×2+铁锭→车料 → 装配(组装架) 出手推车。铁水/毛坯/淬火件/净药材/车料为厂内物品
- 锻打可吃铁水或库存铁锭（面板可切偏好）；**厂内堆位 20**：任一半成品堆到 20 本道工序满料停机（下道堵料/设备断链不再无限堆积——试玩实测断链 WIP 曾堆 231）
- **末道手艺门槛**：五厂最后一道工序（刨光→木工、开刃→锻造、熬制→制药、装配→木工、冶炼→冶炼）需在编有人会该艺才能开工——粗工序人人可上（不锁开局）；无人会＝该道停摆，卡头 ⏸ 报「缺手艺：练人或等对口新生儿」
- **手推车有真实消费端**：运输队载具面板切换需库中有车（实物在场，非 buff）；铁剑消费端＝成军军械储备（常备军构筑需农作物50+铁剑2）
- **耐久 sink**：衍生品的物理折损闭环——手推车每 240 搬运人时折损一辆（木器坊持续有单）；常备兵役的常备军每 150 时军械换装领铁剑×1，军需岗在编才办领用（无人/无剑＝呈报流警告，不叠加惩罚——军需岗从占位变机制）
- 冶炼坊实装单工序：冶炼(冶炼炉) 铁矿+木材→铁锭——需进驻冶炼坊建筑并装炉；铁锭自产
- 移调：信息槽缺人自动从本队作业岗移调（原槽圈停、目标槽半透明人名+慢速圈）；工厂工时在可开工工序间均摊——一人厂独轮回全工序
- 动员=产率减半（动员官在编）；人名/组织名不带编号，同名聚合（村民×3）
- **训练实装**（04 §三 组织对组织）：训练营指令面板选受训编制组织（整只开过来，物理移动抽象为就位）；100 点内部进度升 1 级（速率＝4 点/时×教官在编数×教官 cmd 均值系数×受训在编 int 均值系数——17 §23「学习快慢吃 int」，±20% 带宽）；无教官停摆进度不丢；组织卡头显示「训Ⅰ/Ⅱ…」等级徽标，升级进呈报流
- **训练目标落个体**：训练营面板新增目标选择——属性 +1（钳 0~10）或 全员习得技能；目标技能须教官会（没人教的艺不可选；缺教官停摆进度不丢）；改目标清进度
- **停摆可视**：组织卡头 ⏸ 徽标——工厂缺设备/缺原料/库存达标歇线/未驻建筑、采集队卫星堆满停采时亮起（悬停见原因）
- 锯木坊指令面板：**出材偏好**（优先木材/优先木板——两道工序工时 2:1 分流，产出倾向物理可感）
- **库存目标（按需生产）**：五厂指令面板选项（不限/满20/满40/满80/满160 ×仓库座数，随仓储规模放大、仍取整十）——产物库存达标记线整坊歇线，降库存自动复工（军需式按需生产）；锯木坊按出材偏好盯主产物（优先木材→盯木材），其余厂盯末道产物（铁剑/药水/手推车/铁锭）
- 冶炼坊/常备军/训练营/科研院在空槽候选中按前提/资源禁用并悬停示因；常备军构筑自动流转——军事槽有动员官时直接构筑，人随军转入常备军军事槽（01 §2.6 流转，槽占用人时也示构筑候选）
