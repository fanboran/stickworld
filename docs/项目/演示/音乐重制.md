# 音乐重制

> 分层 BGM 全量重制：制作管线、运行时分层混音与资产登记三层齐备。

- **资产**：`assets/audio/bgm/<cue>/<layer>.ogg` + `music_manifest.json`（游戏加载即用）
- **运行时**：分层混音（cue 调度、层间过渡），架构见音乐系统文档
- **管线**：离线制作管线（设计 → 技法 → 资产登记三层文档），曲目可复做

无渲染产物（听感验收）。
