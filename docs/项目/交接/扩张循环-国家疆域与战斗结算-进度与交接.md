## 四、关键决策

| 决策 | 结论 |
|---|---|
| 战略图染色 | **实装**（创始人 2026-09-22 裁决）——推翻 P0 期「`region_owner_changed` 只发信号、地图表现层不做」的旧口径；P4 落地时把 `region_owner_changed` 接到 `political_lut.set_state_color`（接口已就绪） |
| 出征入口形态 | 两入口并存共用一份数据面：城门出门框（入口一，传统）+ 战略图双击敌聚落（入口二）；确认框先给情报（守军编成/敌将/战利品）再动身 |
| 车轮战扣减 | 剩余配额从 garrison **头部条目填满**（前满后缺，前排主力优先满编）——刷军与情报展示同一函数，禁止两处分叉 |
| 装配可见性 | expansion 实例经组 `expansion_api` 查找（不出全局 class_name，防 preload 链解析失败） |
