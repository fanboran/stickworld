# 乐谱（MusicXML）

> 交付件里"音频之外"的那一半：17 首曲子的**独立乐谱**，能被 MuseScore / Sibelius /
> Dorico / Finale 直接打开，也能打印。音频（`stick-world/assets/audio/bgm/`）是它的
> 演奏版本，谱是它的耐久版本——哪天渲染工具链跑不动了（引擎版本、采样库许可、
> 操作系统），这里仍然是完整的作品。

## 怎么来的

```bash
python tools/music/export_scores.py            # 全部 → tools/music/scores/
python tools/music/export_scores.py --cue village
```

导出器：`musiclib/sheet.py`。**谱面真相源是 `compose/themes.py` + `compose/cues.py`**
（旋律、和声、编制都在那里），本目录是生成物——改曲子请改代码再重跑上面那条命令，
不要只手改 `.musicxml`。

## 记谱口径（读谱前先看这里）

- **音高、和声、曲式**与代码逐音对应；导出后用**音高直方图**核对过（一个音都不多不少）；
- **时值量化到 32 分音符**：代码里的时值带人性化抖动（±0.02 拍）与"留气口"的偏移
  （如 7.7 拍），谱上按最近的标准音符值记；跨小节的音用**连音线**拆开，
  同时起音的音写成**和弦**；
- **声部**：一个编曲层 = 一个 part；层内重叠的音（钢琴的低音长音与右手分解、
  竖琴琶音的余音）按标准做法分 `<voice>` 写；
- 钢琴写**大谱表**（高音 + 低音，按音高分谱表），其余层按音区自动选谱号；
- **力度**写进 `<sound dynamics>`，谱上不印强弱记号——那是渲染脚本的力度曲线管的；
- 循环曲目在第 1 小节与末小节有**反复记号**（`|:` `:|`）；
- 末小节一律补满休止（记谱规范），伸到曲末之外的音按惯例**裁到曲末**。

## 自检

`export_scores.py` 每次导出都会自己量一遍：小节数、**每个声部**每小节的时值总和、
连音线配平、音高直方图与代码一致。任一条不过就非零退出——
谱是给人看的，错了不会像音频那样"跑一遍就听得出来"。
