# 开发设计（本冲刺的决策与参数真相源）

> 只记"是什么 / 为什么这么设计"。逆向机制的公式与出处全文在 `docs/技术/参考逆向/天空与水体逆向笔记.md`，本文不重复，只放设计结论与调参入口。

## 一、美术管线：程序参考图 → 笔触拟合 → mask 抠图

**为什么**：零美术人力出"手绘感"资源；全资产同管线=风格统一；比纯 AI 出图更可控（用户方向：生成式笔触 + 低多边形 + 简单形状混合，AI 只做参考图）。

- 工具链：`tools/ai/gen_resource_ref.py`（合成参考图）→ `tools/ai/stroke_paint.py`（mona-3 StrokeGenerator 分层笔触 + 模拟画布叠压）→ 形状 mask 抠图 → PNG 进 assets
- stroke_paint 要点：`size` 参数定画布尺寸，笔宽/笔长按 `max(W,H)/256` 等比缩放（不同尺寸贴图颗粒度一致）；浅色主体（白云）必须走 `mask_path` 抠图，色距抠图会误抠；`bg` 参数指明参考图底色用于边缘预乘消除
- **参考图必须有颜色结构**（逐 puff 顶亮底灰、受光面/背光面）——纯平滑渐变会让 detail 层误差提前收敛收笔，画出来是软渐变团而非笔触
- 笔触云实例：`tools/ai/gen_cloud_stroke.py`（512x256 ×3 变体，平顶积云 mask + 逐 puff 立体着色）
- 待做硬项：建筑=零件拆分（墙/顶/门/窗）分别笔触化后参数化重组

## 二、天空系统

- 五层视差：星野+月(0.08) → 飞鸟(0.35) → 远山(0.55) → 远树线+雾带(0.70) → 近树线(0.88)；云独立池。层位移 = cam_x × (1−factor)，贴图 region 平铺超宽留视差冗余
- 云池运动学（Terraria Cloud.cs 直译）：scale 0.7~1.3 三档视差、全局风正弦 ×9×视差、相机横移按视差回拉、±1400px 相机跟随带软生灭、云色=环境光照色（夜暗雨浓）、±0.6° 极慢摇摆。**只换贴图不换运动学**
- 日月：线性横穿 + 抛物线高度 + 地平线放大（公式出处见逆向笔记 §一）；昼夜一天 60s（`environment_system.gd` `seconds_per_day`）
- 水：K2C 布局=地图两端海洋；镜像倒影 shader + 滚动岸沫；z 序约定——地面多边形 z=0 不透明会盖低层，水挂 DECORATION(z=1)

## 三、音效系统

- 事件→资产映射在 `audio_manager.gd` `SFX_EVENTS`；值可为数组=随机变体池（Dig_0/1/2 同构）
- 播放机制三件套（Terraria LegacySoundPlayer.PlaySound 逆向）：①同事件重触发**先停旧实例**（防叠音墙）②每次 ±5% 随机音高抖动（防机关枪重复感）③变体随机
- 采集分材质：树=砍草音、石/矿=挖掘音；受击音在 `stickman_entity._on_damaged`
- XNB 提取器 `tools/ai/extract_terraria_sfx.py`：**固定布局解析**（头 6B + uint32 文件总长 + 7bit readers + 对象索引 + fmtSize+WAVEFORMATEX + dataLen + PCM）；avgBytesPerSec 不校验
- 自研合成两件（`gen_sfx.py`）：**鸟鸣**=指数频率轨迹（真鸟滑音非线性）+ FM 喉颤 + 一次泛音 + 呼吸气声，三变体对应三种音节型（柳莺上行重复/雀式颤音/斑鸠双音）；**雨声**=FFT 域滤波天然周期化（rfft→乘频响→irfft 是循环卷积，零 seam）四层叠加（brown 远雨垫 / pink 沙沙 / 细雨嘶 / 大雨滴瞬态）+ 整数分频 LFO 呼吸起伏
- **资产政策（Demo，用户多次明确）**：机制可学、资产可搬——参考游戏资产直接用，逐条登记《素材替换清单》，正式版前删除/替换；程序合成件归 `gen_sfx.py`（防重跑覆盖提取件）

## 四、战斗 AI（RWR 机制 + 换算原则）

- 机制出处与原始数值：逆向笔记 §〇。换算原则：**RWR 参数是 ~10发/s 步枪语境，我方弓 ~0.5发/s——恢复率按射速等比缩放；击杀概率映射为 HP 制伤害倍率；时间带按箭速 850px/s 折算成距离**
- 落地：连射散布热度（每箭 σ×(1+热度)，+0.40/箭，上限 1.2，停火 0.10/s 恢复）→ 热度 ≥0.8 触发点射停顿（持瞄 ×1.8~3.2 随机倍）；命中伤害飞行衰减（≤0.35s 满伤 → ≥0.75s 半伤）
- SWL 遗产机制（瞄准节奏/攻击槽位/举盾威胁/脱靶容忍等）在代码注释与 `docs/技术/架构/场景与战斗/战斗与AI.md`，不在此重复

## 五、架构红线决策

- **跨模块不造依赖环**：world 依赖 ui_global，反向 preload 成环——menu_birds 宁可 70 行本地重绘也不复用 world 的 sky_birds
- **战略图不做后处理**：战略图 CanvasLayer 与 UI 同层（后处理只压世界层）——保持地图界面干净是合理设计
- UI 布局单一真相源：场景是布局唯一真相源，代码建全屏控件走 `UIKit.full_rect()`（AGENTS 核心指令 5）
- 测试策略：平时局部（相关 dev/单测），全量只在收尾；flaky 治理=条件等待替代固定帧等待
