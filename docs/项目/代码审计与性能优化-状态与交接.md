## 二、卡顿嫌疑点（初步代码走读，待实测确认）

1. **极光全图逐列绘制**（`stick-world/modules/world/scripts/map/sky_stars.gd:199` `_on_aurora_draw`）：横跨全图 9800px、步进 24px → 每条带约 408 列 × 3 条带 × 2 个 `draw_rect` ≈ **每次重绘 ~2450 条绘图命令**，12Hz 重绘。可见窗仅 ~1300px，绝大多数画在屏外。
2. **星野全量绘制**（同文件 `_draw_starfield`）：380 颗星全画（含屏外），大星再加 2 条 `draw_line`；星星分布在 9800px 宽度上，可见约 5%。
3. **全屏后处理 shader**（`modules/environment/scripts/post_process.gdshader` + `post_process_layer.gd`）：六层采样（分级/天光/炫光 glow+streak+ghost/渐晕/色差），核显上是固定 GPU 开销。
4. **战斗渲染**（已记录于 `docs/项目/待办事项.md` §战斗性能后续）：96v96 每单位 ~30 条 Line2D，核显 2~16 FPS；已有基准 `tests/dev/battle_perf.gd`。此为已知独立瓶颈，不与本轮环境嫌疑混判。
5. 每帧 `RenderingServer.set_default_clear_color`（`environment_system.gd:141`）与多处 `_process` 内 `get_luminance()`/查找节点——量级小，顺带归入帧逻辑分支处理。
