## 二、第一期施工分解（世界先行）

| 批次 | 内容 | 验收门 |
|---|---|---|
| **M0** | demo 拆除（上表） | run_all 全绿（受影响测试已处置）/ check_godot_errors 干净 |
| **M1** | **统一契约**：CityState（人口/建筑/军队/归属/档位）+ FactionState（名下 tile 聚合）数据模型；worldgen 80 政权初始化为真源；WorldState 新域与存档 schema；`factions.tres` 退役 | 单测：契约装载/聚合查询/存档往返 |
| **M2** | **世界账面 tick**：政权人口/经济/建军推进 + 城市档位成长（离屏轻量 tick） | 集成：离屏跑 N 分钟 → 账面变化可查 |
| **M3** | **W7/W8 离屏战争**：开战判定链（打得过+够得着+记仇）→ 账面对推 → 拉锯领土流转（tile 归属变更）→ 战略图消费（染色/战争标记） | 集成：AI 互战胜负回写账面 + 战略图领土变化可见 |
| **M4** | **焦点战争实体化**：玩家在场的战争升档为真实战斗（复用接敌管道模式 + GarrisonSpawner 数据源换账面） | 集成：走近 AI 战场 → 实体战斗 |
| **M5** | **三出身开局**（该溜子/部落首领/城邦平民）+ 演示目标链重设计 | 手动验收三出身开局体验 |
| **M6** | **追随者三机制**（定居点吸引/雇佣/人望） | 集成：三路各获得人口且有下游 |

依赖：M0 → M1 → M2 → M3 → M4；M5 依赖 M1（契约）；M6 依赖 M5。M3 之后各批可按创始人优先级调整。
