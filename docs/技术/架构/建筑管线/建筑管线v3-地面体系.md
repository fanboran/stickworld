# 建筑管线 v3 · 地面体系（分段链 + 动态建造件）

> **一句话**：地面必须是**运行时可拼**的——本游戏是 RTS 式模拟经营，建筑由玩家在 32px 建造网格上自由建造/拆除、城市会横向扩展并升级规模，所以任何"烘死的整条地面"都不可用。体系 = **静态分段链**（城市基础设施）+ **动态建造件**（跟建筑走）两层。

## 一、地面语义（创始人拍板）

- 屏幕下方约 1/3（`ground_ratio` 0.33~0.4）= **整体可行走区域**；没有建筑时全是可走的地面。
- 建筑建成后**挤占**这块区域的一部分：建筑根线 = 地面带顶线下方 96px（3 格），落地箱（宽=格宽×32、高 96px）挡住所占部分。
- **无预留路肩带**：落地裙边/门前踩踏径只出现在有建筑的面宽内（= 动态建造件）。
- 建筑站位抖动：约 1/3 回退 0.5~1.5 格（带门前小短路）、约 15% 凸前、其余贴线。

## 二、两层架构

| 层 | 内容 | 技术 | 谁说了算 |
|---|---|---|---|
| 静态基础层 | 道路/路缘/路肩底/城门泥地 | **分段链**：3 带（肩 96px/缘 8px/道 160px）× 3 区带 × 5 变体，同族左右边缘约定一致、任意顺序可接，引擎按种子链式铺 | 烘焙时拼好，玩家不改 |
| 动态建造层 | 落地环（基座裙边）/门前径/相邻过渡 | **网格拼接件**：按 4/8 邻居"有没有建筑"选边/角件（位掩码）；建造挂/拆除卸，跟 PlacementGrid | 运行时 |

## 三、区带与规模包含（创始人拍板）

- **区带**：`center`=石板/大理石+残块修补 → `mid`=旧砖+碎石混铺 → `edge`=夯土/砾石/草皮啃噬；同一城市内按距中心的区带取材质（每段 json 带 `zone`）。
- **规模=包含复用**：`village → [edge]`（村的地面就是城市边缘的地面）、`town → [mid, edge]`、`city → [center, mid, edge]`；edge 档 15 段自成一套。写在 `ground_tiles/_manifest.json`。
- 新旧过渡段 3 件：城市升级时新铺装以不规则边缘半盖旧土面。

## 四、decal 撒布

污渍/水洼/裂缝/苔藓/碎屑/车辙/补丁/门前径 8 种，单件 RGBA + json `scatter`（seed 规则/每 10m 密度/尺寸格数/0.7~1.3 抖动/仅 90° 旋转/适用带）。运行时按种子撒，破坏周期感。

## 五、拼接技术调研（为什么这么做）

| 游戏 | 做法 | 对我们的启示 |
|---|---|---|
| 红警（Westwood） | 60×30 等距 tile + **手工预制的过渡块**（海岸块/LAT 粗糙边块/悬崖/坡道），编辑器按邻居**自动选对过渡块**（auto-shore） | "预制过渡件 + 按邻居选件"正是为**运行时可变地图**发明的——用于动态建造层 |
| 泰拉瑞亚 | 8 邻居位掩码 → **47 种 blob 变体**（256 组合数学上坍缩为 47），材质间过渡用边缘/角块 | 动态件之间的融合规则；判定对象从"同材质"换成"有没有邻居建筑" |
| 极乐迪斯科 | 整屏手绘大图，不拼接 | **不可用**：我们要建造/拆除/扩展；只保留它的"补丁拼贴"观感目标 |

## 六、json 契约与引擎消费

- 每段/每件 `.json`：段宽（格）、边缘约定、族/带、`zone`、变体号、锚点；动态件另有格尺寸/邻居掩码/用法。
- 引擎消费：城市布局器出分区规划 → 地面按分区选材质族、按种子链分段 → 建筑事件（建/拆）挂卸动态件 → decal 按种子撒。城市扩展/升级全部增量式，不重烘。
- **硬约束**：一切地面资产**光照中性**（albedo+微 AO，禁烘方向光）；无缝；夜晚=整体乘冷蓝调（-44% 实测）+暖光斑。

## 七、产物与复跑

- 代码：`tools/blender_buildings/ground_tiles.py` + `probe_ground.py`；资产在 `stick-world/temp/ground_tiles/`（分段/件/decal + `_manifest.json`）。
