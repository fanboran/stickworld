## 架构速记

- `spec.gd`（声明式）→ `layout/solver.gd`（层几何/开间/屋顶/图高）→ `builders.gd` 分发 → `builders/{shell,smithy,civic,rural,landmark}.gd` 装配 → `comps.gd` 构件 → `draw/*` 风格层 → `gen_buildings.gd` 出图。
- **25 def 谱系**：街屋 9（含 stone_upper）+ 铁匠铺四级 + 公共 5 + 地标 3（shelter/lighthouse/bridge_house）+ 田园 5。
- **高度基准**：火柴人 130px；层数上限由材质定（稻草1/木板2/石头3/砖4）。
- **确定性**：seed = `hash(["building_v2", def_id, width])`；构件级子流 `painter.branch(tag)`。
- **环境红线**：Polygon2D/draw_polygon 带 UV 采样坍缩 → 纹理一律 `draw_texture_rect`/仿射；纯色才 `draw_colored_polygon`。
- **图像合成陷阱**：`Image.fill_rect` 是**直接覆盖**（不混合），半透明叠加必须用 `blend_rect`；`_px()` 的 alpha 合成必须是标准 source-over（曾写错导致整库发黑）。
- 纸纹后处理 `render_mode blend_mul`；屋顶 rise 随宽度增高、img_h 由坡度推导。
