# benchmark_brains —— 自对弈迭代选手库

「下一版算法必须稳定战胜上一版」的选手脚本都放这个目录。设施构成：

- `bench_brain_base.gd`：选手基类 = 战场观察助手 + 个人级/编制级命令门面（协议与自由度分层见其头注释）。
- `../diag_arena_benchmark_driver.gd`：胜负判定（有效战力先归零方负、超时按剩余战力）、换边轮换（挑战者一半场次在攻方一半在守方）、稳定战胜线（默认 65%）。
- `../diag_arena_metrics_driver.gd`：过程指标（疲于奔命率/追逐翻转/均匀度 CV），胜率之外看打法是否真变好。

## 迭代流程

1. 把现任卫冕者的脚本路径填进 driver 的 `BRAIN_B`（首任卫冕者 = 内嵌默认 AI，即 `BRAIN_B` 留空）。
2. 写挑战者 `my_brain_v2.gd`（继承/duck 复用 base），填进 `BRAIN_A`。
3. headless 跑 `res://tests/dev/diag_arena_benchmark_shots.tscn`，胜率 ≥ 65% → 挑战者接替卫冕者（`BRAIN_B` 换成它），否则回炉。
4. 接受者把脚本路径登记进本 README 的「历任卫冕者」表，形成可追溯的进步链。

## 历任卫冕者

| 代次 | 选手 | 接替依据 |
|---|---|---|
| 0 | 内嵌默认 AI（观察场现状系统：夺点意图规划 + 兵种行为档案） | 基线 |
