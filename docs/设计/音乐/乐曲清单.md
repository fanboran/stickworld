# 乐曲清单（Cue Sheet）

> 本文是音乐资产的**主键表**：一个 cue（乐曲）对应一个游戏状态，一个 `cue_id`
> 对应磁盘上的一个目录。设计意图见 [音乐设计文档.md](音乐设计文档.md)。
>
> 曲名与 cue_id 的对应关系、分层与循环点**由代码生成**（`tools/music/compose/cues.py`
> 与交付的 `music_manifest.json`），本文是它们的可读版本。**改谱面请改代码，
> 不要只手改本文**——两者不一致时以代码与清单为准。
>
> **旋律**在 `tools/music/compose/themes.py`（每个场景一条自己的旋律，口径见
> [音乐设计文档.md](音乐设计文档.md) §三）；渲染前的写谱自检（调外音 / 和声避讳音 /
> 音区 / 留白）：`python tools/music/compose/check_melody.py`。

（整数小节是硬约束，否则每次循环相位漂移）。

## 二、分层表（tier = 强度档位）

运行时按游戏强度逐层淡入：tier 0 常驻，tier 越大越"热闹"。
同一 cue 的全部层**等长、同循环点、同和声进行**，所以任意组合都能叠加。

| cue_id | tier 0（地基） | tier 1（常规） | tier 2（点亮） |
| --- | --- | --- | --- |
| `menu_title` | piano | strings | — |
| `field_day` | piano | strings | harp, bells |
| `field_day_b` | piano | **harp**, strings | bells |
| `field_night` | piano | strings | bells |
| `village` | piano | guitar | marimba, winds |
| `village_b` | piano | **marimba**, guitar | winds |
| `village_night` | piano | guitar | marimba |
| `interior` | piano | — | — |
| `interior_hall` | piano | strings | bells |
| `strategic` | pad | vibraphone, piano | bells |
| `battle` | piano | strings, perc | winds |
| `battle_b` | piano | strings, perc | winds |
| `battlefield` | piano | strings | winds |
| `sting_*`（四首标点） | 各层均 tier 0（整叠同播，不分档） | — | — |

> 轮换版里**主奏层降一档**（`field_day_b` 的 harp、`village_b` 的 marimba）：在这一版里它是主奏而不是点缀，若仍按基础曲的 tier=2 处理，低强度下整首会没有旋律。
> 标点短句（sting）不分层强度——它们是"事件"，一次播完，四首都是多层整叠（各层音量已在交付件里配平）。

### 三.5 旋律表（每曲一条）

旋律定义在 `tools/music/compose/themes.py`，移调写在**乐句**上（不同乐器的舒适音区
不同，一个全局八度常量必然让某些声部跑出音域）。曲式 4×8 小节。

| 旋律 | 曲名 | 用于 | 音区（实际落点） | 曲式 | 写法要点 |
| --- | --- | --- | --- | --- | --- |
| `menu` | 原野·序 | 标题画面 | G5~D6（钢琴） | A A B A | 下属和弦开场（"门先开着"）；落回主音后又回到属和弦收句 |
| `field_day` | 原野·昼 | 白天原野 | D5~E6（钢琴） | A A B A | 主和弦上行三音开场 + 三度下行链；B 段点一次 E6（全曲唯一） |
| `day_harp` | 原野·昼·竖琴 | 白天原野（轮换版） | A5~D6（竖琴） | A A B A | 开头"五音-六音-八度"三级上行是节奏签名；B 段退到中音区平缓答句 |
| `night` | 原野·夜 | 户外夜晚 | B4~F#5（钢琴，比白天低八度） | A A B A | 叹息动机（长音 + 下邻音）；两次半句落点停三音；句尾停 v 的小七音 |
| `village_tune` | 小镇 | 村落·昼 | G4~F#5（钢琴）；B 段 D5~B5（长笛） | A A B A | 民歌式：主音起、1-2-3 上行、附点长-短 |
| `village_marimba` | 小镇·木琴 | 村落·昼（轮换版） | B4~G5（马林巴） | A A B A | 同音重复的"敲击"与切分；B 段放开成长句 |
| `village_night` | 夜镇 | 村落·夜 | E4~G5（钢琴） | A A B A | 三音内的踱步动机，句尾一律停五音，B 段才抬一次 |

> 是**手势**而不是旋律——两小节里的一个动作：上行落定、下行叹息、竖琴一掠。
> 因此它们不占旋律表。

### 三.6 和声骨架表（每曲一条）

骨架与旋律一起写在 `tools/music/compose/themes.py`（`Melody.harmony`）——
**改骨架只改那一行，伴奏自动跟着走**（cues.py 的伴奏一律读 `mel.harmony`）。
可选条目库见 `compose/common.py` 的 `SKELETONS` 与
[作曲技法参考.md](作曲技法参考.md) §二。

| 骨架 | 级数 | 用在哪首 | 为什么是它 |
| --- | --- | --- | --- |
| 丸サ進行 | `IVmaj7 V7 iii7 vi7 IV V I V` | 原野·序（标题画面） | 从下属开场 + 七和弦的暖，做"门先开着"的邀请 |
| 三度下行链 | `I vi IV ii V I IV V` | 原野·昼 | 链式下行天生"顺流"，终止把每句推回开头 |
| カノン進行 | `I V vi iii IV I IV V` | 原野·昼·竖琴 | 全库仅此一首用卡农——它最适合竖琴的分解织体 |
| 自然小調循環 | `i VI III VII`×2 | 原野·夜 | 小调的"夜"，天然的循环感 |
| ポップパンク（axis） | `I V vi IV`×2 | 小镇 | 最明亮的流行循环，配 84bpm 的民歌旋律 |
| 田园骨架 | `I iii IV V I vi IV V` | 小镇·木琴 | 更"生活化"的摇曳版本 |
| 自然小調カノン | `i v VI III iv i iv v` | 夜镇 | 同一族里的"慢下来的版本"，尾句留 iv–v |
| 小室進行 + 变格终止 | `vi IV V I IV I IV V` | 灯下 | 从 vi 起句的哀愁，收在变格终止上（不催） |
| 王道進行 + 变格终止 | `IV V iii vi IV I IV V` | 厅堂 | 4536 的"端正"，配公共空间的回声 |
| ドゥーワップ（50s） | `I vi IV V`×2 | 远望 | 老派甜；64bpm 下最"朦胧"的一条 |
| 出征骨架 | `i VI III VII` | 出征 / 出征·弦乐 | 4 小节一轮的推进感，"开阔不凶" |
| アンダルシア | `i VII VI V`×2 | 余烬 | 下行、凭吊、"这里打过仗" |
| 标点骨架 | `I vi IV V I vi IV I` | 入主 | 完整闭合——标点本来就该解决 |
| （不设骨架） | 和弦内 | 凯旋 / 折戟 / 抵达 | 两小节手势，只落和弦音 |

## 四、自适应设计

### 4.1 纵向混音（vertical remixing）

引擎加载同一 cue 的全部层，同时开始播放，用**层音量**表达强度。
层的进入顺序固定为 **钢琴 → +弦乐 → +钟琴**，退出顺序相反。
底层设计保证：**任何一层被静音，其余层仍是完整的音乐**——
这是"层"能自由开关的前提，也是"骨相好"的检验标准。

### 4.2 状态切换（horizontal re-sequencing）

状态切换以**量化到小节**的交叉淡化为默认（详见引擎侧设计）。
循环体之间可直接硬接（和声在 32 小节处闭合，接得回开头），
跨调性/跨速度的切换用交叉淡化。

### 4.3 昼夜

昼夜切换到**另一首曲子**（`field_day` ↔ `field_night`、`village` ↔ `village_night`）：
旋律不同、调性不同、音区差一个八度（白天在高、夜里落低）、织体密度也不同。

亲缘不靠共用旋律，靠三件事：同一支钢琴、同一族和声骨架、相近的速度与呼吸。
这样玩家听到的是"同一片地方在两种时间里的两种状态"，而不是"白天的慢速重播"。

### 4.4 轮换族（长时抗疲劳）

玩家会在同一张图上停留很久、反复进出同一场景，同一首曲子会循环几十遍。
对策是给**听得最多的三个场景**各准备"同源第二版"，运行时按轮换播放：

| 族 | 基础版（主奏） | 轮换版（主奏） | 变的是什么 |
| --- | --- | --- | --- |
| 野外 · 昼 | `field_day`（钢琴 / `field_day`） | `field_day_b`（竖琴 / `day_harp`） | **旋律另写**；主奏从钢琴换到竖琴；钢琴退成纯伴奏；钟琴只在末句 |
| 村落 | `village`（钢琴 / `village_tune`） | `village_b`（马林巴 / `village_marimba`） | **旋律另写**；主奏换到木质打击；吉他更活跃；长笛仍接第 3 乐句 |
| 战斗 | `battle`（钢琴 / `battle`） | `battle_b`（弦乐 / `battle_strings`） | **旋律另写**；推进音型从钢琴换到弦乐；双簧管提前一个乐句进场 |

**约束**（运行时轮换无缝的前提，由 `test_music_director` 的"族成员同调同速同长同层名"守住）：
同调性、同 BPM、同循环拍数、**层名一一对应**。
轮换按**进入场景的轮次**（第一次进基础版、第二次进轮换版、第三次又回基础版），
不在循环点上硬切——循环尾巴是折回处理过的，切断会露出接缝。

> 清单里的键名是 `variation_sets`（运行时契约，`MusicDirector._pick_variant` 读它）；
> 语义是"同场合的另一首曲子"，不是"同一首曲子的变奏"。

## 五、交付规范

| 项 | 规格 |
| --- | --- |
| 采样率 | 48000 Hz |
| 声道 | 立体声 |
| 格式（游戏内） | OGG Vorbis，`libvorbis -q:a 6`（约 190kbps） |
| 格式（存档） | 母带 WAV 24bit/48kHz，放 `tools/music/out/master/`（不进版本库） |
| 响度 | 音乐 **-15 ±0.5 LUFS**；sting **-14**（文件按流媒体量级交付，游戏内位置由音量滑条决定） |
| 真峰值 | ≤ -1.0 dBTP |
| 循环信息 | 写在 `music_manifest.json`，加载时赋值给 `AudioStreamOggVorbis` |
| 路径 | `stick-world/assets/audio/bgm/<cue_id>/<layer>.ogg` |
| 清单 | `stick-world/assets/audio/bgm/music_manifest.json` |
| **乐谱** | MusicXML（能被 MuseScore 打开、能打印）：`tools/music/scores/<cue_id>.musicxml`，随仓库入库；口径与自检见该目录 README |

`music_manifest.json` 的每条 cue 含：
`title / bpm / bar_beats / bars / beat_count / loop / loop_offset / key /
duration_s / loudness_lufs / layers[]`，其中每个 layer 含
`name / file / tier / db`。
