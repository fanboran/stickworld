### 城块定稿模型（纯抗衡，创始人 2026-09-27 裁决）

**当前实测（1042 聚落 = 1036 正常 + 6 原址复种点）**：refined 城块图陆地灰区 **0.168%**（= 66 个无聚落小离岛，按「无聚落即无主」留荒地）、按 locked 海岸线跨陆块城块 **0**、缝隙 **0**（纯抗衡天然无缝）。

> 2026-09-26 轮曾引入「主张盘封顶 + 灰缝填充点」实现（圆块 ×1.3、657 规模 0 填充）；09-27 创始人裁决**抗衡即唯一边界**，主张盘（`cap_by_claim`）与灰缝撒点（`fill_gap_seeds`）退役删除，git 历史可考古。blob 剪影走现行 R5 场叠加管线（`blob_v2_*`，与游戏内 Tab 城区图同源）——早期 E 图圆化的根因是当时的圆盘城块裁剪，纯抗衡不规则地块下同管线即恢复有机形状。

1. **一地块一聚落**：地块是最小领土单位、不可再分、内部一色；每地块恰一个聚落——原址复种点（level 0）只占地块、不参与政权（政治图允许无主灰）。
2. **城块 = 老 L1 分量内纯「最近聚落抗衡」**：`city_split_v3.grow_cities` 用 EDT 一次距离变换取每像素最近聚落（平面多源膨胀的等价快算），每寸陆地都有归属、无缝无灰；无聚落的老 L1 连通分量（离岛）留荒地。
3. **一城块一陆块**（群岛防跨水染色）：并缝邻接、refine 空洞/水域回填一律同陆块取最近（`landmass_util`：4 连通陆块 + 最近陆地传播到水域）；`enforce_single_landmass` 收尾保证每城块只在一个陆块上。陆块判据 = locked 海岸线（水陆同源 I1 真源），勿用 13 区地块蒙版（少边缘 fringe 会造成假岛分离/假跨块）。
4. **管线顺序**：`settlement_build`（1036 点，确定性）+ 原址复种（`origin_seed_recover`，存量 6 点在 settlements_v2.json）→ `city_split_v3`（全量）→ `refine_city_labels --write` → `city_preview_from_refined`（终图，陆地口径同为 locked）+ `settle_preview_v2`（聚落撒点图，坐标 ×K_FIELD 降 2048）+ `blob_v2_generate`（E 图）。命令级操作手册（含每张验收图的生成脚本/输入速查表）见 [`tools/worldgen/README.md`](../../../tools/worldgen/README.md) §世界重生成 V2 链与验收图管线。
5. **配色保留文化色带版**（同文化同色系深浅）。
6. **blob 走现行 R5 场叠加管线**（`blob_v2_generate.py`/`blob_v2_bake.py`：场场叠加→阈值→marching squares，建成区限制在自身城块内——地块不规则则形状有机多样，与游戏内 Tab 城区图同源；`blob_bake.py` 径向为更早退役代，勿再用于出图）。
7. **剪影成长模型方向（创始人 2026-09-27 口述，待定稿）**：
   - 尺寸曲线与城市规模撒点图同式：R(ps) = r0+r1·ps（8+30px@8192，= settle_preview_v2 的 r=2+7.5·ps@2048），剪影直径逐城等于点直径、面积随规模平方放大；空城 0 面积不画；装不下地块时缩到装得下为止（净空带按「装得下目标」自适应降档 40→24→12→6→0）。
   - **上限跟选址**：剪影上限 = 所在地块容量（0.85×块面积），无全局常数上限——玩家建超级都城需挑大块（实测 43% 的块能养 >2 万 px²，最大 8.9 万 px² = 初始最大城的 7.4 倍；初始跨度 ps 0.01→1.0 即面积 125→12000px²）。
   - **跨档动态烘焙**：规模跨阈值时运行时重烘一张贴图替换原图（玩家可观察城市逐渐壮大）——取代三档叠画预烘；单图替换后三档硬嵌套约束消失，档数可加密（等比面积档 ×2 全图约 10 档 / ×1.5 约 16 档，档距待定稿）。
   - 实现归属：运行时重烘（GDScript 移植或子进程）归 M 系列——M2 世界账面 tick 的自然配套（人口 tick → 跨档 → 重烘）。验收图按每城自身规模连续正比渲染（`blob_v2_generate.py` 独立档 'ps'）。
