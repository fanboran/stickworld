## 三句话概括这条管线

1. **音乐是离线生成的**：Python 作曲 → MIDI → 采样音源渲染成**分轨 WAV** →
   混音母带 → OGG + 清单。游戏运行时只加载成品，不带任何合成器。
2. **分轨是为了自适应**：每个 cue 拆成 2~4 个"层"，引擎按游戏强度逐层淡入淡出
   （纵向混音）。任何一层单独听都成立。
3. **一切可量化**：响度（BS.1770）、真峰值、循环接缝、刺耳度、单声道兼容
   都有阈值检查，`qa_audio.py --check` 非零退出即不通过。

## 维护约定

1. 改混音/EQ/响度 → 同步更新 [音乐质检规范.md](音乐质检规范.md) 的实测基线，
   并重新生成 [音乐质检报告](音乐质检报告-2026-09.md)（或新开一份带日期的）。
2. 引入任何外部素材 → 当场登记 [音乐资产登记与来源.md](音乐资产登记与来源.md)，
   写清 URL、许可、作者、署名串。
3. 管线代码里"为什么这么做"的解释**写在代码注释里**（本目录文档只讲整体），
   避免同一段解释维护两处。
