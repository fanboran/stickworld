# 都城涌现制（政权生成机制重做）

> 立项：2026-09-28 创始人定向（「原来你生成国家一直都是有限都城而不是自适应的吗？……那 1 就单独立项吧」）。
> 状态：**立项待开工**（建议排在世界模型整合图像验收 + §五 收尾之后；与 M2 人口 tick 天然衔接）。

## 定位

把 V2 政权生成的都城产生机制从**有限摆放**改为**自适应涌现**：都城不再是生成端按规则摆出来的集合，而是从人口/文化/历史的竞争过程中自然产生。

## 现行机制（要被重做的东西，事实存档）

- `tools/worldgen/l3/state_build_v2.py:373 pick_capitals`：都城适宜度降序 + 四叉树最小间距（`min_sep_px=900`，8192 级）泊松盘摆放，不够目标数逐轮放宽（`sep_relax^relax`）；先岛群配额（每大岛群 ≥1 席），再出生区加密（间距 ×0.45，`spawn_cluster.capital_sep_mult`），最后全局补齐。
- 都城集合确定后才有国家版图：文化加权竞争 + 都城距离衰减（`capital_decay`：1 + k_capital×测地衰减）+ 规模谱 target + A6 加速史兼并。
- 参数全在 `l3/state_params.json`（capitals 段 + `fields_v2.states_v2.spectrum.spawn_cluster`）。
- 派生约束：出生小国群（L1 69/68 手设计 1-3 城封顶 + 都城加密）依赖摆放制的间距参数——涌现制下这套要重新表达。

## 开工前要拍的口径（创始人裁决点）

1. **涌现载体**：都城=竞争中胜出的城（人口中心性/文化中心性/区位），还是兼并史自然形成核心，或两者混合。
2. **数量锚定**：政权数量是否还锚规模谱先验；完全放开的话地图碎度如何约束。
3. **与加速史（A6）的关系**：涌现并入加速史，还是前置独立阶段。
4. **出生区手设计**：小国群在涌现制下的表达（保护区语义保留与否）。
5. **验收口径**：政治图观感 + 政权规模谱分布 + 确定性（同 seed 可复现）。
