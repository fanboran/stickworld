## 已落内容

1. **箭矢 AMMO + 弓耗弹**（蓝图《武器装备与个人库存》§4.2）
   - `ItemDef.ammo_id` 字段 + `Category.AMMO` 品类；`ItemDB` 新增 `ammo_arrow_001`（箭矢，堆叠 50，图标=战斗箭矢贴图斜置转制 `assets/icons/箭矢_64.png`）；弓 def 挂 `ammo_id=ammo_arrow_001` + `stats.spawn_ammo=20`。
   - 耗弹出口统一在 `weapon_ranged.fire_arrow / fire_arrow_manual`：扣 1 发失败即不出箭（弹道/手感零改动）；拉弓起手门 `begin_player_draw` 无弹拒绝（ui_denied 音）。
   - 玩家侧：InventoryService 附身注入 `weapon_mount.ammo_source = 玩家背包`，脱离收回；开局背包配箭×50；Hotbar 弓格/主手格角标=弹药余量，背包弓条目行内"·箭矢×N"。
   - NPC 免弹（无个体背包，E-4 loadout 弹药接入后收紧）；`ammo_id` 空=免弹数据开关（近战/杖/投矛）。
2. **spawn 按兵种生成 loadout**（两步机制第一步）
   - `modules/units/scripts/entity/entity_loadout.gd`（纯函数：兵种→{main_hand/off_hand/ammo}）；`stickman_entity.note_spawn_weapon` 由 `weapon_type` setter 单点驱动（garrison/recruit/召唤设武器即建档）；守卫=附身不建档、已有记录不覆盖（读档 set_loadout 先写档）。存档经 extra_data["loadout"] 往返（既有通道，弓手武器与箭束随档）。
3. **死亡→物品直接落地**（两步机制第二步）
   - `entity_death.build_drop_manifest`（按 loadout 个体化：主手+盾+弓手箭束+30% 绷带；无档案回落 weapon_type 反查）→ `_drop_loadout_items` 逐件落地 `GroundItem`（`modules/units/scripts/entity/ground_item.gd` + `scenes/components/ground_item.tscn`，尸体两侧散布，挂 EntityHost 随 y-sort，自绘图标+数量角标+接地软阴影）。
   - 拾取：`interaction_controller` 新 kind `ground_item`（ground_item 组扫描，资源点同款矩形）→ 经 `InventoryAPI.get_service()` 入玩家背包，列表制余量留地（超单类上限留地上、武器类已持有同款拒收给拒绝音）。
