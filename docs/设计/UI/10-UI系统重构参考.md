## 二、核心设计借鉴

### 2.1 集中式层号（缺口 1）

《药剂工艺》把**全游戏所有 z 层集中成 117 个枚举值的一个文件**，世界精灵和 GUI 共用一套序：
`GuiBackground=32 / GuiItems=33 / GuiForeground=34 / Tooltip=39 / Cursor=40`，
暗屏也分 `DarkScreenLower=28 / Middle=64 / Upper=79` 三层。

**本作做法**：`modules/ui_global/scripts/theme/layer_order.gd`（LayerOrder）——
一处定义 `CanvasLayer.layer` 与 UIRoot 内 `z_index` 的全部常量，处处引用，杜绝魔法数字。

### 2.2 统一模态栈（缺口 2，最值得抄）

`DarkScreen.cs` 关键设计：

| 机制 | 说明 | 本作对应 |
|------|------|---------|
| 按层索引字典 | `DarkScreen.Entities[layer]`，每层同时只挂一个 `ActiveObject` | `UIModalStack.layers` |
| 打开 | `ShowObject(content, type, targetAlpha, animationTime)`：淡入 + 切换输入阻断 | `UIModalStack.push` |
| 关闭栈 | `DeactivateAll(type, deactivateTilLayer, inclusive, filter)`：从高到低逐层 pop 到指定层 | `UIModalStack.pop_until` |
| 输入屏蔽 | `wholeScreenCollider`/`sceneCollider` 物理碰撞体按 `DarkScreenType` 切换，不是靠 UI 遮挡 | 模态栈统一管"遮罩输入阻断 + 暂停" |
| 点遮罩关闭 | 内容决定 `CanBeClosedWhenClickOnDarkScreen()` | 确认框白名单 |
| 优先级 | `raycastPriorityLevel` 高优先级交互不被遮罩吞（如拖拽） | — |

**做法**：`UIModalStack`（push/pop/top/is_any_open + ESC 统一 pop），替代
`GameRoot._handle_escape` 的特判 if；遮罩输入阻断 + 相机暂停随栈统一。

### 2.3 Toast/确认框独立系统层（缺口 3）

Tooltip 挂在**专门层（Tooltip=39）** + 一整套屏幕适配：
- `marginFromScreenEdge`（距屏幕边缘最小间距）
- `TooltipFitToScreenProcedureStep.cs`（逐步把框挪回屏幕内——正解"confirm 曾跑出屏幕"）
- 独立 `TooltipPositioningSettings` / `TooltipCorner`（绑定点/角落）

**做法**：`UIRoot.SystemOverlay` 固定最高层槽（z=90，ModalOverlay 之上、F3 调试之下），
`StickKit.toast`/`confirm` 一律挂它，内置屏幕边缘约束，不随调用者。

### 2.4 次要项

- **输入屏蔽随模态栈统一**：参照 DarkScreen 的 collider + `CanBeInteractedNow()`。
- **加载覆盖层并入层号常量**：`WorldLoadingLayer.layer = LayerOrder.WORLD_LOADING`。
