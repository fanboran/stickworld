# 性能量测规范

> 性能基线/优化的标准量测方法。违规操作（经主菜单、开声音、共享通道）产生的
> 数字不可与基线对比。基线表与历次战果见 `docs/项目/交接/战斗规模化30fps-进度与交接.md`
> 与本文件 §基线。

## 铁律

1. **不经主菜单**：量测什么模块就直载什么场景（`tests/dev/` 的专用场景）——
   主菜单/音频/UI 全是噪声源；
2. **关声音**：命令行加 `--audio-driver Dummy`（音频混音占 CPU 且抖动大）；
3. **固定分辨率**：`--resolution 1920x1080`（渲染成本与分辨率线性）；
4. **通道隔离**：`user://perf/` 命令通道按 `config/name` 共享——并行跑多个
   实例时先临时改 `config/name`（如 `火柴人帝国模拟-XX实测`），**测完还原**；
5. **同条件 A/B**：对比两版必须同 zoom、同战斗阶段（列阵/行军/接战是三种
   不同画面）、同分辨率；远景糊团不能作为观感/姿态判据；
6. **数字以自己实例的 CSV mark 行为准**（探针协议），resp.txt 只作参考。

## 标准命令

```bash
# 战斗性能（预设 0=遭遇战16 / 1=标准战役48 / 2=大军压境96，默认 2）：
#   热身 8s + 采样 20s，输出 [PERF] JSON 后自动退出；差分开关见文件头
godot --path . --resolution 1920x1080 --audio-driver Dummy \
      res://tests/dev/battle_perf.tscn -- --preset=1
godot --path . --resolution 1920x1080 --audio-driver Dummy \
      res://tests/dev/battle_perf.tscn -- --preset=2 --anim-off   # 差分示例

# 世界场景性能（绕过主菜单直载 game_root，新档语义不碰玩家存档）：
#   热身 10s + 采样 20s
godot --path . --resolution 1920x1080 --audio-driver Dummy \
      res://tests/dev/world_perf.tscn

# headless 模拟速率（无渲染噪声，量逻辑侧）：
godot --headless --path . res://tests/dev/battle_perf.tscn -- --headless-measure
```

## 运行时探针（PerfProbe autoload，仅 debug 构建激活）

文件命令通道：向 `user://perf/cmd.txt` 写命令行（每行一条），回应追加到
`user://perf/resp.txt`，指标每秒追加到 `user://perf/audit_<时间戳>.csv`。
注意：`user://` 目录按 `config/name` 隔离。

| 命令 | 作用 |
|---|---|
| `ping` / `stat` | 存活检查 / 即时 fps·proc·phys·draws·对象数 |
| `mark <名>` | CSV 打标（分析窗口锚点） |
| `scene <res路径>` | 切场景 |
| `shot [名]` | 截图到 `user://perf/<名>.png` |
| `tree [深度]` / `kids <路径>` / `info <路径>` | 场景树/子节点/节点信息 |
| `sysoff <路径>` / `sysoff` 撤销不可逆，恢复用 `syson <路径>` | 关/开子树的 process+physics（差分归因） |
| `call <路径> <方法> [参数...]` | 反射调用节点方法（含私有字段 `get`） |
| `key <键名> <down\|up>` / `mouse <dx> <dy>` 等 | 输入注入 |
| `quit` | 退出（探针在 autoload 段最后，先于其他清理） |

已知坑：`key` 命令只设 `physical_keycode`，监听 `keycode` 的界面（如演练场
R 键）收不到，改用 `call` 直调重开方法；一帧内批量写多条命令会让 stat 读到
同帧值，逐步发。

## 基线表（2026-09-09 战役后，RTX 3050 Laptop / 1920x1080 / 30Hz 物理）

| 场景 | fps_avg | proc/帧 | 备注 |
|---|---|---|---|
| 48 标准战役（96 单位）满编峰 | 10 | ~77ms | panic 刻 15Hz 生效中；减员后 17→25-30+ |
| 96 大军压境（192 单位） | 4.5 | ~180ms | 慢镜头大场面；≥20fps 需 D 刀（交接档 §十） |
| 世界村庄（真实流） | 97 | ~19ms | |
| 主菜单 | 100 | ~11ms | |

回归判定：同命令同条件下 fps 低于基线 30% 即视为回归，先跑差分开关归因
（battle_perf 自带 --anim-off/--rig-hidden/--no-ai/--bodies-ghost/
--freeze-entities/--headless-measure）。
