## ❌ 漏译整段（原版有、我们完全没有）

1. **Saga 是 3D 空间判定**：`FPVector3`、`ZRange/YRange`、`InRangeForHit(xRange, zRange, targetWidth)`——纵深/体型宽度判定系统整段未译（我们纯 2D 平面距离）。复刻 2.5D 时需要决定 z 轴语义。
2. **箭矢插在单位身上**（`doesStickIn` 在单位身上的箭 ≠ `InGroundArrows[]` 插地的箭，两条路径）；箭带毒 `poisonAmount`；箭矢特效 `ArrowEffect/hasEffect`。
3. **Legacy 反伤链**：`ApplyDamageReflect` + `CanReceiveReflectDamage`（管线有 REFLECT 枚举占位，无实现）。
4. **爆头死亡动画分家**：`Kill(isHeadShot, dir, isSpearHeadShot)` + `Death-Headshot` 系列动画（我们死亡动画单一）。
5. Legacy `Unit.Damage` 的 `DAMAGE_TYPE` 细分在我们管线有枚举但**行为未分化**（原版不同类型走不同护甲/格挡规则）。

## 补译优先级（按玩家可感知排序）

1. **事件帧数据化**（走样#1）：spine_import 顺手把 `Hit`/`Sound` 事件时间导出进动画 .tres 元数据，weapon_mount 读真值。Attack1=75%、Attack2=67%、弓=36%——一行数据的事，观感提升最大。
2. **AOE 挥击**（走样#5）：Strike 时按 `NumberOfUnitsThatCanHit` 结算身前扇形内多个目标。
3. **爆头/暴击字段化**（走样#2/#3）：进单位数据表；暴击自伤机制（剑断）可后置。
4. **姿态格挡**（走样#4）：Block 状态 + 正面判定 + blockResetInterval。
5. 其余漏译（跑动攻击/滑铲/3D 判定）等对应系统立项时再译。

## 复刻方法论教训（给后续翻译工作）

- **先跑通黄金参考帧再写实现**：用源数据渲染原版画面作对照（本次 `tools/render_swl_ref.py` 反复翻车：动画 rotate 是**相对 setup 的增量**（绝对角=setup+动画）、CX/CY 取景错、attachment 中心=(骨点+R(骨角)·offset)）。渲染器已修正可用。
- **事件时间在动画数据里**，不在代码里——凡"拍脑袋比例"都该回头查 spine JSON。
- **字段名≠字段用途**：`NumberOfUnitsThatCanHit`（AOE）被误用为围攻上限；`blockChance` 有但姿态条件在别处。
