## 5. 踩坑清单（Godot 4.7，全是实测）

| 坑 | 规避 |
|---|---|
| 未入树节点 `set_anchors_preset()` 不生效（anchors 保持 0，两列叠左上角） | **add_child 之后再设 anchor/offset** |
| 未入树节点 `get_tree()` 打 C++ ERROR "Parameter data.tree is null"（离树构建期高频） | 先判 `is_inside_tree()` |
| `super._draw()` / `super._notification()` 不可调用（虚函数无实现体） | 自绘背景走 override `_draw()`（native 文字先画、自绘在上——**别自绘底会盖文字**，底交给 stylebox） |
| AnimatedTexture 在 StyleBoxTexture 渲染路径**不推进帧**（静态） | 已删贴图路线；如再做需全局换 texture 引用驱动 |
| `theme.default_font` 对 Button 不可靠（Label 生效） | 显式 `t.set_font("font", <type>, font)` 十类控件 |
| `position` setter 配 anchors：只改左上 offset，右下留 0 → **控件被拉到父底**（确认框 434 高的候选根因之一） | 四边 offset 全设，或 add_child 后再动 |
| **autowrap Label 无宽度约束**：min 宽塌缩到单字宽（中文按字断行），长消息折成一行一字把容器撑出数倍高（确认框 434 高的**真根因**） | 先量自然宽，超上限才开 wrap + 钳 custom_minimum_size.x |
| driver 写成场景根本身：change_scene_to_file 释放场景时把 driver 一起杀（await 恢复 get_tree()=null） | boot 场景只做启动器，driver 挂 SceneTree.root（ui_shots_boot 同款） |
| 测试窗口 `--resolution` 非 1920x1080 时项目 stretch 缩放（0.33 倍）使像素探针全错 | 截图/探针一律 `--resolution 1920x1080`（scale=1） |
| ui_shots/driver 类测试：`change_scene_to_file` 释放测试节点自身，await 恢复即 null | driver 挂 `SceneTree.root` 跨场景存活（学 ui_shots_boot） |
| sqlite 存档库：两个 Godot 实例并发跑测试会锁库卡死 | 测试串行跑 |
| Python 环境：`python` 指向 Inkscape 自带（无 pip）；pip 是 Python312 的 | 统一用 `C:\Users\fanbo\AppData\Local\Programs\Python\Python312\python.exe` |
| `--check-only --script` 报 autoload 类（EventBus 等）不存在 | 误报，跑真实场景验证 |

## 6. 用户偏好与红线（血的教训）

- **重大技术选型先问**（贴图 vs 自绘、字体方案都栽过）
- 手绘质感 = 血条同源 boiling（真随机逐帧），不要"平滑波浪线"近似
- 边框永远在标准圆角矩形位置：纯小幅双向扰动、零系统性内缩；描边不吃内容区（margin 挤压 = 矮按钮变横线事故）
- 字要**等粗**（站酷快乐体）+ 可读优先；**禁琥珀字**（丑且不可读，强调只上底色）；描边是最后手段，加粗优先（SketchFonts.bold() 伪粗）
- 字号跟控件走（≥高的 1/2）；弹窗随内容自适应（compact），固定大尺寸仅限设置/暂停级大面板
- 主菜单与游戏内现已统一手绘（用户已改口，不再是"主菜单不动"）
- 中文提交信息 `类型(模块): 描述`
