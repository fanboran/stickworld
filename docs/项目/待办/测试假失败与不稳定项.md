## 环境剧变制造的假失败（识别指南）

磁盘满/恢复、导入缓存损坏这类环境剧变会制造一轮"假失败"，恢复后首跑的红要多重跑再定性。已发生的实例：

- **ctex 空壳**（2026-10-21 C 盘满事故时段）：`.godot/imported/` 里个别 png 的 ctex 只有 56 字节头无数据体（导入器写盘失败残留），运行时 `Failed loading resource` → `test_l2_strategic_map`「13 地区应全部加载成功」稳定 11/13。识别特征 = ERROR 链 `Condition "size <= 0"` → ctex 加载失败；修复 = 删坏 ctex 再 `--import`（9/1334 空壳，精确删即可，无需全清）。
- **孤儿套件文件**：删测试套件只删 `.gd` 漏删 `.tscn`，按目录扫 tscn 的工具（census 普查/直跑）会加载失败空转至看门狗超时，伪装成挂死（exit=124、零断言、引擎 teardown 报错齐全）；batch_runner 清单自检只查「盘上 .gd 在清单」方向，.tscn 残留不在覆盖面。实例 = test_ai_morale.tscn（已清）。
- **run_all bash 挂死**（2026-09-16 立案，2026-10-21 销项）：`-Changed` 起 Godot 前即卡死多日不退。当前树 `-Changed`/全量/`-Match` 三形态复验均正常跑完正常退出，未复现——与当时多会话堆积的未退实例及 C 盘满（临时文件/日志写不出卡死）环境态吻合，按环境性假失败结案。
- **worktree 缺 gitignored 生成产物**：`tools/worldgen/output/**/*.npy` 不进 git，新 worktree 缺水陆掩码 → mapdata 守门必红（`FileNotFoundError: 水陆真相缺输入`）。修复 = 从主工作区拷贝对应掩码产物。
