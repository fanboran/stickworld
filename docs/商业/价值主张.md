# 价值主张

> 基于创始人设计描述的定位分析。

---

## 核心概念

**火柴人帝国模拟：从部落到大帝国** —— 模拟经营 + 组织管理 + 基地建造 + 真实战斗。对标《缺氧》《RimWorld》《监狱建筑师》。

从流浪火柴人拉帮结派起步 → 设计帝国的每一个齿轮 → 以上古魔方的上帝视角看帝国自动运转。

---

## 独特卖点（USP）

1. **组织架构即玩法** — 像设计代码架构一样设计指挥链
2. **无缝尺度跃迁** — 从个体微操到帝国总览，滚轮搞定
3. **自动化帝国** — 你设计的制度自己跑起来（挂机/增量式满足，像《缺氧》的产线自转）
4. **微观可观察** — 放大能看到每个火柴人真实工作/战斗
5. **可分享的组织架构** — UGC 传播（"看看我的最优指挥链"）

---

## 目标用户

- 模拟经营/管理游戏玩家（《缺氧》《RimWorld》《监狱建筑师》）
- 基地建设/建造游戏玩家
- 火柴人游戏爱好者（火柴人战争遗产/杰克驴铁匠铺）
- 次要：被 P 社高门槛劝退、想要"简化大战略体验"的玩家
