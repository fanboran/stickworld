# 世界观与种族设定

> 火柴人异世界——西幻底色但弱化特定文化标识，依靠火柴人独有的视觉语言构建世界观。

---

## 一、火柴人的本质

所有火柴人通体黑色——纯黑线条是种族的视觉统一性。

> **写作纪律**：设定与文案**不做"稀有/核心/世界观基石"式标榜**——越渲染越尬；一切资源都只是被争夺物之一。

### 质感

火柴人不是单纯的黑色线条。根据状态不同，质感可变化：

| 状态 | 质感表现 |
|------|----------|
| 正常 | 纯黑，哑光，类似墨线 |
| 湿润 | 光泽流动，像黑色油漆 |
| 感染/丧尸化 | 发绿，露出白骨线条 |
| 衰老/虚弱 | 线条变淡/断裂/有缺口 |
| 附魔/强化 | 线条变粗/发光/金属质感 |

这种"同一角色多种质感"的技巧可被反复使用，是火柴人美术的核心表现力。

## 二、种族模型

所有变体保持"纯黑线条火柴人"的底层视觉一致性，差异体现在体型、装饰和特效上。种族数据（属性/单位映射）以 `config/units/stickmen.tres` 为准。

### 2.1 原生种族（9）

| 种族 | 分布区域 | 视觉特征 | 文化/能力倾向 |
|------|----------|----------|--------------|
| **平原火柴人** | 温带平原 | 标准体型，简单衣饰 | 农耕文明，组织性强，人口多 |
| **火山火柴人** | 火山地带 | 线条带暗红岩浆纹，体型粗壮 | 冶炼/锻造专精，耐高温 |
| **雪地火柴人** | 极北冰原 | 线条带霜白纹理，体型宽厚 | 耐寒，冰系法术，生存专家 |
| **术师人** | 法术源泉流域 | 线条有淡蓝/紫光晕，人人佩戴法饰 | 法师比例极高，但体质较弱 |
| **火焰火柴人** | 超自然炎热大陆（元素） | 元素体质（视觉待定） | 元素种族，文化见 §六炽焰王庭 |
| **水火柴人** | 左下群岛（元素） | 元素体质（视觉待定） | 元素种族，文化见 §六沧澜千屿 |
| **巨人火柴人** | 高山地带 | 体型巨大 | 攻城锤、搬运重物、震慑敌军 |
| **半人马火柴人** | 待定 | 四足下身，速度极快 | 骑兵替代、信使、侦察 |
| **羽翼火柴人** | 待定 | 背部有简陋翼膜（非真飞，滑翔） | 侦察、传信、骚扰敌军 |

**文化区不是种族**：沙漠火柴人、森林火柴人、游牧火柴人都是平原火柴人在不同气候带/生业下的**文化区变体**——同一种族、不同文化。文明差异化（农耕/游牧/商业/海洋等）由此展开，见 §六与 GDD。

### 2.2 罕见变体（个体层）

散布于各族的罕见变异个体，不构成独立族群聚落：

| 变体 | 特征 | 用途 |
|------|------|------|
| **长臂火柴人** | 双臂超长，指节粗大 | 投石兵、采摘高处资源 |
| **多头火柴人** | 2~3 个头，混乱但多线程 | 多线操作生产（一个顶三个），但不可靠 |

### 2.3 吉祥物：蓝色史莱姆

> 创始人决定：给主角配一只蓝色史莱姆作为吉祥物/宠物。

**设定**：
- 蓝色史莱姆是一种独立的**低等生命形态**——没有固定形状，只有本能
- 野生史莱姆无害但烦人——到处蠕动，偶尔堵路
- 驯化后充当主角的**跟宠**——跟在主角身后蹦跶，没有任何战斗能力，纯装饰

**视觉**：
- 核心颜色：**蓝色**，半透明果冻质感（与火柴人的纯黑线条形成反差）
- 火柴人画风下，史莱姆 = 一个椭圆 + 两个点（眼睛），制作成本极低
- 可以 QQ弹弹、变形、分裂——天然适合做动画

**游戏内存在方式**：
- 主角身边常驻，蹦蹦跳跳
- 不会参与战斗（没战斗力，但可以做出"助威"动画）
- 可选：史莱姆可以当"信使"——玩家在战略图上下达命令时，史莱姆弹过去"送信"。纯动画效果，不影响机制
- B站视频封面：蓝色史莱姆放在角落就是一个视觉锚点——"那游戏的吉祥物"

**为什么是蓝色**：
- 火柴人世界主色调是黑色/大地色，蓝色是唯一的冷色高亮——画面中一眼能看到
- 蓝色史莱姆 = 游戏界经典符号（DQ、各种 JRPG），不需要解释"这是什么"

### 2.4 外观通用规则

- **同种族内部**：个体之间只有装饰细节和体型微差，保持视觉统一（便于素材复用）
- **不同种族**：配合当地特有元素和技艺产生不同的通用装饰风格
  - 例：火山火柴人的盔甲有岩浆纹路，术师人的武器带法术光效
- **特殊剧情角色**：可以有独特的外观设计，适合出周边

## 三、世界观基调

### 3.1 西幻但去西方化

世界观接近西幻（城堡、骑士、法师、龙），但**美术上看不到明显的欧洲要素或东方要素**。使用"世界通用的古代刻板印象"——石墙就是石墙，不需要哥特尖顶或飞檐斗拱。

### 3.2 不严肃的基调

火柴人画风天然带有荒诞感。后期可能出现近现代内容（管理学工具、金融制度），但以**无厘头/戏剧化的方式**呈现，避免前后体验割裂。

- 例：古代法师用魔法水晶球看到的报表可能和 Excel 表格布局一样——不说破，玩家自己会笑
- 例：高层级的"上帝视角"界面可以由某件古物承载（形式待定，不做设定绑定）

### 3.3 火柴人独有历史与传说

火柴人独有的史诗与神话待补——可保留的填充方向：不同文明对罕见变体（长臂/多头）的不同解释（诅咒/祝福/进化分支）。无主线剧情：世界本身是内容，历史由对局涌现。

## 四、液态法力

法师施法消耗的液态资源，产于**魔力泉**（世界生成的既有资源类型；法术源泉流域最密集，分布由世界生成管线负责——见 [`系统/08-程序化世界生成.md`](系统/08-程序化世界生成.md)）〔产地衔接为提案/待定〕：

| 用途 | 消耗量 | 说明 |
|------|--------|------|
| 法术施放 | 低-中 | 战争法术、生产法术的施法材料 |
| 附魔/强化单位 | 中 | 临时或永久增强个体战斗力 |
| 建造特殊建筑 | 中 | 奇观、学院等魔法建筑 |
| 维持大型单位 | 持续 | 巨人、半人马等异形单位需要定期补充 |

**争夺逻辑**：魔力泉是固定的，控制泉眼 = 掌握法术力量的主动权。但游戏里被争夺的东西很多（矿脉、土地、人口、航道、人才），液态法力的争夺只是**剧情着力点之一**，不是唯一的胜负手。

## 五、美术参考

| 参考作品 | 借鉴方向 |
|----------|----------|
| 《火柴人战争遗产》 | 角色比例、战斗动画、纯黑线条风格基准 |
| 《杰克驴铁匠铺》 | 建设/经营界面的温馨氛围 |
| 《王国保卫战》 | 场景层次、建筑细节度、色彩运用 |
| 《环世界》 | 个体单位可观察性、工作动画的多样性 |

**核心原则**：火柴人是美术选择，不是成本妥协。简约的线条风格反而给了独特的设计空间——质感变化、变形动画、夸张的打击反馈，这些在写实风格中需要大量资源才能实现的效果，在火柴人风格中可以低成本做到。

## 六、大陆与王国（按气候编撰）

> 本章为提案稿（创始人授权按各地气候编撰），人名/国名均可改。
> 玩家所在的**原初大陆**是全世界最普通的一块大陆——温带为主、四季分明、什么都不极端；
> 正因普通，它成了所有流亡者与侨民的落脚点，也是各方势力角逐的中心。
> 地块号对应 `region_data.json`（群系图见 `tools/worldgen/output/biome_preview_2048.png`）；
> 种族-地块锚点的机制口径见《世界地图系统完善总体设计》§5.11.1。

### 6.1 原初大陆（玩家大陆，最普通）

| 王国/势力 | 地块 | 气候与地貌 | 居民 | 文化与立场 |

### 6.2 王国关系速写

- 八城邦 ↔ 金穗王国：同文同种，后者常以「老大哥」自居，城邦反感
- 炽焰王庭 ↔ 沧澜千屿：水火世仇，隔着整块大陆骂了几百年，真打起来谁也过不去
- 黄沙商邦：中立渔利，所有势力的商路都走它的绿洲
- 霜峰氏族：谁都不理，但谁都想要它山里的矿
- 清源议会：唯一被所有势力承认的仲裁方——因为法术只有他们懂
