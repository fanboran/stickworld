## 设计目标

1. **窗户不是海报**：界面是纯黑半透明的"玻璃窗"，游戏画面永远透出来——火柴人黑色世界观的天然延续。
2. **一套 token 管全部**：颜色/字号/间距/圆角集中定义，换肤 = 换一套 token。
3. **内容数据驱动**：加一个菜单项/设置项/工作区 = 加一行数据，不写 UI 代码。
4. **按需呈现**：信息密度服从当前管理层级（L1 个体 → L5 帝国），随缩放渐隐渐显。
