# 物流运输系统

## 目的

物资和兵力不会"瞬移"——它们必须沿着你设计的运输网络从产地流向前线/城市。物流是连接经济与战争的血管系统。

## 玩家体验目标

- **从手操到委任**：物流是人事任命——开局 RTS 式手操个体，委任得力干将后逐步封装成部门，像创业公司一路长成大企业
- **设计物流网络**：像设计产线一样设计运输路线
- **瓶颈可视化**：哪里堵了、哪里断了，地图上直观可见
- **战略打击目标**：切断敌方补给线 = 不战而屈人之兵

## 一、运输载体

| 载体 | 速度 | 容量 | 成本 | 地形限制 |
|------|------|------|------|----------|
| 人力搬运 | 慢 | 极小 | 低 | 无限制 |
| 驮兽（可以是畸形火柴人） | 中 | 小 | 中 | 山地减速 |
| 马车 | 中 | 中 | 中 | 需要道路 |
| 船只（河流） | 快 | 大 | 高 | 仅水路 |
| 海船 | 最快 | 最大 | 最高 | 仅海域 + 港口 |
| 魔法传送 | 即时 | 小 | 极高（消耗沥青） | 需传送阵 |

**载具是造出来的**：想用马车先得有人造出马车，想走水路先得有船——运输能力本身是制造与科技的产物，不存在凭空可用的运力。水路的便利性天然优于陆路（快、容量大），控制河流与渡口就是战略优势。

## 二、运输网络设计

### 2.1 网络要素

| 要素 | 说明 |
|------|------|
| **节点** | 城市/仓库/中转站/前线补给站 |
| **路线** | 节点之间的运输路径 |
| **承运人** | 被分配运输任务的火柴人/驮兽 |
| **运输计划** | 什么物资 → 从哪到哪 → 多少 → 频率 |

### 2.2 设计界面

- 类似《异星工厂》的物流网络视图
- 节点之间连线 = 激活的运输路线
- 线粗细 = 运输量
- 线颜色 = 运输状态（绿=顺畅/黄=拥堵/红=中断）
- 点击节点查看库存

### 2.3 运输计划

玩家可以设定：

```
从：[铁矿山脉3号]
到：[王都军械库]
物资：铁矿石
数量：每批 [PLACEHOLDER] 单位
频率：每 [PLACEHOLDER] 天一批
优先级：[高/中/低]
```

## 三、补给线机制

### 3.1 前线补给

前线部队需要持续从后方获得：

| 补给类型 | 消耗速度 | 断供影响 |
|----------|----------|----------|
| 食物 | 持续 | 士气下降 → 战斗力下降 → 可能溃散 |
| 武器弹药 | 战斗中 | 火力下降 → 只能肉搏 |
| 替换兵员 | 有伤亡时 | 部队逐渐减员 |
| 沥青（法术部队） | 持续 | 法师失去施法能力 |

### 3.2 补给线长度惩罚

- 补给线越长 → 运输损耗越大 → 到达前线的物资越少
- 这自然限制了帝国过度扩张——远征军补给跟不上

### 3.3 切断补给

- 敌方小队绕过前线攻击你的运输队 → 补给线中断
- 包围敌军 → 切断其补给 → 不战而降

## 四、物流的组织封装递进

物流不是"解锁功能"，是**人事任命的封装过程**——像创业公司从创始人亲自搬货，一路长成有物流部的大企业。每一档封装都依赖你任命到合适的人：

| 阶段 | 形态 | 玩家操作 |
|------|------|----------|
| 手操个体 | 框选某个火柴人，给他装备手推车，下令"把这堆铁从矿山运到铁匠铺" | RTS 式逐单指挥，开局手忙脚乱是预期体验 |
| 专人委托 | 任命一个运输主管 | 只定"什么时候需要运什么"，线路选择与执行由他负责（他的能力决定封装质量） |
| 运输队/计划 | 用组织系统组建运输队，制定运输计划表（§2.3） | 设定频率/线路/优先级，处理异常 |
| 运输部门 | 多支运输队合并为部门 | 协调定时班次（如河流班轮）与突发运输、跨部门资源调度 |
| 帝国物流部 | 部门自动运转 | 玩家主要做人事任免，只在战略与危机时介入 |

**部门不预设**：不存在固定的"物流部"按钮——运输组织是玩家用通用组织系统搭出来的，名字、层级、管辖范围全部自定义（见 [`01-组织系统.md`](01-组织系统.md)）。运输线路怎么走、多久发一班、用什么载具，全部是玩家可亲自设计的参数——像大公司领导对下属部门拥有微操自由，但具体执行仍受人员能力与物理约束限制。

## 五、物流与经济的关系

- 物资在产地的价格 ≠ 消费地的价格（差额 = 运输成本）
- 物流效率直接影响帝国各地区的经济活力
- 偏远地区物产丰富但运不出来 = 穷
- 修路/开运河/建港口 = 巨大的经济回报（和军事价值）

## 六、战略层面

| 战略行动 | 物流影响 |
|----------|----------|
| 修路 | 运输速度 +50%，成本降低 |
| 建中转仓库 | 长途运输效率提升 |
| 控制河流/海峡 | 掌握关键运输通道 |
| 劫掠敌方补给线 | 不战而屈人之兵 |
| 焦土撤退 | 摧毁己方设施，让敌方就地补给不可行 |

---

## 边缘情况

- **运输队被全歼**：物资损失 + 路线中断 → 需要重新分配承运人和护送
- **仓库爆满**：上游生产 > 下游消费 → 需要扩建仓库或调整生产
- **季节性阻塞**：冬季雪山路线封闭 → 需要备用路线
- **海盗/劫匪**：偏远路线可能被强盗侵扰 → 需要护送
- **远征军补给**：跨越半个地图打远征 → 补给线极长 → 几乎不可行（除非有海军/魔法）
