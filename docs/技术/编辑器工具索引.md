# 编辑器工具索引

> 本文档索引所有 `addons/` 和 `tools/` 下的编辑器扩展、命令行工具、@tool 辅助脚本。
>
> **使用方式**：当用户提到"放置建筑"、"网格标尺"、"烘焙动画"、"代码扫描"等关键词时，先查本表的「关键词反查表」定位脚本，再读脚本头注释获取细节。

## addons/ — 编辑器插件

### MapEditor（项目自带）

| 字段 | 值 |
|---|---|
| 路径 | [addons/map_editor/map_editor_plugin.gd](../../stick-world/addons/map_editor/map_editor_plugin.gd) |
| 类型 | EditorPlugin（`@tool`） |
| 作者 | stick-world（项目自带，v0.1.0） |
| 启用 | Project Settings → Plugins → 启用 MapEditor |
| 用途 | 可视化地图编辑工具栏：「建筑放置」按钮 + 下拉选建筑 + X坐标输入 + 「放置!」按钮 + 「吸附全部」按钮 |
| 操作资源 | 扫描 `res://modules/building_gen/buildings/` 下所有 `.tscn` 文件构建菜单 |
| 配套工具 | [tools/dev/map_grid_drawer.gd](../../stick-world/tools/dev/map_grid_drawer.gd)（场景内绘制网格 + 建筑占地高亮） |
| 关键常量 | `BUILDINGS_DIR`、`CELL_SIZE = 32` |
| 触发条件 | 当前编辑的场景根节点含 `ground_y` 属性时显示工具栏（典型：VillageMap） |

### dev/ — 开发辅助

#### map_grid_drawer.gd

| 字段 | 值 |
|---|---|
| 路径 | [tools/dev/map_grid_drawer.gd](../../stick-world/tools/dev/map_grid_drawer.gd) |
| 类型 | `@tool Node2D`（`class_name MapGridDrawer`，挂场景） |
| 用途 | 编辑器内绘制 32px 网格竖线 + 地面线 + 建筑占地高亮 |
| 配套 | 被 [addons/map_editor/map_editor_plugin.gd](../../stick-world/addons/map_editor/map_editor_plugin.gd) 设置 `ghost_active` / `ghost_world_pos` / `ghost_width_cells` 属性来高亮建筑将占用的竖条 |
| 依赖 | 父节点须有 `ground_y` / `ground_bottom` / `map_right` 属性（典型：VillageMap） |

#### code_scanner.gd

| 字段 | 值 |
|---|---|
| 路径 | [tools/dev/code_scanner.gd](../../stick-world/tools/dev/code_scanner.gd) |
| 类型 | `SceneTree`（CLI，非 `@tool`） |
| 启动 | `godot --headless --path <project_dir> -s res://tools/dev/code_scanner.gd` |
| 用途 | 扫描所有 `.gd` 文件语法和基本质量问题（CI 用） |
| 扫描目录 | `modules`、`core`、`tests`、`tools`（排除 `addons/`） |
| 退出码 | `0` = 无问题，`>0` = 有问题 |

### worldgen/ — 世界生成管线（仓库根 `tools/worldgen/`，非 stick-world 内）

> 目录按生成阶段拆分：`l3/`（L3 大陆/地区）· `l2_export/`（L2 网格提取/烘焙 + 全部视图导出）· `l1/`（L1 地块合并/生成）· `legacy/`（早期分形链）· `archive/`（人工调整工具留档）· `experiments/`（河流实验）。output 历史候选图已移出 git（备份在 `tools/worldgen/_backup/`）。

**L3 大陆/地区（`l3/`）**

| 工具 | 用途 | 输入 → 输出 |
|------|------|-------------|
| `l3/fractal_continent.py` | 分形大陆生成（Delaunay 高度合成 + 河流追踪，8192 级） | 大陆蒙版 → 高度场/河流/预览 |
| `l3/region_split.py` | L3 地区划分（watershed 沿地形切分；`--size` 分辨率自适应） | 8192 高度场 + 大陆蒙版 → `regions/region_labels.npy` |
| `l3/region_preview_annotated.py` | 地区预览标注图 | region 数据 → 标注预览 |

**L2 网格提取 / 烘焙 / 视图导出（`l2_export/`）**

| 工具 | 用途 | 输入 → 输出 |
|------|------|-------------|
| `l2_export/mesh_extract.py` | 共享顶点网格提取（P 社省份网格架构）+ Chaikin 边界平滑 + DP(tol=0.2) 降顶点 | 标签图 → 每 label 的 polygons/holes（相邻共享角点，无缝） |
| `l2_export/earclip.py` | 纯 Python 单环耳切三角剖分（大环先 DP 简化消除 O(n²)） | 多边形 → 三角面 |
| `l2_export/l2_bake.py` | L2 几何烘焙（earcut 剖分 + 描边同源生成 → `l2_geom.bin`，运行时零剖分） | JSON 多边形 → `.bin` |
| `l2_export/export_l2_packs.py` | L2 图包素材（蒙版/底图裁切/高程/索引图；**8K 蒙版裁切海岸线**） | region_labels + 8192 源 → `l2_packs/` |
| `l2_export/export_l2_maps.py` | L2 内部 L1 地块分块（watershed + 河流屏障 + 面积上下限） | 裁切高程/蒙版 → `tiles_8192.npy` + `tiles.json` |
| `l2_export/update_tiles_coastline.py` | 保留人工 tiles 状态按 8K 蒙版裁切海岸线并重建元数据 | tiles + 新蒙版 → 更新 tiles 数据 |
| `l2_export/export_l2_view_packs.py` | L2 运行时视图包（8192 级索引图 + json 多边形 + 烘焙 .bin） | tiles 数据 → `l2_view_packs/` + `config/strategic_map/l2_packs/` |
| `l2_export/export_l3_view.py` | L3 视图素材（海洋归边分区索引图 + 8192 级陆地共享网格） | region_labels → `l3_view/` + `config/strategic_map/` |
| `l2_export/export_l1_overview.py` | L1 全图预览（13 地区 tiles 拼回 8192 坐标系） | 13 地区 tiles → `l1_all_tiles_8192.png` |

**L1 地块合并 / 生成（`l1/`）**

| 工具 | 用途 | 输入 → 输出 |
|------|------|-------------|
| `l1/merge_tiny_tiles.py` | 微小地块合并（L3 全局阈值；`--frac`/`--regions`/`--target-n`） | tiles → 合并后 tiles |
| `l1/merge_tiles_groups.py` | 地块分组合并（邻接 + 面积差最小，均衡 N 组） | tiles → 分组合并 tiles |
| `l1/merge_island_tiles.py` | 岛屿合并（每岛一块） | tiles → 岛屿级地块 |
| `l1/l1_worldgen.py` / `l1/settlement_mapgen.py` | L1 世界/聚落生成（预留，L1 阶段未开始） | seed → L1 数据 |
| `l1/l1_world_split.py` | **全大陆 L1 地块划分（L3 级蒙版）**：城市点（均匀网格 + 扰动 + 每岛≥1 点）→ 受限 Voronoi 直线细胞 → 同 L2 相似色蒙版 | region_labels → `output/l1/`（labels/预览/索引图/JSON）+ `config/strategic_map/`（L3 视图 V 键叠加查看，见 [08-程序化世界生成.md §L3-L](../设计/系统/08-程序化世界生成.md)） |

**遗留 / 归档 / 实验**

| 目录 | 说明 |
|------|------|
| `legacy/` | 早期分形生成链（noise_util/landmask/mask_utils/tectonic/terrain_template/world_map/commands_map/commands_candidates/generate），被 `generate.py` 入口调用，历史留档 |
| `archive/` | 一次性人工调整工具（地区合并/画线切口 HTML 工具 + 应用脚本、地块标记/切分工具） |
| `experiments/` | 河流算法实验（C/Python） |

## 维护规则

- **新增工具**：在 `addons/` 或 `tools/` 下新增任何脚本时，**必须同步更新本文档**（添加条目 + 关键词反查表）。
- **常量变更**：`BUILDINGS_DIR`、`CELL_SIZE`、扫描目录等关键常量变更后，同步更新本文档「操作资源」字段。
- **删除工具**：删除脚本时同步删除本文档对应条目。
- **路由入口**：本文档由 [rule.md](../../.trae/rules/rule.md) 的「项目文档导航」表格引用，AI 在用户提到编辑器工具/插件关键词时应优先读本文档。
