## 一 · 程序化世界生成与聚落规模（tools/worldgen）

噪声高程/群系/河流 → 宜居·资源·成本场 → 文化扩散 → 聚落 → 城块划分 → 政权与道路网，产物经 submodule 喂给战略图。聚落规模生成器按变半径泊松盘撒点、对数正态规模谱定档，规模谱再映射为村→都的聚落实渲染：

## 三 · HD-2D 场景视觉（modules/hd2d · environment）

HD-2D billboard 是火柴人唯一视觉骨架（数据源留实体侧、渲染走骨架镜像）；场景侧有多层视差天空（星野/月亮/白昼飞鸟群/夜间萤火虫，昼夜联动）与全屏后处理（分级/炫光/渐晕/颗粒）。
