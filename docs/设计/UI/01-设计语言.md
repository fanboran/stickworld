# 01 · 设计语言

> 视觉系统的设计原则与 token 总表。所有常量的**代码真相源**是
> `modules/ui_global/scripts/theme/stick_tokens.gd`（StickTokens），
> 本文是设计意图与使用纪律；数值以代码为准。

## 一、视觉哲学

### 1.0 手绘涂鸦是全局唯一皮肤

主菜单、载入屏与游戏内全部 UI（HUD/弹窗/面板/按钮/进度条/分隔线）统一走
**手绘涂鸦皮肤**：自绘控件（`modules/ui_global/scripts/sketch/`）+ StickHand
程序化手写字体。Theme 层留 Flat 玻璃 StyleBox（GlassStyle）兜底未自绘的
原生控件（TabContainer/HSlider 等）。

**亮背景的墨色规则**：白描边（`BORDER` 白 16%）只保证在深底上可见；浮在
亮背景（如主菜单暖金天空）上的控件用**深墨描边**（`ink`，色值与血条
`COLOR_OUTLINE` 同源）——血条"亮世界黑墨线"的同一思路，反过来了也成立。

文字统一 **StickHand**（`tools/fonts/gen_hand_font.py` 产）：以站酷快乐体
（开源可商用，马克笔等粗手绘风）为骨架，字形轮廓点做确定性小幅高斯扰动 +
微倾斜——每个字"定型地微微不一样"，笔画等粗可读性高，矢量无损、布局零漂移；
改扰动风格 = 改管线脚本重跑，不手改产物。

### 1.1 窗户不是海报

界面是一块**纯黑半透明的玻璃窗**：游戏画面从面板底下透出来，玩家永远不"离开"世界。
参考《僵尸毁灭工程》——面板没有海报式的美术底图，只有黑底、细描边、文字。
模态（弹窗/确认框）打开时，遮罩（GenerativeBackdrop）**一体绘制**：全屏压暗打底，
叠加均匀排布的旋转**圆角立方体**网格（低透明白、带 3D 挤出感的顶面）+ 鼠标靠近排斥
（立方体被推开），为玻璃窗添一点"活的"质感。

**为什么**：
- 本作是"无缝缩放"游戏，玩家在 Micro↔Strategic 间连续滑动，界面若是不透明海报，
  每次开合都是一次"出戏"；玻璃窗让观察与操作同时成立。
- 世界观：火柴人由**黑色沥青**构成，黑是世界观底色，黑底 UI 是天然延续而非风格选择。

### 1.2 一个强调色

全套 UI 只有**一个强调色：琥珀**（火光色）。用于且仅用于：

| 用途 | 例子 |
|------|------|
| 主行动点 | 新游戏 / 确定 / 应用 |
| 选中态/激活态 | 当前标签页、当前速度档、选中列表项 |
| 关键数值 | 资源图标、摘要统计数字 |

危险（红）、警告（黄）、信息（蓝）、成功（绿）是**语义色**，只出现在反馈场景
（通知、删除按钮、不足提示），不参与装饰。强调色滥发会导致玩家无法一眼找到"该点哪"。

### 1.3 信息密度服从层级

- 微观层级（L1/L2）：UI 稀疏、字大、只显示个体相关信息
- 宏观层级（L4/L5）：UI 密集、字小、允许报表式排布
- 快捷栏等"操作区"鼓励**密集堆叠**（《博德之门3》技能栏式满足感）

### 1.4 手绘涂鸦层（游戏内主视觉）

游戏内一切面板/按钮的底与描边由**自绘控件**承担，与血条
`HealthBarIndicator` 完全同源：同一 `_wobble` 伪噪声公式、同一 0.12s 沸腾
重掷节拍、同款"实心扰动多边形 + 粗马克笔描边"画法。

**控件族**（`modules/ui_global/scripts/sketch/`）：

| 控件 | 替代 | 说明 |
|------|------|------|
| `SketchPanel` | PanelContainer + stylebox | DARK（大弹窗）/ LIGHT（HUD 横条）两档；边框画在标准圆角矩形位置，只做小幅双向扰动 |
| `SketchButton` | Button | 底色走无描边 Flat（引擎画、文字之下），沸腾描边 `_draw()` 叠加（边缘区不碰文字） |
| `SketchProgress` | ProgressBar | 手绘轨道 + 填充（相位错开的独立沸腾） |
| `SketchLineEdit` | LineEdit | 凹槽底 + 聚焦琥珀描边 |
| `SketchSeparator` | H/VSeparator | 手绘波浪线 |

**绘制纪律**（`SketchDraw` 算法库）：
- 边框永远在标准圆角矩形位置上，扰动是纯小幅双向摆动（血条质感来源），
  **不做任何系统性内缩**
- 直边按 ~18px/段采样（血条同密度），杜绝长边折线感
- 角弧半径扰动钳下限防自交（三角化失败的教训）
- 过小矩形（<8px）回退普通 `draw_rect`（血条同款退化保护）

**为什么自绘而不是贴图**：贴图（含 AnimatedTexture）是循环近似，且所有控件共享
同一纹理缺乏"逐个手画"的差异；自绘每控件独立 seed 逐帧随机重掷，是真沸腾——
与血条在同一个世界里的同一种"活"。

### 1.5 比例与紧凑纪律

- **字号跟控件走**：按钮文字 ≥ 控件高的 1/2（32px 按钮 ≥16px 字、44px ≥18px），
  不做"大按钮小字"的空洞感；调控件尺寸时同步审字号比例。
- **对比优先于装饰**：可读性问题优先用加粗（`SketchFonts.bold()` 伪粗）、
  底色对比、字号档位解决；描边/阴影是最后手段（描边让字糊、观感脏）。
- **强调色只上底不上字**：ACCENT 按钮字色 = 白 + 伪粗，区分靠琥珀底
  （14%/hover 26%）；琥珀字在暖背景上不可读，禁止再用。
- **弹窗随内容自适应**：小对话框（确认框等）宽度由文本撑开、紧凑内边距
  （`SketchPanel.compact`），一行内容就一行高度；固定大 min 宽/高是大面板
  （设置/暂停）的特权。

## 二、色彩 Token

### 2.1 基底

| Token | 值 | 用途 |
|-------|-----|------|
| `WINDOW_BG` | 黑 88% 不透明 | 大面板/弹窗底（主窗体） |
| `WINDOW_BG_LIGHT` | 黑 72% 不透明 | HUD 横条/内嵌区块（更透的玻璃） |
| `MODAL_DIM` | 黑 60% 不透明 | 全屏模态遮罩压暗（生成艺术叠加其上，见 §1.1） |
| `GROOVE_BG` | 黑 45% 不透明 | 输入框/滑条凹槽底 |

### 2.2 描边

| Token | 值 | 用途 |
|-------|-----|------|
| `BORDER` | 白 16% 透明 | 常规 1px 描边 |
| `BORDER_STRONG` | 白 38% 透明 | 悬停/聚焦态 |

### 2.3 文字

| Token | 透明度 | 用途 |
|-------|--------|------|
| `TEXT` | 100% | 正文/按钮 |
| `TEXT_DIM` | 55% | 辅助说明 |
| `TEXT_FAINT` | 32% | 占位符/角标 |
| `TEXT_DISABLED` | 25% | 禁用态 |

### 2.4 语义色

| Token | 色 | 纪律 |
|-------|-----|------|
| `ACCENT` | 琥珀 | 唯一强调色，见 §1.2 |
| `DANGER` | 红 | 删除/战败/错误通知 |
| `WARN` | 黄 | 资源不足/警告通知/数量徽标 |
| `INFO` | 蓝 | 信息通知/链接 |
| `SUCCESS` | 绿 | 完工/增益 |

### 2.5 按钮态底色

按钮底色 = 白色叠加：`BTN_BG` 7% / `HOVER` 15% / `PRESSED` 4% / `DISABLED` 3%。
在黑玻璃上叠加白色薄层产生"浮起"感，不引入新色相。

## 四、形状与间距

| Token | 值 | 说明 |
|-------|-----|------|
| `RADIUS` | 3 | 通用圆角（接近直角的"冷"感） |
| `RADIUS_PANEL` | 6 | 大面板圆角 |
| `BORDER_W` | 1 | 描边宽度（始终 1px，不用粗边框） |
| `PAD_X` / `PAD_Y` | 12 / 6 | 控件内边距 |
| `BTN_H` 系列 | 26 / 32 / 44 | 小/标准/大按钮高度 |
| `ROW_H` | 36 | 设置/菜单行高 |

间距系统：容器 separation 只取 4 / 6 / 8 / 12 / 16 五档。

## 五、动效

| Token | 值 | 用途 |
|-------|-----|------|
| `T_FADE` | 0.12s | 悬停/渐隐渐显 |
| `T_PANEL` | 0.18s | 面板开合 |
| `T_TOAST` | 3.0s | 通知停留 |

纪律：动效只做**透明度和位移**，不做缩放弹跳（与"玻璃窗"气质冲突）；
缩放渐隐渐显（连续缩放时 UI 按层级淡入淡出）是核心动效，见
[04-游戏内HUD](04-游戏内HUD.md) §四。

## 六、图标

现状：`assets/ui/` 为空，模板用**单字占位**（木/石/铁/沥/剑/盾…）。

图标资产规范（入库时执行）：

| 项 | 规范 |
|----|------|
| 风格 | 单色（白）线性素描，火柴人式极简线条 |
| 尺寸 | 16×16 基准，导出 16/24/32 三档 |
| 着色 | 运行时用 `modulate` 上语义色，资产本身纯白 |
| 存放 | `assets/ui/icons/`，命名 `ic_<域>_<名>.png`（如 `ic_res_wood`） |
