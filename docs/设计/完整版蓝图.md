# 完整版蓝图

> **定位**：游戏完整版的玩法终态定稿（创始人逐轮对齐的共识），是各系统设计与整合实施的靶心。凡各系统文档、架构文档、实施批次与本档冲突处，以本档为准（冲突裁决与待回填清单见 §八）。
> **使用方式**：实施任何玩法系统前先读本档对应支柱；验收时对照 §五质量底线逐条检查——**占位管道不算完成**。

---

## 一、产品定位

**火柴人帝国模拟**：RimWorld 式复杂模拟世界为地基 × 渐进自动化为路径 × 纯军事征服为主引擎。

| 支柱 | 内涵 | 参照 |
|---|---|---|
| 帝国模拟 | 建筑 + 人 + 工具构成完整生产链；村民是有技能/职业的个体，资源、人口、装备、知识都在这个世界里真实流动 | RimWorld |
| 渐进自动化 | 初期玩家纯手动亲力亲为，逐步搭建自动化（设施、组织、规则），终态规划好后帝国自动运行 | Minecraft 红石 → 戴森球计划 |
| 纯军事征服 | 扩张只有军事一条路；无外交系统；战争体验是玩法重心 | — |

## 二、完整版征服循环全景

```
【玩家主轴】（起源见 §3.9：三出身之一入场，从个体/小聚落长成帝国）
经营帝国（渐进自动化：生产/人口/装备）
    → 养兵（人 + 装备 + 维持成本）
    → 选目标出征（情报：守军/战形/战利品）
    → 行军抵达（出征是完整体验，非黑屏传送）
    → 接敌开战（指挥官下号令，部队自动执行；可附身参战）
    → 打赢即易手（占领 + 战利品/人口/人才回流）
    → 帝国更强 → 下一个目标 → …… → 统合世界（终局）

【世界平行轴】
AI 政权互相征服/合并（碎 → 合：上百小政权 → 少数超级政权）
——你不打世界也在动；战争对所有人（含玩家）对称存在
```

循环的放大不改变单次体验的结构——**单次即多次**：一次出征→战斗→占领的体验语义做对了，重复 N 次、地图更大、政权更多，都自然成立。因此所有设计精力投向单次体验的语义质量，不投向尺度/数量的配置。

## 三、终态语义八柱

### 3.1 战斗

- **玩家角色**：常态是指挥官——下号令（目标/进退/战术），部队自动执行；随时可附身参战，作为其中一个士兵亲自走位战斗。两种参与方式共存，不做成两套独立模式。
- **死亡语义**：附身战死无惩罚（附身的是他人躯体）；真身战死有惩罚（具体后果待实装前定稿——语义位）。
- **战形由据点类型决定**：营地 = 野战列阵迎击、要塞 = 城墙攻坚、城镇 = 巷战推进。每种战形有专属机制（城墙/建筑掩体/街道），不同目标打法不同。
- **规模涌现**：不设计战斗规模上限——参战兵力是政权经济/人口/装备的自然结果，像 RimWorld 的殖民地规模一样被底层资源限制住。引擎容量随此弹性。
- **敌军对称**：敌方同样由 AI 指挥（敌将决策、撤退评估、战术），不是站桩靶子。

### 3.2 占领与反哺

- **打赢即易手**：守军战败 = 据点归属变更，无控制度渐进、无需多次战役消化。
- **反哺 = 奖励回流**：战利品（资源/装备）、人口（俘虏/归附村民）、人才（见 3.5）直接流入帝国体系。
- **不做**：占领后的反扑事件、治理/叛乱机制、驻军维护费这类刻意堆叠——扩张的代价由模拟本身承担（养兵成本、多线作战的管理复杂度，见 §3.3）。

### 3.3 经济与渐进自动化

- **生产链**：建筑 × 人 × 工具三要素——采集（伐木/采矿/采集）、加工（锯木/冶炼/锻造）、制造（装备/器械）逐级流动；村民按职业/技能在链上工作。
- **自动化路径**：手动（玩家亲采/逐次下令）→ 半自动（建筑+派工运转）→ 全自动（组织规则驱动，帝国自运行）。自动化是玩家逐层搭建的成果，不是开局赠送。
- **战争经济**：养兵的消耗是士兵作为真实个体的需求消耗——穿衣、装备损耗，走人口需求与物品域（模拟因果，惩罚来自模拟本身），**不建抽象军饷/维护费的资源 tick**；进食取泰拉瑞亚式弱化口径（2026-09-27 创始人裁决）——食物是可选增益消耗品：吃了改善个体状态与情绪（经行为权重通道，不是系统数值修正），不吃无惩罚、不构成生存需求，亦不设「食物」资源；部队规模被经济自然限制——这就是规模涌现的底层、也是防滚雪球的天然阻力。
- 村民有个体技能/职业差异，无全局心情/需求系统（剧情人物例外，见 3.6）。

### 3.4 世界与政权演化

- **活的战略层**：AI 政权互相征服合并，政权数量随时间从上百递减到少数超级政权（GDD §五原案保留并升级为核心）；玩家的战略图是这个世界状态的实时呈现（政治归属/疆域/战争）。
- **战争对称**：AI 势力之间、AI 对玩家都可能开战——防御建筑的需求来自这里（世界会打你），而非脚本化反扑事件。〔提案/待定：AI 主动攻击玩家的节奏与强度由政权演化自然驱动〕
- **无外交**：附庸、结盟、宣战理由、声望、联邦统一——全部不做。势力关系只有敌对/中立。
- **实现语义（统一契约 + 模拟分档）**：
  - **统一数据契约**：所有城（玩家/AI）同一套城市模型（人口/建筑/军队/归属政权），政权实力 = 名下城市聚合；初始世界政权以 worldgen 生成的政权（~80，"上百小政权"起点）为真源。玩家政权与 AI 政权同构——"玩家只是其中之一"在数据层成立。
  - **模拟分档**：焦点城实体模拟（村民/建筑真实运转，现有母城形态）、离屏城账面 tick（人口/经济/建军轻量推进，城市随人口档位自然变大）、玩家视角切过去时升档为实体。
  - **离屏战争**：AI 对 AI 的战争按账面对推（双方军力/时间 → 损耗/胜负），结果回写政权账面；玩家在场的战场是真实战斗（BattleInstance 全套）。"活的战略图" = 账面层驱动的世界演化实时呈现，玩家追着热点去看就能看到真的。
  - **AI 内政深度 = 账面级**：政权 tick 推进人口/经济/建军三项，不做建筑清单/生产链级的离屏细算（离屏细算玩家看不见，性价比低）。
  - **实施排序**：统一契约 → 世界账面层 + W7/W8 → 三出身开局（§3.9）→ 追随者三机制——世界先活，玩家逐步长进去。

### 3.5 科技（知识长在人身上）

沿 [`系统/04-科技系统.md`](系统/04-科技系统.md) 原案：科技的载体是具体的人——获得人口即获得其知识、俘获/招揽名师匠人即获得其技术、人才流失即科技流失；后期帝国规模才自主研究（研究也具体到个人）。征服是主要科技来源，但不是"打赢弹解锁"，是"城里的人归你了"。

### 3.6 剧情人物

Kenshi 式：世界上散布独特命名的 NPC——有特定能力、与普通人不同、可与玩家互动（敌将/大师/首领/旅人，具体人物随剧情创作落地）。他们是"知识长在人身上"的主要载体之一，也是世界叙事的锚点。〔人物名单与剧情：待剧情创作，机制位先立〕

### 3.7 玩家实体

玩家在世界中以真实火柴人形态存在（指挥官本体）；可附身任何己方单位参战。附身 = 安全的遥控操作；真身下场 = 有真实风险的亲自参战（死亡语义见 3.1）。

### 3.8 AI 总纲

战斗与世界的 AI 统一走 [`系统/12-游戏AI系统.md`](系统/12-游戏AI系统.md) 分层体系（L1 个体效用轮盘 × RWR 参数 / L2 小队 CoH 相位计划 / L3 组织指挥链 / L4 战略层 CoH 任务槽 + WorldBox 世界面）。政权演化 = L4 世界域的实施（W5-W8 批次候选），不另造机制。

### 3.9 玩家起源与成长

- **三出身开局**：同一张世界、同一套规则，出身只决定初始条件与起步玩法——

| 出身 | 初始状态 | 起步玩法 |
|---|---|---|
| 该溜子 | 无地流浪者 + 几个帮手 | 人望/掠夺/被雇佣，快节奏 |
| 部落首领 | 荒野小聚落 + 人口 | 定居点自然生长，慢热经营 |
| 城邦平民 | 住在 AI 城里，一无所有 | 打工/攒钱/攒人望，时机成熟出走自立 |

- **追随者三机制并存**：定居点自然吸引（有床位有人来、有活干有人留）/ 雇佣（钱）/ 人望（做事攒名望 NPC 来投）。不同出身的起步路径各自侧重，后期全部可用。注：此处"人望"是 NPC 投奔的个体层驱动，≠ §七已砍除的外交声望（宣战理由/国家间声望）。
- **成政权节点**：玩家的聚落所在 **tile 的归属（owner_state_id）变为玩家政权**即成政权——此前只是个体/小队（AI 不将其纳入战争判定，世界对你是中性的）；从这一刻起 AI 会对你开战/拉锯（战争对称 §3.4）。地图系统的领土最小单位就是 tile、聚落是 tile 的属性、`settlement.level` 只是规模档——荒野自建聚落与占据现成城同一语义，无"聚落→城市"成长门槛（世界演化/W8 拉锯的领土流转同按 tile 归属，与政治模式渲染天然对接）。
- **个体期与 AI 政权的交互边界——公共层开放**：AI 城对个体期玩家开放公共层：可进城、可打工/交易/接活，但城的指挥权（建筑/驻军/仓库）归城主；攻击/偷窃会被城驻军攻击——外乡人语义。像真世界的外乡人，"城邦平民"出身由此可玩。

## 四、设计原则（裁决依据）

1. **单次即多次**：单次征服体验的语义质量是唯一质量单位；尺度、数量、里程碑式分期不是设计维度（实施是迭代式的，自然逼近终态）。
2. **涌现优先于配置**：规模、政权格局、世界演化由底层系统（资源/人口/经济/AI 微观行为）自然涌现，不写死上限、不做宏观脚本。
3. **机制不刻意堆叠**："大战略游戏常见"不等于"该做"——反扑事件、治理叛乱、外交、声望均已裁决不做（见 §七），防止机制互打架。
4. **占位 ≠ 完成**：每个环节以"设计语义真实发生 + 基本可交付质量"为完成判据（详见 §五）。

## 五、质量底线（反占位条款）

> 每个环节的完成判据。AI 实施与创始人验收共用此表——任何一条不满足，该环节不算做了。

| 环节 | 底线 | 反例（占位） |
|---|---|---|
| 行军/跨图 | 正常游戏的转场体验（出发→途中→抵达有过程感） | 黑屏/瞬移直达 |
| 接敌 | 守军按据点类型列阵/布防，战斗有"攻打某地"的形 | 守军全图乱冲的野战互殴 |
| 敌将 AI | 敌将决策真实发生且玩家可感知（下令/撤退改变战局） | 阈值配置存在但永不触发的死数据 |
| 战斗执行 | 号令下达后部队的行为符合号令语义 | 信号发了、单位收不到（链路断） |
| 占领 | 打赢后归属变更在所有消费端生效（战略图/情报/经济） | 只改一个字段其余不知情 |
| 反哺 | 战利品/人口/人才真实进入帝国体系且有下游消费 | 资源入账但无处可花、解锁无人消费 |
| 生产链 | 人真的在建筑里干活、工具真的提升产出、产出真的被消耗 | 数值 tick 模拟产出 |
| 追随者/人口 | 三机制（吸引/雇佣/人望）真实发生且有下游（人口干活/参军） | 定时器刷人口、账面数字增长 |
| 政权演化 | AI 势力的征服在战略图上真实发生（玩家能看到世界变化） | 静态势力表 |
| 死亡语义 | 附身死/真身死的后果差异真实落地 | 待定语义位悬空实装 |
