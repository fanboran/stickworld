## 〇、维护规则（保持"单一总账"不退化）

1. **任务只登记在本档**。任何文档写"未完成事项"时，若属建筑系统，写编号引用（如 `3.4`），不重抄条目文本。
2. **编号 = 章内顺序号**（`章.条`，如 `3.4`）：条目按 v2 工作面归章，新任务在所属章**末尾续号**。
3. **编号不复用、不重排**：条目不挪章不改号，删除条目才释放语义（编号本身不再分配给新任务）；任务完成时把 `[ ]` 改 `[x]` 并**移入 §十 已完成史**（在 §十 按完成顺序取 `10.x` 号，原章内号随之作废，跨文档引用同步改指 `10.x`）。
4. **状态只有四种**：`待办` / `阻塞(<编号或闸门号>)` / `在跑(<任务名>)` / `已否`。
5. **状态变更当场回填本档**——尤其 worktree 增删、分支收线、资产迁移之后。
6. 规格细节留在各自的规格档（内景结构 → 《建筑室内结构》§2/§4/§5.2；资产实态 → 《建筑资产清单》§四；玩法设计 → `03-聚落与建筑.md`）。本档管**做什么、谁等谁、什么状态**。

## 一、现状总纲

**范式（v2，一句话）**：玩家主要**选建筑预设**（设施内容/大小/材质打包绑定，可有材质版本预设），高度自定义走**自由建造**（8 格原子块 + 1 格步进，1 格 = 24px，不设上限、硬要设则 64）；功能 = **组织入驻为主**（门槛 = 建筑内对应设施数量，无跨建筑门槛）+ 玩家亲自使用为辅；**核心体验在室内**——缺氧式精密运转机器（设施布局/工作位/机构动线）。

**工程现状（一句话）**：HD-2D 图建筑宿主与 plan 物化已通（`10.1`/`10.2`），工位链有真宿主、靠露天铁砧兜底的时代已结束；仍悬空的玩法链 = 招兵（原生城市兵营零池）/ 仓库 / 生产 / 住房·市场，多等闸门 `8.14`（设施规格定稿）与 `8.15`（经济重做）。
